## 一、世界设定

**核心问题：** 敌人是怎么让你认不出他是敌人的？——篡改你的记忆。

**历史根基：** 尧舜时代，中国先民在四海设"四表"，走遍欧亚大陆。西陆蛮夷屠灭据点，窃取文明成果，将中国女医污为"女巫"。太史阁以编修《四库全书》为名焚毁上古记载。

**思想根基：** 毛泽东《矛盾论》《实践论》《论持久战》《星星之火，可以燎原》+ 马克思《共产党宣言》+ 周易哲学。

**空间劫持：** 中华先民地图原版上南下北，被西陆翻转为上北下南。杭州被翻了一个面变成"威尼斯"——城市被偷了地图之后重新画了一遍。

**时间实证：** 织女星使陨落前在泰西留下"守夜人"血脉——以半块玉佩为信物，等"身佩半玉、腕有星纹"之人。长女继承制，三千年近百代人，四十七人死于火刑。歌没断。

## 二、十二星君

十二银河神族——荧惑、岁星、太白、辰星、镇星、计都、神机、玄冥、天音、地隐、析木、织女——以全部神力化作十二道宫封印"虚噬"。失去神体，打散为凡人灵魂碎片，坠入人间。他们是中华文明"天人合一"的最初实践者。

**织女星使**（云岫）——星河编织者，教会先民养蚕缫丝。陨落于昧谷，留半块玉佩给守夜人。她将一道长诗分成十二缕，散落十二道宫。

## 三、故事总览

十九岁少年**辰生**在九州边陲落星村由药铺老人玄伯抚养。左手腕有青色星纹，颈挂半块玉佩。玄伯守了三十年秘密。

**序章核心事件（暴雨夜）：**
1. 辰生在废弃炭窑躲雨
2. 面罩女子明月被太史阁以"巫医罪"追捕，撞入炭窑
3. 追兵逼近——明月掏出另半块玉佩塞进辰生手里："拿着。快走。后山有路。"
4. 她攥着银针转身迎向追兵
5. 两块玉佩合一，星光涌入——辰生第一次见到母亲云岫的记忆："她叫明月。她的祖上，是我们的人。"
6. 次日，落星村老槐树燃烧，玄伯死于灰烬
7. 辰生从暗格找到四样遗物：**《星轨残卷》**、**玄伯遗书**、**荧惑钥匙**、**九天星晷**（背刻"彰往察来"）
8. 用油布包好遗物，踏上向北的山路。"躲是躲不掉的。他们怕我知道——那我就更要知道。"

## 四、各章详细节拍

### 第一章：星纪宫——矛盾的普遍性·真假之辨

| 项目 | 内容 |
|------|------|
| **星君** | 荧惑（锻锋）·火 |
| **守史者** | 焦烈（太史阁司火史） |
| **地点** | 梁州极北，冰火共存之地 |
| **同伴** | 锻锋（铁匠，被村民称为"火鬼"） |
| **卦象解锁** | 离卦上卦×4下卦=4种火卦 |
| **命盘解锁** | 父母宫（"我从哪里来"） |

**场景节拍：**
1. 辰生步行大半个月到极北。遇到锻锋——一个被村民孤立的年轻铁匠，双手能自燃，被叫"火鬼"
2. 太史阁焦烈带兵前来"收网"，使用的白焰"干净、冰冷、工业化"
3. 锻锋被白焰吞没时——火焰由暗红转金色。他挺直脊梁觉醒："回去报告商徵——荧惑之火没有被'净化'。它还在烧。"
4. 锻锋带辰生到星碑前，首次激活九天星晷——三层环自动旋转对齐
5. 辰生在祭坛深处第一次倒下→九天星晷将他拉回星碑刻星之刻→"被救者用了数千年在等待中保护施救者"
6. **关键词：** "真火不需要打败假火——真火只需要存在，假火就自己瓦解了。"

**情绪弧线：** 恐惧（孤身北上）→愤怒（锻锋被污名）→震撼（金焰觉醒）→第一次感受到"我不是一个人"

| 项目 | 内容 |

| **卦象解锁** | 巽+震上卦 |
| **命盘解锁** | 迁移宫（"走出去才知道真相"） |

**场景节拍：**
1. 森林是活的——树会移动，昨天的路今天消失。守史者林青黛用血浇灌建木维持封印，不知道自己维护的是一座监狱
2. 苏羽被太史阁《人体医学标准》诊断为"半盲"——但她不是看不清，是看得太远了。"远近在她眼里是同一个东西。"
3. 苏羽摘下遮眼布→光芒迸现→百兽归心→枯木逢春。她不是"不正常"——是"超出正常"。歪尺量人。
4. 林青黛发现太史阁骗了她三十年。苏羽："你的错误不是你的选择——是他们给你的选项本身就是错的。"
5. **明月暗线（4.5"巫医之罪"）：** 苏羽说："她（明月）被定的最后一条罪也是'巫医'。""被诊断为'瞎'的人，和被叫做'女巫'的人——同一套操作。"
6. **关键词：** "拿一把歪尺去量一个对的人，然后说这个人不对。"

**情绪弧线：** 迷失（树海迷宫）→愤怒（苏羽被"诊断"）→醒悟（歪尺量人）→寒意（明月的遭遇开始浮现）

### 第三章：娵訾宫——内因与外因·内外之辨

| 项目 | 内容 |
|------|------|
| **星君** | 地隐（石翁）·土 |
| **守史者** | 卫重（被西陆技术改造的司土史） |
| **地点** | 雍州西陲，丹霞山脉 |
| **同伴** | 石翁（被笑为"疯子的老炼丹师"） |
| **卦象解锁** | 坤+艮上卦 |
| **命盘解锁** | 田宅宫（"大地是你的根"） |

**场景节拍：**
1. 西陆洗劫此地——能偷的偷走，偷不走的毁掉，毁不掉的就用五毒阵毒化
2. 石翁炼了三十年丹，炸了三十年炉——但每次炸出的结晶是土行种子。他不是没天赋，是天赋太强压不住了
3. 卫重的右臂镶嵌西陆金属装置——仿品永远只是仿品
4. 石翁不用"解毒教材"——被篡改的书上方法只会越解越深。他用最笨的办法：一味一味地尝毒土。"苦参加三钱，甘草减两钱。"嘴唇发紫、手指溃烂中找到了解方
5. **关键词：** "外因是条件，内因是根据。他们毒不了大地本身。"

**情绪弧线：** 荒凉（毒化大地）→好笑→敬佩（石翁的笨办法）→庄严（"鸡蛋变鸡子，石头变不了"）

| 项目 | 内容 |
|------|------|

| **地点** | 豫州，天机城 |
| **同伴** | 鲁班语（被逐出师门的机关师） |
| **卦象解锁** | 坎上卦（最后一个上卦，64卦菜单完整） |
| **命盘解锁** | 财帛宫（"辨别真假价值"） |

**场景节拍：**
1. 天机城的"史观推演机"运转数百年，输出被当"天意"——但输入数据被篡改过
2. 鲁班语没用工具拆机器——她蹲在机器下听了三天三夜。"第四对齿轮的旋转方向是反的。"
3. **坐标旋转第一次揭示：** 一对坐标齿轮被翻转180度——上南下北（原版）→上北下南（篡改版）。输入方向反了，当然"算不准"

5. **关键词：** "输入错了，方向反了，输出永远错。"

**情绪弧线：** 困惑（机器运转完美但输出全错）→毛骨悚然（发现坐标系被翻转）→振奋（"齿轮被人扳回来了"）

**场景节拍：**

2. 虚噬之力腐蚀这些记忆——被碰过的画面变成灰色噪点，再也无法还原
3. 冥婆在石桥上烧了几百年的火，忍受寒冷和恐惧——但从来没走。因为"走了，冥河就再也没有人守了"

**情绪弧线：** 阴冷（冥河古道）→恐惧（虚噬抹除记忆）→温暖（冥婆烧火）→庄严（"衰老是劳动的勋章"）

| **卦象解锁** | 太乙神数Lv3（9键终极序列） |

**场景节拍：**

2. 阮心在羽音石柱的残响中——听到被翻转的空间常数。天音用五音记录了九州地理方位，西陆连空间编码也翻转了
3. **坐标旋转第二次揭示：** 音乐频率=空间坐标。音阶差导致的"不和谐"——不是因为五音不够，是因为坐标系被旋转了

**情绪弧线：** 凄美（被污染的旋律）→发现（空间常数=音乐编码）→顿悟（"人也一样"）→温柔而坚定（百鸟来朝）

**场景节拍：**
1. 太史阁"标准星图"把星位微调了几度。玄微子以真南北线为轴将假星图旋转180度——所有对不上的卦全部对上了
2. **坐标旋转核心揭示：** 不是微调——是整个空间坐标系被翻了一面。上北下南不是原版。原版是上南下北
3. 玄微子的手指抖了三十年——不是因为算错了，是因为不愿意按颠倒的方向去算。"你按颠倒的坐标系去算——卦是永远不灵的。"
4. 玄微子看辰生的命盘："你的星盘和云岫的一样。但你的命宫不在织女——在辰星。你是道士。你一直是。"
5. **关键词：** "彰往而察来——知道从哪里来，才能知道往哪里去。"

**情绪弧线：** 悬疑（星图为什么总对不上）→毛骨悚然（坐标系被翻转）→庄严（"你是道士"）→命盘点亮（"终于知道我是谁了"）

### 幕间·汇合——三千年的信物

辰生在所有同伴面前完整讲述明月的故事。三千年守夜人、四十七次火刑、一根被烤弯又磨直的银针、一张监狱纸条上倒着写的字。历代守夜人的牺牲与坚持被全面揭示。暗线从隐到显。十七座城市的坐标翻转密函证据被拿出。两条暗线——时间（明月）和空间（坐标旋转）——在此交汇。

### 第十二章：寿星宫——人民创造历史

| 项目 | 内容 |
|------|------|
| **BOSS** | 商徵（太史阁主，寿命200+年） |
| **终极BOSS** | 西陆国师（十二星君盗版缝合体） |
| **地点** | 悬浮于苍穹之上的倒悬宫殿 |
| **命盘解锁** | 兄弟宫（十二命宫全部同时激活） |

**场景节拍：**
1. 寿星宫悬浮在苍穹之上——整座宫殿重力方向是反向的。商徵坐在云岫的脊骨做成的椅子上
2. "我见过你母亲醒着的样子。"商徵的第一句话。辰生没有说话——云岫的脊骨在椅子下微微发抖
3. 商徵的手段叫"时间删除"——把你挥出的每一剑从时间线上抹去。攻击不在时间轴上→无法造成伤害
4. 但十二缕长诗在十二位同伴手中同时吟诵。攻击可以从时间中删除——**意义不能。** 诗不是攻击，是记录。记录不在时间轴上。记录比时间更老
5. 商徵在星光中看到200年前那个年轻的自己——坐在星空下捧读《史记》、眼中充满对真理的热爱的自己。那个在师父面前立誓"实事求是，为往圣继绝学"的人
6. 他跳入自己守了300年的化史炉。炉子在一个人压下来时——熄灭了
7. **终战：** 西陆国师带着十二星君盗版缝合体降临。仿品遇到真品，不需要被打败——只需要被认出。十二道真星力同时绽放，仿品体系崩溃
8. **关键词：** "仿品遇到了真品，不需要被打败——只需要被认出。"

**情绪弧线：** 愤怒（云岫被镇压在椅子下）→绝望（剑被从时间中删除）→团结（十二人同吟长诗）→复杂（商徵跳炉）→胜利（仿品崩溃）

## 五、终章——彰往而察来

1. 云岫化作新的织女星永久悬于夜空。十二星君化作十二颗亮星环绕——不是来统治，是来照亮
2. 太史阁改组为"修史馆"。被烧三百年的古籍碎片由年轻人一片片拼回去
3. 辰生成为行走的说书人。左手腕系着从北境监狱门口枯树上解下的红线——明月最后的痕迹
4. 回到落星村。老槐树根还在，树冠抽了新芽。在药铺原址种了银杏——能活几千年
5. 继续往西走——昧谷的废墟里还有人在等。有些孩子的祖先被叫做"女巫"——他欠她们一篇没讲完的说书

**最后一句：** "四表之内，皆为兄弟。约定——至今有效。"

**觉醒的目的从来不是复仇。是当家做主。** 破除黑暗不是为了控诉——是为了让阳光照进来。
