## 文档写作标准

所有.md文件必须遵循 `Obsidian写作规范-底层逻辑.md`。摘要：

- **frontmatter必填：** category / status / phase / tags / updated
- **标签从标签库选取：** 禁止纯数字、色值、未定义标签
- **Wikilink优先短名：** 同文件夹用文件名·跨文件夹用相对路径
- **命名：** 中文+连字符·不用空格/下划线
- **修改后：** 运行 `python _audit.py` → 必须零问题

## 审计工具

```bash
python _audit.py        # 全项目自动审计（必须零问题）
python _audit.py --json # JSON输出（供CI消费）
python _obsidian_scan.py # Obsidian标签/wikilink健康扫描
```

审计检查项：
- WuXing枚举是否在非权威文档中重定义
- 废弃货币（灵砂/金锭/银两）是否在活跃GDD中残留
- 物价系数/BOSS掉落是否与_shared_data.json一致
- Wikilink是否有断链
- TODO/待定标记是否遗留
- C#代码块花括号是否平衡
