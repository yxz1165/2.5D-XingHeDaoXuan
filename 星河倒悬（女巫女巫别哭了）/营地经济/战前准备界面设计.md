# 战前准备界面设计 —— 类似原神深渊/星铁忘却之庭的选配阶段

> **核心体验：** 站在BOSS门前，5套预先配好的Build一字排开。看一眼BOSS信息，选一套，调整细节，确认——踏入战场。
> **参考：** 原神·深境螺旋选队 / 星穹铁道·忘却之庭编队 / 怪猎·任务板选装备

---

## 一、触发场景

| 场景 | 触发方式 | 界面类型 |
|------|---------|---------|
| BOSS房门前的星碑 | 按F→选"备战" | 完整备战界面 |
| 道宫入口 | 首次进入道宫·自动弹出 | 简易备战（仅选法器+同伴） |
| 剧情强制战 | 剧情走到开战点·自动弹出 | 快速备战（仅确认当前配置） |
| 日常刷材料 | 在任意星碑处 | 完整备战界面 |

## 三、五个Build槽的卡片内容

每张卡片显示最关键的信息——一眼就能判断"这套适不适合这个BOSS"：

```
┌──────────────┐
│ 🔥 焦烈速杀   │  ← Build名称（玩家自命名）
│              │
│ ⚔️ 桃木剑     │  ← 主法器（图标+名字）
│ 🪞 八卦镜     │  ← 副手法器
│              │
│ 离☲ + 乾☰    │  ← 核心卦术（上卦+下卦·玩家一眼知道输出类型）
│              │
│ 👥 锻锋 苏羽  │  ← 出战同伴（头像+名字）
│              │
│ 📋 XH-v3K7-..│  ← 卦码（可选显示·点击复制）
└──────────────┘
```

**卡片的交互：**
- 鼠标悬停 → 卡片放大 + 显示更多细节（铭刻·命盘概要）
- 点击选中 → 高亮边框 + 下方展开符箓/丹药面板
- 右键 → 弹出菜单：编辑 / 重命名 / 删除 / 复制卦码

## 五、操作流程（从进场到开战）

```
1. 玩家走到星碑前 → 按F
   
2. 星碑菜单弹出：
   [休息] [摇卦] [备战] [锻造] [卦码]
                   ↓
3. 点"备战" → 进入备战界面

4. 左侧显示BOSS信息（首次挑战时显示"???"·击败一次后显示完整信息）
   右侧显示5个Build槽

5. 玩家选择一个Build → 卡片高亮 → 下方展开细节

6. （可选）在此界面调整符箓/丹药 → 右键卡片编辑

7. （可选）点"摇卦问卜" → 6次甩鼠标 → 获得启示Buff
   → 如果已经摇过 → 显示当前启示·可重摇

8. 确认 → 点"进入战斗"
   → 过场动画 → BOSS登场 → 开打
```

## 六、与三钱摇卦的衔接

备战界面右下角的"摇卦问卜"按钮：

```
┌──────────────────┐
│ 🔮 摇卦问卜       │
│                  │
│ 如果还没摇卦：    │
│   点击 → 进入摇卦流程（6次甩鼠标）             │
│   → 获得启示Buff → 回到备战界面               │
│                  │
│ 如果已经摇过：    │
│   显示当前启示：   │
│   本卦䷝离为火     │
│   变卦䷷火山旅     │
│   → 火卦伤害+15%  │
│     变爻四爻·同伴增益翻倍                     │
│   [重摇·消耗20卦气]                           │
└──────────────────┘
```

**设计意图：** 摇卦 = 战前"占卜这次能不能赢"。是仪式感，也是策略——摇的卦可能提示你用不同的Build。
