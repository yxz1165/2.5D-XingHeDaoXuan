# 落星村——营地重建系统

> **定位：** 游戏的中心枢纽。序章后被烧成废墟，随主线推进逐步重建。不只是"回血的地方"——是辰生的"家"、同伴的居所、锻造炼丹的工坊、剧情推进的枢纽。
> **参照：** 《哈迪斯》的冥府大厅（每次回来同伴对话有更新） + 《星露谷物语》的农场建设（解锁新建筑有成就感） + 《火焰纹章：风花雪月》的修道院（同伴在固定位置·可对话）
> **关联：** [[世界地图与区域解锁设计]] | [[道宫副本进入机制设计]]

---

## 一、情感定位

```
落星村不只是功能中心——它是辰生唯一的"家"。

序章结尾·辰生从炭窑爬出来·看到老槐树在燃烧·药铺化为灰烬。
那一刻他失去了一切。

重建落星村的过程 = 辰生把"家"从废墟中重新建起来的过程。
每过一座道宫 = 一个同伴回归 = 一座建筑重建 = 一个村民归来。
到最终章·落星村从灰烬中重生·辰生站在老槐树下·看着村中灯火。
```

---

## 二、落星村的三个状态

### 状态一：废墟（序章结尾→星纪宫前）

```
落星村在序章雨夜事件后被太史阁烧毁：
  - 老槐树 → 烧焦的树干（但根部有微弱的新芽·暗示不死）
  - 药铺 → 灰烬+几根烧黑的房梁
  - 村民房屋 → 废墟·无NPC
  - 村口 → 太史阁告示牌被烧了一半
  - 辰生房间 → 还在·但里面的东西都没了

此时唯一的星碑在村中央（老槐树旁）·是辰生唯一的营地。
```

### 状态二：重建中（星纪宫通关→寿星宫前）

```
每通关一座道宫·回村落星村·触发重建事件：
  - NPC回归事件（村民/同伴）
  - 建筑重建动画（俯视角·工匠NPC+材料堆积→建筑拔地而起·约3秒）
  - 新功能解锁
```

### 状态三：重生（寿星宫通关·终章）

```
落星村完全重建：
  - 12座建筑·灯火通明
  - 老槐树根部的新芽长成了新枝
  - 12位同伴各居其所
  - 村民在村中生活·有日夜循环
  - 村口立着石碑·刻着"落星村"和重建年份
```

## 四、建筑功能详解

### 4.1 药铺（第1个重建·星纪宫后）

```
位置：原药铺原址（老槐树东侧）
重建者：锻锋（用真火重新烧制了药铺的瓦片）

功能：
  炼丹台 → 消耗材料合成丹药
    - 回血丹（霜叶草×2）
    - 卦气丹（冰晶矿×1 + 冻土灵菇×1）
    - 火抗丹（炎石×1 + 霜叶草×1）
    - …约15种丹药配方·随着进度解锁

  药材田 → 种植草药（种下→回村时已长成·约现实时间30分钟）
    - 3个种植槽（初始）→ 6个（完成药铺升级支线）

  药柜 → 查看已收集的丹药配方·已发现的药材图鉴
```

### 4.2 卦堂（第2个·玄枵宫后）

```
位置：老槐树正对面
重建者：苏羽（用风卦清理了废墟·用岁星之力让老槐树抽了新芽）

功能：
  命盘台 → 查看紫微斗数命盘·查看四化流转当前状态
  
  摇卦室 → 三钱摇卦（与星碑摇卦功能相同·但在"家"里摇卦有特殊对话）
    辰生："在自己家里摇卦……和在野外不一样。"
    苏羽（如果在卦堂）："卦象更安静了。"
  
  卦象研究墙 → 已解锁的64卦以木牌挂在墙上
    - 每解锁一个新卦→苏羽给你讲关于这个卦的故事（1-2分钟·世界观补充）
    - 所有卦解锁后→墙上64块木牌围成完整的八卦图
```

### 4.3 冶炼坊（第3个·娵訾宫后）

```
位置：村北·靠近后山
重建者：石翁（用五色土重建了冶炼炉·炉温比普通炉高3倍）

功能：
  锻造台 → 法器的锻造与铭刻
    详见 [[法器锻造与进阶系统GDD]]
  
  矿石仓库 → 存放矿石·满仓触发"矿脉发现"支线（解锁新矿石种类）
  
  熔炉 → 熔炼低品质矿石为高品质
    3个低级矿石 → 1个中级矿石
    3个中级矿石 → 1个高级矿石
```

### 4.4 剑庐（第4个·降娄宫后）

```
位置：冶炼坊旁边·靠山壁
重建者：顾锋（花了一天一夜·用手指在石壁上刻出了剑庐的剑痕纹路）

功能：
  剑架 → 展示当前拥有的法器（银针/桃木剑/铜钱剑/七星剑挂在墙上）
    切法器在剑庐内有特殊动画（不是瞬间切换·是从剑架上取下）
  
  磨剑石 → 法器进阶（提升法器基础属性·需要材料+铜钱）
  
  试剑石 → 测试法器伤害（对着石头砍·显示DPS数字·不消耗卦气）
    辰生可以在试剑石前练习连携·有DPS统计面板
```

### 4.5-4.12 其余建筑功能概述

| 建筑 | 核心功能 |
|------|------|
| **机关工坊** | 制作可放置的陷阱(副本中一次性使用)·购买阵法图纸 |
| **点将台** | 训练同伴(提升同伴等级上限)·每日悬赏任务(铜钱+材料) |
| **暗阁** | 情报交易(揭示隐藏地点)·特殊商品·暗杀委托 |
| **渡魂堂** | 合成特殊丹药(如"假死丹"·无敌3秒)·生命/死亡相关支线 |
| **星象台** | 星图拼图小游戏·太乙神数练习模式(不消耗卦气·有排行榜) |
| **乐坊** | 收集音乐·提升同伴好感(弹琴给同伴听)·解锁五音相关技能 |
| **村民宅院** | 村民回归后随机触发日常委托·给村民帮忙有奖励 |
| **云岫纪念祠** | 终章触发·看12缕长诗完整版·选择结局分支 |

### 5.3 同伴对话更新

每次回村，同伴可能有新的对话（取决于主线进度、好感度、触发过的事件）：

```
首次对话（加入时）：介绍自己·认识辰生
通关相关道宫后："下一座道宫……你准备好了吗？"
触发特殊事件后：如锻锋在焦烈战后对白焰的反思
好感度升级时：分享个人故事
收集品发现时：对收集品的反应
终章前夕：对最终战的感受
```

## 七、村落日夜与天气

### 7.1 时间系统

```
村内时间流动（仅落星村·野外时间独立）：
  - 白天/傍晚/夜晚 三时段循环
  - 每时段约现实时间10分钟
  - 同伴位置和对话随时段变化
  - 某些事件只在特定时段触发（如影只在夜晚可见）
  - 可以在老槐树下"休息到次日"来切换时段
```

### 7.2 天气

```
村内天气随机（不影响功能·纯氛围）：
  - 晴天（最常见）
  - 阴天
  - 小雨（村民在檐下避雨·有特殊对话）
  - 大雨（罕见·与序章雨夜事件呼应）
  - 雪（终章前夕·老槐树覆雪）
```
