## 二、P0——可立即整合到现有系统

### 2.1 内丹修炼系统（对应百科：道教内丹）

**当前状态：** 卦气只是一个"法力值"
**深化方案：** 卦气四层修炼

```
炼精化炁（Lv1-3）  → 卦气上限100，标准恢复
炼炁化神（Lv4-6）  → 卦气上限150，战斗中恢复+50%
炼神还虚（Lv7-9）  → 卦气上限200，太乙神数可用卦气替代冷却
炼虚合道（Lv10）   → 卦气无限（终章特殊状态）
```

**解锁方式：** 每过3个道宫突破一层。突破需要"丹劫"——一场特殊的内丹Boss战（心魔/幻境）。

### 2.2 人体经络技能树（对应百科：中医经络）

**当前状态：** 紫微命盘是被动天赋
**深化方案：** 将天赋树改为"经络图"

```
任脉（前正中线）→ 卦气相关天赋
督脉（后正中线）→ 伤害/爆发天赋
冲脉 → 暴击/会心天赋
带脉 → 防御/护盾天赋
阴跷·阳跷 → 闪避/移速天赋
阴维·阳维 → 元素抗性天赋
```

**操作：** 打开经络图→消耗"真气点数"点穴→不同经脉上的穴位给予不同属性的被动加成。视觉上是人体经络图——比传统天赋树辨识度高得多。

### 2.3 二十四节气动态世界（对应百科：二十四节气）

**当前状态：** 无时间系统
**深化方案：** 游戏内时间按节气流转

| 节气 | 世界变化 | 游戏影响 |
|------|---------|---------|
| 立春·春分·清明·谷雨 | 万物复苏 | 木/风属性卦术伤害+15% |
| 立夏·小满·芒种·夏至·小暑·大暑 | 炎炎夏日 | 火属性卦术伤害+20%，冰系敌人弱化 |
| 立秋·处暑·白露·秋分·寒露·霜降 | 秋高气爽 | 金属性暴击率+10%，草药采集翻倍 |
| 立冬·小雪·大雪·冬至·小寒·大寒 | 冰天雪地 | 水属性控制时长+30%，火系消耗+20% |

**实现：** 每次在星碑处休息→时间推进→节气变化。特定BOSS在特定节气有不同行为模式。

### 2.4 五音十二律音律系统（对应百科：五声音阶·十二律）

**当前状态：** 天音乐师（阮心）只是NPC
**深化方案：** 五音=五种战场Buff

| 五音 | 法器操作 | Buff效果 |
|------|---------|---------|
| 宫 do（土） | ↑↑ | 全队防御+20%（45s） |
| 商 re（金） | →→ | 全队暴击+15%（45s） |
| 角 mi（木） | ←← | 全队移速+25%（45s） |
| 徵 sol（火） | ↓↓ | 全队攻击+20%（45s） |
| 羽 la（水） | ↓↑ | 全队卦气恢复+50%（45s） |

**操作：** 阮心作为同伴时，1键（集火）改为五音Buff循环选择，双击释放。十二律可做成音律收集系统——在不同道宫发现失传音律。

## 三、P1——新增游戏系统

### 3.1 符箓系统（对应百科：道教符箓派）

**定位：** 一次性强力消耗品——"写好的卦术"

```
玩家在非战斗时 → 打开符箓界面 → 选择卦象写入符纸 → 消耗卦气+符纸材料
战斗中使用 → 按特定键位释放 → 零卦气消耗、零冷却、瞬发

符纸等级：
  黄符（基础）：写1卦  → 消耗1张黄符纸+卦气20
  青符（进阶）：写2卦连携 → 消耗1张青符纸+卦气50
  金符（稀有）：写奇门阵法 → 消耗1张金符纸+卦气80
```

**材料来源：** 朱砂（采矿）、黄纸（商店/掉落）、桃木炭（桃木剑专属技能副产品）。

**与法器系统的关系：** 桃木剑的"虚空画符"是实时画符，符箓系统是提前写好——两种画符方式互补。

### 3.2 炼丹系统（对应百科：道教外丹·中医方剂）

**定位：** 战斗消耗品制作

| 丹型 | 效果 | 材料 |
|------|------|------|
| 回气丹 | 回复30卦气 | 朱砂+灵芝 |
| 续命丹 | 回复40%生命 | 人参+当归 |
| 火抗丹 | 火伤-30%（60s） | 寒水石+冰片 |
| 破封丹 | 解除封印/定身 | 麝香+冰片 |
| 爆气丹 | 15秒卦气无限（副作用：结束后卦气归零30秒） | 丹砂+硫磺+雄黄 |

**炼丹机制：** 收集药材→选择丹方→放入炼丹炉→"火候"小游戏（太乙神数简化版：按键控制火候大小→不炸炉就成功）

**与哲学映射的关系：** 炼丹在娵訾宫（内因与外因）解锁——内丹（自身修炼）vs 外丹（药物辅助）= 内因vs外因的玩法表达。

### 3.3 二十八宿小关卡（对应百科：二十八宿）

**定位：** 每座道宫内部的2-3个小型星宿关卡

```
星纪宫（荧惑·火）：
  ├── 斗宿·斗木獬 —— 冰原深处的古战场（精英：冰封獬豸）
  ├── 牛宿·牛金牛 —— 冻湖下的青铜遗迹（解锁：金牛之力=防御+10%）
  └── 女宿·女土蝠 —— 极夜洞穴中的回声（BOSS条件触发：特定卦象顺序打开暗门）

玄枵宫（岁星·木）：
  ├── 虚宿·虚日鼠 —— ...
  ├── 危宿·危月燕 —— ...
  └── 室宿·室火猪 —— ...
```

**每个星宿小关卡：** 15-20分钟游戏时间、1个小BOSS或谜题、1个永久属性奖励（类似塞尔达神庙）。

### 3.4 藏象战斗状态系统（对应百科：中医藏象·五脏五志）

**定位：** 辰生的战斗状态受"五志"影响

```
喜（心·火）→ 卦术施放速度+20%，但防御-15%
怒（肝·木）→ 普攻伤害+30%，但卦气消耗+25%
忧（肺·金）→ 闪避无敌帧+5，但移速-20%
思（脾·土）→ 卦气恢复+50%，但受到攻击硬直+10帧
恐（肾·水）→ 受到致命伤害时自动触发空亡（隐身1s），冷却180s
```

**触发方式：** 战斗中特定事件触发（同伴倒地→怒，连续受击→恐，顺利连击→喜），或在星碑处选择"调神"切换。

### 3.5 道教斋醮科仪系统（对应百科：道教·斋醮科仪）

**定位：** 大型仪式=道宫Boss战前的准备环节

```
在进入BOSS房间前 → 布置"斋坛"
选择科仪类型：
  罗天大醮（全面）—— BOSS全属性-5%+全队+8%
  火醮（火卦）—— 火卦伤害×1.5，但其他卦-20%
  水醮（水卦）—— 水卦控制时间×2
  度亡醮—— BOSS的召唤物自动削弱50%
  祈晴/祈雨—— 改变BOSS战场天气
```

**消耗：** 卦气+材料（香、烛、符纸）+时间（布置仪式本身是叙事演出）。

### 6.2 谶纬预言（对应百科：谶纬·推背图·烧饼歌）

```
每个道宫藏1-2条预言（卦辞形式）
玩家收集 → 在梅花易数观象模式下解读

```

