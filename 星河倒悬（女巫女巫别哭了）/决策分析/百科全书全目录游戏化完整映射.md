## 第一典 · 历代文化沿革典

### 一、中华文化起源

| 百科条目 | → 游戏化 | 优先级 |
|---------|---------|--------|
| **盘古开天辟地** | 世界起源神话：星君降临人间的"开天"=十二星君用星辰之力劈开虚噬的混沌 | P1 |
| **女娲抟土造人/炼石补天** | 上一次虚噬入侵时，织女星君（云岫）用生命"补天"（封印虚噬裂缝） | P0 |
| **伏羲画八卦** | 第一位辰星卦师——发现星君力量可编码为八卦。序章中玄伯遗物记载此事 | P0 |
| **神农尝百草** | 地隐星君（石翁）的前世——尝百草=建立中药材体系→娵訾宫的解锁叙事 | P1 |
| **仓颉造字** | 太史阁"化史"的对立面——仓颉是第一个拒绝篡改真相的人，他的字被太史阁销毁了 | P2 |
| **大禹治水** | 大洪水=虚噬入侵后的世界性灾难，九鼎=九座封印虚噬的祭坛。实沉宫的叙事背景 | P1 |

| **嫦娥奔月** | 月亮=织女星君的领域。云岫（织女）的故事线 | P0 |
| **精卫填海** | 析木星君陨落后的碎片——仍在试图修复星辰秩序 | P2 |
| **夸父逐日** | 镇星星君上一世试图用蛮力驱散虚噬——力竭而死 | P2 |
| **共工怒触不周山** | 不周山=天柱=连接人界与星界的通道。被太史阁炸毁以阻断星君力量传承 | P2 |
| **愚公移山** | 实沉宫"持久战·群众路线"的寓言化表达 | P2 |

| **三皇五帝** | "三皇"=最早的三位星君，"五帝"=五德终始的五行星君 | P3 |

| **焚书坑儒** | 太史阁的前身——第一次大规模销毁星君相关文献 | P0 |

| **司马迁《史记》** | 司马迁是太史阁中的"叛徒"——他在正史中偷偷留下了星君真相的线索 | P2 |
| **张骞凿空西域（丝路开通）** | 丝路=西陆（海溟国）第一次大规模接触东方→最终演变为入侵 | P1 |

| **佛教东传入洛阳白马寺** | 外来宗教→与西陆的入侵有隐约关联（"海溟国也信某种宗教"） | P2 |
| **张衡浑天仪·地动仪** | 机关术的早期成就→神机星君（鲁班语）的机械风格参考 | P1 |
| **《伤寒杂病论》（张仲景）** | 中医在游戏中的理论基础→娵訾宫的草药系统 | P1 |
