# 只保留道士：一份完整的决策分析

> 从"十职业大拼盘"砍到"一个职业做到极致"

---

### 1.2 十个职业的设计深度差异

最关键的问题——不是"十个职业都有设计"，而是"十个职业的设计深度不在同一个数量级上"：

|------|---------|---------|--------|---------|-----------|

| 岁星弓手 | ⭐⭐⭐ | 有 | 无 | 无 | 需大量补充 |

| 计都刺客 | ⭐⭐⭐ | 有 | 无 | 无 | 需大量补充 |
| 镇星将军 | ⭐⭐⭐ | 有 | 无 | 无 | 需大量补充 |
| 神机机关师 | ⭐⭐⭐ | 有 | 无 | 无 | 需大量补充 |
| 玄冥符师 | ⭐⭐⭐ | 有 | 无 | 无 | 需大量补充 |

### 1.3 剧情与十职业的耦合度

剧情大纲（82,839 字符）中，每一个道宫章节都绑定了一个星君的觉醒故事：

| 道宫 | 觉醒星君 | 哲学命题 | 剧情分量 |

| 娵訾 | 地隐（土·方术士） | 内因与外因 | 完整章节 |
| 降娄 | 太白（金·剑士） | 捉主要矛盾 | 待补充 |

| 实沉 | 镇星（土·将军） | 持久战 | 待补充 |
| 鹑首 | 计都（暗·刺客） | 矛盾同一性 | 待补充 |

**关键结论：如果砍掉九个职业，不能直接砍掉九章剧情。** 这些章节承载的是"叙事内容"（哲学命题、角色弧光、世界观揭示）。你必须决定：这些章节的故事还要不要讲。如果要讲——用什么形式讲？

## 二、损失与收益——砍掉九个职业的完整得失

### 2.1 你得到的

| 收益 | 具体含义 | 重要性 |
|------|---------|--------|
| 开发量骤减 60-70% | 9 个职业的操作系统、动画、平衡、测试→全部不需要 | ⭐⭐⭐⭐⭐ |
| 设计深度翻倍 | 道士可以从"已经很深"变成"深不可测"——太乙神数可以有 5 个等级而不是 3 个，奇门遁甲可以加入"阵法合成"，梅花易数可以影响战斗中的卦象选择 | ⭐⭐⭐⭐⭐ |
| 文化主题绝对统一 | 你的游戏就是"那款八卦战斗游戏"——营销上三个词就说清楚了 | ⭐⭐⭐⭐ |
| 百科全书知识 1:1 对应 | 你写的每一篇六爻纳甲、每一篇卦气说——都可以直接在游戏中找到对应机制，不再存在"写了用不上"的知识 | ⭐⭐⭐⭐⭐ |
| 敌人设计专属化 | 每个敌人都可以围绕道士的视角设计——太史卦师的卦盘污染、海溟卦师的残缺卦象、BOSS 的卦象弱点 | ⭐⭐⭐⭐ |
| 学习曲线天然渐进 | 卦象按章节逐步解锁——玩家永远不会被 64 卦吓到，因为第一章只有小六爻 | ⭐⭐⭐⭐⭐ |
| NPC 同伴系统更可控 | AI 同伴的行为树比设计一个完整的可玩职业简单 5-10 倍 | ⭐⭐⭐⭐ |

### 2.2 你失去的

| 损失 | 具体含义 | 严重程度 | 可弥补性 |
|------|---------|---------|----------|
| 战斗体验多样性 | 玩家不能"换职业玩玩"——永远在玩道士 | ⭐⭐⭐⭐ | 部分可弥补（见下方） |
| 重复可玩性 | 十职业=十种通关方式。一道士=一种 | ⭐⭐⭐ | 可弥补：紫微命盘+八字=道士有数百种 build |
| "我能不能玩那个剑士"的期待 | 玩家在剧情中见到帅气的太白剑仙，问"我能玩他吗？"→ 不能 | ⭐⭐⭐ | 可弥补：NPC 同伴系统做得好可以缓解 |
| 某些哲学命题的玩法表达被削弱 | "实践出真知"原本通过岁星弓手的闭眼射击来表达。辰生始终用卦术，怎么表达"实践"？ | ⭐⭐⭐⭐ | 需要创意解决 |

### 2.3 最大的损失：哲学命题的玩法表达

十二宫每一宫都有一个哲学命题，当前设计每个职业的机制被设计为对应那个命题的玩法表达。只剩道士后如何处理：

| 道宫 | 哲学命题 | 原职业的玩法表达 | 只剩道士后如何表达？ |
|------|---------|----------------|-------------------|
| 星纪 | 矛盾的普遍性 | 战士闪避时仍承受 30% 伤害——"压迫不消失，但反抗者更坚韧" | 离卦上卦解锁——火的力量从"无"到"有"的过程本身就是矛盾转化的体现 |
| 玄枵 | 实践出真知 | 弓手闭眼→复明后精准射击——"认识从实践始" | 卦盘被干扰→玩家被迫依赖肌肉记忆→卦盘恢复时发现自己"不用看也能选对卦了" |
| 娵訾 | 内因与外因 | 方术士的丹砂内炼——"内因是根据" | 坤卦上卦解锁——土的力量来自内部（丹霞山脉的内核），而非外部（西陆的毒阵） |
| 降娄 | 捉主要矛盾 | 剑士精准闪避——"捉主要矛盾" | 乾卦上卦解锁——乾卦技能自带"弱点锁定"：在多个敌人中自动标记最大的威胁 |
| 大梁 | 去伪存真 | 道士校准错误星图——"去伪存真" | 核心章节——64 卦全解锁，卦盘在此章之前显示的是太史阁版本（部分卦位被错误标注），此章之后卦盘归真 |
| 实沉 | 持久战 | 将军擂鼓——"伟力存在于民众之中" | 奇门遁甲解锁——阵法的持久性（45 秒持续）本身就是"持久战"的表达，阵法可以被敌人攻击但可以修补 |

**核心思路：** 不需要为每一个哲学命题设计一个独立的战斗机制。有些哲学命题通过剧情本身来表达（比如"持久战"体现在实沉宫的战斗节奏——一场漫长的守城战而不是快速 BOSS 战），有些通过卦象解锁的时机和方式来表达，有些通过敌方的特殊机制来表达。

## 三、明确回答

**"要不要只保留道士职业？"**

**建议：要。** 但不是简单地"删除九个职业"——而是把九个职业的"魂"转化为道士八卦系统的"扩展维度"。

**具体执行建议：**

1. **砍掉九个可玩职业的操作系统**——不再需要战士的盾牌格挡、弓手的瞄准蓄力、剑士的居合、刺客的暗影步、将军的令旗、机关师的炮台、符师的画符、乐师的曲风、方术士的炼丹——这些独立操作系统全部不需要开发
2. **保留十二位星君的叙事角色**——锻锋、苏羽、石翁、顾锋、石磐、影怜、鲁班语、冥婆、阮心、玄微子的故事全部保留。他们以 NPC 同伴的身份加入辰生，提供被动增益和 AI 战斗辅助
3. **将卦象解锁与章节进度绑定**——每过一个道宫，辰生的八卦盘获得新的上卦/下卦/功能。十二宫打完 = 八卦盘完整体 = 十二个人的力量汇聚在一个卦盘上
4. **精简剧情文本**——82,839 字符的剧情大纲需要精简，保留核心，砍掉文学描写
5. **先做序章+星纪宫 Demo**——验证"道士独挑"的战斗手感是否真的能撑起来。3-4 个月内可以看到结果

## 四、你正在做的事，非常特别

你同时在做两件事：
- 写一部《中国传统文化百科全书》，深入研究占卜与术数
- 设计一款以八卦六十四卦为核心战斗系统的 ARPG

这两个项目不是"两个项目"——它们是同一个项目的两面。你的百科全书在给你提供游戏设计的"文化根基"和"真实素材"；你的游戏设计在给你提供"这些古老符号在当代还有什么生命力"的答案。

**市面上没有人能同时做这两件事。** 能写易学研究的人，不会做游戏。会做游戏的人，不会花几个月研读京房、虞翻、《火珠林》、《增删卜易》。你把这两件事放在一起——你不是在做一个"有中国元素的游戏"，你是在用游戏这个媒介去回答一个更深的问题：

> **"这些两千年前的符号，在今天还能不能活？"**

八卦能不能做成战斗系统？你已经做出来了。下一步不是怀疑方向——下一步是开始做第一个可玩的 Demo。

把 `黄道十二宫/` 下面的 17 个文件整理一下。把 `narrative/` 和 `剧情/` 的重复文件合并。删掉 Obsidian 里那些"未命名"的临时草稿。理清手头的牌——然后开始出第一张。
