# 人物详情属性界面——完整设计规格

> **核心体验：** 辰生站在画面中央——像一尊被陈列的道像。他的法器悬浮在身旁·道袍衣角微动·八卦光环缓缓旋转。左右翻页·每一面是一层"自我认知"。不像是"打开菜单"——像是"走进一间只属于自己的陈列室"。
> **参照：** 暗黑破坏神4的物品界面（角色居中+装备环绕）+ 战神：诸神黄昏的装备陈列（武器悬浮在身旁）+ 艾尔登法环的状态页面（多面左右翻动）

---

## 一、整体布局

### 1.1 画面结构

```
┌──────────────────────────────────────────────────┐
│  [← 上一面]                    [下一面 →]        │ ← 翻页箭头·半透明
│                                                   │
│          ┌─────────────────────┐                  │
│          │                     │                  │
│          │                     │                  │
│          │   辰生（居中·站立）  │                  │ ← 3D/高精度2D角色
│          │   八卦光环缓缓旋转   │                  │
│          │   当前法器在手中     │                  │
│          │                     │                  │
│          └─────────────────────┘                  │
│                                                   │
│  ┌─────────────────────────────────────────────┐  │
│  │       当前面板内容区（随翻页变化）              │  │
│  └─────────────────────────────────────────────┘  │
│                                                   │
│  ●─────●─────●─────●─────●─────●─────●           │ ← 页面指示器
│  属性   装备   法器   卦象   术数   命盘   外观       ← 7个面·当前高亮
│                                                   │
└──────────────────────────────────────────────────┘
```

### 1.2 交互方式

```
翻页：
  鼠标滚轮 → 左右翻面（平滑滑动动画·约0.3秒过渡）
  键盘 Q/E → 左右翻面
  手柄 LB/RB → 左右翻面
  鼠标点击底部指示器 → 直接跳到对应面

所有面板可以顺时针/逆时针循环·没有"到底了"。

离开：
  按 Esc / Tab / B → 关闭界面·回到游戏
```

### 1.3 进入动画

```
按 Tab 打开界面 → 
  0.0s: 画面变暗·游戏世界淡出·留辰生一人
  0.3s: 辰生从战斗姿态变为站立姿态（收剑·垂手）
  0.5s: 八卦光环从脚下升起·比战斗中的光环更大更亮
  0.7s: 装备/法器从辰生身上"浮出"——悬浮在身体周围的展示位
  1.0s: 界面就绪·可以开始翻页
```

## 三、交互细节

### 3.1 翻页动画

```
向右翻页（滚轮向下 / E / RB）：
  当前面板 → 向左滑出（0.15s）→ 透明消失
  辰生切换姿态（0.2s·不同面板不同站姿）
  新面板 → 从右滑入（0.15s）→ 到位

向左翻页（滚轮向上 / Q / LB）：
  当前面板 → 向右滑出
  新面板 → 从左滑入

翻页期间装备/光环的悬浮位置平滑过渡
```

### 3.2 不同面板下辰生的姿态

| 面板 | 辰生姿态 | 特殊效果 |
|------|------|------|
| 属性 | 自然站立·双手自然垂放 | 无特殊 |
| 装备 | 双臂微展·装备槽环绕身体 | 装备从身上"浮出"·悬浮在展示位 |
| 法器 | 右手持当前法器·左手自然 | 法器架在身后排开·选中法器发光 |
| 卦象 | 左手掐诀·右手垂放 | 八卦光环展开·卦位高亮 |
| 术数 | 站立·双臂微张 | 身上叠加当前术数的视觉特效 |
| 命盘 | 低头看地面 | 脚下命盘投影展开·12宫亮起 |
| 外观 | 可旋转·可放大缩小 | 无UI遮挡·纯粹展示 |

```
点击装备槽 → 右侧弹出该槽位可用物品列表：
```

## 四、陈列柜——"装备环绕角色"

### 4.1 装备在角色周围的展示位

在装备面板（面2）中，已装备的道具不是放在UI格子里——是悬浮在角色身体周围对应的位置：

```
        头饰位(头顶)
           
  法器·主(右手旁)    法器·副(左手旁)
     
        道袍位(身体)
        葫芦位(腰间)
         
  铭刻·剑身(剑身位置)  铭刻·剑格(剑格位置)
```

每个展示位是一个发光的微型"星碑"（小石柱）·装备悬浮在石柱上方·缓慢旋转。

### 4.2 未装备的槽位

未装备的槽位显示为**灰色虚线光柱**——暗示"这里可以放东西"。
