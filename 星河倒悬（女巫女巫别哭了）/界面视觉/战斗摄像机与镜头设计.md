## 一、镜头设计哲学

```
三类游戏镜头哲学：

1. 战神(2018)：一镜到底·肩后视角·镜头不切
   → 优点：沉浸感极强·适合电影化叙事
   → 缺点：快节奏多目标战斗时视野受限

2. 鬼泣/DMC：角色居中·镜头自动拉远·淡化摄像机存在感
   → 优点：360°视野·适合高速战斗
   → 缺点：缺乏"镜头作为叙事工具"的表现力

3. 仁王/只狼：锁定→镜头聚焦·解锁→自由视角
   → 优点：精确控制·适合1v1剑戟
   → 缺点：多目标战斗时锁定切换繁琐

星河倒悬方案：混合型——默认肩后·战斗中自适应·特殊时刻镜头主动叙事
```

## 二、基础镜头参数

### 2.1 默认战斗镜头

| 参数 | 值 | 说明 |
|------|-----|------|
| FOV（视场角） | 75° | 标准第三人称·可调范围60°-90° |
| 水平偏移 | 右侧0.5m | 肩后视角·辰生在画面左侧1/3处 |
| 垂直偏移 | 上方1.2m | 略高于辰生头顶 |
| 距离 | 4.5m | 辰生到摄像机的默认距离 |
| 俯角 | 15° | 略微俯视·地面可见范围大 |
| 平滑速度 | 8.0 | 镜头跟随的插值速度（越高越灵敏） |
| 碰撞检测 | 开启 | 镜头碰到墙壁→自动拉近至辰生背后 |
| 碰撞最小距离 | 1.5m | 拉近的最小极限（防止穿模到辰生体内） |

### 2.2 锁定镜头

| 参数 | 值 |
|------|-----|
| 锁定方式 | 按下R3(手柄)/中键(鼠标)→锁定中心屏幕最近敌人 |
| 切换目标 | 右摇杆←/→(手柄)/滚轮(鼠标) |
| FOV | 65°（锁定后拉近） |
| 距离 | 4.0m（锁定后微近） |
| 镜头位置 | 自动调整使辰生和目标都在画面中 |
| 解锁 | 再次按锁定键/目标死亡/目标脱战 |

## 三、动态镜头行为

### 3.1 闪避时的镜头

| 效果 | 参数 |
|------|------|
| FOV变化 | 闪避瞬间FOV +5°（0.1s→恢复） |
| 镜头延迟 | 闪避期间镜头滞后0.05s（让闪避感觉更快） |
| 震屏 | 闪避落地时微震·幅度0.5·持续0.1s |
| 离卦闪避特化 | 闪避路径残留火痕→镜头短暂跟随火痕（0.2s） |
| 震卦瞬移闪避 | FOV瞬间+15°→快速回弹（"被拽过去的"感觉） |

### 3.2 演卦（按住右键选卦）时的镜头

| 效果 | 参数 |
|------|------|
| 时停期间 | FOV -5°（稍微拉近·专注感） |
| 时间流速30% | 镜头运动也减速到30%（和世界同步） |
| 上卦选择 | 鼠标方向=镜头微移（鼠标↗→镜头微右上转·帮助定位） |
| 选卦完成松手 | FOV瞬间+8°→0.3s回弹（"释放"感） |
| 卦气不足(不减速) | FOV不变·正常镜头·但屏幕边缘微暗（提示无保护） |

### 3.3 普攻命中时的镜头

| 连段 | 镜头效果 |
|------|---------|
| 普攻第1段命中 | 微震·幅度0.3·持续0.05s |
| 普攻第2段命中 | 微震·幅度0.5·持续0.08s |
| 普攻第3段命中 | 中震·幅度0.8·持续0.1s·镜头微推近(+0.2m) |
| 普攻最终段命中 | 强震·幅度1.2·持续0.15s·镜头推近后弹回 |
| 法器专属技命中 | 更强震·幅度1.5-2.0·镜头推近0.5m(蓄力)→猛弹回(释放) |

### 3.4 卦术命中时的镜头（Hit-Stop联动）

| Hit-Stop帧 | 镜头行为 |
|:--:|------|
| 2帧 | 震屏幅度0.8·镜头暂停随Hit-Stop |
| 4帧 | 震屏幅度1.2·镜头暂停·画面颜色饱和度短暂+20% |
| 6帧 | 震屏幅度1.5·镜头暂停·画面颜色反转一帧 |
| 8+帧(太乙神数) | 全场暂停·镜头从辰生身后→转到正面→特写→拉回身后 |

## 四、特殊战斗时刻的镜头演出

### 4.1 崩解触发（同卦第4次命中）

```
崩解触发时：
  0.0s: Hit-Stop 8帧(0.13s)·画面暂停
  0.13s: 镜头猛推至辰生背后1.5m（贴背）·FOV+15°
  0.3s: 卦象特效从辰生身上爆发→镜头被"震退"到4.5m
  0.5s: FOV恢复正常·画面饱和度从150%回落
  0.8s: 一切恢复正常

  音效：闷响→碎裂声→卦象元素的风暴声→安静
```

### 4.2 太乙神数成功

```
太乙神数完美完成时：
  - 全屏暂停·画面去色（黑白的）
  - 镜头从辰生身后→弧形绕到正面（1.5s）
  - 特写辰生的脸→他的眼睛反光金色
  - 镜头猛拉→升到高空(20m)→俯视战场
  - 卦术从天空降下（离卦=流星雨·震卦=雷暴·乾卦=金柱）
  - 画面瞬间恢复彩色·Hit-Stop结束·爆炸发生
  - 镜头从高空猛坠回辰生身后
```

### 4.3 BOSS阶段转换

```
阶段转换演出（焦烈·阶段二→阶段三）：
  1. 焦烈释放白焰全屏→镜头拉远到15m·FOV=90°
     → 让玩家看到"整个房间都被白焰吞没"的震撼
  2. 辰生离卦真火变金色（锻锋觉醒）→
     镜头从15m猛推到辰生身后2m·FOV=60°
     → 让玩家看到剑身上金焰的细节
  3. 金色火焰扩散→镜头从2m慢拉回4.5m
     → 让玩家同时看到"剑上的金焰"和"正在褪色的白焰墙"
  4. 焦烈失神2s→镜头切到焦烈正面→他的眼睛反光金色→切回
```

### 4.4 同伴觉醒演出

```
锻锋觉醒（星纪宫通关）：
  1. 辰生在星空中坠落→镜头紧随·旋转（模拟失重感）
  2. 锻锋的火焰轮廓从星光中凝聚→镜头慢推近·FOV从75°降到45°
  3. 锻锋取出荧惑真火→镜头聚焦在火种上·背景失焦
  4. 火种没入辰生胸口→镜头切到辰生的左手腕→星纹从灰色变暗金色
  5. 镜头缓慢拉回→辰生回到星纪宫入口·远处天边多了6颗更亮的星

  这段演出中玩家不可操控·时长约45秒·可跳过（长按空格）
```

## 五、震屏规则

### 5.1 震屏等级

| 等级 | 幅度 | 频率 | 持续 | 触发条件 |
|:--:|:--:|:--:|:--:|------|
| 微震 | 0.3-0.5 | 高(60Hz) | 0.05s | 普攻第1段命中 |
| 轻震 | 0.5-0.8 | 中(40Hz) | 0.1s | 普攻第2段·卦术命中(2帧Hit-Stop) |
| 中震 | 0.8-1.2 | 中(30Hz) | 0.15s | 普攻第3段·卦术命中(4帧) |
| 强震 | 1.2-1.5 | 低(20Hz) | 0.2s | 重卦命中·法器专属技 |
| 烈震 | 1.5-2.0 | 极低(10Hz) | 0.3s | 崩解触发·太乙神数成功 |
| 剧震 | 2.0-3.0 | 极低(8Hz) | 0.5s | BOSS大招·场景坍塌 |

### 5.2 震屏衰减

```
震屏不叠加（取最大值·不求和）：
  - 同时触发多个震屏→以最大幅度+最长持续为准
  - 前一次震屏未结束→新震屏幅度更大→前一次被覆盖
  - 前一次震屏未结束→新震屏幅度更小→新震屏被忽略

衰减曲线：线性或二次衰减
  幅度(t) = 最大幅度 × (1 - t/持续)²  （二次衰减·更自然）
```

### 5.3 震屏可调

| 设置 | 默认 | 范围 |
|------|:--:|------|
| 震屏强度 | 100% | 0%-200% |
| 震屏风格 | 标准 | 标准/柔和(半幅)/狂野(×1.5)/关闭 |
| 手柄震动 | 100% | 0%-200% |
| BOSS战震屏 | 标准 | 标准/增强/关闭 |

## 七、镜头与UI的关系

- **镜头拉近(FOV缩小)→HUD边缘淡出**（不要太挤）
- **镜头拉远(FOV增大)→HUD完全显示**
- **演卦时停→卦盘UI在镜头前展开·卦盘位置随鼠标方向微移**
- **锁定目标→目标血条+卦象弱点UI出现在目标头顶**
- **被击中→屏幕边缘泛红·红度=失去生命的比例**
