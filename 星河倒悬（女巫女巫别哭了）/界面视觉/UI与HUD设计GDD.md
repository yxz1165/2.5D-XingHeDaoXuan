# UI 与 HUD 设计 GDD —— 《星河倒悬》
> **共享标准引用：** 五行枚举·货币体系·装备槽位·星碑交互·伤害公式→`战斗系统/共享系统接口定义.md`（全项目权威定义）

## 1. Overview

UI系统采用中国传统美学——水墨、星图纹样、竹简质感，与团结引擎 UI Toolkit 实现。战斗HUD追求信息清晰但不遮挡画面，菜单界面追求沉浸感。

核心设计原则：
- **少即是多**：HUD 默认只显示血条+资源条+技能冷却，其余信息按需浮现
- **中国传统视觉语言**：菜单背景用古纸/竹简纹理，光标音效用古琴泛音，过场字幕用竖排楷体
- **色盲友好**：元素颜色不仅靠颜色区分（火=菱形图标/水=圆形图标/金=方形图标等）
- **真伪可辨**：真传装备用金边，仿品装备用灰紫边+暗纹闪烁

### 2.4 八卦盘UI（核心战斗界面）

> **补充日期：** 2026-08-03（GDD一致性审核后补全）
> **触发：** 按住鼠标右键 → 150ms后时停 → 卦盘在屏幕中央展开

#### 2.4.1 卦盘布局

```
┌─────────────────────────────────────────────────┐
│                                                 │
│              ╭───────────────────╮              │
│              │   时停计时环 4.2s  │              │
│              │                   │              │
│              │     ☲ 离(火)      │  ← 鼠标方向=上卦│
│              │   ↗  ↑  ↖       │              │
│              │  ☴风 ☲火 ☷地    │              │
│              │  →     ⊕     ←  │  ⊕ = 鼠标位置  │
│              │  ☳雷 ☵水 ☱泽    │              │
│              │   ↘  ↓  ↙       │              │
│              │  ☶山 ☵坎 ☰天    │              │
│              │                   │              │
│              ╰───────────────────╯              │
│                                                 │
│  下卦按键提示（未解锁=灰色·已解锁=金色）：         │
│  [1]☰乾  [2]☱兑  [3]☲离  [4]☳震               │
│  [Q]☴巽  [E]☵坎  [R]☶艮  [F]☷坤               │
│                                                 │
│  卦气：▓▓▓▓▓▓▓▓▓▓░░ 78/100                      │
└─────────────────────────────────────────────────┘
```

#### 2.4.2 卦盘元素规格

| 元素 | 规格 | 说明 |
|------|------|------|
| **卦盘本体** | 直径280px·圆形·半透明墨色底（alpha 0.85） | 屏幕中央·不随鼠标移动 |
| **上卦扇区** | 8个45°扇区·内径60px·外径140px | 鼠标进入扇区=该扇区高亮·卦符放大120% |
| **扇区高亮** | 当前扇区=对应元素色+外发光 | 离=金红·巽=翠绿·震=蓝白·坎=深蓝·艮=土黄·乾=亮金·兑=银灰·坤=暗黄 |
| **鼠标死区** | 圆心半径32px | 防止8方向交界处抖动·死区内=默认上次上卦 |
| **下卦按键栏** | 卦盘下方80px·8个方形按键（40×40px） | 金色边框=已解锁·灰色=未解锁·按下时=元素色填充 |
| **时停计时环** | 卦盘外圈·环形倒计时条 | 最大8秒·红色递减→最后2秒变红闪烁 |
| **卦气条** | 卦盘下方·水平条·200px宽·10px高 | 蓝→金渐变·低于20%变红闪烁 |
| **卦名显示** | 卦盘正下方·30px楷体 | 选中上下卦后实时显示卦名（如"䷍火天大有"） |
| **预存提示** | 卦盘左下角 | [3]预存1: ䷍火天大有 / [4]预存2: 无 |

#### 2.4.3 扇区视觉状态

| 状态 | 视觉 |
|------|------|
| 空闲（鼠标未进入） | 卦符淡金色·半透明·字号16pt |
| 悬停（鼠标进入扇区） | 卦符亮金色·不透明·字号20pt·扇区底色+元素色20%·外发光 |
| 选中（点击/停留>0.3s） | 卦符锁定·扇区边框加粗2px·脉冲动画（0.5s周期）·其余扇区暗淡 |
| 未解锁 | 卦符灰色·扇区有"🔒"锁图标 |
| 伪卦污染（太史卦师战中） | 卦符红色抖动·有裂痕纹理·辨伪窗口弹出（见§10.4） |

#### 2.4.4 时停视觉反馈

| 阶段 | 视觉 | 音效 |
|------|------|------|
| 按下右键（0-150ms） | 无卦盘·闪避动画播放 | 闪避音效 |
| 时停激活（150ms） | 画面去饱和20%·卦盘从中心放大弹出（0.2s过渡）·敌人动作变慢 | 低沉嗡鸣声+心跳声放大 |
| 选卦中 | 卦盘稳定·鼠标控制高亮 | 持续嗡鸣（底层）+鼠标移动音（高频·轻微） |
| 松手释放 | 卦盘收缩消失（0.15s）·画面饱和度恢复·卦术特效爆发 | 嗡鸣骤停→卦术释放音效 |
| 超时（8秒） | 卦盘变红→自动释放当前选中卦象 | 警告音+自动释放音效 |
| 被打断 | 卦盘碎裂动画（0.3s）·卦气保留50%提示弹出 | 碎裂声+5秒冷却提示音 |

#### 2.4.5 卦盘与HUD的共存

- 卦盘展开时：HUD血条/资源条/同伴血条保持可见（不遮挡·略微缩小至80%）·其余HUD元素（小地图·连击数·道具栏）淡出
- 卦盘收起后：所有HUD元素0.3s内恢复
- BOSS血条在卦盘展开时移至屏幕顶部（避免被卦盘遮挡）

#### 2.4.6 三爻归真时的卦盘变化

- 被伪卦污染的卦位→红色抖动+裂痕纹理
- 鼠标移到红色卦位→卦盘右侧弹出"辨伪窗口"（160×100px·竹简纹理·竖排文字）
- 辨伪窗口3s后自动消失（如果2.5s内未操作）
- 成功归真→红色卦位爆裂为金色粒子→重新变回正常金色卦符

#### 2.4.7 小六爻模式 vs 八卦盘模式

| 对比项 | 小六爻（Shift+右键） | 八卦盘（右键） |
|--------|-------------------|--------------|
| 扇区 | 6分区·60°/扇 | 8分区·45°/扇 |
| 方向标记 | 汉字（大安/留连/速喜/赤口/小吉/空亡） | 卦符（☲☴☳☷☶☰☱☵） |
| 下卦选择 | 无（方向直接释放） | 8键选择 |
| 减速 | 无（实时速度） | 30%流速·消耗卦气 |
| 视觉风格 | 简化红黑双色·快速·实用 | 完整金色卦盘·华丽·战术 |
| 适用场景 | 紧急时刻·新手·快速反应 | 预谋战斗·高手·战术选择 |

## 3. 主菜单界面

### 3.1 菜单结构

```
主菜单 (Esc)
├── 继续游戏
├── 背包
│   ├── 装备 (武器/防具/饰品)
│   ├── 消耗品
│   ├── 材料
│   ├── 关键道具
│   ├── 星君信物
│   └── 记忆碎片
├── 角色
│   ├── 辰生 (属性+天赋盘)
│   ├── 同伴列表 (10人)
│   └── 职业切换
├── 星图 (世界地图+道宫入口)
├── 队伍 (编队)
├── 任务日志
├── 知残手札 (收集品阅读)
├── 系统设置
└── 返回游戏
```

### 3.2 背包界面

- 左侧：分类标签（竖排，竹简样式）
- 中间：物品网格列表（横向4列）
- 右侧：选中物品详情 + 操作按钮（装备/使用/出售/分解/标记）
- 底部：金币+材料数量概览
- 装备对比：悬停时自动弹出当前装备 vs 悬停装备的属性差异（绿色↑/红色↓）

### 3.3 角色界面

- 左侧：角色立绘（水墨风格）+ 等级/经验条
- 中间：属性面板（攻击/防御/生命/暴击/暴伤/元素增伤/抗暴/元素抗性）
- 右侧：天赋盘（三条路线可视化）
- 底部：当前装备预览（4槽位小图标）

### 3.4 星图（大地图）

- 卷轴展开式地图，水墨风格
- 已解锁区域：彩色 + 标注
- 未解锁区域：灰色 + 云遮
- 道宫入口：星辉标记（金色=已通关/蓝色=当前可进入/灰色=未解锁）
- 城镇/NPC：图标标注
- 点击可传送（仅已发现的星碑）

## 4. 对话框与过场

### 4.1 对话界面

- 底部居中：对话文字（仿宋体，22px）
- 左侧：说话者立绘（半身像）
- 右侧：对话选项（竖排，最多4项）
- 历史记录：↑键回看

### 4.2 过场字幕

- 竖排从右至左滚动（符合古文阅读习惯）
- 关键台词逐字显示（typewriter效果）+ 古琴泛音
- 哲学命题总结（每宫觉醒后的黑屏白字）使用大字楷体，停顿3秒
