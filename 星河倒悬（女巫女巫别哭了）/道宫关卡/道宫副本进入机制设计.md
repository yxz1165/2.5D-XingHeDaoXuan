# 道宫副本——超大型副本进入机制与内部结构

> **定位：** 12道宫不是"地图上走上去按F"的普通副本。每宫有独特的进入条件、入口奇观、入场演出、多层结构。
> **关联：** [[世界地图与区域解锁设计]] | [[道宫关卡设计]] | [[探索与宝箱系统设计]]

---

## 一、设计原则

```
道宫 ≠ 普通副本
道宫 = 地图上可见的巨大奇观 + 需要满足条件才能进入 + 内部是多层超大型副本

如果普通副本是一个山洞——
道宫就是一座被封印的失落神殿·你站在外面就能感受到它的存在。
```

| 原则 | 说明 |
|------|------|
| **奇观化入口** | 每宫入口在地图上是一个巨型建筑/自然奇观·远距离可见 |
| **条件进入** | 不是"走到→按F"·需要满足特定条件（钥匙/卦术/同伴/时间/摇卦） |
| **入场演出** | 条件满足后有专属的进入演出（俯视角也能有冲击力） |
| **多层结构** | 内部不是走廊——2-4层·每层有关卡机制·层间有"休息层" |
| **BOSS封印** | BOSS房间在道宫最深处·有封印结界·只有击败BOSS后才能离开 |

## 三、进入条件（逐宫）

### 3.1 星纪宫——极光之柱

```
可见条件：进入北冥冰原即可看到极光之柱
进入条件：需要荧惑钥匙（序章玄伯遗物中获得）
          
进入流程：
  1. 走到极光之柱前→地面有星图凹槽
  2. 自动触发→辰生取出荧惑钥匙→钥匙浮空→插入凹槽
  3. 极光之柱从幽蓝变成金色→光柱裂开一道门
  4. 辰生走进去→门闭合→副本开始

入场演出（俯视角）：
  - 钥匙插入→屏幕从冷色调渐变为暖金色
  - 光柱裂开→地面震动·冰面出现金色裂痕
  - 辰生走入→镜头从俯视变为俯视微斜（跟随身后）
  - 光门闭合→外界声音消失·只剩风声
```

### 3.2 玄枵宫——世界之树

```
进入条件：
  1. 锻锋在队伍中（荧惑真火可点燃古木之心）
  2. 使用离卦+乾卦组合对着树干上的星图纹路释放

进入流程：
  走到巨木根部→树干上有暗淡的星图纹路→
  辰生按住右键→选离卦+乾卦→松手→真火从剑尖涌出→
  火焰沿着星图纹路自动蔓延→整棵树干亮起金色纹路→
  树干裂开→内部是螺旋向下的木梯

入场演出：
  - 火焰蔓延→摄像机缓慢上移→从根部到树冠全部被点亮
  - 裂口形成→古木发出低沉的"呼吸声"
  - 苏羽（如果在队伍中）："岁星……在这里面。"
```

### 3.3 娵訾宫——五色大地

```
进入条件：
  1. 石翁在队伍中（地隐星君·感应大地之力）
  2. 在五色裂缝处使用坤卦（大地卦术共鸣）
  3. 裂缝处的毒瘴需要先被净化→石翁的大地净化（自动触发）

进入流程：
  走到五彩裂缝前→石翁自动触发对话："这里……大地在哭。"
  → 石翁施展大地净化→毒瘴消散→裂缝扩大→
  辰生按住右键→坤卦+任意下卦→大地共鸣→
  裂缝裂开成一条通道→石阶从裂缝中浮现→通向山体内部

入场演出：
  - 毒瘴消散→画面从绿色滤镜恢复正常
  - 裂缝扩大→地面震动·山体发出低沉的隆隆声
  - 石阶浮现→五色光芒从裂缝中射出·石阶上刻着古老的丹砂符号
```

### 3.4 降娄宫——剑碑林

```
进入条件：
  1. 找到剑碑林中的"无字碑"（唯一没有刻字的剑碑）
  2. 用乾卦对着无字碑释放（乾=天=剑道至尊）

进入流程：
  剑碑林中有数百把巨剑→其中一把是光秃秃的无字碑→
  辰生走到无字碑前→按右键→乾卦选任意下卦→释放→
  乾卦的金光击中无字碑→碑身从内部亮起→
  碑身浮现文字（失传的剑谱最后一式）→
  碑身旋转→地面打开→螺旋石阶向下

入场演出：
  - 金光击中→无字碑从底部开始亮起
  - 文字逐行浮现→像有人在碑上写字（看不见的手）
  - 周围的剑碑同时微微震动→剑鸣声从四面八方传来
```

### 3.5 大梁宫——倒悬之塔

```
特殊：这是唯一不可见的道宫入口——需要"找到"它。

进入条件：
  1. 到达西陆边城后→与多个NPC对话→收集线索
     - 老铁匠："城里有一个地方……地图上没有。"
     - 茶馆的说书人："推演机。司史闫序造的。据说在地下。"
     - 乞丐："给我3枚铜钱。我告诉你一个洞。"
  2. 乞丐的线索→指向城中一口枯井
  3. 枯井底→梅花易数（长按F）→发现隐藏的暗门
  4. 暗门后→向下延伸的楼梯→越来越深→到达地下空间

入场演出：
  - 枯井底→梅花易数→井壁上的苔藓褪去→露出齿轮纹路
  - 暗门打开→齿轮转动声从门后传来
  - 辰生走进暗门→身后的井口越来越远→变成一个小光点
  - 楼梯走到底→空间突然开阔→推演机的全貌展现出来
```

### 3.6-3.12 其余道宫的进入条件概述

| 道宫 | 进入条件 | 关键要素 |
|------|---------|---------|
| **实沉宫** | 石磐在队伍·在赤水断崖使用艮卦（山·镇守） | 战场遗物×3（分散在赤水战场各地的掉落） |
| **鹑首宫** | 影在队伍·永夜帷幕前使用"空亡"小六爻（隐身穿过） | 影的特殊能力（穿过暗影结界） |
| **鹑火宫** | 鲁班语在队伍·用七星剑敕令"破"→击碎熔炉封印 | 需要七星剑·鹑火宫解锁时应该已有七星剑 |
| **鹑尾宫** | 冥婆在队伍·沙下之城的塔尖处使用三钱摇卦→摇出"归魂卦" | 特定卦象（归魂卦·变爻在上爻） |

## 四、道宫内部结构（统一框架）

### 4.1 道宫标准层结构

每座道宫内部包含：

```
道宫入口（奇观）
  │
  ├─ 层0·门厅 ———————————————————— 安全区·星碑·进入即激活
  │    · 无敌人·有星碑·可以休息/换同伴/调整装备
  │    · 有时有NPC（道宫的守门人/星君的残留意念）
  │
  ├─ 层1·外围 ———————————————————— 探索+战斗·中等规模
  │    规模：4-6个屏幕
  │    内容：基础敌人·道宫专属环境机制教学·1-2个宝箱
  │          1个"中点星碑"（小安全区·不能传送·只能回血）
  │
  ├─ 层2·核心 ———————————————————— 谜题+战斗·大中规模
  │    规模：6-10个屏幕
  │    内容：道宫专属谜题机制·更强敌人·1个精英怪
  │          机关/钥匙/卦术开门·隐藏房间(梅花易数)
  │
  ├─ 层3·深处 ———————————————————— 高强度战斗·中等规模
  │    规模：4-6个屏幕（部分道宫合并到层2·总共2-4层）
  │    内容：最强杂兵配置·道宫专属挑战·BOSS门前星碑
  │
  └─ 层B·封印之间 ——————————————— BOSS房间
       规模：1个大型屏幕（特殊场景·不可传送·不可退出）
       内容：BOSS战斗·阶段变换·场地机制
            击败后→星君觉醒演出→道宫通关
```

### 4.2 层间传送

```
星碑之间可传送（道宫内部星碑互相连接·但不能传到宫外）：
  门厅星碑 ↔ 中点星碑 ↔ BOSS门前星碑

BOSS房间 = 不可传送·进入后门封闭·击败BOSS后门重新打开
```

### 4.3 每层的"道宫专属机制"

| 道宫 | 专属环境机制 | 表现 |
|------|------------|------|
| 星纪宫 | 极寒/极热区域切换 | 冰面减速·火山区域灼烧 |
| 玄枵宫 | 活体树木 | 树根移动改变通路·树液有毒·树枝可踩 |
| 娵訾宫 | 五彩矿脉 | 不同颜色的矿脉给辰生不同的buff/debuff |
| 降娄宫 | 剑碑共鸣 | 激活剑碑→临时获得剑碑上刻的能力 |
| 大梁宫 | 推演机模拟 | 房间布局每15秒重新排列一次 |
| 实沉宫 | 战场士气 | 我方/敌方士气条·士气高的一方伤害+30% |
| 鹑首宫 | 暗影领域 | 无光区域·只有梅花易数可以看到敌人 |
| 鹑火宫 | 熔炉锻造 | 熔岩可浇铸临时装备·火焰机关·金属地面导电 |
| 鹑尾宫 | 时间沙漏 | 某些房间的时间流速不同 |
| 大火宫 | 音律机关 | 踩踏特定音符石板→打开门/触发陷阱 |
| 析木宫 | 重力反转 | 天花板=第二层地面·上下颠倒 |
| 寿星宫 | 十二卦术考验 | 每个房间需要特定卦术才能通过 |

## 五、道宫内的非战斗要素

### 5.1 探索要素

| 要素 | 说明 |
|------|------|
| **道宫宝箱** | 每层1-2个·比普通副本宝箱品质高 |
| **星图碎片** | 散落在道宫各处·收集后拼成完整星图·解锁额外剧情 |
| **残碑/壁画** | 讲述该道宫星君在陨落前的故事 |
| **隐藏房间** | 需要梅花易数+特定卦术才能进入·奖励稀有法器铭刻 |
| **机关谜题** | 如：乾卦击打3个钟→门打开·震卦给机关充电→平台升起 |
| **捷径解锁** | 打通后可以从门厅直接传送到BOSS门前（方便重试） |

### 5.2 道宫商人

某些道宫内有游荡的商人（在层1或层2的安全区）：
- 出售丹药、卦气回复物品
- 出售该道宫专属的消耗品（如星纪宫的火抗丹药）
- 价格是落星村商人的1.5倍（"荒郊野外的·贵点正常"）

## 六、道宫完成后的变化

### 6.1 通关后

```
1. BOSS被击败→星君觉醒→同伴加入
2. 道宫内部停止刷新敌人（可自由探索·补拿遗漏的宝箱/星图碎片）
3. BOSS房间变成"觉醒之间"→可以回去与星君残影对话（额外剧情）
4. 道宫入口奇观的外观变化：
   - 星纪宫的极光之柱从幽蓝变成金色（真火回归）
   - 玄枵宫的世界之树从枯黄变成翠绿（生命回归）
   - 降娄宫的剑碑全部亮起（剑谱回归）
   ...以此类推·每宫通关后入口奇观"活过来"
5. 该区域地图上的太史阁哨站减少（太史阁在该区域失去影响力）
```

### 6.2 影响世界

```
每通关一座道宫：
  - 对应的星君同伴加入落星村
  - 太史阁在该区域的力量削弱
  - 该区域解锁新的NPC对话/支线
  - 落星村解锁对应建筑/设施
  - 下一区域的迷雾散开
```
