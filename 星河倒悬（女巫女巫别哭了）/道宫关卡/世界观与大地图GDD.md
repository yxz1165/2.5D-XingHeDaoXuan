# 世界观与大地图 GDD —— 《星河倒悬》
> **共享标准引用：** 五行枚举·货币体系·装备槽位·星碑交互·伤害公式→`战斗系统/共享系统接口定义.md`（全项目权威定义）

## 1. Overview

游戏世界由**七大国度**、**海溟国**（海外窃国）、**十二道宫**和**太史阁中枢**构成。大地图是连接这些区域的枢纽——玩家在大地图上移动、发现道宫入口、前往城镇、触发支线。大地图本身不是开放世界，而是**节点式地图**：关键地点通过路径连接，玩家沿路径移动（类似《杀戮尖塔》地图选择但更开放）。

核心设计原则：
- **七国各有文化底色**：基于中国传统地域文化设计（非写实，而是提取文化符号进行幻想化）
- **海溟国不在地图上**：玩家无法直接到达海溟国——它在地图的"边缘之外"，只有通过剧情和敌人才能感知它的存在
- **道宫即锚点**：每座道宫是地图上最显著的地标，周围环绕着相关的小镇、村落、遗迹
- **知残者网络**：散落各地的NPC构成隐形信息网络，是"群众路线"在大地图上的体现

## 3. 大地图系统

### 3.1 地图结构

```
                    [星纪宫·幽]
                        |
        [娵訾宫·雍]——[大梁·陈]——[琅琊港]
              |         /  \         |
        [鹑火宫·蜀]—[实沉·陈]—[降娄宫·海]
              |         |            |
        [鹑首·越]—[玄枵·越]    [析木遗迹·海] ← 星君已逝
              |                    |
        [大火宫·越]          [寿星宫·苍穹] ← 终章
              |
        [鹑尾宫·越]
```

- 玩家在大地图上以**节点移动**方式旅行
- 移动消耗"时间"（影响昼夜，某些事件/敌人仅在特定时间出现）
- 道宫入口是特殊节点，需要满足解锁条件才能进入

### 3.2 移动方式

| 方式 | 速度 | 消耗 | 解锁条件 |
|------|------|------|---------|
| 步行 | 基础 | 时间 | 初始 |
| 马车 | 2x | 铜钱（50文/段） | 通过主要城镇的驿站 |
| 星碑传送 | 即时 | 免费 | 在道宫激活星碑后，可从任意星碑传送到已激活的星碑 |
| 织女长诗（终局） | 即时到任何节点 | 免费 | 通关后 |

### 3.3 大地图事件

在路径上移动时可能触发随机事件：

| 事件类型 | 概率 | 内容 |
|---------|------|------|
| 太史阁巡逻 | 20% | 战斗：捕史者×3-5（可避战） |
| 海溟暗哨（6宫后） | 10% | 战斗：海溟暗卫×2-4 |
| 知残者密会 | 8% | 获得1条知残手札 + 经验 |
| 商人车队 | 15% | 临时商店（价格+20%） |
| 游方药师 | 10% | 购买稀有药品 |
| 民间说书人 | 12% | 1段被篡改的民间故事 → 辰生提出质疑 → 经验 |
| 难民流亡 | 15% | 得知某地被太史阁/海溟国侵占（世界状态更新） |
| 山贼/流寇 | 10% | 战斗，掉落材料+少量铜钱 |

## 4. 城镇与设施

### 4.1 城镇功能

每个主要城镇提供：

| 设施 | 功能 |
|------|------|
| 铁匠铺 | 装备强化、仿品鉴定与重铸、武器元素重铸 |
| 药铺 | 药品购买、炼丹（需提供配方和材料） |
| 杂货铺 | 消耗品、材料、背包扩容道具 |
| 驿站 | 马车快速旅行、星碑传送 |
| 茶楼/酒肆 | 打听传闻（获取支线线索和知残者情报） |
| 仓库 | 存储物品（与星碑仓库互通） |

### 4.2 特殊地点

| 地点 | 位置 | 功能 |
|------|------|------|
| 落星村（废墟） | 离国边陲 | 游戏开始地点，后期可返回触发玄伯回忆剧情 |
| 太史阁总舵 | 陈国·大梁 | 可在第12宫前潜入（支线），获取太史阁内部情报 |
| 海溟商馆 | 琅琊国·东海港 | 海溟国在中华的前哨站，可偷窃海溟钢 |
| 东海古战场 | 陈国海岸 | 实沉宫附属区域，隐藏BOSS（海溟侵略军亡灵） |
| 知残者暗市 | 越国·百草谷 | 购买稀有材料、隐世丹方、未被篡改的古籍 |

## 5. 知残者网络

知残者是散布在七国的"知道部分真相的人"。他们不是正式组织（太史阁的镇压使任何组织化都不可能），而是通过口头、暗号、密信维持的松散网络。

### 5.1 知残者类型

| 类型 | 身份 | 提供信息 |
|------|------|---------|
| 守书人 | 偷偷保存未被烧毁古籍的人 | 某段被篡改历史的真相 |
| 传谣者 | 在茶楼说"反太史阁"故事的说书人 | 民间流传的真相碎片 |
| 前修史官 | 像玄伯一样叛逃太史阁的人 | 太史阁内部运作秘密 |
| 星君亲属 | 转世星君的家人/朋友 | 星君觉醒的关键线索 |
| 海溟逃兵 | 从海溟国叛逃的人（极少） | 海溟国盗窃的证据 |

### 5.2 知残手札收集

- 在各地与知残者对话、完成他们的任务、在隐藏区域探索，可获得"知残手札"
- 知残手札 = 一段文字记录，揭示被篡改历史的某个碎片
- 收集全部 50 份手札 → 解锁"完整真相"成就 + 奖励橙装「知残者灯」
- 每 10 份手札 = 解锁一段辰生的独白（对收集到的真相碎片的反思）

## 6. 世界昼夜与天气

| 系统 | 说明 |
|------|------|
| 昼夜 | 大地图移动消耗时间，每段路径消耗 2-6 小时 |
| 夜晚 | 敌人视野降低，但海溟暗卫更活跃（暗哨隐身时间翻倍） |
| 天气 | 随机（晴/阴/雨/雪/雾），影响元素效果（雨天火伤-10%/雾天远程命中-10%） |
| 节气 | 随主线进度固定推进（每宫对应一个节气区间），影响特定区域的开放 |

## 7. 依赖系统

| 系统 | 关系 |
|------|------|
| 道宫关卡 | 道宫在大地图上的位置和入口 |
| 剧情系统 | 主线推进解锁新区域 |
| 战斗系统 | 大地图遭遇战 |
| UI系统 | 星图界面显示 |
| 背包系统 | 知残手札收集 |

## 8. 可调参数

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `MapTravelTimePerSegment` | 2-6h | 每段路径消耗时间 |
| `RandomEventChance` | 25% | 每段路径触发事件概率 |
| `ZhiCanShardsTotal` | 50 | 知残手札总收集数 |
| `DayNightCycleEnabled` | true | 昼夜循环 |
| `WeatherEnabled` | true | 天气系统 |
