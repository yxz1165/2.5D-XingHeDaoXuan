## 三、地图探索要素（标准ARPG要素）

### 3.1 可见要素（大地图上直接看到）

| 要素 | 图标 | 说明 |
|------|:--:|------|
| **星碑** | ⭐ | 传送点+存档+摇卦点·每个区域1-3个 |
| **道宫入口** | 🏯 | 巨型奇观·特殊进入（详见 [[道宫副本进入机制设计]]） |
| **普通副本** | 🕳️ | 洞穴/废墟/哨站·1-3层·有BOSS |
| **NPC聚居地** | 🏘️ | 村落/驿站/城镇·商人·支线·情报 |
| **宝箱(可见)** | 📦 | 分布在野外·副本中·直接按键开启 |
| **采集点** | 🌿 | 草药/矿石/特殊材料·用于炼丹锻造 |
| **机关/谜题** | ⚙️ | 需要特定卦术/法器/同伴才能激活 |
| **精英怪** | 💀 | 野外游荡的强力敌人·掉落特殊材料 |
| **隐藏洞穴入口** | ❓ | 需要梅花易数(长按F)才能看到 |

### 3.2 不可见要素（需要探索/卦术才能发现）

| 要素 | 发现方式 | 奖励 |
|------|---------|------|
| **卦占宝箱** | 三钱摇卦定位方位+距离→走到附近→地面发光→挖掘 | 法器铭刻材料·稀有丹药配方 |
| **埋藏物品** | 梅花易数观象→地面微弱光点→交互挖掘 | 星图碎片·玄伯遗物·剧情信件 |
| **隐藏暗门** | 梅花易数→墙壁/地面出现裂纹→卦术击碎 | 隐藏房间·BOSS·宝箱 |
| **残碑古文** | 梅花易数→文字浮现→阅读 | 世界剧情碎片·同伴背景故事 |
| **星脉节点** | 七星剑步罡踏斗→特殊脚印组合→星脉显现 | 永久属性提升·星晶 |

## 四、地图交互体系

### 4.1 俯视角操作

```
WASD = 八方向移动
鼠标 = 指向交互目标
F = 交互（对话/开箱/采集/进入副本）
长按F = 梅花易数观象（20m范围揭示隐藏要素·消耗卦气5/秒）
Tab = 打开大地图
M = 打开小地图（半透明叠加在画面左上角）
```

### 4.2 小地图信息

```
小地图显示：
  ✅ 已探索区域（亮色）
  🌫️ 未探索区域（暗色/迷雾）
  ⭐ 已激活星碑
  🏘️ 已发现的聚居地
  🕳️ 已发现的副本
  ❓ 梅花易数揭示的隐藏点（短暂标记·30秒后消失）
  💀 精英怪（进入15m范围后显示）
```

### 4.3 迷雾解锁

```
迷雾 = 黑雾覆盖未探索区域
  - 走到附近5m → 迷雾消散（永久）
  - 激活星碑 → 该区域的迷雾全部消散
  - 完成道宫 → 下一区域的入口迷雾消散
```

## 五、传送与快速移动

### 5.1 星碑传送网络

```
已激活的星碑之间可互相传送：
  打开大地图 → 点击星碑图标 → 传送（加载画面·约2-3秒）

限制：
  - 不能传送到未激活的星碑
  - 战斗中不可传送
  - 副本内不可传出（但副本内有专属传送点）
  - 传送消耗：免费（设计选择·方便玩家）
```

## 六、区域解锁与主线推进

### 6.1 解锁流程

```
序章（落星村·雨夜事件）
  ↓ 云岫教学幻境
  ↓ 获得星轨残卷·荧惑钥匙·九天星晷
  ↓ 老槐树残根前·"躲是躲不掉的"→踏上向北的山路
  ↓
第一章·北冥冰原 → 迷雾解锁(落星村以北)
  ↓ 找到星纪宫入口(极光之柱)
  ↓ 通关星纪宫→锻锋觉醒
  ↓
第二章·苍梧之森 → 迷雾解锁(北冥冰原以南·落星村以东)
  ...每过一宫解锁相邻区域
```

### 6.2 解锁不只是"开门"

| 解锁方式 | 说明 | 示例 |
|---------|------|------|
| **剧情解锁** | 通关前一个道宫 | 星纪宫通关→苍梧之森迷雾散开 |
| **同伴解锁** | 需要特定同伴的能力 | 苍梧之森的巨木根须→需要苏羽的箭射断 |
| **卦术解锁** | 需要特定卦术 | 丹霞山脉的毒瘴→需要坤卦净化 |
| **法器解锁** | 需要特定法器 | 炎火山的熔岩河→需要七星剑的步罡踏斗跨越 |
| **时辰解锁** | 特定时间才能进入 | 黑齿沼泽的暗影屏障→只能在夜晚进入 |
| **摇卦解锁** | 卦象启示指向位置 | 大梁宫入口隐藏在边城的"地下"→需要摇出特定卦象启示才能找到 |

### 7.2 副本结构（以"太史阁哨站"为例）

```
入口：大地图上→悬崖边的石砌建筑·旗帜·哨兵巡逻

第1层·哨站外围（3-5个屏幕）
  - 2个巡逻的太史学徒
  - 1个在哨塔上的太史弓箭手
  - 1个补给箱（铜钱+丹药）

第2层·哨站内部（3-4个屏幕）
  - 3个太史守卫（更密集）
  - 1个卦术陷阱（走过触发白焰灼烧）
  - 1个隐藏房间（梅花易数揭示·含法器铭刻材料）

第3层·指挥室（1个屏幕·BOSS房）
  - BOSS：太史校尉
    - 使用3种伪卦（比学徒多1种）
    - 生命50%时召唤2个太史守卫
    - 掉落：校尉令牌(开启同区域其他哨站隐藏门)·星晶×3·铜钱×80
  - 通关后→房间后方有捷径出口(直接回到副本入口·不用走回头路)
```

## 九、区域之间的过渡

### 9.1 区域连接方式

| 连接类型 | 说明 | 示例 |
|---------|------|------|
| **道路** | 明显的土路/石板路·小地图上虚线 | 落星村→北冥冰原(北上小道) |
| **峡谷/隘口** | 狭窄通道·两侧是高墙/山壁 | 北冥冰原→苍梧之森(风之隘口) |
| **桥梁** | 跨越河流/悬崖 | 丹霞山脉→青要山(剑痕桥) |
| **洞穴隧道** | 穿过山体的通道 | 苍梧之森→丹霞山脉(地底根须通道) |
| **传送门** | 特殊条件下激活的传送门 | 空桑遗迹→星海裂隙(音之传送门) |

### 9.2 首次进入新区域的体验

```
1. 区域名称大字浮现（屏幕中央·渐显→停留2秒→淡出）
2. 画面色调/滤镜根据区域环境切换
   - 北冥冰原：蓝白冷色 + 微弱极光粒子效果
   - 苍梧之森：浓绿 + 雾 + 光斑(树叶缝隙)
   - 炎火山：橙红 + 热浪扭曲效果 + 火山灰飘落
3. 小地图切换为该区域的迷雾覆盖地图
4. 最近的星碑自动高亮在小地图上（"先去激活星碑"的指引）
```

| 参数 | 值 |
|------|-----|

### 10.2 地形层次

```
俯视角下的地形表现：
  - 地面纹理 + 法线贴图（草地/雪地/沙地/石板）
  - 高差用阴影 + 斜坡过渡
  - 悬崖边缘 = 不可通行的暗色区域
  - 建筑物 = 屋顶透明化（进入时）
  - 树木/石柱 = 半透明遮挡（辰生走到后面时）
```
