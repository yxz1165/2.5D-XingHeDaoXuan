## 一、AI架构总览

### 1.1 统一的敌人基类

所有敌人共享以下基础状态机：

```
                    ┌──────────────┐
                    │   Idle 待机   │
                    └──┬───┬───┬──┘
                       │   │   │
              ┌───────┘   │   └────────┐
              ▼           ▼            ▼
         ┌─────────┐ ┌────────┐ ┌──────────┐
         │ Patrol  │ │ Alert  │ │ Combat   │
         │  巡逻    │ │ 警觉   │ │  战斗     │
         └────┬────┘ └───┬────┘ └────┬─────┘
              │           │           │
              └───────────┴───────────┘
                          │
                 ┌───────┬┴───────┬────────┐
                 ▼       ▼        ▼        ▼
            ┌───────┐ ┌──────┐ ┌──────┐ ┌──────┐
            │ Attack│ │Dodge │ │Block │ │Flee  │
            │  攻击  │ │ 闪避 │ │ 格挡 │ │ 逃跑  │
            └───┬───┘ └──┬───┘ └──┬───┘ └──┬───┘
                │         │        │         │
                └─────────┴────────┴─────────┘
                          │
                    ┌─────┴─────┐
                    ▼           ▼
              ┌──────────┐ ┌──────────┐
              │ Stagger  │ │  Death   │
              │  硬直     │ │  死亡     │
              └──────────┘ └──────────┘
```

### 1.2 全局AI参数

| 参数 | 默认值 | 说明 |
|------|:----:|------|
| 检测范围 | 15m | 360°球形检测，发现玩家即进入Combat |
| 警觉范围 | 25m | 进入Alert状态，转身面对玩家 |
| 脱战距离 | 35m | 超过此距离且5秒未受伤害→脱战 |
| 脱战时间 | 8s | 丢失目标后持续搜索时间 |
| 巡逻路径 | 2-6个航点 | 非战斗状态下循环 |
| 决策频率 | 0.25s | 每4帧做一次行为决策 |
| 目标切换最小间隔 | 1.5s | 防止频繁切换目标 |
| 攻击冷却散度 | ±20% | 每次攻击冷却加入随机抖动·防止机械感 |

### 1.3 受击反应参数（所有敌人通用）

| 硬直等级 | 持续时间 | 可行动 | 动画 |
|:--:|------|:--:|------|
| Lv1 抖动 | 0.1s | ✅ | 模型微颤·不影响当前动作 |
| Lv2 硬直 | 0.3s | ❌ | 后仰·打断当前动作 |
| Lv3 击退 | 0.5s | ❌ | 滑退2-5m·倒地判定结束可受身 |
| Lv4 浮空 | 0.7s | ❌ | 击飞至空中2m·落地方可受身 |
| Lv5 击倒 | 1.2s | ❌ | 倒地→起身·起身后1.5s霸体 |

## 二、Phase 1 敌人详细设计

### 2.1 冰原狼（环境野兽）

**定位：** 新手第一个敌人。教会玩家闪避+小六爻方向选择。
**出现位置：** 极北苔原·入口区
**数量：** 5只（分散）

#### 基础属性

| 属性 | 值 |
|------|:--:|
| 生命 | 80 |
| 攻击 | 12 |
| 防御 | 5 |
| 移速 | 6m/s（追击）/ 3m/s（巡逻） |
| 攻速 | 1.5s/次 |
| 韧性 | 60（Lv1硬直阈值20·Lv2阈值60） |
| 硬直上限 | Lv2（不会被击飞/击倒） |

#### 行为树

```
Idle: 原地站立·偶尔转头·耳朵抖动动画·每3-5s低吼
  │
  ├─ 玩家进入25m → Alert: 转身面对玩家·龇牙·发出警告低吼·持续2s
  │    └─ 玩家继续靠近(15m内) → Combat
  │
  └─ Combat:
      ├─ [优先] 玩家距离>8m → 追击（移速6m/s·直线跑）
      ├─ [优先] 生命<20% → 逃跑（移速6m/s·随机方向·30%概率）
      ├─ 玩家距离2-5m → 攻击决策:
      │   ├─ 70% 扑咬: 蓄力0.4s→冲刺3m→咬合·伤害15·硬直Lv1
      │   ├─ 20% 横扫: 无蓄力·前方180°爪击·伤害10·无硬直
      │   └─ 10% 佯攻: 假扑0.3s→后跳2m→立即再次攻击（冷却减半）
      └─ 玩家距离<2m → 后跳3m·冷却3s
```

#### 攻击参数

| 攻击 | 启动帧 | 活跃帧 | 结束帧 | 伤害 | 硬直 | 冷却 | 弹窗颜色 |
|------|:--:|:--:|:--:|:--:|:--:|:--:|------|
| 扑咬 | 24帧(0.4s) | 12帧 | 20帧 | 15 | Lv1 | 2.0s | 红色轨迹 |
| 横扫 | 6帧(0.1s) | 8帧 | 14帧 | 10 | 无 | 1.5s | 无（快速攻击） |
| 佯攻 | 18帧 | 0帧(假) | 16帧 | 0 | 无 | 1.0s | 红色轨迹→中断 |

#### 受击反应

- 被小六爻赤口击退→滑退3m+眩晕1.5s→恢复后立即猛扑（仇恨+30%）
- 被火卦命中→身上着火·会在地上打滚灭火（1.5s·期间无法行动·灭火后全属性-10%）
- 冰原狼对冰属性免疫（暂未解锁冰卦·此条为预留）

### 2.2 太史学徒（基础人形敌人）

**定位：** 最常见杂兵。教会玩家识别伪卦+卦象克制。
**出现位置：** 冰火外围·探索区（×8）
**特色：** 使用被篡改的伪卦——白色小火焰

#### 基础属性

| 属性 | 值 |
|------|:--:|
| 生命 | 120 |
| 攻击 | 18 |
| 防御 | 10 |
| 移速 | 4m/s |
| 攻速 | 2.0s/次 |
| 韧性 | 100（Lv1阈值30·Lv2阈值70·Lv3阈值100） |
| 硬直上限 | Lv3（可被击飞） |

#### 伪卦位

太史学徒的卦盘上有 **1个** 红色伪卦位（随机在离/巽/震中选一个）：
- 伪卦被归真→学徒该卦位的技能失效+反噬伤害100%ATK
- 归真后15秒内学徒无法使用该卦位

#### 行为树

```
Idle: 站立·手捧卦盘（白色·有裂痕）·偶尔查看卦盘
  │
  ├─ 玩家进入20m → Alert: 收起卦盘·拔剑·喊话("卦象指示——入侵者！")
  │
  └─ Combat:
      ├─ [优先] 玩家正在选卦(右键按住)→ 冲刺打断·优先级最高
      ├─ 距离4-8m → 伪火卦·白焰弹(70%) / 冲刺斩(30%)
      ├─ 距离2-4m → 三连斩(60%) / 后撤+白焰弹(40%)
      ├─ 距离<2m → 踢击推开(2m·硬直Lv1)→接白焰弹
      ├─ [反应] 被火卦命中→慌张("这火……不一样！")→攻击欲望-30%
      └─ [反应] 生命<30%→后退→"卦盘碎了！"→放弃进攻·只闪避(10s后死亡)
```

#### 攻击参数

| 攻击 | 启动 | 活跃 | 结束 | 伤害 | 硬直 | 冷却 | 弹窗颜色 | 弹窗时间 |
|------|:--:|:--:|:--:|:--:|:--:|:--:|------|:--:|
| 白焰弹(伪离卦) | 36帧(0.6s) | 飞行·10m/s | 18帧 | 20 | Lv1 | 3.0s | 白色光圈 | 0.5s |
| 冲刺斩 | 18帧(0.3s) | 12帧 | 15帧 | 25 | Lv2 | 4.0s | 红色直线 | 0.2s |
| 三连斩·1段 | 12帧 | 6帧 | 8帧 | 12 | Lv1 | — | — | — |
| 三连斩·2段 | 8帧(取消1段) | 6帧 | 10帧 | 14 | Lv1 | — | — | — |
| 三连斩·3段 | 10帧 | 8帧 | 15帧 | 18 | Lv2 | 5.0s | 红色闪光 | 0.3s |
| 踢击 | 8帧 | 4帧 | 10帧 | 8 | Lv1·击退2m | 4.0s | — | — |

#### 弹窗（Telegraph）设计

所有攻击必须有弹窗提示——玩家可以通过视觉预判来闪避：

| 攻击 | 弹窗视觉 | 弹窗时长 | 音效 |
|------|---------|:--:|------|
| 白焰弹 | 学徒手前白色光圈扩大 | 0.5s | 白焰嗡鸣声 |
| 冲刺斩 | 学徒压低身体·剑拖地擦出火花 | 0.25s | 金属摩擦声 |
| 三连斩 | 学徒举剑·剑身闪一次白光 | 0.1s(仅第一段) | 短促金属声 |
| 踢击 | 学徒上半身后仰·重心转移 | 0.15s | — |

### 2.3 太史守卫（持盾精英杂兵）

**定位：** 教会玩家"破盾"和"找破绽"。守卫持盾正面格挡，需要绕后或用火卦破盾。
**出现位置：** 冰火外围（×4）、熔岩中层走廊（×4）
**特色：** 持盾·白焰箭矢·需要特定策略

#### 基础属性

| 属性 | 值 |
|------|:--:|
| 生命 | 200 |
| 攻击 | 22 |
| 防御 | 25（正面格挡=防御×4=100） |
| 移速 | 3m/s（持盾）/ 5m/s（弃盾） |
| 韧性 | 200（Lv1阈值60·Lv2阈值130·Lv3阈值200） |
| 硬直上限 | Lv3 |

#### 盾牌机制

```
正面格挡：
  - 守卫面向辰生 ±60°内的攻击×0.25伤害（防御×4）
  - 格挡成功后守卫不硬直·可立刻反击
  - 艮卦(山)的定身、坤卦(地)的沉重对盾牌无效
  - 离卦(火)对盾牌造成150%耐久伤害

盾牌耐久 = 150（相当于第二条生命条）
  - 每次正面格挡消耗 攻击伤害×0.1 点耐久
  - 火卦命中消耗 攻击伤害×0.3 点耐久
  - 乾卦(天)破甲命中消耗 攻击伤害×0.5 点耐久
  - 耐久归零→盾牌碎裂·守卫弃盾

弃盾后：
  - 防御降至10
  - 移速升至5m/s
  - 攻击模式从"保守格挡"切换到"疯狂冲锋"
  - 失去白焰箭矢能力（箭矢需盾牌上的弓槽）
```

#### 行为树

```
Combat:
  ├─ [状态·持盾] 盾牌耐久>0:
  │   ├─ 辰生距离>8m → 举盾缓慢靠近(2m/s·接箭模式下)
  │   ├─ 辰生距离5-8m → 白焰箭矢(60%) / 盾冲(40%)
  │   ├─ 辰生距离<5m → 盾击(50%) / 格挡等待(50%)
  │   ├─ [反应] 辰生绕到背后(±120°)→快速转身·举盾·冷却1s
  │   └─ [反应] 被火卦命中→盾牌冒出黑烟·守卫后退一步·"这盾牌——怎么可能！"
  │
  └─ [状态·弃盾] 盾牌碎裂:
      ├─ 疯狂冲锋: 直线冲撞·移速5m/s·碰撞伤害30·撞墙自伤15
      ├─ 拳击连打: 3段·15/18/22伤害·硬直Lv1/Lv1/Lv2
      └─ 生命<20%→逃跑·"撤退！盾没了！"
```

#### 攻击参数

| 攻击 | 启动 | 伤害 | 硬直 | 冷却 | 弹窗 |
|------|:--:|:--:|:--:|:--:|------|
| 白焰箭矢 | 48帧(0.8s·张弓搭箭) | 30 | Lv2 | 4.0s | 箭尖白色光圈聚能·0.6s |
| 盾冲 | 30帧(0.5s·举盾蓄力) | 25+击退3m | Lv3 | 6.0s | 盾牌表面白光闪耀·0.3s |
| 盾击 | 15帧(0.25s·短距推盾) | 18 | Lv1·击退1m | 2.0s | 守卫呼气声·盾牌微移 |
| 拳击1段 | 10帧 | 15 | Lv1 | 1.5s | — |
| 拳击2段 | 8帧 | 18 | Lv1 | — | — |
| 拳击3段 | 12帧 | 22 | Lv2 | 3.0s | 拳头微光 |

### 2.4 太史司火副官（精英怪）

**定位：** BOSS前精英。教会玩家"阶段变化"和"白焰转化"。
**出现位置：** 熔岩中层·挑战区（×1）
**特色：** 二阶段战斗·白焰结界·离卦真火反噬

#### 基础属性

| 属性 | 值 |
|------|:--:|
| 生命 | 600 |
| 攻击 | 30 |
| 防御 | 20 |
| 移速 | 4m/s |
| 韧性 | 350（Lv1阈值100·Lv2阈值200·Lv3阈值350） |
| 硬直上限 | Lv3 |

#### 阶段一（100%-50%生命）：白焰专家

```
Combat·阶段一:
  ├─ 距离>6m → 白焰三连射（追踪火球×3）
  │   - 每发间隔0.3s·各独立追踪
  │   - 伤害20/发·硬直Lv1
  │   - 弹窗：副官身前出现3个白色光圈·依次发射
  │   - 冷却：4.0s
  │
  ├─ 距离3-6m → 白焰之墙（前方扇形白焰·持续8s）
  │   - 覆盖前方120°×6m
  │   - 站在白焰上：每秒受15伤害+灼烧(20/次)
  │   - 用离卦真火覆盖→白焰被吞→转化为金色安全区（辰生站上去回卦气+5/秒）
  │   - 弹窗：副官单手拍地·地面白色纹路扩散·1.0s
  │   - 冷却：8.0s
  │
  ├─ 距离<3m → 白焰爆发（自身圆形AOE·R=3m）
  │   - 伤害35·硬直Lv2·击退3m
  │   - 弹窗：副官身体被白色火焰包裹·0.5s
  │   - 冷却：6.0s
  │
  └─ 每20s → 召唤白焰之灵×2
      - 生命100·伤害10·白焰弹自动攻击
      - 被离卦击杀→不刷新·转化为辰生卦气+10
```

#### 阶段二（50%-0%生命）：极寒囚笼

```
进入条件：生命降至50%
转换演出（2s·不可跳过）：
  副官跪地→白色火焰从身体溢出→地面结冰→BOSS房间温度骤降
  副官起身：周围4m范围变成极寒光环·每2秒对辰生造成10点冰霜伤害
  被动：移速+20%·攻击速度+30%
  台词："海溟国的冰……他们说这是天然的……"

Combat·阶段二:
  ├─ 冰火双重（冰锥+白焰弹交替·共4发）
  │   - 冰锥：直线·宽1m×10m·伤害25·迟缓25·弹窗0.4s
  │   - 白焰弹：追踪·伤害20·灼烧20·弹窗0.4s
  │   - 发射顺序：冰→火→冰→火·每发间隔0.3s
  │   - 冷却：5.0s
  │
  ├─ 冰牢（从地面升起冰柱围困辰生）
  │   - 4根冰柱·围成2m×2m方框·升起时间1.0s
  │   - 冰柱升起前地面冰纹扩散·弹窗0.6s
  │   - 被困→冰柱持续6s→结束后爆发冰霜AOE（伤害40）
  │   - 挣脱：火卦命中冰柱→冰柱碎裂·副官受到50反噬伤害
  │   - 冷却：12.0s
  │
  └─ 召唤冰火元素（1冰+1火·各生命120）
      - 每40s召唤一次·最多同时存在4个
      - 被克制卦击杀→元素对副官反噬
```

#### 特殊交互：离卦真火转化

副官的任何白焰技能——被辰生的离卦（真火）命中时：

```
白焰+真火=转化判定:
  1. 离卦(真火)判定覆盖在白焰区域上
  2. 白焰被"吞"→变色为金色火焰
  3. 金色火焰区域：
     - 对辰生：安全区·站在上面卦气+5/秒·灼烧免疫
     - 对副官：火焰区域变成伤害区·每秒受20反噬伤害
  4. 副官反应："那火是什么——不对！不对！那不是我们的火！"
```

### 2.5 焦烈——星纪宫BOSS

#### 基础属性

| 属性 | 阶段一 | 阶段二 | 阶段三 |
|------|:--:|:--:|:--:|
| 生命 | 2500（100%-70%） | 2500（70%-40%） | 2500（40%-0%） |
| 总生命 | 2500 | — | — |
| 攻击 | 35 | 30 | 35 |
| 防御 | 25 | 30（冰甲） | 20（冰甲被金焰融化） |
| 移速 | 3m/s | 3.5m/s | 2.5m/s（虚弱·动作迟缓） |
| 韧性 | 500 | 500 | 400 |
| 硬直上限 | Lv3 | Lv3 | Lv4（可被浮空） |
| 异常抗性 | 灼烧免疫 | 灼烧/迟缓免疫 | 全部减低50% |

#### 阶段一：白焰专家（100%-70%）

> **焦烈充满自信。他真心相信白焰比真火先进。**

```
Combat·阶段一:

【白焰连射】追踪火球×3
  启动：1.2s（双手聚焰）·弹窗：手前白焰聚能
  弹道：3发·各独立追踪·飞行速度8m/s
  伤害：22/发·硬直Lv1
  冷却：4.5s

【白焰之墙】前方扇形白焰·持续8s
  启动：2.0s（单手拍地）·弹窗：地面白色纹路从手掌扩散
  范围：前方120°×8m·高度2m的白色火墙
  伤害：站上面每秒18伤害+灼烧(25/次)
  特殊：离卦真火斩可覆盖→白焰墙转化为金色安全区
  冷却：10.0s
```

## 三、通用AI工具函数

### 3.1 距离评估

```csharp
enum DistanceZone { Melee, Close, Mid, Far, OutOfRange }

DistanceZone EvaluateDistance(Vector3 enemyPos, Vector3 playerPos) {
    float dist = Vector3.Distance(enemyPos, playerPos);
    if (dist < 2.5f) return DistanceZone.Melee;      // 贴身
    if (dist < 6f)   return DistanceZone.Close;       // 近距离
    if (dist < 12f)  return DistanceZone.Mid;         // 中距离
    if (dist < 25f)  return DistanceZone.Far;         // 远距离
    return DistanceZone.OutOfRange;                    // 脱战
}
```

### 3.2 威胁评估（多目标时）

```
威胁值 = 距离权重(近+50%) × 伤害输出(最近3秒DPS) × 仇恨修正
  - 辰生当前锁定目标：仇恨×1.5
  - 最近攻击过此敌人的目标：仇恨×1.3
  - 生命最低的目标：仇恨×0.7（敌人倾向攻击威胁大而非残血的）
```

### 3.3 攻击选择权重

```
攻击选择 = 加权随机·不是纯随机：
  距离合适 + 冷却就绪 + 上次使用距今>最小间隔 → 候选攻击池
  从候选池中按权重随机选择（非均匀分布·高频攻击权重低·大招权重高但冷却长）
```

### 3.4 群战AI协调

同一场战斗中如果存在多个敌人：

```
群战槽位系统：
  - 槽位1(主攻)：1个·主动接近辰生·频繁攻击
  - 槽位2(远程)：1-2个·保持距离·远程攻击
  - 槽位3(待机)：其余·在外围巡逻·不主动攻击
  - 槽位1死亡→槽位3中仇恨最高的晋升至槽位1
  - 槽位2减少→槽位3优先补充远程

防止"所有敌人同时攻击"→给玩家操作空间
防止"所有敌人都在看戏"→保持战斗压力
```

## 四、弹窗（Telegraph）统一规范

所有敌人攻击前必须有可读的视觉/音频提示：

| 攻击类型 | 弹窗方式 | 弹窗时长 | 色系 |
|---------|---------|:--:|------|
| 普通攻击 | 武器/身体微光+前摇动画 | 0.2-0.4s | 白色 |
| 强力攻击 | 地面范围指示+蓄力动画+音效渐强 | 0.5-1.0s | 红色 |
| 不可格挡攻击 | 红色闪光+特殊音效 | 0.8-1.5s | 红色+震动 |
| BOSS大招 | 全屏提示+镜头拉远+BOSS台词 | 1.5-3.0s | 金色+全屏震动 |
| 伪卦攻击 | 卦盘白色闪烁+卦象符号短暂浮现 | 0.4-0.6s | 白色卦符 |

### 辅助选项

- **色盲模式：** 红色指示→改为形状指示（三角警告标志）+ 画面边框高亮
- **弹窗透明度：** 玩家可调（0-100%）
- **简化弹窗：** 关闭地面范围指示·仅保留敌人动画前摇
