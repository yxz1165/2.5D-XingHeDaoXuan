# 新手教程：卦象入门 —— 《星河倒悬》

---

## 1. Overview

本教程是辰星卦师（道士）职业的新手引导关卡。玩家在此学会**阴阳爻的识别与拖拽组合**，理解八卦基础，完成从「完全不懂卦」到「能自主选出想要的卦象」的第一次跨越。

**设计原则**：
- **零文字，全操作**：能拖拽的绝不用文字解释，能看的绝不要求读。
- **融于剧情**：教程伪装成一段「星轨残卷中的传承记忆」——辰生的母亲云岫留下的教学幻境。教程的叙事意义是"母亲在教孩子认字"，情感意义是辰生第一次与母亲隔时空对话。
- **循序渐进**：阴阳 → 四象 → 八卦 → 小六爻，每一步都是前一步的自然延伸。
- **拖积木交互**：阴阳爻如同积木块，从旁边的爻池拖入卦槽，拼出一个完整的卦。手感像搭乐高。

**触发时机**：序章结尾，辰生在落星村废墟中第一次打开《星轨残卷》时。玩家无法跳过——这是剧情的有机组成部分。

## 2. 剧情包装

### 2.1 场景设定

辰生跪在药铺的灰烬前，手中握着那本被烧掉边缘的《星轨残卷》。他翻开第一页。

页面上没有文字——只有一片流动的星辉。

星辉从书页中涌出，包裹了他的视线。当他重新睁开眼时，他不在落星村了。

他站在一片虚空之中——脚下是透明的，倒映着星辰。头顶也是星辰。四周悬浮着无数发光的符号，像萤火虫一样缓慢飘浮。那些符号他看不懂——有长的，有短的，有排列成某种图案的。

一个声音在虚空中响起。不是从耳朵听到的——是直接从脑海里响起的。

那是一个女人的声音。温暖，但遥远。像隔着厚厚的玻璃在说话。

> *"辰生。你打开了这本书，说明玄伯已经不在了。我是你的母亲，云岫。这不是真正的我——这是我在被镇压前，用最后的力量注入残卷中的一缕意识。我把它藏在这里，是因为我知道总有一天你会找到它。"*

> *"现在，闭上眼睛。我要教你认字。这些字——不是用笔写的。这些字叫'爻'。它们是星辰的语言。你手腕上的那道纹路，就是其中一爻。"*

辰生低头看自己的左手腕内侧——那道从小就在的青色六芒星纹路。在星辉中，它正在微微发光。

> *"来。跟着我。"*

### 2.2 叙事节奏

| 教程阶段 | 教学内容 | 剧情台词（云岫） | 情感节点 |
|---------|---------|----------------|---------|
| 登录 | 认识阴阳爻 | "这是'爻'。星辰的语言。” | 母亲第一次教孩子 |
| 四象 | 两爻组合 | "两根爻放在一起，就能说出四种话。" | |
| 八卦 | 三爻成卦 | "再往上加一根——这就是卦。八个卦，就是天地间八种最基本的力量。" | 从认字到造词 |
| 小六爻 | 六根爻的组合 | "六根爻叠在一起，就是'大成卦'。后面你会学到更多。" | 母亲的教学接近尾声 |
| 离别 | 教程结束 | "我剩下的意识不多了。记住这些，辰生。有一天你会用到的。去吧——去找到那十二个人。" | 母子隔时空的告别 |

## 3. 阶段一：认识阴阳爻

### 3.1 场景

虚空之中，辰生面前浮现出第一根**发光的长条形光柱**。

它长约一臂，悬浮在辰生面前，缓缓旋转。金色的光，温润不刺眼。

> *"这是阳爻。长长的一根。就像太阳——光明的、主动的、伸展开的。来，伸出手——摸摸它。"*

- **交互**：玩家移动鼠标，光标移到阳爻上时，阳爻微微膨胀，发出一声温暖的嗡鸣（类似大提琴的G弦）。点击 → 阳爻被"点亮"，亮度翻倍，云岫说："对了。这就是阳。"

阳爻收回，另一根浮现——**两截分开的短光柱**，中间有一个清晰的断口。

> *"这是阴爻。断开的。就像月亮——安静的、被动的、收束着的。你试试。"*

- **交互**：同上，点击后云岫说："对了。阳是长，阴是断。阳是一，阴是二。这是最根本的东西。"

### 3.2 验证：区分阴阳

画面同时出现两根爻——一根长的（阳），一根断开的（阴）。

> *"来，指给我看——哪一根是阳爻？"*

- **交互**：玩家点击其中一根。正确 → 那根阳爻化为一道金色粒子钻进辰生的左手腕纹路。错误 → 那根阴爻轻轻震一下，云岫说："不对。阳是长的。再试一次。"

成功通过后，辰生左手腕的第一条纹路被点亮。

### 3.3 交互设计细节

- 阳爻：一根连续的金色光柱，长度约 200px，宽约 20px，圆角。悬浮时有微弱的向外光晕。
- 阴爻：两根分开的金色光柱，每根长约 80px，中间断口约 40px，宽约 20px。悬浮时断口处有微弱的内缩光晕。
- Hover 音效：阳爻 → 低音嗡鸣（大提琴），阴爻 → 清脆的风铃声（三角铁）。
- 点击反馈：选中后爻柱短暂闪烁（0.3s），然后化为粒子飘向辰生的手腕。

## 4. 阶段二：认识四象（两爻组合）

### 4.1 场景

> *"一根爻只能分阴阳。两根爻放在一起，就有了四种变化。这叫'四象'。来，看我怎么做，然后你自己做一遍。"*

画面中出现一个**卦槽**——一个垂直的长方形凹槽，分为上下两格。每一格都是一个等高的矩形槽位，可以容纳一根爻（长条或断裂条）。

卦槽右侧出现一个**爻池**——一个半透明的圆形区域，里面漂浮着：
- 若干根**阳爻**（金色长条，∞ 符号表示无限取用）
- 若干根**阴爻**（金色断条，∞ 符号表示无限取用）

### 4.2 演示环节

云岫的声音先做一次演示：

> *"看好了。"*

一只由星光凝成的半透明手从爻池中取出一根阳爻，拖入上格。再取一根阳爻，拖入下格。

```
┌──────────┐
│  ━━━━━━   │  ← 上格：阳爻（☰ 的上半 = 阳）
│  ━━━━━━   │  ← 下格：阳爻（☰ 的下半 = 阳）
└──────────┘
  这是老阳
```

卦槽旁边的虚空中浮现四个大字：**老阳** —— 然后大字化为一个符号 `⚌`。

> *"两根阳爻——这叫'老阳'。太阳当空，万物生长。这是最旺盛的力量。"*

同样的演示重复四次：

| 组合 | 上格 | 下格 | 名称 | 符号 |
|------|------|------|------|------|
| 老阳 | 阳 | 阳 | 老阳 | ⚌ |
| 少阴 | 阳 | 阴 | 少阴 | ⚍ |
| 少阳 | 阴 | 阳 | 少阳 | ⚎ |
| 老阴 | 阴 | 阴 | 老阴 | ⚏ |

### 4.3 玩家实操

> *"该你了。来，自己做一个老阳。"*

- **交互**：爻池高亮，卦槽上格闪烁提示。玩家从爻池拖一根阳爻到上格（拖拽过程中爻条跟随鼠标，半透明），放入 → 咔嗒一声，上格填满。下格开始闪烁。拖入第二根阳爻 → 咔嗒。卦槽完整，闪烁绿光。四象符号 `⚌` 浮现。

> *"好。现在做一个少阴。"*

- 同样的交互，玩家需要拖入：上格阳爻 + 下格阴爻。

> *"你对阴阳的理解已经超过很多成年人了。我们再进一步。"*

### 4.4 拖拽交互细节

- **拖拽手感**：鼠标点击爻池中的爻 → 生成一个半透明跟随鼠标的爻条。鼠标移动到卦槽格位上方 → 格位边框亮起（吸附提示）。松手 → 爻条以弹性动画落入格位（0.2s，缓动曲线）。
- **错误提示**：如果拖入的爻类型不对（比如要求阳爻却拖了阴爻），爻条会被轻轻"弹"回爻池，格位短暂显示红色边框，无语音提示（鼓励自行纠正）。
- **音效设计**：
  - 拖起爻条 → 轻微的吸附声（类似磁铁分开）
  - 放入格位 → 木块嵌入的咔嗒声
  - 卦槽完整 → 钟磬一声（短促清脆）
  - 卦槽错误被弹回 → 低沉闷响

## 5. 阶段三：认识八卦（三爻成卦）

### 5.1 场景

卦槽扩展为**三格**（上、中、下）。

> *"四象再加一根爻——就成了八卦。三根爻，从上到下，分别代表天、人、地。来，我们现在开始正式学卦了。每一个卦我都给你出题，你来拼。"*

### 5.2 出题模式

云岫出一个卦名，玩家从爻池拖三根爻填入卦槽。

#### 题一：乾

> *"天。三根都是阳。这是最刚健的力量。来，拼一个乾卦。"*

```
┌──────────┐
│  ━━━━━━   │  上爻 ☰ —— 天
│  ━━━━━━   │  中爻 ☰ —— 人
│  ━━━━━━   │  下爻 ☰ —— 地
└──────────┘
     乾 ☰
```

玩家拖入三根阳爻 → 卦槽完成 → 乾卦符号 `☰` 在虚空中以金色大字浮现 → 化为一个天体投影（一个小太阳，金光四射）。

> *"乾——天行健，君子以自强不息。你父亲最喜欢这一卦。"*

#### 题二：坤

> *"地。三根都是阴。来，坤卦。"*

```
┌──────────┐
│  ━╍━━━   │  上爻 ☷ —— 天（阴）
│  ━╍━━━   │  中爻 ☷ —— 人（阴）
│  ━╍━━━   │  下爻 ☷ —— 地（阴）
└──────────┘
     坤 ☷
```

完成后 → 坤卦符号化为一片大地的投影（褐色土壤，微弱的绿色萌芽）。

> *"坤——地势坤，君子以厚德载物。这是我。这是织女。"*

#### 题三至题八：依次出题

| 题序 | 卦名 | 爻组合（从上到下）| 口诀 | 投影效果 |
|------|------|-------------------|------|---------|
| 3 | **震** ☳ | 阴+阴+阳 | 震——雷。动也。 | 一道闪电劈下 |
| 4 | **巽** ☴ | 阳+阳+阴 | 巽——风。入也。 | 一阵风卷起树叶 |
| 5 | **坎** ☵ | 阴+阳+阴 | 坎——水。陷也。 | 水波荡漾 |
| 6 | **离** ☲ | 阳+阴+阳 | 离——火。丽也。 | 火焰升腾 |
| 7 | **艮** ☶ | 阴+阴+阴→错，应为 阳+阴+阴 | 艮——山。止也。 | 山体隆起 |
| 8 | **兑** ☱ | 阴+阳+阳 | 兑——泽。说也。 | 湖水倒映星空 |

> 设计注：艮卦题目故意设为易错题——玩家可能惯性以为"三阴是坤、三阳是乾"，艮卦是"阳+阴+阴"打破了这个模式。云岫可以在此多给一句提示："注意——山不是纯阴。山顶需要一点阳。"这是教学节奏中制造微小波峰的手段。

### 5.3 变体：卦象找茬

完成八卦出题后，云岫提出一种新的测试方式：**卦槽中已经放好一个卦，但有一根爻是错的。找出错误并替换。**

> *"这个卦叫离——火。但是有人放错了。你看看，哪个爻不对？"*

卦槽中显示：阳+阴+阴（这是艮）。正确答案是：阳+阴+阳。

玩家点击错误的爻（第三爻），该爻高亮闪红 → 从爻池拖入正确的爻替换 → 离卦完成。

这是一个 **"认错"** 环节——不是从零拼，而是识别错误。更接近实战（实战中误选了错误的爻会得到意外的卦象效果）。

### 5.4 八卦速记表（教程内展示）

完成所有出题后，画面浮现八个卦的汇总。不是文字表——而是**交互式圆盘**：

```
         乾 ☰
     兑 ☱   巽 ☴
  离 ☲        坎 ☵
     震 ☳   艮 ☶
         坤 ☷
```

鼠标悬停任何一卦 → 该卦放大，三根爻依次亮起，旁边浮现卦名和单字提要。这是后面实战中"八卦盘"的简化预览版。

## 6. 阶段四：六爻成卦（上卦+下卦）

### 6.1 场景

卦槽扩展为**六格**（上下两组，每组三格）。

> *"八经卦是基础。但你接下来要遇到的卦，是六十四卦——由两个经卦重叠而成。上面的叫'上卦'，下面的叫'下卦'。六个空格，看起来多了——但你已经有基础了。上面三格是一个八经卦，下面三格是另一个。你只是在做两次你已经会了的事情。"*

### 6.2 示范：天火同人

云岫再次演示：

> *"天火同人——上卦是乾，下卦是离。"*

星光之手拖入：

```
上卦（乾 ☰）
┌──────┐
│ ━━━━ │ 阳
│ ━━━━ │ 阳
│ ━━━━ │ 阳
└──────┘

下卦（离 ☲）
┌──────┐
│ ━━━━ │ 阳
│ ╍━━  │ 阴
│ ━━━━ │ 阳
└──────┘

同人卦 ☰☲
```

> *"天在上，火在下。天是刚健的领导者，火是明亮的追随者。同人——大家心在一起，就是最亮的火。"*

### 6.3 玩家实操

出三道题，难度递增：

| 题序 | 卦名 | 上卦 | 下卦 | 提示 |
|------|------|------|------|------|
| 1 | **地山谦** | 坤 ☷ | 艮 ☶ | "上卦坤你刚才做过了。下卦艮——还记得山顶那一点阳吗？" |
| 2 | **火雷噬嗑** | 离 ☲ | 震 ☳ | 无提示。 |
| 3 | **水天需** | 坎 ☵ | 乾 ☰ | "上卦坎是水——上下阴中间阳。下卦是乾，简单。" |

每完成一题 → 卦象符号浮现 → 化为该卦的投影（同人卦 = 一片聚集的萤火虫；谦卦 = 一座谦卑低伏的山丘；噬嗑卦 = 一道咬合的闪电）。

### 6.4 错误反馈

- 上卦正确 + 下卦错误 → 下卦三格闪红，爻池中该卦所需爻的类型闪烁提示（仅第一次错误时提示，之后不再提示）。
- 上下卦整体错误 → 卦槽整体闪红，云岫说："不对。再来一次。从上卦开始——注意每一爻。"

## 7. 阶段五：快速占卜——小六爻

### 7.1 场景

> *"六十四卦太慢——战斗中敌人不会等你把六个格子填满。所以，我教你一个快的——小六爻。不需要填格子了——你只需要甩一下手。"*

画面切换：六格卦槽消失。取而代之的是围绕辰生的**六个光环区域**（就是实战中的小六爻界面）。

> *"六个方向——六个答案。甩过去，就是占卜。来，试试——甩向'速喜'（右上），给自己加速。"*

### 7.2 交互

- 时间进入轻度减速（50%），六个区域的光环围绕角色。
- 玩家移动鼠标到右上区域（速喜光环高亮） → "松手"（教程提示文字）→ 角色获得速喜 buff（金色粒子环绕，持续10s）。

> *"对。战斗中感觉到危险，就往'空亡'甩——正下方——你可以瞬间向后闪出一段距离，还能隐身一瞬。试一下。"*

- 玩家甩向下方 → 角色后跳+隐身 → 云岫："对。这就是'退'——但退是为了下一步的'进'。"

### 7.3 小六爻实战模拟

> *"现在来一次真的。我会派一个幻影来追你。你判断一下——该用什么？"*

一个半透明的星光人影出现在场景中，向辰生走来。速度中等。

**正确答案**：往下甩（空亡后退），或者往右上甩（速喜加速跑开）。

玩家完成后，幻影消失。

> *"好。你在战斗中不会离开这四个爻位——速喜（追）、空亡（退）、留连（控）、小吉（爆）。这四个就是你的本能。记住了，就不用想了。"*

## 8. 阶段六：告别

### 8.1 场景

虚空开始变得不稳定。星辰的光芒在闪烁。云岫的声音变得断断续续。

> *"我……剩下的力量不多了。你还记得我们学了什么吗？"*

画面依次出现玩家在本教程中完成的每一个卦的符号——乾、坤、震、巽、坎、离、艮、兑——每一个符号浮现时，对应卦槽中玩家亲手拼出的爻条会短暂重现。

> *"这些不是符号。它们是活的。乾不是三个'长条'——它是一种从下往上推的力量。坤不是三个'短条'——它是一种承托万物的温柔。你以后会懂的——在战斗中，在遇到那些人的时候。"*

> *"辰生。我走之前，最后告诉你一件事。你左手腕上的纹路——不是六芒星。它是'爻'的首笔。是织女的丝线。当你把这十二道纹路全部点亮，你就能重新织出被扯断的因果。"*

画面聚焦辰生的左手腕——上面亮着第一道纹路。纹路在发光，温润的星光。

> *"去星纪宫。极北之地。那里有第一个人——荧惑星君，锻锋。去找他。剩下的，边打边学。"*

### 8.2 教程结束过渡

虚空退去。星光消散。辰生重新站在落星村的废墟中。

手中，《星轨残卷》的第一页，不再是空白——上面浮现了八卦图。八个符号，静静地印在泛黄的纸页上。

## 9. 交互设计规范

### 9.1 爻条视觉规格

| 属性 | 阳爻 | 阴爻 |
|------|------|------|
| 长条长度 | 200px | 2× 80px（中间间距 40px） |
| 宽度 | 24px | 24px |
| 圆角 | 12px | 12px |
| 颜色（默认）| 金色 #F0D060 | 金色 #F0D060 |
| 颜色（hover）| 亮金 #FFE890 + 外光晕 | 亮金 #FFE890 + 外光晕 |
| 拖拽中 | 半透明 70% + 跟随鼠标 | 同上 |
| 幻影（预放置位） | 半透明 30%，脉动闪烁 | 同上 |

### 9.2 卦槽视觉规格

| 属性 | 值 |
|------|-----|
| 总尺寸 | 240px 宽 × 360px 高（六格）或 180px 高（三格） |
| 单格尺寸 | 220px × 44px |
| 边框 | 2px 金色 #B8860B，内发光 |
| 填充后 | 边框变为亮金色，内部浮现弱星光粒子 |
| 错误闪烁 | 边框变红 #FF4444，持续 0.5s |

### 9.3 爻池视觉规格

| 属性 | 值 |
|------|-----|
| 位置 | 屏幕右侧，卦槽右侧 80px |
| 形态 | 圆形区域，直径 300px，边缘虚化 |
| 内容 | 阳爻条 × ∞（池中随机浮动 3-5 条），阴爻条 × ∞ |
| 拖拽生成 | 从池中拖出一条，池中立即刷新一条（∞取用） |

### 9.4 音频设计

| 事件 | 音效 | 频率/时长 |
|------|------|---------|
| 爻条拖起 | 吸附分离声（磁铁） | 0.1s |
| 爻条放入格位 | 木块嵌入咔嗒声 | 0.15s |
| 卦槽完整 | 钟磬一声（C5 音，短促） | 0.3s |
| 错误被弹回 | 低沉闷响（G3 音） | 0.2s |
| 云岫说话时 | 背景有低沉的星光嗡鸣（持续音垫） | 持续 |
| 虚空环境 | 微弱的星尘叮当声（随机，似玻璃风铃） | 间歇 |

## 10. 边缘情况

### 10.1 玩家不会拖拽

- 教程在拖拽环节开始前，自动演示一遍拖拽操作（星光之手演示）。
- 如果玩家在 10 秒内没有执行拖拽 → 爻池中的目标爻自动高亮 + 卦槽目标格位闪烁 + 屏幕上浮现半透明鼠标图标做"拖拽手势"。
- 30 秒无操作 → 云岫温柔地说："不着急。用手指按住那条长的，拖过去就行。"

### 10.2 玩家反复拼错

- 前两次错误 → 云岫给提示。
- 第三次错误 → 云岫说："来，我再做一次给你看。" → 自动演示。
- 第四次错误 → 目标爻在爻池中高亮脉冲 + 卦槽格位闪烁 + 画面用 30% 透明度的爻条显示正确放置位置（"作弊提示"）。
- 第五次错误 → 自动完成该题，云岫："没关系。有些东西需要时间。我们下一题。"

### 10.3 玩家想跳过教程

- 教程不可跳过（首次通关必须经历——这是剧情的一部分）。
- 但有快速通道：在任意出题环节，如果玩家连续 3 次秒选正确（总用时 < 1s），该阶段剩下的题自动跳过。
- 二周目（新游戏+）：教程自动跳过，直接进入正常游戏。

### 10.4 不同输入设备

| 设备 | 拖拽操作 | 选卦操作 |
|------|---------|---------|
| 键盘+鼠标 | 鼠标左键拖拽 | 鼠标移动选择 |
| 手柄 | 左摇杆移动光标 + A 按住拖拽 + 释放 | 右摇杆选择方向 |
| 触摸屏（预留） | 手指直接拖拽 | 手指滑动选择 |

## 12. 验收标准

1. **零知识可完成**：从未接触过易经的玩家，在不查阅外部资料的情况下，能在教程结束时独立拼出乾、坤、离三个卦。
2. **拖拽交互流畅**：爻条从爻池到卦槽的拖拽全程无卡顿、无判定失败，吸附范围 ≥ 30px。
3. **阴阳区分准确率**：教程结束时，玩家区分阴阳爻的准确率 ≥ 95%（即最多错一次）。
4. **情感共鸣**：教程结束时，玩家能记住云岫的至少一句台词（在后续测试中通过问卷调查验证）。
5. **时间控制**：慢速玩家（阅读理解困难）完成全程 ≤ 15 分钟，快速玩家 ≥ 5 分钟。
6. **不可跳过但有快通道**：达人玩家在 5 分钟内完成全部出题，教程不应产生任何拖沓感。
7. **剧情一致**：教程中的所有对话与《剧情大纲》中云岫的人设一致——温暖、坚定、实事求是。
8. **可随时复习**：教程结束后，玩家打开《星轨残卷·爻象入门》可以重新进入"练习模式"（仅出题环节，无剧情对话，可无限次重玩）。

---

> **设计总结**：这不是一个教程——这是母亲教孩子识字。玩家在教程中感受到的不应该是"我被教了卦"，而是"我想认识母亲教给我的这些符号"。当第八章实沉宫云岫的完整记忆苏醒时，玩家会想起这个虚空——他曾经在这里，和她一起，拼过那些发光的积木。
