## 一、世界观

### 上古
银河神族居于天穹之上，掌管黄道十二宫，维持天地秩序。

### 坠落
一场变故，神族下凡，散落人间，记忆被封，神力沉寂，化作凡人。

### 篡改
某个势力趁神族沉寂，重写历史、抹去真相——好比清朝修《四库全书》，「寓禁于修」，把真实埋在正统叙事的底层。

### 如今
世间流传的「神话」只是残片，真正发生过的事被掩盖了。

---

### 明线：救母
类似「沉香劈山救母」。  
- 主角的母亲被镇压，魂魄分散封印在黄道十二宫之中。  
- 主角踏上旅程，闯十二宫，收集母亲魂魄碎片，最终劈开封印。  
- 情感驱动：亲情，朴素直接，不需要任何前置知识就能被打动。

### 暗线：唤醒神族
- 每闯过一宫，不止解救母亲一缕魂魄，同时也在唤醒一位沉睡的银河神族。  
- 这些神族散落人间，以凡人身份生活，早已忘记自己是谁。  
- 你需要找到他们、唤醒记忆、帮助他们通过试炼、重获神力。  
- 黄道十二宫 = 十二位神族成员的沉睡/试炼之地。

### 真相
- 那个「篡改历史的势力」一直在阻止神族觉醒。  
- 母亲之所以被镇压，不是因为她犯了错——是因为她拒绝遗忘，她是最后一个记得真相的人。

## 二、全局操作规范（全职业通用）

所有职业共用同一套按键基底，支持键鼠与手柄，核心原则为**减负 + 高上限**。

### 键鼠方案

| 操作 | 按键 | 功能 |
| :--- | :--- | :--- |
| 移动 | `W` `A` `S` `D` | 控制角色移动 |
| 闪避/翻滚 | `空格` | 带无敌帧 |
| 对话/交互 | `F` | 与NPC、物品互动 |
| 普通攻击 | `鼠标左键` | 连续攻击，可被技能取消后摇 |
| 职业核心机制 | `鼠标右键` | 短按/长按触发不同效果，各职业特殊交互（格挡/瞄准/演卦/部署/曲风等） |
| 高频技能 | `Q` `E`  |
| 核心/辅助/冷却技能 | `1` `2` `3` `4` | 同上，由长按鼠标右键触发底层核心技能组，第一次按是触发，第二次是一次完整组合，按两次为完整一组，每个职业都有不同的组数，是核心的技能链设计，通常为冷却型、召唤型或功能型技能 |

### 手柄方案

| 操作 | 手柄 (Xbox 布局) |
| :--- | :--- |
| 移动 | 左摇杆 |
| 视角/瞄准 | 右摇杆 |
| 闪避 | `A` |
| 对话/互动 | `X` |
| 普通攻击 | `RB` |
| 职业核心机制 | `RT` 或 `LT` |
| 技能 `Q` / `E` | `Y` / `B` |
| 技能 `1-4` | 方向键 或 `LB`+`ABXY` 组合键 |

> 设计要点：所有职业的核心机制统一在鼠标右键/手柄扳机键上，极大减少记忆成本。  
> 高频技能 `Q` `E` 使用无名指/食指操作，在WASD移动中也可即时触发。  
> `1-4` 为低频技能，手指短暂离开移动键不影响生存。

## 三、十位银河神族职业设计

每一位职业都对应一位沉睡的星君，其战斗机制与他的神职、记忆碎片紧密相关。  
所有技能均采用 **短按 / 长按** 双形态设计，按键数量少而表现丰富。

---

### 1. 荧惑星君 · 战士

**象征**：火星，征伐与火。  
**核心机制（鼠标右键）**：**盾牌格挡**。按住右键可吸收正面伤害，精准格挡成功可触发强力反击。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **破甲斩** – 削减敌人防御 | **盾牌猛击** – 眩晕、造成硬直 |
| `E` | **冲锋** – 快速接近目标 | **旋风斩** – 旋转攻击周围敌人，期间可移动 |
| `1` | **战吼** – 提升自身和队友攻击力 | **嘲讽战吼** – 强制周围敌人攻击自己 |
| `2` | **裂地斩** – 前方直线冲击波 | **跳劈** – 跃起后砸向目标区域，范围伤害 |

---

### 2. 岁星巡狩 · 弓箭手

**象征**：木星，生机与巡游。  
**核心机制（鼠标右键）**：**瞄准蓄力**。按住右键拉弓蓄力，伤害随蓄力时间增加，蓄力期间可移动（移速降低）。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **后跳射击** – 向后位移并对身前敌人射出一箭 | **散射** – 射出扇形多支箭 |
| `E` | **切换箭矢** – 循环切换：普通箭 → 火焰箭 → 冰霜箭 → 雷电箭 | **元素箭雨** – 向鼠标指向区域倾泻当前元素箭矢 |
| `1` | **标记射击** – 标记一个敌人，攻击被标记目标伤害提升 | **多重标记** – 标记更大范围 |
| `2` | **鹰灵伙伴** – 召唤一只鹰协助攻击 | **鹰眼** – 短时间内极大提升暴击率 |

---

### 3. 太白剑仙 · 剑士

**象征**：金星，肃杀与锋芒。  
**核心机制（鼠标右键）**：**剑气 / 居合**。短按右键释放中距离剑气斩；长按右键收刀蓄力后释放一闪，伤害极高且带穿透。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **突刺** – 向前快速刺击 | **升龙斩** – 使敌人浮空 |
| `E` | **回旋斩** – 360°攻击，可取消其他技能后摇 | **剑舞** – 连续斩击，期间可移动 |
| `1` | **影步** – 向鼠标方向瞬移一段距离 | **残影** – 在原地留下幻影吸引敌人 |
| `2` | **剑阵** – 召唤数把飞剑围绕自身，对触碰敌人造成伤害 | **万剑归宗** – 将飞剑射出，攻击前方大范围 |

---

### 4. 辰星卦师 · 道士

**象征**：水星，智慧与卦象。  
**核心机制（鼠标右键）**：**演卦状态**。按住右键时间减速，显示八卦盘。  
**卦象输入**：使用 `1` `2` `3` `4` 键输入卦象，短按为阳卦，长按为阴卦。  

**八卦映射**：  
`1`：乾(☰) / 坤(☷)  
`2`：兑(☱) / 巽(☴)  
`3`：离(☲) / 坎(☵)  
`4`：震(☳) / 艮(☶)  

**施法流程**：按住右键 → 依次输入上卦、下卦 → 松开右键或自动施放对应64卦技能。  

**辅助技能**：

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **重复上次卦象** – 瞬间释放上一次施放的卦象 | **逆转卦象** – 上下卦互换 |
| `E` | **卦象切换** – 循环切换预存卦象 | **卦盘重置** – 取消当前输入 |

> 新手辅助：屏幕可开启卦象提示面板，显示当前按键对应的卦名。  
> 高手深度：通过连续卦序打出复杂的卦变连击，形成破防、浮空、斩杀等连锁。

---

### 5. 计都星使 · 刺客

**象征**：隐曜，暗与终结。  
**核心机制（鼠标右键）**：**暗影步**。短按右键向鼠标位置瞬移；长按右键进入隐身状态（持续消耗精力）。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **封喉** – 对目标进行背刺，暴击加成 | **影缚** – 投掷锁链束缚敌人 |
| `E` | **撒菱** – 在地面铺设铁蒺藜，敌人踩中减速并流血 | **烟幕** – 投掷烟雾弹，降低周围敌人视野 |
| `1` | **暗器·袖箭** – 中距离飞镖 | **暗器·飞蝗** – 多发飞镖 |
| `2` | **影分身** – 制造一个分身吸引火力 | **影杀阵** – 分身爆炸，造成范围伤害 |

---

### 6. 镇星大将 · 将军

**象征**：土星，稳固与守护。  
**核心机制（鼠标右键）**：**令旗指挥**。按住右键出现环形指令盘，移动鼠标选择“进攻”“固守”“撤退”等指令，影响场上友军行为。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **横扫千军** – 前方扇形范围攻击 | **据守** – 进入防御姿态，减伤并反弹伤害 |
| `E` | **战旗投掷** – 投掷战旗，范围内友军强化 | **集结号令** – 将附近友军召唤至身边 |
| `1` | **擂鼓** – 提升全军攻击和移动速度 | **鸣金** – 全军短暂无敌 |
| `2` | **铁壁阵** – 生成一个护盾力场 | **冲锋阵** – 指挥部队向前推进，造成群体击退 |

---

### 7. 神机星君 · 墨家机关师

**象征**：造物，工巧与智慧。  
**核心机制（鼠标右键）**：**部署弩炮台**。按住右键在鼠标位置部署一个自动炮台，最多同时存在2个。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **机关飞鸢** – 发射直线飞行的机关鸢，命中爆炸 | **雷击** – 引导一道闪电攻击前方，眩晕敌人 |
| `E` | **机关冲车** – 召唤冲车直线冲锋，击退路径敌人 | **墨守之盾** – 为自身和附近炮台套上护盾 |
| `1` | **机关犬** – 召唤自爆机关犬冲向敌人 | **强化指令** – 短时间内大幅强化所有机关造物 |
| `2` | **捕兽夹** – 在脚下放置夹子，敌人踩中禁锢 | **机关矩阵** – 在目标区域生成减速力场 |

---

### 8. 玄冥星君 · 阴阳家符师

**象征**：阴阳，诅咒与赐福。  
**核心机制（鼠标右键）**：**画符**。按住右键可在鼠标画出简单图形（可预设），根据图形施放对应符法。新手可使用预设符。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **五雷符** – 对单体敌人造成雷击 | **引雷符** – 为自己附雷，普攻附带雷电 |
| `E` | **替身符** – 在原地放置符咒替身吸引敌人 | **神行符** – 短时间内大幅提升移动速度 |
| `1` | **失魂符** – 诅咒敌人降低攻击力 | **惊心符** – 诅咒敌人，使其持续恐惧 |
| `2` | **回春符** – 治疗自身或队友 | **金刚符** – 为自己施加无敌，持续1秒 |

---

### 9. 天音星君 · 舞乐家

**象征**：音乐，光环与元素。  
**核心机制（鼠标右键）**：**切换曲风光环**。短按右键循环切换：破阵乐（攻击光环）→ 清平乐（治疗光环）→ 霓裳曲（速度光环）。长按右键蓄力施放当前曲风的终结技。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **云锣惊弦** – 前方音波攻击 | **反弹琵琶** – 持武器旋转，击退周围敌人 |
| `E` | **胡旋舞步** – 短距离闪现，可穿怪 | **公孙剑舞** – 化为剑光穿梭，对路径敌人造成多次伤害 |
| `1` | **鼓动** – 提升自身和队友攻击力 | **琴心** – 持续消耗精力，大幅增强光环效果 |
| `2` | **箜篌引** – 将周围敌人拉向自己并减速 | **编钟轰鸣** – 召唤巨大编钟砸下，造成大范围眩晕 |

---

### 10. 地隐星君 · 方术士

**象征**：大地，丹术与近战爆发。  
**核心机制（鼠标右键）**：**炼丹 / 引爆**。战斗中获得丹砂资源。长按右键消耗丹砂炼制一颗金丹环绕自身（最多3颗）；短按右键引爆所有金丹，造成巨额伤害。  

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `Q` | **朱砂掌** – 用沾满丹砂的双手前推，扇形火焰伤害 | **水银泻地** – 向前方地面甩出水银，持续伤害并减速 |
| `E` | **金石为开** – 冲拳，若击杀敌人立刻恢复一颗金丹 | **铅汞囚笼** – 用铅汞之力禁锢周围敌人并拉至面前 |
| `1` | **五石散** – 服用后狂暴，攻击攻速提升但持续掉血 | **沸血散** – 投掷毒药，使地面敌人中毒并降低治疗效果 |
| `2` | **雄黄护体** – 释放雄黄之雾，清除自身异常并短期免疫debuff | **磁石引** – 将所有近距离敌人拉拢到一点并眩晕 |

## 四、设计验证与总评

### 1. 减负与操作流畅度
- 所有职业的核心操作键仅 `Q` `E` + `鼠标右键`，上手难度与主流动作游戏持平。  
- `1-4` 为低频技能，使用间隔合理，手指短暂离开WASD不影响移动与生存。  
- 长短按判定时间为0.2秒，体感清晰，避免误触。  

### 2. 职业深度与上限
- 每个职业均通过“短按/长按”将单键信息量翻倍，但记忆模型符合直觉（长按多为蓄力、强化或范围技）。  
- 道士64卦系统通过“重复上次卦象”的 `Q` 键为新手提供拐杖，高手可打出复杂卦序连击。  
- 符师画符、将军指挥等机制同样提供预设与自定义双轨，确保入门容易，精通极难。  

### 3. 动作游戏节奏
- 道士演卦减速、弓箭手蓄力移速惩罚等设计，创造了“子弹时间”思考窗口，不破坏割草爽感。  
- 战士格挡反击、剑士连招取消、刺客隐身背刺等，提供了高风险高回报的即时满足感。  

### 4. 平台兼容
- 整套操作逻辑可无缝迁移至手柄，所有职业机制均通过左摇杆移动 + 扳机键 + 面键实现，已通过内部映射验证。  

### 5. 文化与玩法统一
- 技能名称与机制均源自中国文化符号（八卦、丹砂、五石散、编钟、令旗……），让玩家在操作中自然感受东方幻想底蕴。  
- 星君记忆与战斗风格绑定，角色成长即是找回被篡改的历史真相，玩法与叙事高度统一。
