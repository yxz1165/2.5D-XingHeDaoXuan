## 二、宝箱系统

### 2.1 宝箱品类

| 品级 | 外观 | 分布 | 内容 | 开启方式 |
|------|------|------|------|------|
| **木箱** | 普通木箱·铁箍 | 野外·副本普通区 | 铜钱(20-50)·基础丹药·采集材料 | 走到→按F·直接开 |
| **铜箱** | 铜制·雕花 | 副本深处·精英怪附近 | 铜钱(50-150)·法器铭刻材料·配方 | 走到→按F·直接开 |
| **银箱** | 银制·机关锁 | 道宫·隐藏房间 | 星晶(1-2)·稀有铭刻·法器进阶材料 | 走到→按F·需要钥匙或解谜 |
| **金箱** | 金制·卦纹 | 道宫BOSS区域外 | 星晶(3-5)·同伴武器·稀有法器 | 需要特定卦术+解谜 |
| **卦占宝箱** | 埋在地下·不挖看不到 | 野外·特殊位置 | 铭刻精华·星图碎片·古老卦辞 | **三钱摇卦定位→挖掘** |

### 2.2 卦占宝箱——三钱摇卦嵌入探索

这是把"三钱摇卦"从战前占卜扩展为探索工具的关键设计。

```
卦占宝箱的完整发现流程：

1. 发现线索
   大地图探索中→地上出现微弱的金色闪光点（持续3秒·间隔30秒再闪一次）
   走到闪光点附近→辰生自动说："这里……有什么东西。"
   打开背包→选择三钱→站在闪光点上摇卦

2. 摇卦定位
   站在闪光点上→按F→选"摇卦寻宝"（不是战前占卜·是寻宝模式）
   同样甩6次铜钱→但这次不问"启示"——问的是"方位"
   
   六爻结果→卦象自动解读为方向和距离：
   ┌────────────────────────────────────┐
   │  卦象：风地观 ䷓                    │
   │                                    │
   │  宝在：西北方·约四十步              │
   │  深度：三尺                        │
   │  提示：近水                        │
   │                                    │
   │  （小地图上出现一个金色问号标记）     │
   └────────────────────────────────────┘

3. 按指示寻找
   小地图上出现金色问号标记（不精确·大致范围R=8m的模糊区域）
   走到标记区域→梅花易数（长按F）→地面出现金色裂纹→
   裂纹最密集的地方→按F挖掘→卦占宝箱出现

4. 打开宝箱
   宝箱从地下冒出→金色光柱一闪→箱子落地→按F打开
   内容：稀有物品（不会出现的普通宝箱里的东西）
```

#### 卦占宝箱的奖励梯度

| 卦象难度 | 定位精度 | 宝箱品级 | 奖励 |
|---------|:--:|:--:|------|
| 本卦+变卦都有 | 精确·R=3m | 金箱级 | 星晶×3-5·铭刻精华·星图碎片 |
| 只有本卦 | 中等·R=8m | 银箱级 | 星晶×1-2·铭刻材料 |
| 摇错了重摇 | 模糊·R=15m | 铜箱级 | 大量铜钱·丹药配方 |

> **设计意图：** 摇卦不是"必出宝物"——是你的卦术水平决定了寻宝效率。高手一卦精准定位·新手需要多摇几次。

### 2.3 宝箱分布数据

| 区域类型 | 宝箱总数 | 普通 | 卦占宝箱 | 银箱 | 金箱 |
|------|:--:|:--:|:--:|:--:|:--:|
| 每个野外区域 | 8-12 | 5-7 | 2-3 | 1 | 0 |
| 每个普通副本 | 3-5 | 2-3 | 0-1 | 1 | 0 |
| 每座道宫 | 6-10 | 0 | 3-4 | 2-3 | 1 |
| **总计** | ~200 | ~120 | ~45 | ~25 | ~12 |

## 三、梅花易数探索系统

### 3.1 观象（长按F·非战斗）

```
基础功能（序章解锁）：
  长按F → 辰生闭眼 → 画面变成黑白+微蓝色调
  → 20m范围内的隐藏要素以蓝色轮廓显现
  → 持续消耗卦气·每秒3点
  → 松开F → 画面恢复正常·发现的要素在小地图上短暂标记(30秒)

显现的要素：
  ✅ 隐藏洞穴入口（墙壁上出现蓝色裂纹）
  ✅ 暗门（地面/墙壁上出现蓝色方框）
  ✅ 埋藏物品（地面出现蓝色光点）
  ✅ 可破坏墙壁/障碍（碎石堆泛蓝光）
  ✅ 敌人脚印（追踪支线目标时用）
  ✅ 残碑文字（碑上浮现蓝色文字）
```

### 3.2 进阶能力（大梁宫解锁）

```
进阶观象（大梁宫·"去伪存真"后解锁）：
  - 范围扩大到40m
  - 卦气消耗降到每秒1点
  - 可以"看穿"幻象墙壁
  - 可以识别NPC是否说谎（对话时NPC的轮廓显示颜色：蓝=真话·红=谎言）
  - 可以看穿宝箱的"陷阱"（木箱里有机关=红光）
```

### 3.3 梅花易数与卦术的联动

| 卦术 | 观象联动效果 |
|------|------------|
| 离卦在身 | 观象时隐藏宝箱显示为金色（比蓝色更明显） |
| 巽卦在身 | 观象范围+10m（风送远方信息） |
| 坎卦在身 | 观象时水中的隐藏要素也能看到（原本不可见） |
| 坤卦在身 | 埋藏物品的深度提示（"三尺"→"一尺"·更容易找到） |

## 四、环境交互与破坏

### 4.1 可破坏物

| 物品 | 破坏方式 | 掉落 |
|------|---------|------|
| **木箱/木桶** | 普攻·任意卦术 | 铜钱(5-15)·丹药·偶尔有惊喜 |
| **碎石堆** | 乾卦·震卦 | 矿石·有时后面有隐藏通道 |
| **枯井覆盖** | 艮卦震开 | 井下可能有宝箱或副本入口 |
| **冰墙** | 离卦融化 | 冰封的物品/通道 |
| **毒藤** | 离卦烧掉 | 被藤蔓封住的入口 |
| **幻象墙壁** | 梅花易数看穿·普攻通过 | 隐藏房间 |
| **锁住的铁门** | 需要钥匙·或乾卦重击破门 | 宝箱·精英怪 |

### 4.2 环境陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| **落石区** | 地面有阴影+碎石滚落声 | 闪避躲开·艮卦格挡 |
| **毒气区** | 绿色雾气·持续掉血 | 坤卦净化·石翁大地净化 |
| **冰裂缝** | 地面冰纹·踩上崩裂 | 速喜加速跑过·巽卦飘过 |
| **火焰机关** | 墙上喷火口·规律间歇 | 坎卦灭火·看准节奏跑过 |
| **绊索** | 地面细线·梅花易数可见 | 跳过·或故意触发让追兵中招 |

### 6.1 采集点

| 类型 | 分布 | 用途 | 刷新 |
|------|------|------|------|
| 草药 | 野外·森林·山地 | 炼丹 | 每过一座道宫刷新 |
| 矿石 | 山脉·洞穴·副本 | 法器锻造·铭刻 | 每过两座道宫刷新 |
| 特殊材料 | 道宫内部·不刷新 | 稀有制作 | 不刷新·一次性的 |
| 同伴礼物 | 各区域隐藏 | 提升同伴好感度 | 不刷新 |

### 6.2 采集动效（俯视角）

```
走到采集点前→辰生头上出现"🌿"图标→按F→
  - 草药：辰生蹲下·手前出现摘取动画·草药消失→背包+1
  - 矿石：辰生用剑敲击·矿石碎裂→背包+N
  - 特殊：辰生蹲下观察→特殊材料浮空→背包+1（有特殊音效和金光）
  
总时间：约1秒·不打断游戏节奏
```

## 七、支线任务系统

### 7.1 任务类型

| 类型 | 触发方式 | 数量 |
|------|---------|:--:|
| **NPC委托** | 与城镇/驿站NPC对话 | ~20 |
| **同伴任务** | 好感度达到一定等级·在落星村触发 | ~12 |
| **悬赏任务** | 在星碑处的悬赏板接取 | ~15 |
| **探索发现** | 发现隐藏地点/物品自动触发 | ~10 |
| **世界事件** | 特定条件（时间/进度/天气）触发 | ~8 |

### 7.2 支线任务示例

```
【失踪的猎人】— 北冥冰原·驿站老人
  触发：与冰原驿站的老人对话
  任务：找到在冰裂缝带失踪的猎人
  
  流程：
    1. 老人："我儿子三天前去了冰裂缝带·没回来。"
    2. 前往冰裂缝带→梅花易数→发现猎人脚印
    3. 跟随脚印→发现猎人被困在冰裂缝底部（周围有冰原狼）
    4. 击败冰原狼→与猎人对话→猎人腿受伤
    5. 选择：
       - 护送猎人回驿站（步行·沿途保护不受狼攻击）
       - 给猎人小吉卦术回复·让他自己走回去（消耗卦气20）
  
  奖励：铜钱×100·冰抗丹药×3·驿站老人以后商品打8折

【逃兵的信】— 北冥冰原·受伤的太史兵
  触发：在太史阁哨站附近找到受伤的太史逃兵
  任务：替他把一封信送到苍梧之森的林间药庐·给他娘
  
  流程：
    1. 逃兵："求求你……把这封信送到苍梧之森……给我娘。"
    2. 去苍梧之森→找到林间药庐→交给老妇人
    3. 老妇人打开信→信中揭露太史阁的内部腐败→
       老妇人："我儿没有白死。"
    4. 获得：太史阁内部情报（揭示大梁宫推演机的秘密）
  
  奖励：剧情的钥匙·解锁大梁宫进入线索
```
