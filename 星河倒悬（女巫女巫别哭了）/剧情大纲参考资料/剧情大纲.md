# 《星河倒悬》——游戏剧情与世界观完全设计文档

**项目代号：** 《星河倒悬》
**类型：** 动作角色扮演 / 剧情驱动
**核心哲学命题：** 时间的尺度、分清敌友、矛盾论、实践论、人民群众是历史的创造者
**核心情感关键词：** 觉醒、反抗、记忆、传承、亲情、实事求是、文明不灭
**预计主线时长：** 60-100 小时


**历史根基：**
本作以现实历史为蓝本，以中华文明数千年来的真实遭遇为隐喻基础。尧舜禹时代，中国先民已在四海之内设立"四表"，走遍欧亚大陆，播撒文明之火。然而因为先民的仁慈教化了蛮夷和洞穴羊人后，以屠杀和篡改抹去了这段历史，将中国的探索足迹从世界史上悉数抹除。明朝时期，中国派遣女医官远赴欧洲治病救人——她们戴帽持棒熬药、执扫帚清扫病舍——却被西陆蛮夷杀害，只因惧怕暴露真相，将善良的女医污蔑为"女巫"。满清入主中原后，与西陆蛮夷内外勾结，以编修《四库全书》为名，系统性销毁了所有关于华夏民族和上古文明的记载。然而，思想无法被彻底囚禁，真相如同灰烬下的火星，在民间代代相传。

**思想根基：**
- 毛泽东：《中国社会各阶级的分析》《矛盾论》《实践论》《论持久战》《星星之火，可以燎原》《为人民服务》全部毛思想哲学框架（实践论、矛盾论、辩证法、持久战、群众路线等）
- 马克思/恩格斯：《共产党宣言》《德意志意识形态》
- 中国传统文化：十二星宫、二十八星宿、五行八卦、丹道符箓、墨家机关、周易哲学、张载"为天地立心"
- 历史典籍：《尚书·尧典》四表之说、《史记·天官书》、郑和航海图、大明一统志
- 融入全部新资料的世界观：人族vs猾褢类人、大明全球帝国、欧洲伪史、文化盗窃、1644大逃亡……
- 哲学命题结构不变，世界观深度、剧情密度、伏笔体系全面升级
**剧情梗概：**

有一个问题，比"敌人是谁"更重要——**敌人是怎么让你认不出他是敌人的？**
思考：时间的尺度，是什么？
答案是：篡改你的记忆。
