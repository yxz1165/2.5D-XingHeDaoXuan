# 卦码视觉显示分析——屏幕上的八卦能多大、多清楚

> ䷀ 这个字符在1080p屏幕上用72号字显示——大概2.5厘米高。用200号字——大约7厘米。它是标准Unicode字符，和汉字、英文字母一样受字体渲染管线处理，放大缩小不会像素化。

---

## 一、基础事实：八卦字符的物理尺寸

### 1.1 字号→实际尺寸换算

```
72pt = 1英寸 = 2.54cm（印刷标准）
屏幕显示时取决于屏幕PPI（像素密度）：

1080p·24寸显示器（≈92 PPI）：
  12pt → 约4mm   → 勉强可辨认（和汉字最小可读尺寸相同）
  18pt → 约6mm   → 舒适阅读
  24pt → 约8mm   → 清晰
  36pt → 约13mm  → 醒目
  48pt → 约17mm  → 标题级
  72pt → 约25mm  → 大幅展示
  120pt → 约42mm → 占屏幕高度约1/6
  200pt → 约70mm → 占屏幕高度约1/4

4K·27寸显示器（≈163 PPI）：
  同样pt数 → 物理尺寸相同（因为pt是物理单位，系统自动换算像素）
  12pt → 约27px实际渲染像素（4K下）
  在4K下，12pt字符和1080p下12pt字符的物理尺寸完全相同
```

### 1.2 关键结论

**八卦字符可以放大到任意尺寸——它是矢量字体，不会像素化。** 和中文汉字一样，从8pt到800pt都可以清晰显示（取决于字体的Hinting质量）。

放大的唯一限制：字体文件中的字形设计精细度。如果字体是为12-24pt正文设计的，放大到200pt可能边缘不够锐利——但Unicode八卦符号（☰-☷·䷀-䷿）通常由专门的符号字体设计师绘制，在大多数字体中放大到72pt以上仍然清晰。

## 二、不同使用场景的推荐字号

### 2.1 游戏内·Build装备界面（HUD嵌入）

```
场景：玩家在装备界面查看当前Build的卦码
定位：辅助信息，不是主视觉
推荐字号：14-18pt
显示方式：单行水平排列

┌──────────────────────────────────────────────┐
│  当前Build：🔥 焦烈速杀                        │
│                                              │
│  ☲䷝ ☷ ☰䷀ ☷ ☵䷜ ☷ ☳䷲ ☷ ☶䷁                  │  ← 16pt
│  火    天    水    雷    山                     │  ← 10pt 注释
│                                              │
│  字母码：XH-v3K7M2A-8F4P9S                    │  ← 12pt
└──────────────────────────────────────────────┘

屏幕占用：约400px宽 × 40px高（在1920×1080的界面上很小一块）
```

```
┌────────────────────────────────────┐
│                                    │
│         ☲ ䷝                       │  ← 48pt 大字

屏幕占用：约300px宽 × 500px高

```

### 2.3 星碑处·摇卦结果展示（沉浸式演出）

```
场景：三钱摇卦完成后，六爻叠起→卦象展开
定位：全屏沉浸式演出
推荐字号：72-120pt
显示方式：竖排·动画逐行展开

动画顺序：
  1. 背景变暗 → 星光粒子从四周汇聚
  2. 第一行从右飘入：☲ ䷝
  3. 分隔符从下升起：   ☷
  4. 第二行从右飘入：☰ ䷀
  5. ...（5段·约8-10秒完整演出）
  6. 全部显示后 → 卦象微微浮动（呼吸式缩放·±5%·周期4秒）
  7. 玩家按任意键 → 收入装备界面

全屏时每行约150px高 × 5行 = 750px（在1080p屏幕上占70%高度）
```

### 2.4 社区分享截图（社交媒体）

```
场景：玩家截取卦码展示画面，分享到微博/QQ/Twitter
实际分辨率：取决于截图分辨率（通常1920×1080或3840×2160）
在手机端查看：被缩放至约360-414px宽

要注意的问题：
  48pt的六十四卦字符 → 在4K截图中约67px高
  → 缩放到手机屏幕（假设高度从2160缩到780）→ 约24px高
  → 在手机上仍然清晰可辨（24px ≈ 约8pt在手机上·相当于中等字号）

  但如果原图用24pt → 手机上约12px → 勉强可读
```

## 五、可读性测试：不同字号下的八卦辨识力

### 5.1 先天八卦（☰-☷·8个）的辨识测试

```
字号 → 相邻易混卦的辨识情况

8pt：  ☰☱☲☳☴☵☶☷  → ☳和☶几乎无法区分（中间一横1px差异）
12pt： ☰☱☲☳☴☵☶☷  → ☳和☶勉强可辨（中间一横2-3px差异）
16pt： ☰☱☲☳☴☵☶☷  → 全部清晰可辨
24pt： ☰☱☲☳☴☵☶☷  → 完全无歧义

结论：八卦字符在12pt以上可安全使用。但推荐最小14pt。
```

### 5.2 六十四卦（䷀-䷿·64个）的辨识测试

```
字号 → 辨识情况

8pt：  ䷀䷁䷂䷃䷄䷅䷆䷇  → ䷂(屯)和䷄(需)只有最上一横的差异→1px→几乎无法区分
12pt： ䷀䷁䷂䷃䷄䷅䷆䷇  → 勉强可辨
16pt： ䷀䷁䷂䷃䷄䷅䷆䷇  → 大部分可辨，少数相似卦（䷂ vs ䷄）仍需仔细看
20pt： ䷀䷁䷂䷃䷄䷅䷆䷇  → 全部清晰

结论：六十四卦需要更大字号。推荐最小16pt，安全字号20pt。
混排时：可用八卦字符做段标识（18pt）+ 六十四卦做数据（20pt）——八卦可以小一点，六十四卦必须大一点。
```

## 六、最终建议：各场景字号标准

| 使用场景 | 八卦(☰-☷)字号 | 六十四卦(䷀-䷿)字号 | 分隔符(☷)字号 | 显示方式 |
|---------|:--:|:--:|:--:|------|
| 装备界面·HUD嵌入 | 14pt | 16pt | 14pt | 单行水平 |
| 卦码弹出窗口 | 24pt | 32pt | 20pt | 分行（每段一行） |
| 星碑演出·全屏 | 72pt | 96pt | 48pt | 竖排动画 |
| 社区截图分享 | 36pt | 48pt | 28pt | 竖排 |
| 手机端显示 | 14pt | 18pt | 14pt | 横滑或分行 |
| 电视端显示 | 48pt | 60pt | 36pt | 竖排填屏 |
| QR码中央装饰 | 6pt | 8pt | — | 嵌入QR中央 |
| 视频/直播覆盖 | 24pt | 28pt | 18pt | 画面角落横排 |

---

> **一句话：䷀这个字符，你在游戏里给它多大的字号，它就占多大的屏幕。在1080p下用72号字≈2.5厘米高，用200号字≈7厘米高。它是矢量字体——不会模糊，不会像素化。唯一要注意的是小字号下（14pt以下）个别相似卦可能混淆，推荐六十四卦最小16pt。**
