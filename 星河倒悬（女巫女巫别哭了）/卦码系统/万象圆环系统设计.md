# 万象圆环系统 —— 完整系统设计

> **注意：** 本文档聚焦系统结构、装配逻辑、解锁流程、交互设计。各模块的具体数值参数另见数值设计文档。

---

# 一、世界观根基

## 1.1 万象圆环是什么

万象圆环不是一件装备。它不是被制造出来的。它是九天星晷投影到辰生手腕上的界面——是星晷的"表盘"。

九天星晷本身是一个青铜圆盘，背面刻着"彰往察来"四个字。当辰生激活星晷后，星晷不再是一个手持工具——它化为一套同心光环，投影在他的左手腕上。这个投影就是万象圆环。

```
九天星晷（物理实体·青铜圆盘）
    │
    └── 投影到辰生左手腕 → 万象圆环（能量形态·同心光环）
          │
          ├── 核心：星晷的三层环中·最内层的环→太极位
          ├── 第1圈：星晷的第二层环→河图洛书位
          ├── 第2圈：星晷的第三层环→八卦位
          ├── 第3-5圈：星晷上蚀刻的天干地支·生肖·五行铭文→投影为光环
          └── 外圈：辰生自己收集的卦术→在手腕外形成卦符环
```

## 1.2 为什么是"万象"

万象不是一万种东西。万象是宇宙的每一个秩序层。

古人观天时，不是只看星星。他们看的是整个天空：太阳的轨道（太极）、月亮的二十八宿（星宿）、五星的位置（五行）、北斗的指向（八卦方位）、岁星的十二年周期（地支/生肖）、太阳的十日周期（天干）。

万象圆环就是把整个天空戴在手腕上——每一圈，对应一层古人观测宇宙的"刻度"。

## 1.3 辰生和万象圆环的关系

辰生一开始只有星晷——一个不会发光的青铜盘。序章结束时，星晷被激活——它亮了。但它只投影出了核心圈（太极）和第2圈（先天八卦）。其余圈层是空白的——光晕在转，但没有"刻度"。

随着辰生走过更多道宫、遇到更多星君、收集更多被太史阁抹除的知识——圆环的空白圈层一个接一个被点亮。不是"升级"——是"想起来"。万象圆环本来就在。只是被遗忘了。

# 二、圈层体系

## 2.1 七层结构

万象圆环由七个同心圈层组成。从内向外：

```
层数  圈层名      象征              在圆环中的视觉位置
────────────────────────────────────────────
核心   太极        万物的起点         正中心·一个点
第1圈  河图洛书    数字与秩序         核心外第一圈·黑白点阵
第2圈  八卦        空间与方向         核心外第二圈·8个扇区
第3圈  天干地支    时间与节奏         八卦圈外·22个文字刻度
第4圈  十二生肖    生命力与特质       地支圈上·12个动物虚影
第5圈  五行        关系与转化         生肖圈外·5色光晕流动
外圈   六十四卦    可能性与实践       最外层·16个卦符
```

## 2.2 每层的"角色"

| 圈层 | 回答什么问题 | 决定什么 | 模块数量 | 装配限制 |
|------|------|------|:--:|------|
| 核心·太极 | "我从哪里开始？" | 战斗哲学·基础属性倾向 | 44 | 1枚 |
| 第1圈·河图洛书 | "卦气怎么流动？" | 卦气生成与消耗模型 | 5 | 1枚 |
| 第2圈·八卦 | "方向怎么定义？" | 卦术输入映射 | 3 | 1枚 |
| 第3圈·天干 | "多久准备好了？" | 冷却节奏 | 10 | 1枚 |
| 第3圈·地支 | "时间因我而变吗？" | 时间减速效率 | 12 | 1枚 |
| 第4圈·十二生肖 | "我选择什么特质？" | 被动buff | 12 | 1枚 |
| 第5圈·五行 | "万物怎么联系？" | 元素倍率关系 | 4 | 1枚 |
| 外圈·六十四卦 | "我带了哪些可能性？" | 出战卦术清单 | 64 | 最多16卦 |

## 2.3 圈层的"旋转"

万象圆环不是静态图案。每一圈在独立旋转。

| 圈层 | 旋转方向 | 旋转速度 | 象征 |
|------|:--:|:--:|------|
| 核心·太极 | 不转（固定） | 0 | 原点不动 |
| 第1圈·河图洛书 | 逆时针 | 极慢（1圈/分钟） | 数字永恒循环 |
| 第2圈·八卦 | 逆时针 | 慢（1圈/30秒） | 空间缓缓流转 |
| 第3圈·天干地支 | 顺时针 | 快（1圈/10秒） | 时间急流 |
| 第4圈·十二生肖 | 不转（固定） | 0 | 特质恒定 |
| 第5圈·五行 | 顺时针 | 中（1圈/15秒） | 元素流转不息 |
| 外圈·六十四卦 | 逆时针 | 极慢（1圈/2分钟） | 卦象如星辰缓缓移动 |

**核心模块影响所有圈层的旋转：**
- 太极·阳 → 五行圈加速·八卦圈加速
- 太极·阴 → 天干地支圈减速·河图洛书圈停止
- 星宿核心 → 所有圈停止旋转·转为固定位置·星宿图案在核心闪烁
- 十二星宫核心 → 外圈六十四卦反向旋转

# 三、圈层获取时间线

万象圆环不是一次性全部开放的。圈层是随着剧情推进一层一层被"记起来"的。

## 3.1 各圈层首次解锁

| 圈层 | 解锁时机 | 剧情关联 | 初始状态 |
|------|------|------|------|
| **核心+第2圈** | 序章·星晷激活 | 玄伯遗物中九天星晷第一次发光 | 核心=太极三选一·第2圈=先天八卦（不可更换） |
| **第1圈·河图洛书** | 第5章·大梁宫 | 化史炉灰烬中发现河图洛书的残片→"原来数字可以这样排列" | 初始=河图·天数 |
| **第3圈·天干地支** | 第5章·大梁宫（卦盘归真后） | 修正被篡改的卦位后·星晷自动投影出天干地支刻度→"原来时间刻度也是被改过的" | 天干=甲·地支=子 |
| **第4圈·十二生肖** | 第6章·实沉宫 | 地下网络中有人用生肖做代号→辰生发现生肖不只是动物·是地支的"面孔" | 初始生肖=牛（因为星纪宫对应的地支是丑·对应生肖是牛） |
| **第5圈·五行** | 第3章·娵訾宫（首次解锁）·第4章可更换 | 石翁炼丹时展示五行相生→"金生水·水生木·木生火·火生土·土生金" | 初始=五行·正位 |
| **外圈·六十四卦** | 第1章开始可装配·第5章全解锁 | 每道宫解锁对应卦象 | 序章=0卦·第1章=4卦·…·第5章=64卦全解锁 |
| **核心更换能力** | 第1章后（星纪宫通关） | 焦烈被击败→荧惑钥匙升级→星晷第一次被"外力"改变→此后核心可以更换 | — |

## 3.2 各圈层模块的来源

| 圈层 | 模块获得方式 | 举例 |
|------|------|------|
| 核心·星宿 | 击败星宿试炼（28个·可选） | 斗宿试炼→南斗注生盘 |
| 核心·十二星宫 | 击败道宫BOSS（12个·主线） | 焦烈→焦烈之白焰 |
| 河图洛书 | 探索收集·达成特定条件 | 累计50次完美闪避→河图·地数 |
| 八卦 | 主线推进 | 第5章卦盘归真→后天八卦 |
| 天干 | 战斗成就·积累型解锁 | 用火卦击杀200个敌人→丙 |
| 地支 | BOSS首杀 | 焦烈·星纪宫→子 |
| 生肖 | 道宫通关 | 星纪宫通关→鼠 |
| 五行 | 战斗成就·特殊条件 | 连携大师→五行·逆行 |
| 六十四卦 | 道宫主线推进 | 第1章解锁离卦4种·第5章64卦全解锁 |

## 3.3 模块获得的"因果感"

所有模块的获得方式必须让玩家觉得"合理"——不是"随机掉落"，是"因为做了这件事，所以得到了这个"。

| 获得方式 | 设计原则 | 反例 |
|------|------|------|
| BOSS首杀 | BOSS的"特质"被星晷吸收→化为模块 | — |
| 星宿试炼 | 试炼本身就是"证明你理解了这个星宿" | 不能是"刷N次试炼随机掉落" |
| 战斗成就 | 用某种战斗方式达到极致→解锁对应的模块 | 不能是"RNG" |
| 探索收集 | 在世界中找到被太史阁隐藏的知识碎片 | 不能是"随机刷新" |
| 主线推进 | 道宫通关→自动解锁 | — |
| 条件触发 | 特定行为累计到一定次数 | 必须有明确进度提示 |

# 四、装配系统

## 4.1 装配地点——星碑

万象圆环只能在星碑处装配。理由：
1. 星碑是星晷的能量源——靠近星碑圆环才能"展开"到可操作大小
2. 战斗中不可装配——防止玩家在战斗中暂停换Build（破坏沉浸感）
3. BOSS房前必有星碑——玩家在BOSS前最后确认配置

## 4.2 装配界面流程

```
星碑菜单 → "万象圆环"

进入界面：
  - 全屏·深色星空背景
  - 中央=辰生左手腕的圆环放大·所有圈层可见
  - 右侧=模块面板·根据当前选中的圈层显示可用模块列表
  - 左侧=当前配置效果汇总（实时更新）

操作流程：
  ① 点击一个圈层（或鼠标滚轮切换圈层）
     → 该圈层高亮·其余圈层变暗
     → 右侧面板显示该圈层的：
        - 当前装配的模块
        - 所有已解锁的可用模块
        - 未解锁模块的解锁条件（灰显+提示）
  
  ② 点击右侧面板中的模块
     → 拖拽到圈层上→装配
     → 或双击→自动替换当前模块
  
  ③ 卸下模块
     → 点击当前装配的模块→拖拽出圈层
     → 该圈层恢复为"基础状态"（不能空圈）
  
  ④ 确认配置
     → 点击"保存配置"→存入3个配置槽之一
     → 或直接退出→当前配置自动生效
```

## 4.3 配置存档槽

3个存档槽。可以在星碑处一键切换。

| 槽位 | 默认用途 | 解锁 |
|------|------|:--:|
| 槽1 | 自定义 | 初始 |
| 槽2 | 自定义 | 第4章·降娄宫通关 |
| 槽3 | 自定义 | 第8章·鹑火宫通关 |

切换配置时——手腕上的圆环更换动画（旧光环散开·新光环重组）。约1.5秒·期间不可操作但不打断游戏。

## 4.4 配置分享——万象卦码

保存配置时自动生成卦码。每圈层一个编码段。

```
XH-WX-v3-[核心]-[河图]-[八卦]-[天干]-[地支]-[生肖]-[五行]-[64卦]-[校验]

编码规则：
  核心：00=北斗·01-28=星宿·A1-L1=十二星宫·T1=太极阳·T2=太极阴·T3=无极
  河图：1-5
  八卦：0=先天·1=后天·2=自定义
  天干：甲-癸=1-10
  地支：子-亥=1-12
  生肖：鼠-猪=1-12
  五行：1=正位·2=逆行·3=独尊·4=流转
  64卦：16进制·16个卦位各2字符

示例卦码：
XH-WX-v3-03-2-1-丙-午-虎-4-1A2F3C4D5E6F7A8B-9Y4
```

输入卦码 → 系统检查你是否有卦码中所有的模块 → 
  - 全部有：加载该配置
  - 有缺失：提示"缺少：[模块名]·解锁条件：[条件]"

# 五、圈层之间的交互

## 5.1 圈层兼容性

所有圈层模块原则上都可以自由组合。但存在"软兼容"——某些组合效果会互相抵消。

| 情况 | 示例 | 处理方式 |
|------|------|------|
| 两个模块效果叠加 | 太极·阳(攻击+20%)+生肖虎(首次攻击必暴) | 正常叠加·"阳虎流" |
| 两个模块效果矛盾 | 河图·天数(普攻卦气+30%)+洛书·戴九(站立卦气恢复+50%) | 可以共存·但实战中你不可能同时普攻和站立→"build陷阱"·留给玩家自己发现 |
| 模块在特定章节无用 | 轸宿天车(传送免费)·在第1章没用 | 正常可装配·但无效果·"你自己的选择" |

**设计哲学：** 系统不阻止"蠢"组合。蠢组合是玩家学习系统的一部分——你试过一次发现不行，下次就不会了。就像魂系游戏不阻止你裸体打Boss。

## 5.2 圈层之间的"共振"

当某些特定组合恰好和宇宙秩序一致时——万象圆环出现"共振"——手腕上的所有圈层短暂同速旋转——金色星光从圆环中心爆发。

共振=隐藏的超级Buff·官方不告诉玩家·让社区自己发现。

| 共振名 | 条件 | 效果（简明） |
|------|------|------|
| **四象归位** | 四象共鸣全部激活 | 全圈层同步旋转·卦术全属性+ |
| **子午对冲** | 地支子+生肖马+五行正位 | 时间减速期间可正常速度移动 |
| **十天干齐** | 天干=甲+地支=午+太极阳 | 卦术CD减半 |
| **日月合璧** | 太极阳+河图天数+后天八卦+离卦外圈全火 | 火卦必定暴击 |
| **五星连珠** | 五行流转+5个不同五行的外圈卦术各1个 | 连携触发崩解时额外赠送一次免费卦术 |

共振列表不对外公开——在游戏发售后的社区Wiki中被逐渐发现。

## 5.3 不能装配的状态

| 状态 | 原因 | 解决方案 |
|------|------|------|
| 某圈层只有一个模块且被卸下 | 圈层不能为空 | 必须先获得另一个模块才能卸下当前模块 |
| 卦码导入的配置中有未解锁模块 | 玩家还没达到解锁条件 | 提示缺失模块+解锁条件·"此配置当前不可用" |
| BOSS战中 | 战斗中不可更换 | BOSS房外有星碑·"前方为BOSS战·请确认配置" |

# 六、交互细节

## 6.1 战斗中万象圆环的显示

按住右键选卦时：
- 所有圈层可见·但透明度降低（选卦界面叠在上面）
- 当前鼠标指向的扇区=第2圈八卦的对应扇区高亮
- 外圈16卦符中·当前选中的上卦对应的4个下卦卦符亮起
- 核心的图案在选卦时微微放大——"你是在和你的'核心'一起选卦"

## 6.2 装配后的首次战斗

更换模块后进入第一次战斗：
- 手腕上的新模块微微发光3秒——"新力量初现"
- 如果是首装该模块（从未装过的·不是换回去的）——光更亮
- 没有额外的UI提示——"不需要告诉你·你自己选了它·你知道它在那"

## 6.3 模块在战斗中激活的视觉反馈

| 触发时机 | 视觉反馈 |
|------|------|
| 河图洛书·卦气模型触发 | 手腕上的黑白点阵微微一亮 |
| 五行·相生触发 | 五色光晕中的两色短暂加速流转 |
| 地支·时间效果触发 | 22个文字刻度中·该地支的文字亮起 |
| 生肖·被动触发 | 该生肖的虚影短暂凝实（马跑快一步·虎爪拍一下·蛇吐信子） |
| 核心·星宿触发 | 中心的星宿图案旋转半圈 |
| 核心·星宫触发 | BOSS的剪影在中心一闪 |

全部反馈都是"手腕上"的——不需要抬头看屏幕角落的buff栏。

## 6.4 模块的详细查看

在装配界面中，右键点击任意模块 → 弹出模块详情面板：

```
┌──────────────────────────────────┐
│ ★ 生肖·龙                        │
│                                  │
│ 卦术伤害+5%                      │
│ 每通过1座道宫+1%（当前+12%）     │
│                                  │
│ 来源：完成任意7个星宿试炼         │
│ 获得日期：你已经拥有了            │
│                                  │
```

# 七、与其他系统的关系

## 7.1 万象圆环 vs 术数系统

术数系统（12种·3槽位）改变的是**卦术的"思维方式"**——前摇减免、连携窗口、暴击概率。

万象圆环改变的是**卦术的"存在方式"**——用什么元素、从什么方向、在什么节奏中释放。

两者是正交的——可以叠加。一个Build = 万象圆环配置 + 术数选装 + 法器选择 + 同伴阵容。

## 7.2 万象圆环 vs 法器系统

法器（4主·8副）改变卦术的**物理形态**——银针=针·桃木=斩·铜钱=散·七星=敕。

万象圆环的模块不改变物理形态。它改变"这一卦术在什么条件下释放、带着什么元素权重、在什么节奏中冷却"。

同一个离卦——
- 法器=银针：18根火焰针
- 万象圆环·核心=焦烈之白焰：火焰针变为白色·必定触发五行相克
- 万象圆环·五行=逆行：相克倍率交换→"白焰"火针打水属性敌人时反而吃亏

## 7.3 万象圆环 vs 同伴系统

生肖模块的效果部分和同伴被动重叠——但生肖是"辰生自己的特质"，同伴被动是"同伴在场上提供的"。两者可叠加。

例：同伴锻锋(火卦+15%)+生肖龙(卦术+5%+每道宫1%)=火卦累计加成。

## 7.4 万象圆环 vs 星宿命盘系统

万象圆环的**核心**层使用的28个星宿模块——就是在星宿命盘系统中定义的28枚命盘。它们是同一套模块，在两个界面中都可操作。

在星碑的"星宿命盘"菜单中更换核心=在万象圆环界面中更换核心。同一件事，两种入口。

# 八、美术与音效设计方向

## 8.1 圆环材质

万象圆环是能量投影——不是金属·不是石头·不是任何实体材质。它是星光。

- 基础色：暗金（辰星卦师的基础色）
- 随核心模块变化：太极·阳=偏暖金·太极·阴=偏冷银·星宿=该星宿的颜色（斗宿=冰蓝·心宿=暗红·翼宿=青绿）
- 透明度：常态下约40%透明·选卦时升至80%·装配界面中100%
- 边缘：不是锐利的线——是微弱的星光光晕——像星云的边缘

## 8.2 圆环动画

| 动画 | 描述 |
|------|------|
| 常态 | 各圈以各自速度独立旋转 |
| 选卦·按住右键 | 所有圈层旋转速度降至10%·当前指向扇区高亮·其余扇区变暗 |
| 装配·拖拽模块 | 模块从右侧面板"飘"向圈层·嵌入时一圈星光涟漪扩散 |
| 卸下模块 | 模块化为星光碎屑·退回到面板中 |
| 切换配置 | 圆环分解为多层星光碎片·重组为新配置的排列·总耗时1.5秒 |
| 共振触发 | 所有圈层短暂同速旋转（约2秒）·金色星光从中心爆发·声音=低沉的编钟共鸣 |

## 8.3 音效方向

| 操作 | 音效 |
|------|------|
| 进入装配界面 | 星晷旋转的低沉嗡鸣 |
| 选中圈层 | 轻微的"叮"——像敲击青铜的边缘 |
| 拖拽模块 | 风声——像星光流动的声音 |
| 嵌入模块 | 低沉的"嗡"——该圈层对应频率的共鸣 |
| 卸下模块 | 星光碎屑的细微"沙沙"声 |
| 切换配置 | 所有圈层同时共鸣——最短的编钟和弦 |
| 共振触发 | 编钟+大提琴低频——只有一次 |
| 退出装配界面 | 嗡鸣渐弱·回到环境音 |

# 十、设计原则总结

1. **不是"装备系统"——是宇宙的每一层秩序。** 每圈一个"为什么"，不是一个"加多少"。
2. **解锁=记起来。** 模块不是掉落——是辰生在旅途中重新接触到被太史阁抹除的知识。
3. **不阻止蠢组合。** 你不该装的自己试过就知道了。这是学习。
4. **共振是社区发现的。** 官方文档不列共振表。让玩家在Wiki上兴奋地编辑。
5. **所有反馈都在手腕上。** 不看buff栏，看自己的左手腕。
6. **每一圈都可以换。** 没有"这一圈是固定的"——从核心到外圈，全是你的选择。
7. **和法器共生，不互斥。** 法器改变卦术的物理形态，圆环改变卦术的存在条件。同一卦在不同圆环+法器组合下=完全不同。

# 十一、模块收集与存储系统

## 11.1 模块不占背包

万象圆环的模块不是物品。它们不占背包格子，不出现在物品栏中，不可丢弃，不可出售，不可交易。

模块是"知识"——是辰生在旅途中触摸到的宇宙秩序片段。一旦获得，永久拥有。

## 11.2 模块的"家"——星晷内部

所有已解锁但未装配的模块存储在九天星晷的内部。星晷的三层环之间的夹层中——每一个夹层对应万象圆环的一圈。

```
九天星晷 = 青铜圆盘·三层环·背面"彰往察来"
    
    星晷的三层环夹层 → 对应万象圆环的模块存储空间：
    
    第一层夹层（最内） → 核心模块库（太极·北斗·星宿·星宫）
    第二层夹层         → 河图洛书 + 八卦 + 天干地支模块库
    第三层夹层（最外） → 生肖 + 五行模块库
    
    外圈六十四卦 → 不在星晷夹层中·卦符直接存储在辰生的记忆中
```

## 11.3 获得模块时的演出

```
获得流程：

1. 触发条件达成（击败星宿试炼/BOSS/成就/收集）
2. 屏幕中央短暂出现模块的图案（约1.5秒）·不是弹窗·是光晕浮现
3. 左手腕的万象圆环自动展开（战斗外）或微微一亮（战斗中）
4. 新模块对应的圈层短暂亮起——该圈层多了一个"空位"被填满的光效
5. 星晷在背包中自动打开·三层环旋转·模块被"吸入"对应夹层
6. 屏幕左上角出现一行小字："星宿归位——南斗注生盘"
   或 "地支觉醒——子时之力"
   或 "生肖感应——龙纹浮现"

不需要按键确认。不需要"打开背包查看"。你看到了。
```

# 十二、"空圈"的状态

## 12.1 每圈的初始状态

在圈层首次解锁之前，万象圆环中该圈的位置是**空白**的——不是暗的，不是灰的。是"还没有被记起来"。

| 状态 | 视觉 | 含义 |
|------|------|------|
| **未解锁圈层** | 非常淡的星光环·几乎看不清·不旋转 | 辰生还不知道宇宙有这一层 |
| **已解锁·空圈**（没有模块）| 清晰的星光环·缓慢旋转·但环上没有文字/图案 | "知道这里应该有什么·但还没找到" |
| **已解锁·已装配** | 完整的环·图案/文字/光晕清晰·按对应速度旋转 | 正常运行 |

## 12.2 空圈的交互

已解锁但空圈的圈层——在装配界面中该圈层中间有一个微弱的脉冲光点。"这里在等一个模块。"

首次将一个模块拖入空圈时——光点爆发为一圈涟漪——"这个空位被填上了。"此后该圈层不再有空圈动画。

# 十三、模块的"记忆"——自定义模块

## 13.1 终局锻造

二十八宿全部完成后，在寿星宫的星碑前解锁"万象锻造"——玩家可以将两个同圈层的模块"融合"为一个自定义模块。

```
融合规则：
  ① 选择两个已解锁的同一圈层模块
  ② 支付费用：星晶×5 + 九天星晶×1
  ③ 结果模块 = 主模块的完整效果 + 副模块50%的效果
  ④ 融合后原两个模块仍然保留——不会失去它们
  ⑤ 自定义模块在圈层中显示为"融合·[主模块名]+[副模块名]"
  ⑥ 最多拥有5个自定义模块（每个圈层最多1个）
```

## 13.2 自定义八卦

完成任意3个道宫无伤通关→解锁"自定义八卦"——在第2圈八卦圈中，可以自由排列8个上卦的位置。拖拽卦符到8个扇区中任意位置。

这是为速通和限制挑战玩家准备的终极工具——"离卦必须在↑方向·坤卦必须在↓方向·这是我的肌肉记忆。"

# 十七、异常状态处理

## 17.1 模块被"封印"

某些剧情节点或敌人攻击可能封印特定圈层的模块（如国师的记忆抹除）。被封印的模块在光环上显示为"裂痕"——效果减半。

封印解除方式：
- 在星碑处休息（清除所有封印）
- 击败施加封印的敌人（自动解除该敌人施加的封印）
- 使用亢宿·亢金咽喉盘的主动技（兑卦·"咬断"封印）

## 17.2 配置冲突

如果玩家导入的卦码中包含已拥有的模块+未拥有的模块→"此配置需要3个未解锁模块。是否仅加载已解锁的部分？"→选择"是"=加载已解锁部分·其余圈层保持当前配置。选择"否"=不加载。

## 17.3 存档/读档

万象圆环的当前配置保存在存档中。读档后恢复。配置槽1/2/3独立保存——不会因为读档而丢失已保存的配置。

7. **和法器共生。** 法器改物理形态，圆环改存在条件。
8. **不弹窗教程。** 同伴暗示·演出引导·自己发现。
9. **模块是知识。** 不占背包·不可丢弃·永久拥有。
10. **星晷是模块的家。** 三层夹层=三层存储空间。
11. **获得方式=叙事。** 每个模块的获得方式和它自己的故事一致。
12. **配置可以分享。** 万象卦码=完整配置的编码。
13. **终局可以锻造。** 二十八宿全完成后可以融合自定义模块。
14. **空圈有故事。** 未被记起来的圈层=空圈脉冲="这里在等一个模块"。
15. **第三人称可见倾向。** 光环颜色变化让观察者知道辰生的配置倾向。
