# 星宿命盘系统 —— 八卦盘核心替换·星宿之力

> **核心设定：** 辰生左手腕上的八卦盘是战斗的核心——八个卦位在外圈旋转，中央镶嵌着一枚星宿命盘。这枚命盘不是固定的——每击败一个星宿试炼，就能将其星宿之力刻入命盘
。替换中央命盘，就是替换辰生的战斗核心。
>
> **一句话：** 八卦为形，星宿为心。盘心一转，命格即变。

---

# 一、系统概述

## 1.1 视觉呈现

```
         ☰ 乾
     ☱ 兑    ☴ 巽
         ┌───────┐
         │       │
   ☲ 离 │  ★   │ ☵ 坎
         │  星宿  │
         │  命盘  │
         └───────┘
     ☳ 震    ☶ 艮
         ☷ 坤

八卦在外 = 战斗中的卦术输入界面（不变）
星宿命盘在中心 = 可替换的核心模块（通过试炼解锁）
```

辰生左手腕上的八卦盘不是一个平面图案——它是立体的。八根半透明的卦符在腕上半腰处缓缓旋转，五彩半透明。盘心位置是一个凹槽——星宿命盘就镶嵌在这个凹槽里。更换命盘时，凹槽中的旧命盘化为星光消散，新命盘从星晷中浮出，旋转着嵌入凹槽。

## 1.2 核心规则

```
1. 初始命盘 = 北斗（默认·无需解锁）
2. 击败1个星宿试炼 = 解锁该星宿的命盘
3. 一次只能镶嵌1枚命盘
4. 在星碑处可以更换命盘（战斗中不可更换）
5. 命盘效果 = 被动常驻 + 主动卦术变体 + 四象共鸣
6. 28星宿全解锁 = 四象归一·四枚命盘同时生效

星宿命盘的解锁顺序 = 道宫推进顺序
   → 越后面的道宫·星宿命盘越强
   → 但不是"后面的替换前面的"——是"不同场景用不同的"
```

## 1.3 和八卦盘的关系

```
八卦盘外层 = 卦术选择（战斗中操作·不变）
     ↓ 鼠标右键按住 → 选上卦方向 → 选下卦按键 → 释放
     
八卦盘中心 = 星宿命盘（被动效果·可替换）
     ↓ 提供：基础属性加成 + 特定卦术伤害类型加成 + 专属卦术变体
     
命盘不改变八卦盘的"操作方式"——
改变的是卦术的"效果和属性倾向"。
```

## 3.2 命盘更换动画

```
卸下：    凹槽中命盘化为星光 → 星光散开 → 凹槽变空
          辰生手腕星纹短暂变暗 → 失去该命盘的所有效果

嵌入：    选择的命盘从星晷中浮出 → 旋转 → 缩小 → 嵌入凹槽
          嵌入瞬间 → 手腕星纹中对应星宿的星点亮起 → 效果激活

更换冷却：无冷却·可随时在星碑处更换
          但在BOSS战中不可更换（进入BOSS房间前·星碑提醒"前方为BOSS战·请确认命盘配置"）
```

# 四、四象共鸣——套装效果

## 4.1 共鸣规则

```
完成一象全部7个星宿试炼 → 解锁该象的"共鸣"

拿玄武举例：
  完成斗·牛·女·虚·危·室·壁 全部7个试炼
  → 解锁"玄武共鸣"
  → 无论镶嵌哪一枚玄武命盘
  → 额外激活玄武共鸣效果

共鸣是叠加的——完成2象=双共鸣·完成4象=四象归一
```

## 4.2 四象共鸣效果

| 共鸣 | 激活条件 | 共鸣效果 | 视觉变化 |
|------|------|------|------|
| **玄武共鸣** | 北方7宿全完成 | 受伤后3秒内·防御+30%·卦气恢复翻倍 | 手腕星纹多一圈龟甲纹路 |
| **白虎共鸣** | 西方7宿全完成 | 暴击后3秒内·攻击+30%·移速+20% | 手腕星纹多一圈虎纹纹路 |
| **朱雀共鸣** | 南方7宿全完成 | 击杀敌人后·卦气全满·下一个卦术伤害+50% | 手腕星纹多一圈羽毛纹路 |
| **青龙共鸣** | 东方7宿全完成 | 每过60秒·自动获得一层"龙鳞"·吸收下一次受伤（最多3层） | 手腕星纹多一圈龙鳞纹路 |
| **四象归一** | 28宿全完成 | 四共鸣全部永久激活·不受命盘限制·无需镶嵌特定命盘 | 手腕星纹·四圈纹路同时存在·流转不息 |

## 4.3 共鸣的美术表现

```
八卦盘中心的命盘：
  无共鸣：    命盘本身的光晕（对应星宿的颜色）
  一象共鸣：  命盘外圈多一圈光晕（对应四象的颜色）
  二象共鸣：  两圈光晕同时存在·交替闪烁
  三象共鸣：  三圈同心光环
  四象归一：  四圈光环融合成一道白色的星环·命盘上的星宿图案开始缓缓旋转
```

# 五、初始命盘——北斗

## 5.1 默认命盘

辰生进入游戏时，八卦盘中心镶嵌的是**北斗命盘**——无需解锁，一开始就有。它代表辰生作为"辰星卦师"的基础卦术天赋——在接触星宿之力之前，他和北斗七星有先天的联系（南斗主生·北斗主死·辰星卦师掌推演·北斗指引方向）。

| 北斗命盘 | 效果 |
|------|------|
| 基础被动 | 卦气恢复+5% |
| 卦术变体 | 无（北斗不是星宿·不提供卦术变体） |
| 专属能力 | 小六爻甩鼠标时·自动显示北斗方位（额外第7个方向·天枢）——甩向北斗方位（左上30°）=大安+速喜双重效果 |

## 5.2 北斗的定位

北斗命盘不是"弱"——它是"基础"。在没有任何星宿命盘时，北斗提供最平衡的卦术体验。有了星宿命盘后，北斗可以一直用，也可以被替换。速通玩家可能用北斗用到第12章——"我不需要花里胡哨的命盘效果，卦气恢复+5%足够。"

# 六、命盘与卦码分享

## 6.1 命盘编码

更换命盘后，辰生的"当前状态"发生变化——命盘选择被编码进卦码中。

```
卦码v3.0结构：
XH-v3-[法器段]-[卦术段]-[命盘段]-[铭刻段]-[校验段]

命盘段（4字符）：
  第1字符 = 当前镶嵌的命盘编号（01-28·00=北斗）
```

例：`XH-v3-M2A8-3F4P-07-S1N2-9Y4` = 铜钱剑·当前卦术配置·**斗宿(07)命盘**·铭刻配置·校验

## 6.2 社区分享

玩家分享Build时，命盘是Build最核心的组成部分：
- "离卦速杀流·心宿命盘+朱雀共鸣+七星剑"
- "无伤跑酷流·尾宿命盘+青龙共鸣+银针"
- "新手生存流·斗宿命盘+玄武共鸣+桃木剑"

## 7.3 命盘在战斗帧数据中的位置

命盘效果在帧级精确参数中属于"被动常驻"——和同伴被动同层——在卦术前摇/后摇减免之前先计算命盘加成。
