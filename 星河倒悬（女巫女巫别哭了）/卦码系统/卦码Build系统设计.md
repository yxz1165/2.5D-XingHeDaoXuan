# 卦码系统（Build Code）设计——"改枪码"式的装备分享系统

> **核心定位：** 一个卦码 = 针对一个具体问题的完整装备方案。
> 码的价值不在于"里面有什么装备"——在于"它解决了什么问题"。

---

## 一、为什么需要卦码

### 1.1 后期组合爆炸

当玩家打到第十章以后，以下全部解锁：

| 系统 | 可选数量 | 组合数 |
|------|:--:|------|
| 上卦槽（4槽×8种上卦） | C(8,4) | 70 |
| 下卦槽（4槽×8种下卦） | C(8,4) | 70 |
| 术数系统（3槽×12种术数） | C(12,3) | 220 |
| 法器（2槽×4种） | C(4,2) | 6 |
| 卦阵（2槽×8种） | C(8,2) | 28 |
| 同伴（12选2） | C(12,2) | 66 |
| 紫微命盘（120种模板+四化流转） | — | 120×4 |
| 外观（6品类·各多种皮肤） | — | ~50 |
| 法器精通等级（4法器×5级） | 5⁴ | 625 |

**总组合数 ≈ 70×70×220×6×28×66×120 = ~1.4×10¹²。** 加上紫微命盘变化和外观·实际可达10¹³以上。

### 1.2 卦码解决的问题类型

后期全解锁后，玩家面对的不是"怎么配装备"——而是这些具体问题：

| 问题类型 | 示例 | 卦码要回答的问题 |
|---------|------|---------------|
| **卡BOSS** | "焦烈三阶段白焰全屏怎么躲？" | 用火卦吞噬白焰+乾坤下卦最大化伤害的完整配装 |
| **速刷** | "星晶在哪刷最快？" | 铜钱剑叠108计数+五雷令连锁清场的速刷方案 |
| **探索** | "娵訾宫隐藏房间找不到" | 拂尘清debuff+甘露碗净化+梅花易数的探索方案 |
| **挑战** | "能不能只用银针通关？" | 银针Lv5入化+三清铃+针铃惊魂共鸣的极限配装 |
| **入门** | "第四章刚拿铜钱剑怎么配？" | 适合第四章进度的低门槛配装（锻造+3以内） |
| **理解** | "纳音系统到底怎么用？" | 专门展示纳音词条协同的教学配装 |
| **创意** | "全部堆一个属性会怎样？" | 极限单属性堆叠的实验性配装 |

## 三、编码格式

> **完整编码规格见：** `03-卦码实现规格书.md`（52字符·46卦符+6个☷分隔符·273bit有效数据）

卦码 = 真正的六十四卦符序列。例如：

```
䷀䷝䷜䷲䷸䷖䷁䷊☷䷋䷌䷍䷎䷏䷐䷑...
```

每卦6条爻=6bit·与Base64同等密度。☷（坤·纯阴）作为段分隔符。

会读卦的人看到䷝（火天大有）=火系Build·看到䷜（水火未济）=水系Build。不需要导入游戏就能粗略理解这个Build是什么。

## 四、生成与导入流程

**生成：**
```
装备界面 → [生成卦码] → 弹出窗口显示完整信息 → 
  [复制字母码]（对外分享·100%兼容）
  [复制八卦码]（游戏内·沉浸式）
  [生成QR码]（扫码导入）
```

**导入：**
```
装备界面 → [导入卦码] → 粘贴 →
  → 系统自动识别格式（八卦/字母/QR）
  → 检查装备持有情况：
    ✅ 桃木剑（已拥有·Lv5·锻+9）→ 装载
    ⚠ 荧惑火印（需击败焦烈）→ [暂时跳过] [去获取]
  → 一键装载
```
