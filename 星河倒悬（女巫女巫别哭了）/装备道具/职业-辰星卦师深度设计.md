# 职业深度设计：辰星卦师（道士）

---

## 1. Overview

辰星卦师——对应的星君为**辰星（水星）**——是《星河倒悬》十位可操控角色中**操作门槛最高、上限最深**的职业。其战斗机制基于中国传统数术体系：八卦六十四卦、六爻、奇门遁甲、太乙神数、紫微斗数、四柱八字、梅花易数。设计挑战在于：**如何让一个承载七套完整数术体系的角色，操作简单到能上手，上限高到能封神。**

解决方案是**分层架构**：所有数术共用同一个操作底座（按住鼠标右键 → 时间减速 → 输入 → 松手释放），区别仅在于减速状态下按键语义的不同。四种战斗模式通过鼠标滚轮或 Tab 键切换，从「小六爻（0门槛）」到「太乙神数（终极绝招）」层层递进。三种非战斗系统（紫微斗数、四柱八字、梅花易数）用于成长定制和探索。

辰星卦师的最大特色是：**不需要背64卦就能玩，但背下64卦的人玩的是另一个游戏。**

---

## 2. 玩家幻想

- **指尖掐算，掌控战场**：按住右键，时间流速降到10%，八卦盘在指尖展开——你就是那个在暴雨中从容掐指一算的道士。敌人挥刀的动作悬在半空，而你已经在选下一卦。
- **凭直觉就能玩**：小六爻模式下，0.3秒甩一下鼠标选个方向，卦象即出。敌人冲过来往下甩（空亡后退），想追击往右甩（速喜加速）。不需要任何知识储备，肌肉记忆就是你的卦盘。
- **越玩越深**：从「八卦盘上8个符号」到「64卦全记忆」，从「预设阵法一键放置」到「自定义九宫八门布局」，从「太乙神数照提示按键」到「闭眼9键零失误」。每一个阶段都有新的深度等你去挖。
- **紫微斗数命盘打开新维度**：同一个64卦技能配置，换了命盘就是完全不同的效果。你的道士是你的，不是攻略上的。
- **名场面制造机**：濒死边缘，用4.5秒完成了9键零失误太乙神数输入→全场逆转→队友从绝望到狂喜。这种体验，全职业只有道士能给。
- **发现秘密的人**：梅花易数让你看到其他职业永远看不到的东西——那面墙背后有密室，那棵树下面埋着遗迹。你是队伍里那个"什么都知道"的人。

## 3. 详细规则

### 3.1 操作底座（所有数术共通）

#### 3.1.1 键位总览

| 操作 | 按键 | 说明 |
|------|------|------|
| 进入演卦状态 | 按住 `鼠标右键` | 时间减速至 10%，卦盘展开 |
| 退出/释放 | 松开 `鼠标右键` | 施放当前卦象，时间流速恢复 |
| 切换卦盘模式 | `鼠标滚轮` 或 `Tab` | 循环切换：小六爻→八卦→奇门遁甲→太乙神数 |
| 上卦/方向选择 | `鼠标移动` | 在卦盘上选择方向/卦象 |
| 输入辅助键 | `1` `2` `3` `4` | 根据当前模式语义变化（见各模式详解） |
| 重复/逆转 | `Q` | 重复上次卦象（短按）/ 逆转上下卦（长按） |
| 取消/预存 | `E` | 取消当前输入（短按）/ 预存卦象（长按） |
| 梅花易数 | 长按 `F`（非战斗） | 进入环境观象状态 |

#### 3.1.2 卦盘切换机制

```
┌────────────────────────────────────────────────────┐
│                                                    │
│   按住鼠标右键 → 时间减速至 10%                      │
│                                                    │
│   ┌───────┬───────┬───────┬───────┐               │
│   │ 小六爻 │  八卦  │奇门遁甲│太乙神数│               │
│   │ 0门槛  │ 核心   │  阵法  │  终极大招 │               │
│   │ 0.3s   │ 1s     │ 4s     │ 5s      │               │
│   │ 快如本能│ 64种变化│ 智斗布局│ 规则逆转 │               │
│   └───────┴───────┴───────┴───────┘               │
│                                                    │
│   鼠标滚轮 或 Tab 循环切换                           │
│   松手 = 释放当前卦盘的选中结果                       │
│                                                    │
└────────────────────────────────────────────────────┘
```

#### 3.1.3 时间减速详细参数

| 参数 | 值 |
|------|-----|
| 减速比率 | 正常流速的 10% |
| 减速期间移动速度 | 正常移速的 50% |
| 减速期间受伤害倍率 | 150%（高风险，被打了更疼） |
| 减速期间霸体 | 无（可被强力攻击打断） |
| 被打断惩罚 | 卦气清空，该模式进入 5 秒冷却 |
| 最长持续减速 | 8 秒（超过后自动释放当前卦象） |

### 3.2 模式一：小六爻（快速占卜）

#### 3.2.1 设计定位

零门槛入口。新手的第一站，老手的肌肉记忆。小六爻不要求玩家懂任何占卜知识，只要求**凭直觉判断当前最需要什么**。

#### 3.2.2 操作方式

```
按住右键（小六爻模式）→ 屏幕上鼠标周围出现6个区域 → 鼠标甩向目标方向 → 松手
```

整个过程最快 **0.3 秒**，穿插在普攻连段之间丝毫不打断节奏。

#### 3.2.3 六爻效果表

| 爻位 | 鼠标方向 | 卦象符号 | 效果 | 持续时间 | 冷却 | 直觉记忆 |
|------|---------|---------|------|---------|------|---------|
| **大安** | ↑ 正上 | ☰☰ | 防御+30%，每秒回复 1% HP | 12s | 3s | 安全，稳 |
| **速喜** | ↗ 右上 | ☲☲ | 攻速+25%，移速+20% | 10s | 3s | 快，追 |
| **小吉** | ↘ 右下 | ☴☴ | 下次技能伤害+30% | 下次技能 / 15s | 3s | 好，猛 |
| **空亡** | ↓ 正下 | ☵☵ | 向后瞬移 5m，隐身 1.5s | 即时 | 5s | 跑，躲 |
| **赤口** | ↙ 左下 | ☱☱ | 前方 90° 锥形 6m 恐惧 2s | 即时 | 6s | 吼，吓 |
| **留连** | ↖ 左上 | ☶☶ | 前方 8m 线型缠绕减速 60%，持续 4s | 即时 | 4s | 缠，绑 |

- 同时只能有一个小六爻效果激活。新占卜覆盖旧效果。
- 每次小六爻占卜积累 **1 层卦气**（用于太乙神数）。
- 小六爻占卜**不会被敌人格挡或免疫**——它是占卜结果，不是攻击。

#### 3.2.4 视觉呈现

- 6 个区域以半透明光环形式环绕鼠标，每个区域有对应的卦象符号和单字标识（安/喜/吉/亡/口/连）
- 鼠标移入某区域 → 该区域亮度 +50%，其余区域暗至 20%
- 松手释放 → 选中区域短暂闪烁，一道与该爻位对应的光效从角色身上爆发

#### 3.2.5 设计意图

小六爻不是让玩家背 6 个效果，而是培养**肌肉记忆**：
- 敌人冲脸 → 本能往下甩（空亡）
- 敌人逃跑 → 本能往右上甩（速喜）
- 敌人蓄力大技能 → 往左上甩（留连缠绕打断）

**0.3 秒足以**。高手在普攻第三段后摇中插入一个小六爻，无缝衔接。

### 3.3 模式二：八卦六十四卦（核心战斗）

#### 3.3.1 设计定位

道士的主力输出/控制/辅助系统。这是道士 80% 战斗时间使用的模式。承载 64 卦的全部变化，但通过**分类记忆法**和**智能提示**大幅降低门槛。

#### 3.3.2 操作方式

```
按住右键（八卦模式）→ 八卦盘出现（8方向=8经卦）→ 
鼠标选择上卦 → 盘面自动刷新为下卦盘 → 
鼠标选择下卦 → 松手释放
```

完整一次八卦占卜约 **0.8-1.5 秒**。

#### 3.3.3 八卦盘视觉设计

```
         乾 ☰ (金/白)
     兑 ☱           巽 ☴
   (泽/银)         (风/绿)

离 ☲                 坎 ☵
(火/红)             (水/蓝)

     坤 ☷           震 ☳
   (地/黄)         (雷/青)

         艮 ☶ (山/棕)
```

- 每个卦位用**颜色区分**，减少符号辨认时间
- 已选上卦时，盘面高亮 3 个「推荐下卦」（由 AI 根据当前战况计算）
- 右上角悬浮显示当前卦名（如 `☰☲ 同人·聚`）

#### 3.3.4 辅助键（1/2/3/4）

| 按键 | 短按 | 长按 |
|------|------|------|
| `1` | 重复上次卦象（0.2s 释放，新手拐杖） | 逆转上下卦（同人→大有） |
| `2` | 取消当前输入 | 预存当前卦象到 `3` 或 `4` |
| `3` | 释放预存卦象 #1（无时间减速，瞬间释放） | 清空预存 #1 |
| `4` | 释放预存卦象 #2（无时间减速，瞬间释放） | 清空预存 #2 |

- 预存卦象意味着：玩家可以在战斗间隙（非减速状态）提前把两个卦存好。战斗中按一下直接出，不需要时间减速。**这是高手和新手最重要的分水岭。**

#### 3.3.5 64 卦分类记忆法

**不需要背 64 卦。记住 8 个上卦功能类别即可。下卦看提示选。**

##### 上卦功能类别

| 上卦 | 经卦 | 元素 | 功能方向 | 特点 |
|------|------|------|---------|------|
| ☰ | 乾 | 天/金 | **强制位移** | 击飞、击退、浮空、牵引 |
| ☷ | 坤 | 地/土 | **防御/回复** | 护盾、治疗、净化、减伤 |
| ☳ | 震 | 雷/木 | **爆发/打断** | 高伤害、眩晕、打断、突进 |
| ☴ | 巽 | 风/木 | **持续伤害** | DOT、减抗、穿透、扩散 |
| ☵ | 坎 | 水 | **控制/减速** | 冻结、减速、位移限制 |
| ☲ | 离 | 火 | **破防/驱散** | 灼烧、破甲、驱散敌buff |
| ☶ | 艮 | 山/土 | **定身/沉默** | 定身、沉默、格挡、反伤 |
| ☱ | 兑 | 泽/金 | **混乱/偷取** | 魅惑、混乱、偷buff、反转 |

##### 下卦变化规律

- **乾(☰)** 为下卦：效果最大化，但消耗+30%
- **坤(☷)** 为下卦：效果折半，但消耗-50%
- **震(☳)** 为下卦：附加 0.5s 眩晕
- **巽(☴)** 为下卦：效果扩散至周围 2 个额外目标
- **坎(☵)** 为下卦：持续延长 50%
- **离(☲)** 为下卦：附加灼烧 DOT（3 秒，伤害为上卦效果的 15%）
- **艮(☶)** 为下卦：施放时获得短暂霸体（1s）
- **兑(☱)** 为下卦：对目标附加随机 debuff（混乱/减速/减攻）

#### 3.3.7 资源：卦气

- 每次成功施放八卦卦象获得 **1 层卦气**。
- 卦气上限：**10 层**（随等级提升，Lv30 提到 15 层，Lv50 提到 20 层）。
- 卦气作用：
  - 消耗 3 层 → 进入太乙神数模式
  - 不消耗 → 每层卦气使八卦伤害 +2%（叠满 20 层 → +40%）
- 卦气在脱离战斗 15 秒后开始衰减（每秒 -1 层）。

### 3.4 模式三：奇门遁甲（战场阵法）

#### 3.4.1 设计定位

战前/战斗间隙的阵地铺设。不是激战中频繁切换的模式。奇门遁甲的精髓是**把战场改造成你的主场**。

#### 3.4.2 操作方式

```
按住右键（奇门遁甲模式）→ 战场显示 3×3 九宫格线 → 
鼠标选择宫位（高亮） → 按 1/2/3/4 键选择门 → 松手放置
```

放置一个阵法约需 **3-5 秒**。可提前布阵，也可战斗中拉开距离后使用。

#### 3.4.3 九宫八门体系

```
┌──────────┬──────────┬──────────┐
│  休门 ☵   │  生门 ☷   │  伤门 ☳   │
│  治疗领域  │  强化领域  │  伤害领域  │
│ 每秒+2%HP │ 伤害+20%  │ 敌人-5%HP/s│
│ 伤害-15%  │ 治疗+30%  │  即死抗性   │
├──────────┼──────────┼──────────┤
│  开门 ☰   │  中宫 ☯   │  杜门 ☴   │
│  加速领域  │  蓄力领域  │  屏障领域  │
│ 移速+30%  │ 在此宫施放 │ 进入即隐身  │
│ 技能CD-20%│ 卦象消耗-50%│ 出则解除    │
├──────────┼──────────┼──────────┤
│  惊门 ☱   │  死门 ☶   │  景门 ☲   │
│  恐惧领域  │  斩杀领域  │  幻象领域  │
│ 敌人进入即 │ 对<20%HP敌人│ 制造3个幻象 │
│ 恐惧2s    │ 伤害+100%  │ 敌方AI混乱  │
└──────────┴──────────┴──────────┘
```

#### 3.4.4 门之生克

| 关系 | 组合 | 效果 |
|------|------|------|
| 克制：开门 → 杜门 | 我方开门覆盖敌方杜门 | 敌方杜门效果清除，我方开门效果+50% |
| 克制：死门 → 生门 | 我方死门覆盖敌方生门 | 敌方生门治疗反转（变伤害） |
| 克制：休门 → 伤门 | 我方休门覆盖敌方伤门 | 敌方伤门伤害-75% |
| 克制：惊门 → 景门 | 我方惊门覆盖敌方景门 | 敌方幻象全部识破消失 |
| 相生：生门 + 休门 | 两阵相邻 | 生门范围 +50%，休门效率 +50% |
| 相生：开门 + 景门 | 两阵相邻 | 开门内施放的幻象继承施法者 50% 攻击力 |

- 出现克制关系时，较晚放置的阵法获得 3 秒「先手优势」（不受对方阵法影响）。
- **阵法斗法**：敌方守史者也会布置阵法。你需要识别对方阵法 → 用克制的门覆盖 → 阵法对抗。

#### 3.4.5 阵法参数

| 参数 | 值 |
|------|-----|
| 同时存在阵法数上限 | 3 个（Lv45 后提升为 4 个） |
| 单个阵法持续 | 45 秒 |
| 单个阵法冷却 | 20 秒（从放置时开始计算） |
| 阵法范围 | 九宫每格 6m × 6m |
| 阵法血量 | 每个阵法有 3 点耐久，被 BOSS 攻击每次-1，精英攻击每两次-1 |
| 放置距离 | 最远 15m |

#### 3.4.6 新手辅助：预设阵法

新手不需要手动选门。三套预设一键放置：

| 预设 | 布局 | 用途 | 一键放置键 |
|------|------|------|----------|
| **攻击阵** | 上排：伤门 / 中排：开门 / 下排：死门 | 最大化输出 | `3`（奇门模式下） |
| **防守阵** | 上排：休门 / 中排：中宫 / 下排：杜门 | 保命回复 | `4`（奇门模式下） |
| **控制阵** | 上排：惊门 / 中排：杜门 / 下排：景门 | 拖住敌人 | `3`+`4`（奇门模式下同时按） |

高手可以自定义每个格子——在非战斗状态下编辑自定义阵法布局（最多保存 5 套）。

### 3.5 模式四：太乙神数（终极演算）

#### 3.5.1 设计定位

道士的终极技能。不是"伤害最高的技能"——是**改变规则**的技能。每场战斗中只能使用 1-2 次（取决于卦气积累）。使用太乙神数的体验应该是：**心跳加速、手心出汗、成功则全场欢呼。**

#### 3.5.2 触发条件

1. 积累 **3 层以上卦气**
2. 切换到太乙神数模式
3. 输入完整的按键序列（5/7/9 键）
4. 输入成功 → 释放效果
5. **输入期间被任何伤害命中 → 打断 → 卦气清空 → 太乙模式进入 60s 冷却**

#### 3.5.3 按键序列设计

太乙神数的输入是一套**固定序列**，不打乱、不随机。每次都是同一个序列。玩家需要的是**肌肉记忆**——就像格斗游戏搓必杀技。

序列设计融入了传统数术的符号含义：

| 等级 | 太乙神数 | 键数 | 输入序列 | 效果 |
|------|---------|------|---------|------|
| Lv20 | **太乙·阴阳逆** | 5键 | `1` `→` `2` `←` `3` | 全场敌人与友军位置互换；敌人 buff 变 debuff，debuff 变 buff |
| Lv35 | **太乙·时空滞** | 7键 | `1` `↑` `3` `↓` `2` `↑` `4` | 全场敌人完全静止 5 秒（含 BOSS），队友伤害 +100% |
| Lv50 | **太乙·因果绝** | 9键 | `2` `↑` `3` `→` `1` `←` `4` `↓` `2` | 标记一个敌人，删除其过去 10 秒内造成的一切伤害和治疗 |

其中 `↑` `↓` `←` `→` = 鼠标甩动方向，`1` `2` `3` `4` = 按键。

#### 3.5.4 输入辅助与惩罚

- **输入提示**：太乙模式下，屏幕中央以 40% 透明度显示剩余未输入的序列提示（新手拐杖）。
- **节奏**：每个输入间隔容忍度为 0.8 秒。超过 → 判定中断。
- **误触**：按错一个 → 中断，卦气清零，从头再来。
- **成功音效**：每完成一键 → 一声编钟低鸣；完成全部 → 钟磬齐奏 + 屏幕短暂的全屏星辉闪烁。
- **中断音效**：一声闷响，类似钟被手按住。

#### 3.5.5 设计意图

太乙神数不是"冷却好了就放"的大招。它是**赌局**：
- 你赌这 4-7 秒内不会被碰到
- 你需要用奇门遁甲的保护阵法、队友的控制掩护来争取输入时间
- 成功带来的回报是规则层面的翻转——不是"伤害高"

### 3.6 紫微斗数：命运星盘（被动成长定制）

#### 3.6.1 设计定位

非战斗系统。紫微斗数是道士的**第二套天赋树**，与传统天赋盘完全独立、平行生效。如果说天赋盘是"你选择怎么变强"，紫微斗数命盘就是"你的道士天生适合什么道路"。

#### 3.6.2 命盘结构

命盘包含了 12 宫，每宫有 1 颗主星。12 宫对应道士的 12 种被动倾向：

| 宫位 | 影响方向 | 紫微系主星示例 | 天府系主星示例 |
|------|---------|-------------|-------------|
| **命宫** | 核心机制（如卦象速度/CDR） | 紫微：暴击时 15% 概率额外触发一次卦效 | 天府：卦象消耗 -10%，效果 -5% |
| **兄弟宫** | 同伴协同 | 天机：队友在阵法中伤害 +8% | 天梁：队友受治疗 +12% |
| **夫妻宫** | 控制/魅惑抗性 | 太阳：对魅惑/混乱免疫率 +25% | 太阴：被魅惑时反射给施法者 50% 概率 |
| **子女宫** | 召唤物/阵法耐久 | 武曲：阵法耐久 +1 | 七杀：召唤物攻击力 +20% |
| **财帛宫** | 资源获取 | 天同：卦气获取 +30% | 廉贞：击杀敌人回复卦气 1 层概率 30% |
| **疾厄宫** | 异常状态抗性 | 巨门：DOT 伤害 -15% | 天相：受治疗时额外净化 1 个 debuff |
| **迁移宫** | 移动/闪避 | 贪狼：闪避无敌帧 +0.1s | 破军：闪避距离 +20% |
| **交友宫** | 好友/佣兵协同 | 左辅：友方 NPC 伤害 +15% | 右弼：友方 NPC 防御 +15% |
| **官禄宫** | 小六爻效果 | 文昌：小六爻持续时间 +30% | 文曲：小六爻冷却 -20% |
| **田宅宫** | 阵法效果 | 禄存：阵法持续 +15 秒 | 天马：阵法冷却 -5 秒 |
| **福德宫** | 卦气相关 | 擎羊：卦气满时伤害 +10% | 陀罗：卦气不满时防御 +10% |
| **父母宫** | 剧情相关 | 铃星：吸收的剧情记忆碎片效果 +25% | 火星：触发剧情觉醒时短暂无敌 5s |

#### 3.6.3 命盘调整

- 初始命盘在**首次切换至道士时**随机生成（基于游戏时间戳——见四柱八字）。
- 玩家可使用「星曜石」调整任意一宫的主星（稀有掉落/任务奖励）。
- 12 宫全紫微系主星 = 「紫微朝垣」成就 → 解锁隐藏外观（白色道袍+紫色星纹）。
- 12 宫全混搭 = 正常强度。12 宫全极端 = 高风险高回报。

### 3.7 四柱八字：出生时辰（角色基底）

#### 3.7.1 设计定位

非战斗系统。在首次创建/切换道士时自动生成，为角色提供独一无二的基底属性。让每个玩家的道士都**天然不同**。

#### 3.7.2 八字生成规则

八字由游戏内**创建时刻的时间戳**转换为干支：

| 柱 | 影响 | 示例：甲子年 丙午月 戊辰日 壬子时 |
|------|------|------|
| **年柱** | 基础属性倾向（攻/防/HP） | 甲子 = 木水 → 攻+2% 防+1% |
| **月柱** | 元素亲和 | 丙午 = 火火 → 离卦(火)效果+8% |
| **日柱** | 核心机制 CDR | 戊辰 = 土土 → 卦象冷却 -5% |
| **时柱** | 隐藏被动（一个小机制） | 壬子 = 水水 → 冰冻免疫率 +15% |

#### 3.7.3 八字影响量化

- 每柱的效果量控制在 **±5%** 以内（总八字影响不超过 ±15%）。
- 不是"好八字 vs 坏八字"——是"这个八字适合火卦 vs 那个八字适合水卦"。
- 有预设「中庸八字」供不想深究的玩家直接使用（效果全 0%）。
- 「改命丹」（极稀有，整个主线流程约获得 3 颗）可以重新生成八字。

### 3.8 梅花易数：环境感知（探索/调查）

#### 3.8.1 设计定位

非战斗系统。道士独有的探索能力。让道士成为队伍中"什么都知道"的那个人。

#### 3.8.2 操作方式

```
长按 F（非战斗状态）→ 进入「观象」状态 → 
屏幕中环境元素被高亮（树影方向、鸟群飞向、水流、花瓣数量等）→ 
松开 F → 自动演算 → 以角色为圆心，半径 40m 内揭示隐藏内容
```

#### 3.8.3 可揭示内容

| 内容 | 揭示方式 | 持续时间 |
|------|---------|---------|
| 隐藏密室/秘道入口 | 墙壁闪烁星光轮廓 | 直到进入或离开区域 |
| 陷阱 | 地面红色高亮 | 30s |
| 可破坏墙壁 | 墙壁中央出现裂纹标记 | 直到离开区域 |
| 隐藏宝箱 | 宝箱位置出现金色问号 | 直到打开 |
| 叙事线索/知残者印记 | 发出持续的低频嗡鸣（声音提示） | 直到互动 |
| 敌人弱点（仅限该区域敌人） | 怪物图鉴自动解锁 1 条弱点信息 | 永久 |

#### 3.8.4 冷却与限制

- **冷却时间**：90 秒
- **感知范围**：以角色为中心 40m 半径（约 1.5 个屏幕）
- **可感知层数**：仅当前层（不能穿层感知）
- **剧情限制**：某些剧情关键隐藏不被梅花易数揭示（需剧情触发）

#### 3.8.5 视觉/听觉反馈

- 观象期间：屏幕色调转为暖黄色，环境声降低 80%，风声变得清晰
- 演算成功：一声清脆的铜钱落地音 + 屏幕微闪
- 有发现：持续的低频嗡鸣（距离越近越响）
- 无发现：一声叹息（音效）——"此地无物。"

## 5. 公式与数值

### 5.1 卦象伤害公式

```
卦象最终伤害 = 基础卦伤 × (1 + 卦气层数 × 0.02) × (1 + 元素亲和) × (1 + 暴击加成) × 敌方抗性减免
```

| 变量 | 说明 |
|------|------|
| 基础卦伤 | 每卦的固定数值（由卦象表定义） |
| 卦气层数 | 当前累积卦气（上限 20） |
| 元素亲和 | 八字月柱 + 装备 + 天赋的元素加成之和 |
| 暴击加成 | 暴击时 = 1 + 暴伤%，否则 = 1 |
| 敌方抗性减免 | 1 - 敌方对应元素抗性 |

### 5.2 卦气积累速度

```
小六爻占卜：1 层/次（冷却 3s） → 最大获取 20 层/分钟
八卦占卜：1 层/次（冷却按卦） → 最大获取 8 层/分钟
击杀精英：2 层
击杀 BOSS：5 层
财帛宫·天同：额外 +30% → 上述数值 × 1.3
```

### 5.3 入门数值基准（Lv1 道士）

| 属性 | 基准值 |
|------|--------|
| 卦象基础伤害（平均） | 攻击力 × 1.2 |
| 八卦占卜释放时间 | 1.2s（平均） |
| 小六爻占卜释放时间 | 0.35s |
| 卦气上限 | 10 |
| 阵法持续时间 | 45s |
| 梅花易数冷却 | 90s |
| 太乙神数输入时间（Lv20） | 约 3s（5键+确认） |

## 6. 边缘情况

### 6.1 被打断

- 时间减速期间被打断 → 卦气清空，该模式进入 5s 冷却
- 太乙神数输入被打断 → 卦气清空 + 60s 冷却（最严重惩罚）
- 梅花易数被打断 → 正常进入 90s 冷却

### 6.2 阵法与场景边界

- 阵法不能放置在地形碰撞体内部
- 阵法不能放置在悬崖/深渊边缘（最小安全距离 2m）
- 阵法跨越场景切换（如进入 BOSS 房间）→ 保留但位置重置为入口附近
- 敌方阵法与我方阵法重叠 → 按生克规则判定，较晚放置者获得 3s 先手优势

### 6.3 命盘切换

- 在安全区域（城镇/营地/太史阁驿站）可以自由调整命盘
- 战斗中不可调整命盘
- 命盘调整后，旧命盘保存为「命盘快照」（最多保存 5 套）

### 6.4 八字不可逆性

- 八字生成后不可逆（除非使用改命丹）
- 改命丹使用后，旧八字永久丢失（无法切换回去）
- 中庸八字 = 所有加成为 0%，不做任何选择就是中庸

### 6.5 卦气衰减边界

- 脱离战斗 15s 后开始衰减
- 在安全区域：卦气保留不衰减
- 在 BOSS 战前准备区：卦气不衰减（设计意图：让玩家可以满卦气进 BOSS）

## 9. 验收标准

1. **小六爻 0 门槛**：未接触过占卜知识的玩家，能在首次战斗中凭直觉完成小六爻占卜，并在 5 分钟内形成"冲过来→往下甩"的肌肉记忆。
2. **八卦上路**：新手使用 `1` 键重复功能，能在不主动选择卦象的情况下通关主流程。使用 `1` 键不应感觉自己"错过了什么"——重复功能本身是有效的玩法。
3. **八卦深度**：记住 8 个上卦功能类别的玩家，能在战斗中自主选择卦象并取得更好的效果（伤害/控制提升 30% 以上）。
4. **奇门新手友好**：使用预设阵法的玩家与手动选门的高端玩家，在主线难度下的表现差异不超过 20%。
5. **太乙零失误不可能**：在 Lv50 太乙神数（9键）输入中，即使是测试团队的顶级玩家，在压力下也无法做到 100% 成功率（目标成功率：60-80%）。
6. **命盘有意义但不过载**：一个完全不碰紫微命盘的玩家，在主线最终 BOSS 战中仍可通关——但调整命盘的玩家能明显感知到差异（约 15-25% 战斗力差异）。
7. **八字不卡人**：任何八字组合都能通关主线。极端八字 = 不同的玩法倾向，不是"能玩/不能玩"。
8. **梅花易数有物可寻**：每个主线关卡中，至少有 3 处隐藏内容只能通过梅花易数发现。
9. **操作流畅**：小六爻占卜穿插在普攻连段中不应产生任何可感知的停顿（释放时间 ≤ 0.4s）。
10. **学不会也能玩**：使用辰星卦师通关主线的玩家中，至少 50% 的人不需要主动理解"大六爻和梅花易数的区别"——他们用小六爻+八卦重复功能也能爽玩。

---

> **设计总结**：辰星卦师不是让玩家成为道士——是让玩家**体验到成为道士的快乐**。那种"掐指一算便知天下事"的从容，"摆阵布局以人心为棋"的智谋，"太乙一出乾坤逆转"的震撼。不需要先读十年易经。游戏本身就是易经的入口。
