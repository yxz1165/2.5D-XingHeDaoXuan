# 道士独挑——法器系统设计：当桃木剑遇上八卦盘

> 核心问题：如何在保留八卦战斗系统的同时，让玩家使用桃木剑等传统道士法器？
> 关键洞察：**法器不是替代卦术——法器是卦术的物理载体。**

---

## 一、问题的本质

当前战斗系统的结构是：

```
银针普攻（鼠标左键）+ 八卦选卦（鼠标右键）+ 小六爻/奇门/太乙（修饰键切换）
```

如果直接"加入剑的攻击"，最坏的情况是：
- 剑和八卦变成两套互不相关的系统 → 玩家只用剑或只用卦 → 设计被架空
- 剑替换了银针普攻 → 只是换了个皮肤 → 没有实质深度

**正确的做法：让剑成为卦术的延伸和变形，而非平行系统。**

---

## 二、道教法器传统：一个被忽略的丰富设计空间

现实中的道士（尤其是正一派、闾山派等实战派）使用的法器：

| 法器 | 传统用途 | 游戏化映射 |
|------|---------|-----------|
| **桃木剑** | 斩妖除魔、画符、结界 | 中距弧斩，卦气附加"斩邪"效果 |
| **铜钱剑** | 镇煞、破暗、辟邪 | 快攻连打，每次命中叠加debuff |
| **七星剑** | 召将、敕令、步罡踏斗 | 重击出击，卦术"命令"属性（强制敌人执行动作） |
| **银针** | 针灸、点穴、暗器 | 极速近战，卦气快速积累（当前设计） |
| **令牌** | 发号施令、召神遣将 | 正面格挡，增强同伴指令效果 |
| **法铃（三清铃）** | 惊鬼、清场、聚神 | 范围冲击波，打断敌人卦术施法 |
| **八卦镜** | 反射、护身、照妖 | 格挡反弹飞行卦术，揭示隐形敌人 |
| **符箓（黄纸）** | 封印、加持、攻击 | 一次性消耗品，预写卦术零消耗释放 |

**关键结论：道士不是"只挥剑的人"，也不是"只算卦的人"。道士是"用法器引导卦术的人"。**

---

## 三、核心设计：法器作为卦术的"物理载体"

### 3.1 设计理念

> **同样的离卦（火），用银针释放 = 火焰针雨，用桃木剑释放 = 真火斩，用七星剑释放 = 火敕令。**

基础框架不变：
- **占卜选卦系统（右键八卦盘）** — 文化核心，完全保留
- **小六爻/奇门遁甲/太乙神数** — 完全保留
- **新增：法器替换普攻模组 + 改变卦术表现形态**

### 3.2 法器系统总览

```
道士法器 =
├── 普攻模组（左键连段）—— 不同法器有不同的攻击动作
├── 卦术变形（右键释放）—— 同卦不同器 = 不同视觉效果+判定+连携
├── 法器专属技（左键+右键组合）—— 类似"武器战技"
└── 法器切换（战斗中即时切）—— 类似仁王/对马岛的架势切换
```

## 四、四种核心法器设计

### 4.1 银针（默认法器·已设计）

**定位：** 卦气发动机——快速积累卦气，为其他法器铺路

| 维度 | 设计 |
|------|------|
| 普攻连段 | 3段近战刺击（第3段附带随机小六爻） |
| 攻击速度 | 极快（0.3s/段） |
| 攻击范围 | 极近（1.5m） |
| 卦气积累 | 每段命中 +8卦气（最高效） |
| 基础伤害 | 低（基准值×0.6） |
| 硬直能力 | Lv1（仅抖动，不打断敌人） |

**卦术变形特征：**
- 所有卦术呈现为"针"的形态——如离卦 = 火焰针雨（散射）、坎卦 = 冰针穿透
- 卦术释放速度 +30%（因为针轻）
- 卦术范围 -20%

**法器专属技——点穴：**
- 长按左键蓄力 → 精准刺击 → 命中敌人特定部位
- 头部：眩晕2秒 / 手部：敌人无法施法3秒 / 腿部：敌人移速-50%

**切换理由：** 卦气不足时切银针；面对高速敌人时用银针保持压制。

---

### 4.2 桃木剑（本章核心·新设计）

**定位：** 均衡法器——物理攻击与卦术释放的最佳平衡点

**解锁时机：** 第一章（星纪宫）结束时，玄伯遗物中藏有一柄断了的桃木剑——锻锋觉醒后，用真火重铸剑身。

| 维度 | 设计 |
|------|------|
| 普攻连段 | 4段弧斩（横→横→纵→回旋） |
| 攻击速度 | 中（0.5s/段） |
| 攻击范围 | 中距（2.5m，弧面覆盖前方120°） |
| 卦气积累 | 每段命中 +5卦气 |
| 基础伤害 | 中（基准值×0.85） |
| 硬直能力 | Lv2（普攻可打断轻甲敌人） |
| 特殊属性 | 对"伪卦/仿品/亡灵"类敌人伤害+25%（斩邪） |

**卦术变形特征：**
- 卦术以"剑斩"形态释放——离卦 = 真火斩（前方扇形火浪）、震卦 = 雷剑突刺（直线穿透）
- 卦术范围 = 基准值
- 卦术释放附带一次剑斩伤害（物理+卦术双重判定）

**法器专属技——虚空画符：**
- 战斗中长按左键蓄力 → 桃木剑在空中画出特定符箓（玩家用小六爻方向选择符型）
- ↑ = 火符（前方直线灼烧）/ ↓ = 水符（回复卦气）/ ← = 雷符（前方落雷） / → = 风符（前方DOT区域）
- 画符消耗卦气25，不进入八卦盘选卦流程（即时释放）
- 画符期间可以移动（慢走，不可闪避）

**哲学映射（大梁宫·去伪存真）：**
- 桃木剑的核心能力"斩邪"在"去伪存真"章节获得最大强化
- 在大梁宫的BOSS战中，桃木剑可以斩断"伪卦"——使被西陆篡改的卦术恢复正常
- 剑尖画出的符箓 = 书写真相的动作

**切换理由：** 大多数常规战斗的默认选择；需要群体控制时切桃木剑。

---

### 4.3 铜钱剑（中期法器）

**定位：** 连击法器——高频率攻击 + debuff叠加 + 暴击经济

**解锁时机：** 第四章（降娄宫）后，顾锋以"剑气"为启发，帮辰生将108枚铜钱串成剑。

| 维度 | 设计 |
|------|------|
| 普攻连段 | 5段快攻（刺→刺→挑→扫→散落回收） |
| 攻击速度 | 快（0.35s/段） |
| 攻击范围 | 中近距（2m） |
| 卦气积累 | 每段命中 +3卦气 +1铜钱计数 |
| 基础伤害 | 中低（基准值×0.7） |
| 硬直能力 | Lv1 |
| 特殊属性 | 108铜钱计数系统（见下方） |

**铜钱计数系统（核心机制）：**

```
每次普攻命中 → 铜钱计数+1
每18枚铜钱 → 触发一次"通宝"效果：
  18枚：下一次卦术零卦气消耗
  36枚：暴击率+15%（持续至108枚或战斗结束）
  54枚：获得一个"铜钱护盾"（吸收20%生命伤害）
  72枚：下一次法器专属技必暴击
  90枚：当前卦气翻倍
  108枚：全场铜钱雨——自动攻击周围所有敌人（1.5×攻击力×敌人数量），计数归零
```

**设计意图：** 铜钱剑鼓励"持续进攻"——你打得越久、越猛，就越强。和银针的"打了就切"形成相反策略。

**卦术变形特征：**
- 卦术附加"金币"视觉效果——离卦 = 火焰铜钱散射（散弹式AOE）
- 卦术消耗 -20%（因为铜钱的"财"属性）
- 卦术伤害 -10%（威力下降，但频次增加）

**法器专属技——撒豆成兵：**
- 长按左键蓄力 → 撒出铜钱 → 铜钱在地面形成短暂的"结界环"（3m直径，8秒持续）
- 结界内：敌人减速30%、辰生卦气恢复翻倍

**切换理由：** 面对高血量单体敌人用铜钱剑叠计数；需要快速刷卦气时用铜钱剑。

---

### 4.4 七星剑（后期法器）

**定位：** 重击法器——高伤害 + "敕令"效果 + 星君共鸣

**解锁时机：** 第八章（鹑火宫）后，玄微子传授。剑身上镶嵌七颗宝石，对应北斗七星。

| 维度 | 设计 |
|------|------|
| 普攻连段 | 3段重击（纵劈→横扫→突刺） |
| 攻击速度 | 慢（0.8s/段） |
| 攻击范围 | 远距（3.5m） |
| 卦气积累 | 每段命中 +12卦气（但段数少） |
| 基础伤害 | 高（基准值×1.3） |
| 硬直能力 | Lv3（普攻可击退中甲敌人） |
| 特殊属性 | 敕令——对"灵体/星君/伪星力"类敌人，可强制其执行动作 |

**敕令系统（核心机制）：**

七星剑的每一段普攻附带"敕令值"积累。敕令值满后，敌人头顶出现"敕令标记"——按下右键不进入卦盘，而是触发敕令：

| 敕令类型 | 效果 | 适用对象 |
|---------|------|---------|
| 伏（剑尖下指） | 敌人强制跪下2秒（不可行动） | 人类敌人 / 精英怪 |
| 退（剑身横推） | 敌人后退5m+恐惧3秒 | 群体敌人 |
| 破（剑尖前刺） | 直接破除敌人的卦术护盾/阵法 | 卦师类敌人 |
| 归（剑身朝天） | 对伪星力敌人——强制其"回忆起真实身份" | BOSS特殊阶段 |

**设计意图：** 七星剑不是用来"砍"的——是用来"命令"的。北斗七星在道教中是"天之号令"，七星剑是道士行使号令的工具。

**卦术变形特征：**
- 卦术以"北斗星光"形态释放——离卦 = 天权星火（从天而降的火柱）、坎卦 = 天璇星水
- 卦术范围 +30%
- 卦术释放速度 -40%（因为剑重）
- 卦术消耗 +30%

**法器专属技——步罡踏斗：**
- 长按左键蓄力 → 按照北斗七星方位踏出7步 → 每一步留下一个星光脚印
- 7步踏完 → 七星连成北斗阵 → 阵内15m范围 → 所有卦术零消耗（持续10秒）
- 踏斗期间不可闪避，可被强力攻击打断
- 冷却：一场战斗一次（或300秒）

**哲学映射（鹑火宫·劳动创造文明）：**
- 七星剑"命令"的不是毁灭——是调遣
- 鹑火宫的主题是"劳动创造"——鲁班语（神机星君）用机关创造，辰生用七星剑调遣星辰之力
- 步罡踏斗 = 用自己的身体丈量大地 = 劳动的行为

**切换理由：** BOSS战高端输出；面对需要"破除"机制的敌人；后期追求极限伤害时。

## 五、法器切换机制

### 5.1 切换方式

不采用"滚轮循环"（和卦盘模式切换冲突），也不采用"菜单选择"（打断战斗）。

**推荐方案：方向键瞬间切换**

```
↑ 方向键 = 桃木剑（最常用，放在最容易按到的位置）
← 方向键 = 银针（卦气发动机，放在左边=撤退/回复的直觉）
→ 方向键 = 铜钱剑 / 七星剑（前期是铜钱，后期获得七星后替换）
↓ 方向键 = 铜钱剑（前后期不变）

手柄：十字键↑/←/→/↓ 对应四种法器
```

**切换响应：** 瞬时切换，切法器时当前连段中断但可以立刻开始新法器的普攻。切换有0.3秒冷却（防止误触连切）。

### 5.2 法器切换与卦术连携

**核心机制——"切器即切卦"：**

```
玩家正在用桃木剑 → 释放了离卦真火斩 → 命中后↓方向键切银针 →
银针的下一段普攻自动附带"离火针"效果（灼烧DOT）

→ 银针打完3段积累卦气 → 切回桃木剑 →
桃木剑的第1段攻击变为"火针蓄势斩"（增伤30%）
```

**设计意图：** 切换法器不只是换普攻——是创造"武器连携"的深度。高手可以在一次卦术释放后无缝切换法器，打出叠加效果。

### 5.3 法器精通度

每个法器有独立的精通等级（通过使用该法器积累经验值）：

| 等级 | 效果 |
|------|------|
| Lv1 | 初识：基础属性 |
| Lv2 | 熟练：普攻段数+1（银针3→4、桃木4→5、铜钱5→6、七星不变） |
| Lv3 | 精通：法器专属技冷却-30% |
| Lv4 | 大师：切至此法器时，第一个卦术消耗-50% |
| Lv5 | 入化：解锁隐藏连携——特定法器组合的切器连携变为"奥义"级效果 |

## 六、对现有战斗系统的影响评估

### 6.1 需要修改的 GDD 部分

| 原设计 | 修改为 |
|--------|--------|
| 普攻仅银针3段 | 4种法器各有独立普攻模组 |
| 右键卦术表现统一 | 同卦不同器 = 不同形态（但数据核心不变） |
| 无武器系统 | 法器系统（4件 + 可能的隐藏法器） |

### 6.2 不需要修改的部分

- ✅ 八卦盘选卦系统（右键 + 8方向 + 1/2/3/4下卦）— 完全保留
- ✅ 小六爻（Shift + 鼠标方向）— 完全保留
- ✅ 奇门遁甲（Ctrl + 九宫格）— 完全保留
- ✅ 太乙神数（双击Tab + 按键序列）— 完全保留
- ✅ 64卦组合公式 — 完全保留，法器只是改变"同一个卦的表现形态"
- ✅ NPC同伴系统 — 完全保留
- ✅ 紫微命盘/梅花易数 — 完全保留
- ✅ 卦气系统 — 各法器积累速度不同，但底层逻辑不变

## 七、桃木剑战斗体验——纸面模拟

以星纪宫BOSS战（焦烈）为例，假设玩家在此时已获得了桃木剑：

```
【开场】
→ 银针开局 → 快速3段命中积累卦气 → 卦气35

【阶段一：白焰专家】
→ ↑方向键切桃木剑 → 按住右键 → 鼠标指↑（离卦上卦）→ 按1（乾下卦，最大化伤害）
→ 松手 → "真火斩" —— 桃木剑斩出一道金色火焰弧，前方扇形15m灼烧
→ 焦烈白焰被金色真火覆盖 → 短暂失神
→ 桃木4段连斩追击 → 卦气恢复

【阶段二：极寒囚笼】
→ 焦烈释放冰牢 → ←方向键切银针 → 闪避出冰牢 → 银针快速打击冰元素召唤物
→ 卦气积累到50 → 切回桃木剑
→ 长按左键蓄力 → "虚空画符·火符" → 前方直线灼烧 → 破除焦烈的极寒光环

【阶段三：真相】
→ 焦烈释放终极白焰 → 锻锋觉醒 → 离卦变金色
→ ↓方向键切桃木剑（已精通Lv2） → 按住右键 → 离卦 + 巽下卦（加速）
→ 金色真火斩2连发 → 白焰全部被转化
→ 焦烈最后的白焰熄灭 → 掌心燃起橙色小火苗
→ 用桃木剑（剑尖下垂，不攻击）→ 等待剧情演出
```

**关键感受：**
- 桃木剑不只是"挥剑"——每一个斩击都是某个卦术的物理延伸
- 银针和桃木剑的切换不是"换武器"——是"换节奏"：银针快攻积累 → 桃木爆发释放
- 虚空画符给了桃木剑一种"我在用法器写咒"的仪式感——不只是在砍

## 八、建议的 Phase 1 调整

原 Phase 1 只涉及银针普攻。如果引入法器系统，建议：

### Phase 1 最小集（序章+星纪宫）

```
法器：银针（默认）+ 桃木剑（星纪宫通关获得）
法器切换：↑/←方向键（仅2种，不需要4方向）
切器连携：基础版（切器后首段增伤15%，不需要复杂组合）
卦术变形：仅离卦×4下卦的桃木剑版本（4种火卦剑术效果）
```

## 十、总结

**核心洞见只有一句话：**

> 桃木剑不是在"八卦之外"再搞一套东西——桃木剑是卦术的"笔"。道士不是用剑砍人，是用剑写卦。

- 同一个离卦 = 银针的火针 / 桃木剑的真火斩 / 铜钱剑的火钱散射 / 七星剑的火敕令
- 底层的卦象系统（选卦逻辑、卦气消耗、64卦组合）完全不变
- 法器层叠加在上方——改变的是"卦术如何被释放到世界中"
- 四种法器 = 四种战斗节奏——不是四种职业，是同一个人用不同的方式引导星辰

**这对"道士独挑"决策的意义：** 法器系统证明了"只保留一个职业"不是减法——是加法。一个职业内部有四套武器节奏，比十个职业各自一套更有深度。
