## 三、法器进阶路线

### 3.1 精通等级（所有主法器+副手法器共用）

每件法器独立精通等级，通过使用该法器战斗积累经验：

| Lv | 名称 | 所需经验（击杀数） | 主法器效果 | 副手法器效果 |
|:--:|------|:--:|-----------|------------|
| 1 | 初识 | 0 | 基础属性 | 基础效果 |
| 2 | 熟练 | ~50 | 普攻段数+1 | 冷却-15% |
| 3 | 精通 | ~150 | 专属技冷却-30% | 冷却-30%+效果+20% |
| 4 | 大师 | ~400 | 切至此法器时首卦消耗-50% | 可以使用2次/场战斗 |
| 5 | 入化 | ~1000 | 解锁"奥义"连携 | 解锁"共鸣"槽（与主法器配对触发套装） |

### 3.2 锻造等级（星碑处·消耗材料升级法器基础属性）

每件主法器独立锻造等级：

| 锻造Lv | 材料 | 攻击提升 | 特殊解锁 |
|:--:|------|:--:|---------|
| +0 | — | 基准 | 基础 |
| +1 | 青铜锭×3 | +5% | — |
| +2 | 青铜锭×5+铁锭×2 | +10% | — |
| +3 | 铁锭×5+精铁×2 | +15% | 解锁第一个纳甲槽 |
| +4 | 精铁×5+钢锭×2 | +20% | — |
| +5 | 钢锭×5+秘银×2 | +25% | 解锁第二个纳甲槽 |
| +6 | 秘银×5+陨铁×2 | +30% | — |
| +7 | 陨铁×5+星晶×2 | +35% | 解锁第三个纳甲槽 |
| +8 | 星晶×5+星核×1 | +40% | — |
| +9 | 星核×3+九天星晶×1 | +50% | 解锁全部六个纳甲槽 |

**锻造材料来源：**
- 青铜锭/铁锭/精铁/钢锭 → 采矿+营地锻造台合成
- 秘银 → 降娄宫·剑冢区域
- 陨铁 → 析木宫·星陨之地
- 星晶 → 各道宫精英怪掉落
- 星核 → BOSS掉落
- 九天星晶 → 终章·寿星宫

### 3.3 铭刻（纳甲纳支·在锻造解锁的槽位上铭刻天干地支）

每件法器最多6个铭刻槽（对应六爻：初→上），+3/+5/+9锻造等级各解锁2个槽。

**铭刻材料：** 天干石（甲乙丙丁戊己庚辛壬癸·10种）+ 地支晶（子丑寅卯辰巳午未申酉戌亥·12种）

```
铭刻示例（桃木剑）：
  初爻槽·甲子 → 甲（木·青龙）+ 子（水）= 坎卦效果+15%
  二爻槽·丙寅 → 丙（火·朱雀）+ 寅（木）= 离卦灼烧时间+2s
  三爻槽·庚申 → 庚（金·白虎）+ 申（金）= 乾卦暴击伤害+20%
  
  当丙寅和庚申同时存在 → 纳音触发：
  丙寅=炉中火 + 庚申=石榴木 → "火木相生" → 离卦命中后附加木属性DOT
```

**22种铭刻材料来源：**
- 天干石（10种）→ 各道宫矿脉
- 地支晶（12种）→ 各道宫精英怪/隐藏房间

**30种纳音词条：** 当铭刻的两个天干地支符合纳音配对时激活（甲子乙丑=海中金、丙寅丁卯=炉中火……），每种纳音=一个特殊词条。

## 五、与全部现有系统的接口

### 5.1 法器 ↔ 战斗系统

```
主法器切换（↑↓←→）→ 普攻模组 + 卦术形态 + 专属技
副手法器（L1）→ 独立技能
符箓（Ctrl+1~4）→ 零消耗瞬发
```

### 5.2 法器 ↔ 三钱摇卦

```
银针在膝 → 老阳概率+2%
桃木剑在膝 → 变爻启示效果+50%
铜钱剑在膝 → 额外铜钱掉落Buff
七星剑在膝 → 乾/坤卦额外敕令卦
```

### 5.3 法器 ↔ 奇门遁甲

```
法尺装备 → 阵法范围+5m
八卦道袍 → 阵法持续+10s
镇星土印 → 阵法不可被摧毁
```

### 5.4 法器 ↔ 同伴系统

```
令牌装备 → 同伴指令效果翻倍
计都暗印 → 影同伴处决阈值提升
折木牺牲印 → 空亡触发时同伴获得同样3s无敌
```

### 5.5 法器 ↔ 内丹修炼

```
卦气四层（炼精化炁→炼炁化神→炼神还虚→炼虚合道）
  Lv1 → 可使用主法器
  Lv2 → 可使用副手法器
  Lv3 → 可使用紫符
  Lv4 → 解锁共鸣系统
```

### 5.6 法器 ↔ 二十四节气

```
不同节气 → 不同法器有优势/劣势：
  春（木旺）：桃木剑·拂尘·法尺效果+20%
  夏（火旺）：七星剑（火敕令）效果+20%
  秋（金旺）：银针·铜钱剑·八卦镜效果+20%
  冬（水旺）：七星剑（水敕令）·甘露碗效果+20%
  四季末（土旺）：令牌·五雷令效果+20%
```

### 5.7 法器 ↔ 锻造商店

```
各道宫铁匠/商人：
  星纪宫·北部营地 → 青铜·铁质材料
  娵訾宫·丹霞镇 → 丹砂·草药·银针精通书
  降娄宫·剑冢村 → 秘银·钢锭·剑类精通书

  析木宫·祭坛 → 陨铁·星核·甘露碗
```
