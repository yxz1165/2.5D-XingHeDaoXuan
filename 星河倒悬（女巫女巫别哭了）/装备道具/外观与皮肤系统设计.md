# 外观与皮肤系统设计

> **定位：** 纯外观系统——不影响数值·不影响战斗平衡。角色的道袍、法器的外观、三钱铜钱的皮肤、八卦光环的样式·全部可自定义。获得方式=主线解锁+星晶兑换+特殊成就。
> **关联：** [[装备道具/法器锻造与进阶系统GDD]] | [[术数系统/卦象选装与选卦交互——完整规格书]] | [[营地经济/经济系统设计]]

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **纯外观·零数值** | 任何皮肤不增加任何属性·不改变战斗机制 |
| **可见即可得** | 在92px俯视角下仍需可辨识（颜色+轮廓变化） |
| **获得有意义** | 不是"买"来的——是"玩"来的·每件有获得故事 |
| **卦象主题** | 皮肤设计围绕八卦/六十四卦/星宿/五行等文化元素 |
| **不割裂体验** | 新手辰生穿着打补丁的青布道袍→终章穿着星辰法衣——外观本身就是成长叙事 |

## 二、皮肤品类

### 2.1 品类总览

| 品类 | 数量 | 影响 | 获得方式 |
|------|:--:|------|------|
| **道袍** | 12套 | 角色整体外观·颜色·纹理·下摆 | 每过一宫解锁1套 + 特殊成就 |
| **法器皮肤** | 16种 | 4法器×各4种皮肤·改变法器外形 | 星晶兑换 + 隐藏获得 |
| **三钱皮肤** | 8套 | 摇卦时三枚铜钱的外观 | 六爻纳币进度 + 星晶兑换 |
| **光环皮肤** | 8种 | 八卦光环的样式和颜色 | 术数系统精通 + 星晶兑换 |
| **葫芦挂件** | 6种 | 腰间葫芦的外观 | 同伴好感度 + 隐藏获得 |
| **星纹光效** | 8种 | 左手腕星纹的光效颜色和形状 | 紫微命盘完成度 + 成就 |

### 2.2 俯视角可见性

在28m×20m基准距离·角色92px下：

| 皮肤部位 | 可见像素 | 辨识方式 |
|------|:--:|------|
| 道袍整体颜色 | ~60px | 主色调变化明显（青→赤→金→白） |
| 法器外形 | ~54px | 桃木剑变冰晶剑·轮廓截然不同 |
| 三钱铜钱 | ~8px/枚 | 颜色+光效（摇卦时特写镜头放大） |
| 八卦光环 | ~160px直径 | 颜色+纹理+旋转速度 |
| 葫芦 | ~16px | 颜色+形状（葫芦变大变小变扁） |
| 星纹 | ~3px | 发光颜色·暗金→纯金→银→星蓝 |

## 九、星晶兑换商店

### 9.1 货币

星晶 = 道宫通关奖励(每宫2-5颗) + 精英怪掉落 + 隐藏发现。

总计112颗可收集·部分皮肤需要用星晶兑换。

### 9.2 兑换价格

| 品类 | 皮肤 | 星晶价格 |
|------|------|:--:|
| 法器皮肤 | 冰晶桃木剑/星辰针/金丝铜钱剑/血月七星剑… | 30-80 |
| 三钱皮肤 | 星晶钱/五行三钱 | 20-40 |
| 光环皮肤 | 星辰光环/虚空光环 | 50-80 |
| 葫芦挂件 | 冰晶葫芦/铜钱葫芦 | 20-30 |

> 星晶不可购买·只能通过游戏内获得。确保"花钱也买不到"的稀有度。
