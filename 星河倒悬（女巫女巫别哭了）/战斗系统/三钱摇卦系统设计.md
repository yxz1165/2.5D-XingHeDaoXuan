# 三钱摇卦系统设计——完整的战前占卜·从概率到代码

> **定位：** 战斗外系统·星碑处触发。6次甩鼠标→3枚铜钱空中旋转落地→本卦+变卦→卦象启示Buff。与紫微斗数形成双层占卜——三钱问"今日"·紫微问"此生"。

## 一、文化根源——真实的"三钱法"

### 1.1 传统三钱摇卦

三钱法是中国民间最流行的六爻占卜方式——用三枚铜钱替代了古代的大衍筮法（50根蓍草）。简单快速，人人可用。

```
操作：
  三枚铜钱 → 合掌摇动 → 抛落桌面 → 看正反面
  正（有字面）= 阳爻（⚊）· 反（无字面）= 阴爻（⚋）
  重复6次 → 从下往上画出6爻 → 得到本卦

老阳老阴 = 变爻 → 反转 → 变卦
本卦 = 当前处境 · 变卦 = 未来走向
```

### 1.2 四种爻型

三枚铜钱的正反面组合共4种结果：

| 结果 | 正反比 | 爻象 | 标记 | 概率 |
|------|:--:|:--:|------|:--:|
| 三正 | 3正·0反 | ⚊ 老阳 | ○（变爻·阳→阴） | 1/8 |
| 二正一反 | 2正·1反 | ⚊ 少阳 | —（不变） | 3/8 |
| 一正二反 | 1正·2反 | ⚋ 少阴 | —（不变） | 3/8 |
| 三反 | 0正·3反 | ⚋ 老阴 | ×（变爻·阴→阳） | 1/8 |

**任一爻为变爻的概率：** 1/8 + 1/8 = **1/4**
**一卦六爻全不变的概率：** (3/4)⁶ = 729/4096 ≈ **17.8%**
**至少有一爻变的概率：** 1 - 0.178 = **82.2%**

### 1.3 验证——完整概率分布

```
6次抛掷·每次独立·每爻四种结果：
  老阳概率 1/8
  少阳概率 3/8
  少阴概率 3/8
  老阴概率 1/8

一卦6爻·有k个变爻的概率（二项分布）：
  P(k=0) = (6C0)(0.25)⁰(0.75)⁶ = 0.1780 → 17.8%
  P(k=1) = (6C1)(0.25)¹(0.75)⁵ = 0.3560 → 35.6%
  P(k=2) = (6C2)(0.25)²(0.75)⁴ = 0.2966 → 29.7%
  P(k=3) = (6C3)(0.25)³(0.75)³ = 0.1318 → 13.2%
  P(k=4) = (6C4)(0.25)⁴(0.75)² = 0.0330 → 3.3%
  P(k=5) = (6C5)(0.25)⁵(0.75)¹ = 0.0044 → 0.44%
  P(k=6) = (6C6)(0.25)⁶(0.75)⁰ = 0.0002 → 0.02%

验证总和：0.178+0.356+0.2966+0.1318+0.033+0.0044+0.0002 = 1.000 ✓

最常见情况：1-2个变爻（合计65.3%）· 极端情况：6个全变（0.02%·约每5000次出1次）
```

## 二、游戏机制——站在星碑前占卜

### 2.1 触发与流程

```
1. 站在星碑 → 按F → 选"摇卦问卜"
2. 辰生跪坐·三枚铜钱浮在掌中
3. 界面提示："按住右键→甩动鼠标→松手"
4. 第1次甩 → 铜钱飞出→旋转→落地 → 初爻浮现（画面下方）
   第2次甩 → 二爻浮现（初爻上方）
   ...重复6次
5. 六爻齐 → 本卦高亮 → 变爻闪烁反转 → 变卦浮现
6. 启示面板弹出 → 显示Buff+代价 → [接受] [重摇·-20卦气]
```

### 2.2 甩动参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 单次甩动时间 | 0.5-1.5秒 | 鼠标按住→甩出→松手 |
| 甩动速度影响 | 铜钱旋转圈数（纯视觉·不影响概率） | 快甩=多转几圈·慢甩=少转 |
| 方向影响 | 微弱偏向（±1%·心理暗示·不影响实际概率） | — |
| 6次总耗时 | 约5-10秒 | 含动画等待 |
| 速通模式 | 按住Shift连续快甩·2秒完成 | — |

### 2.3 铜钱物理（视觉）

```
甩动瞬间 → 3枚铜钱从掌心飞出
  → 空中旋转·互相碰撞·发出"叮叮"声
  → 落地·弹跳·最终停稳
  → 正面（有字·阳）— 金色光柱升起
  → 反面（无字·阴）— 暗色光柱·中间断裂
  → 老阳/老阴波动特效（闪烁·嗡鸣）
```

## 五、与紫微斗数·流日运势的叠加

### 5.1 叠加算法

```
摇卦获得本卦 → 取本卦五行（乾金·坤土·震木·巽木·坎水·离火·艮土·兑金）

今日流日运势增强的宫位 → 该宫位主星五行

两种五行比较：
  比和（同五行）    → 运势叠加·摇卦Buff × 1.5
  相生（生关系）    → 运势增强·摇卦Buff × 1.2
  相克（克关系）    → 运势一般·摇卦Buff × 1.0
  对冲（反克关系）  → 运势冲突·摇卦Buff × 0.7·建议重摇或换Build
```

### 5.2 代码实现

```csharp
// ⚠️ WuXing 枚举定义已迁移至「共享系统接口定义.md」§一（全项目唯一权威定义）
// 引用方式：using static WuXing; + using static WuXingExtensions;
// 枚举值：Metal=0, Water=1, Wood=2, Fire=3, Earth=4（相生序）

public static class WuXingRelations {
    // 五行相生：金→水→木→火→土→金
    public static bool IsGenerating(WuXing a, WuXing b) {
        return ((int)a + 1) % 5 == (int)b;
    }
    // 五行相克：金→木→土→水→火→金（隔一位）
    public static bool IsOvercoming(WuXing a, WuXing b) {
        return ((int)a + 2) % 5 == (int)b;
    }
    // 反克 = 被克
    public static bool IsOvercome(WuXing a, WuXing b) => IsOvercoming(b, a);
    
    // 六十四卦五行映射
    public static WuXing GetHexagramWuXing(int hexagramId) {
        // 上卦定五行
        int upper = hexagramId / 8; // 0乾金·1兑金·2离火·3震木·4巽木·5坎水·6艮土·7坤土
        return upper switch {
            0 or 1 => WuXing.Metal,
            2 => WuXing.Fire,
            3 or 4 => WuXing.Wood,
            5 => WuXing.Water,
            6 or 7 => WuXing.Earth,
            _ => WuXing.Earth
        };
    }
    
    // 运势叠加计算
    public static float GetFortuneMultiplier(int hexagramId, ZiweiDestiny destiny, int gameDay) {
        var (enhanced, _) = destiny.GetDailyFortune(gameDay);
        var dailyWuXing = GetPalaceWuXing(destiny, enhanced);
        var shakeWuXing = GetHexagramWuXing(hexagramId);
        
        if (dailyWuXing == shakeWuXing) return 1.5f;  // 比和
        if (IsGenerating(dailyWuXing, shakeWuXing)) return 1.2f; // 相生
        if (IsOvercoming(dailyWuXing, shakeWuXing)) return 1.0f; // 相克
        return 0.7f; // 对冲·运势冲突
    }
}
```

## 六、完整实现代码

### 6.1 核心类

```csharp
[Serializable]
public class CoinDivination {
    // === 单次抛掷结果 ===
    public enum YaoType { LaoYang, ShaoYang, ShaoYin, LaoYin }
    
    // === 生成一爻 ===
    public static YaoType ThrowOnce() {
        int heads = 0;
        for (int i = 0; i < 3; i++) {
            if (UnityEngine.Random.value < 0.5f) heads++; // 正面=阳
        }
        return heads switch {
            3 => YaoType.LaoYang,  // 三正
            2 => YaoType.ShaoYang, // 二正一反
            1 => YaoType.ShaoYin,  // 一正二反
            0 => YaoType.LaoYin,   // 三反
            _ => YaoType.ShaoYang
        };
    }
    
    // === 摇卦完整流程 ===
    public static ShakeResult PerformDivination() {
        var result = new ShakeResult();
        for (int i = 0; i < 6; i++) {
            result.yao[i] = ThrowOnce();
        }
        result.Calculate();
        return result;
    }
}

public class ShakeResult {
    public CoinDivination.YaoType[] yao = new CoinDivination.YaoType[6]; // [0]=初爻·[5]=上爻
    public int benGuaId;  // 本卦ID(0-63)
    public int bianGuaId; // 变卦ID(0-63)·若无变爻则=-1
    public List<int> changingYao = new List<int>(); // 变爻位置(0-5)
    
    // 计算本卦和变卦
    public void Calculate() {
        int benValue = 0; // 6bit·从初爻到上爻
        int bianValue = 0;
        
        for (int i = 0; i < 6; i++) {
            bool isYang = (yao[i] == CoinDivination.YaoType.LaoYang || 
                          yao[i] == CoinDivination.YaoType.ShaoYang);
            bool isChanging = (yao[i] == CoinDivination.YaoType.LaoYang || 
                              yao[i] == CoinDivination.YaoType.LaoYin);
            
            if (isYang) benValue |= (1 << i);
            if (isYang && isChanging) {
                changingYao.Add(i);
                // 变爻反转
            }
            bianValue = benValue;
            foreach (int ci in changingYao) {
                bianValue ^= (1 << ci); // 翻转该bit
            }
        }
        
        benGuaId = benValue;
        bianGuaId = (changingYao.Count > 0) ? bianValue : -1;
    }
    
    // 获取启示——使用统一的RevelationTableFull数据结构
    public Revelation GetRevelation() {
        var rev = new Revelation();
        rev.benGuaRevelation = RevelationTableFull.Get(benGuaId);
        rev.bianGuaRevelation = (bianGuaId >= 0) ? RevelationTableFull.Get(bianGuaId) : null;
        rev.changingYaoEffects = new List<ChangingYaoEffect>();
        foreach (int ci in changingYao) {
            rev.changingYaoEffects.Add(GetChangingYaoEffect(ci));
        }
        return rev;
    }
    
    // 变爻位图——6bit·每位=1个变爻位置(0=初爻·5=上爻)
    public int GetChangingYaoBitmap() {
        int bitmap = 0;
        foreach (int ci in changingYao) bitmap |= (1 << ci);
        return bitmap; // 0-63
    }
```

```
帧 0-5（按住右键·蓄力）：
```

## 十六、特殊机制——稀有卦象

### 14.1 泰卦（䷊·1/64概率）

泰卦是唯一纯吉无代价的卦。摇出泰卦时：
- 额外播放特殊动画：天地交泰·金色光柱贯穿屏幕
- 启示Buff：全元素伤害+10%·全抗+10%·无代价
- 成就解锁："天地交泰"（首次摇出泰卦）
- 成就解锁："国泰民安"（在所有12座道宫中各摇出一次泰卦）

### 14.2 六爻全变（概率0.02%）

- 额外播放特殊动画：六爻全部闪烁·同时反转·屏幕短暂全白
- 启示：全部6个变爻效果同时激活（每个效果独立·不冲突）
- 成就解锁："天命加身"（摇出六爻全变）
- 成就解锁："逆天改命"（六爻全变后击败BOSS·不重摇）

### 14.3 六爻全不变（概率17.8%）

- 本卦=唯一结果·无变卦
- 启示面板简化：
  "此卦无变·天意已定·无需再问"
  → 启示效果×1.5（因为"天意坚决"）
