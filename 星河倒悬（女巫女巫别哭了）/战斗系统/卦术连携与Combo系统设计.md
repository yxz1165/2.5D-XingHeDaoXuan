# 卦术连携与Combo系统——完整设计规格

> **定位：** 连接"普攻""卦术""法器切换""形态切换""环境交互"五层操作的连携规则。本系统的目标是把"选卦→放卦"升级为"选卦→连卦→切器→再连卦"的流畅战斗流。
> **依赖：** [[战斗系统GDD]] | [[卦术战斗体感设计]]
> **关联：** [[64卦完整战斗数据规格书]] | [[敌人AI战斗行为树]]

---

## 一、设计目标

当前战斗系统的核心循环是"普攻→选卦→放卦→看效果→再选"。这个循环是正确的——但它缺少一个关键层：**连携**。

```
没有连携的战斗： 普攻 → 选卦 → 放卦 → 等冷却 → 再选 → 再放
有连携的战斗：   普攻 → 选卦 → 取消窗口切入 → 切法器 → 相生连携 → 重卦收尾
```

**连携的目标不是让玩家"按更多按钮"——是让正确的操作选择获得超额回报。**

## 二、取消窗口系统

这是所有连携的物理基础。没有取消窗口，玩家必须等动画播完才能做下一个动作。

### 2.1 取消窗口总表

| 动作 | 可取消时机 | 可取消为 |
|------|----------|---------|
| **普攻第1段** | 命中后2帧 | 闪避、选卦 |
| **普攻第2段** | 命中后3帧 | 闪避、选卦、法器切换 |
| **普攻第3段** | 命中后4帧 | 闪避、选卦、法器切换、同伴指令 |
| **普攻最终段** | 命中后6帧 | 所有动作（含太乙神数） |
| **卦术释放** | 命中后4帧 | 闪避、法器切换、选卦（不触发时停·直接进入选卦状态） |
| **闪避** | 无敌帧结束后 | 普攻、选卦（闪避后1秒内卦术瞬发） |
| **法器切换** | 切换完成即刻 | 普攻、选卦（切换后1.5秒内首卦连携加成） |
| **小六爻** | 释放后即刻 | 普攻、闪避 |
| **太乙神数成功** | 演出结束后 | 任意动作（全场硬直中） |
| **太乙神数失败** | 硬直结束后 | 闪避（不能立刻普攻·有0.5秒惩罚帧） |

### 2.2 取消窗口的视觉提示

- 辰生身上闪一次微弱的白光 → 当前动作可取消
- 成功取消（在窗口内操作）→ 白光变为对应卦象的颜色
- 错过窗口（操作太晚）→ 无白光，正常输入排队

### 2.3 取消窗口的难度梯度

| 窗口大小 | 难度 | 输出增益 |
|---------|:--:|:--:|
| 6帧（普攻最终段） | 新手友好 | 标准伤害 |
| 4帧（卦术命中） | 中等 | 连携加成+15% |
| 3帧（普攻第2段） | 进阶 | 连携加成+25% |
| 2帧（普攻第1段） | 高手 | 连携加成+35% |

> **设计意图：** 新手用6帧窗口也能打出连携。高手追求2帧窗口→获得更高的连携加成→追求风险回报比。

## 三、卦象连携系统

### 3.1 五行相生连携

切换卦术时，如果新卦的上卦五行"生"旧卦的上卦五行，触发相生连携：

| 切换方向 | 五行关系 | 连携效果 | 卦气奖励 |
|---------|---------|---------|:--:|
| 火☲ → 土☷/☶ | 火生土 | 旧卦残留效果延续50% | +5 |
| 土☷/☶ → 金☰/☱ | 土生金 | 新卦破甲率+30% | +8 |
| 金☰/☱ → 水☵ | 金生水 | 新卦吸血率+10% | +10 |
| 水☵ → 木☴/☳ | 水生木 | 新卦DOT持续时间翻倍 | +10 |
| 木☴/☳ → 火☲ | 木生火 | 新卦伤害+40% | +15 |

### 3.2 五行相克爆发

切换卦术时，如果新卦的上卦五行"克"旧卦的上卦五行，触发相克爆发（伤害向）：

| 切换方向 | 五行关系 | 爆发效果 |
|---------|---------|---------|
| 火☲ → 金☰/☱ | 火克金 | 新卦破甲+50%·敌人防御-30%（10秒） |
| 金☰/☱ → 木☴/☳ | 金克木 | 新卦打断等级+1（硬直→击退→浮空→击倒） |
| 木☴/☳ → 土☷/☶ | 木克土 | 新卦对护盾伤害×3 |
| 土☷/☶ → 水☵ | 土克水 | 新卦定身/冻结时长翻倍 |
| 水☵ → 火☲ | 水克火 | "水火既济"·蒸汽爆炸·AOE伤害200%ATK |

### 3.3 同卦叠加·崩解

连续使用同一上卦（不限下卦）的次数累积效果：

| 连续次数 | 效果 | 视觉 |
|:--:|------|------|
| 第1次 | 标准 | 标准特效 |
| 第2次 | 伤害+10% | 卦象颜色加深 |
| 第3次 | 伤害+20%·硬直等级+1 | 卦象周围出现光环 |
| 第4次 | **崩解触发**·附加上卦专属终结效果 | 全屏卦象特效 |
| 第5次+ | 崩解效果刷新·但伤害不再递增 | — |

**各卦崩解效果：**

| 上卦 | 崩解效果 |
|------|---------|
| ☲ 离 | 敌人跪地灼烧3秒·防御清零 |
| ☳ 震 | 敌人全身麻痹4秒·完全无法行动 |
| ☴ 巽 | 敌人被龙卷卷起3秒·落地受坠落伤害 |
| ☵ 坎 | 敌人冻结3秒·冻结期间暴击率100% |
| ☶ 艮 | 敌人护甲碎裂·永久防御-40% |
| ☰ 乾 | 敌人被击飞出战场边界·落地眩晕3秒 |
| ☱ 兑 | 敌人永久混乱·攻击最近的任何人（含其队友） |
| ☷ 坤 | 敌人完全破防·你回复50%卦气 |

> **崩解的设计哲学：** 不是"伤害够高了"——是"你被这种力量连续击中4次·你的身体已经撑不住了"。这是叙事性的崩坏，不是数值的溢出。

## 四、普攻→卦术 连携

### 4.1 普攻段位连携

在普攻的不同段位取消切入卦术，获得不同的连携加成：

| 从…切入卦术 | 连携加成 | 风险 |
|------------|---------|------|
| 普攻第1段后 | 卦术释放速度+20% | 低（窗口2帧·容易错过） |
| 普攻第2段后 | 卦术伤害+15% | 中（窗口3帧·适中） |
| 普攻第3段后 | 卦术必定暴击 | 中高（窗口4帧·需续连段） |
| 普攻最终段后 | **卦术伤害×2** + 卦气消耗减半 | 高（窗口6帧但最终段前摇长·容易被打断） |

### 4.2 普攻→小六爻 瞬切

普攻中直接按 `右键+Shift` 切小六爻：
- 普攻取消→小六爻释放总时间：0.5秒（含取消窗口）
- 小六爻命中后的1秒内，普攻伤害+30%（"爻→剑"反馈）
- 推荐连段：普攻第2段→取消→小六爻空亡（后撤隐身）→重新站位→普攻第1段起手

### 4.3 普攻→法器切换→卦术（高阶连段）

```
普攻第3段命中 → 4帧窗口内 → 切换法器（↑桃木剑）
  → 法器切换完成即刻 → 按住右键选卦（利用切器后1.5秒内首卦连携加成）
  → 离☲+乾☰ → 桃木剑真火斩 → 伤害×2（普攻最终段加成）+ 切器连携加成25%
```

## 五、法器切换连携

### 5.1 切器窗口

法器切换后的1.5秒内，第一个卦术获得"切器连携加成"（已定义在 [[战斗系统GDD]] §4.7）。

### 5.2 切器→卦术→再切器（循环连携）

高阶玩家可以在一次完整的连段中完成两次法器切换：

```
起手：银针 → 普攻3段积累卦气 → 命中后切桃木剑
  → 桃木剑离卦+乾卦释放（切器连携：伤害+25%）
  → 卦术命中4帧窗口内 → 切铜钱剑
  → 铜钱剑巽卦+兑卦释放（切器连携：铜钱计数保留+必暴击）
  → 铜钱剑普攻收尾叠计数

总时间：4-5秒
总伤害：标准单卦的2.5-3倍
风险：两次切器窗口都在4帧内·错一次=连段中断
```

### 5.3 四法器循环连携（终极操作）

仅在有全部4法器且法器精通Lv4以上时可能实现：

```
银针(攒气) → 铜钱剑(叠计数) → 桃木剑(爆发) → 七星剑(终结)
   ↑_______________________________________________↓
              （循环，每次循环卦气+20奖励）
```

成功完成4法器循环连携→触发"四象归真"→全场伤害×1.5（持续8秒）。

## 六、形态切换与卦术连携

### 6.1 同形态内连击（不换卦）

保持同一个上卦，只换下卦释放：
- 第2次同卦释放：无额外奖励（不鼓励无脑复读）
- 但可以用Q键快速复读（伤害-20%·无下卦效果）

### 6.2 换卦不换器

保持同一个法器，切换上卦+下卦：
- 如果新卦五行相生旧卦→触发相生连携（§3.1）
- 如果新卦五行相克旧卦→触发相克爆发（§3.2）
- 如果新卦五行不相生不相克→标准释放

### 6.3 连换三次不同上卦

在12秒内使用3种不同上卦→触发"三才贯通"：
- 第4个卦术伤害+50%
- 卦气+30
- 卦术冷却全部重置

```
例：离☲（火）→ 震☳（木·木生火·相生）→ 坎☵（水·水生木·二次相生）
  → "三才贯通"触发 → 第4个卦（任意）伤害×1.5
```

## 九、实战连段范例

### 9.1 新手连段（序章可用·仅小六爻+银针）

```
大安（↑·增伤）→ 普攻3段 → 取消 → 速喜（↓·加速追击）→ 普攻2段 → 小吉（←·回血）
时间：6-8秒
难度：★☆☆☆☆
```

### 9.2 中级连段（星纪宫可用·离卦+双法器）

```
银针普攻3段攒气 → 4帧窗切桃木剑 → 切器连携 → 离☲+乾☰ 真火斩
  → 命中 → 4帧窗 → 小六爻赤口（↙·击退包围敌人）
  → 闪避后撤 → 离☲+震☳ 火雷炸
时间：5-7秒
难度：★★★☆☆
```

### 9.3 高级连段（前6宫可用·三法器+相生连携）

```
铜钱剑普攻5段叠计数（目标72枚通宝）→ 4帧窗切桃木剑
  → 切器连携（计数保留+必暴击）→ 离☲+坎☵ 真火斩吸血
  → 卦术命中4帧窗 → 切银针（卦气消耗-50%）
  → 相生连携（火生土→但切银针不触发）→ 震☳+乾☰ 雷爆
  → 太乙神数Lv1收尾（3键·铜钱护盾保护输入窗口）
时间：8-12秒
难度：★★★★☆
```

### 9.4 终极连段（全解锁·四法器+三才贯通+太乙神数Lv3）

```
起手：银针 → 普攻3段 → 6帧窗 → 离☲+乾☰（相生起点·火）
  → 卦术命中4帧窗 → 切铜钱剑 → 震☳+巽☴（木·木生火·相生连携）
  → 卦术命中4帧窗 → 切桃木剑 → 坎☵+兑☱（水·水生木·二次相生）
  → "三才贯通"触发
  → 切七星剑 → 步罡踏斗 → 七星阵激活
  → 第4卦·乾☰+坤☷（伤害×1.5三才 + ×1.5七星阵 = ×2.25）
  → 太乙神数Lv3 9键完美（全场即死<30%HP）
时间：15-20秒
难度：★★★★★（全游戏最难操作·成功=全场清场）
```

## 十、连击计数与评分

### 10.1 连击计数器

屏幕右侧显示实时连击数：
- 每次普攻命中：+1
- 每次卦术命中：+3
- 连携成功（取消窗口内操作）：+5
- 崩解触发：+10
- 击杀：+15

### 10.2 连击等级与奖励

| 连击数 | 等级 | 卦气奖励 | 特效 |
|:--:|------|:--:|------|
| 0-9 | — | — | — |
| 10-24 | D | +5 | 数字变白 |
| 25-49 | C | +10 | 数字变蓝·微弱光晕 |
| 50-74 | B | +15 | 数字变紫·屏幕边缘微光 |
| 75-99 | A | +20 | 数字变金·震屏减弱 |
| 100-149 | S | +30 | 数字燃烧·敌人掉落率+20% |
| 150+ | SS | +50 | 数字七彩·每50连击卦气全回复 |

### 10.3 连击中段惩罚

- 3秒内无任何命中 → 连击归零
- 受到伤害 → 连击减半（不是归零·保留操作记忆）
- 闪避不中断连击
- 切换法器不中断连击
- 选卦中按E取消 → 连击保留（没打出卦不算断连）

## 十一、数值平衡速查

### 11.1 连携伤害乘数汇总

| 连携类型 | 最大乘数 | 触发条件 |

| 普攻最终段→卦术 | ×2.0 | 6帧窗口内切入 |
