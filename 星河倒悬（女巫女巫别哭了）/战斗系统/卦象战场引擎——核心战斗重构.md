# 卦象战场引擎——让战斗一眼惊艳的核心重构

> **问题：** 当前战斗系统本质上是一个"64选项技能轮盘"——选方向+按键→出效果。不管内部多深，从外面看就是"选了个技能放出去"。不惊艳。
> **重构目标：** 战斗不只是"用卦术打人"——**战斗本身在"创作卦象"。每一场战斗都是一次占卜。**
> **核心机制：** 六爻战场书写 + 卦象占场 + 变爻实时演化 + 卦盘显现 + 卦vs卦对抗

---

## 零、这个系统为什么"一眼惊艳"

先设想一个场景——玩家第一次看到这款游戏的画面：

```
画面中：
  辰生站在战场中央·脚下是一个直径6m的发光八卦盘（地面上·不是UI）。
  他按住右键·八卦盘上的离卦位高亮·金色火焰从卦位涌出.
  他松手——火焰不是"射出去"——是从脚下的八卦盘上"长出来"的·像火焰的树。

  战场上方·虚空中悬浮着三条已经写好的爻线：
    ⚊ （阳·金色·实线）
    ⚋ （阴·蓝色·断线）
    ⚊ （阳·正在书写中·还在闪烁）

  辰生一套连携·第四爻被写入——⚋ 阴爻落下。
  还差两爻。

  BOSS焦烈也在书写他自己的六爻——他那边已经有五条爻·全是白色的伪爻。

  辰生的六爻完成了——䷾ 水火既济·卦象从虚空轰然落入战场·
  整个战场被卦象覆盖·规则改变：火焰转化为生命。

  焦烈的伪爻在真卦面前开始崩裂。他说不出话。
  
  观众看到这里——六条爻线在战场上悬浮·八卦盘在地面旋转·
  卦术从脚下涌出——这不是任何已知的游戏。这是新的。
```

**这就是"惊艳"的定义：你看到三秒就知道这个东西你没见过。**

## 一、战斗双层架构

```
┌─────────────────────────────────────────────────────┐
│                                                      │
│   战略层：六爻战场                                    │
│   ┌─────────────────────────────────────────────┐   │
│   │  每一次"有意义的行动" → 写入一条爻线           │   │
│   │  6条爻全部写入 → 卦阵激活 → 战场规则改变        │   │
│   │  爻可以被翻转（变爻）·卦可以被对抗（卦vs卦）    │   │
│   │  时间跨度：15-30秒·每场战斗1-3个卦阵            │   │
│   └─────────────────────────────────────────────┘   │
│                                                      │
│   操作层：选卦放卦                                    │
│   ┌─────────────────────────────────────────────┐   │
│   │  按住右键 → 八卦盘展开 → 选上卦+下卦 → 放卦    │   │
│   │  普攻·闪避·切法器·连携                         │   │
│   │  时间跨度：0.3-4.5秒·实时操作                   │   │
│   └─────────────────────────────────────────────┘   │
│                                                      │
│   两层通过"爻线写入"联动：                             │
│   操作层的每一次动作 → 战略层的爻线推进                 │
│   战略层的卦阵激活 → 操作层的战术选择改变               │
│                                                      │
└─────────────────────────────────────────────────────┘
```

## 二、六爻战场——核心机制

### 2.1 六爻的初始状态

进入战斗时，战场上方（俯视角的"天空"——即屏幕上方区域）悬浮着六条爻线：

```
              ═══ 上爻 (灰色虚线·未定)
              ═══ 五爻 (灰色虚线·未定)
              ═══ 四爻 (灰色虚线·未定)
              ═══ 三爻 (灰色虚线·未定)
              ═══ 二爻 (灰色虚线·未定)
              ═══ 初爻 (灰色虚线·未定)

位置：屏幕上方·水平排列·透明·不影响战斗视野
```

### 2.2 爻线写入规则

**什么动作写入爻？**

| 动作 | 写入爻位 | 阴/阳 | 说明 |
|------|:--:|:--:|------|
| 普攻连段完成（银针3段/桃木4段等） | 初爻 | 阳 | "第一击·根基" |
| 卦术命中敌人 | 二爻 | 视卦术属性 | 火雷天=阳 / 水地山=阴 |
| 闪避成功（无敌帧内躲过攻击） | 三爻 | 阳 | "动在腰腹·灵活" |
| 法器切换连携成功 | 四爻 | 视切换方向 | 银针→桃木=阳 / 桃木→银针=阴 |
| 同伴特殊能力触发 | 五爻 | 阳 | "君位·同伴即力量" |
| 被敌人击中（非闪避·非格挡） | 上爻 | 阴 | "天命垂怜" |
| 格挡成功（艮卦·盾牌格挡） | 上爻 | 阳 | "以身承天" |

**写入时的视觉效果：**

```
被写入的爻线：
  0.0s: 灰色虚线开始发光
  0.2s: 虚线变为实线——落下
        ⚊ 阳爻 = 金色·从上方"坠落"到爻线位置·撞击产生光波
        ⚋ 阴爻 = 蓝色·从上方"飘落"·分裂为两段
  0.4s: 爻线稳定·颜色微亮·已写入
  0.5s: 屏幕微震（仅第一次写入·六爻完整时不震）
  
音效：
  阳爻写入 → 金属撞击声·短促
  阴爻写入 → 水滴滴落声·柔和
```

### 2.3 六爻速度

| 爻位 | 写入所需时间 | 累计 |
|:--:|:--:|:--:|
| 初爻 | 战斗开始后3-6秒 | ~5秒 |
| 二爻 | +4-8秒 | ~10秒 |
| 三爻 | +3-6秒 | ~15秒 |
| 四爻 | +5-10秒（法器切换·看玩家水平） | ~20秒 |
| 五爻 | +8-15秒（同伴技能冷却长） | ~30秒 |
| 上爻 | 变量（被打中/格挡成功） | ~30秒 |

**正常水平的玩家：每25-35秒完成一个完整的六爻卦阵。** 一场杂兵战（8-15秒）通常无法完成·但精英战和BOSS战一定会有1-3个卦阵激活。

### 2.4 六爻完整——卦阵激活

六爻全部写入的一瞬间：

```
演出（2.5秒·不可跳过·但可以继续操作）：

  0.0s: 六条爻线全部亮起
        → 屏幕边缘出现八卦盘的暗影（微透明·覆盖整个画面边缘）
  
  0.3s: 六爻从屏幕上方"坠落"到战场地面
        → 在战场地面上投影出巨大的卦符（䷀䷁䷾...·约8m直径）
        → 卦符从地面"浮起"——像3D投影·悬在战场上方
  
  0.8s: 卦阵效果激活
        → 屏幕中央浮现卦名（甲骨文→金文→隶书→简体·四字体瞬变）
        → 卦辞文字在卦符周围浮现（如"元亨利贞"·飘浮3秒后消散）
  
  1.5s: 战场规则改变生效
        → 画面滤镜微调（乾卦=金色滤镜·坤卦=土色·离卦=暖橙...）
        → HUD上出现卦阵图标+剩余时间
        → 辰生自动说一句卦辞（如"天行健——"）
```

**卦阵持续15-25秒（视卦象而定）。持续结束后六爻重置为灰色虚线·开始新一轮书写。**

## 三、卦阵效果——六十四种战场规则

卦阵不是"给一个buff"——是**改变战场的底层规则**。以下是16个核心卦的卦阵效果：

### 3.1 乾宫卦阵

| 卦 | 卦阵规则 |
|------|------|
| ䷀ 乾为天 | **"天行健"**——所有攻击带击飞·击飞距离×3·持续20s |
| ䷫ 天风姤 | **"后以施命诰四方"**——所有卦术施放速度×2·冷却减半·15s |
| ䷠ 天山遁 | **"君子以远小人"**——辰生移速×2·敌人移速-50%·18s |
| ䷋ 天地否 | **"天地不交"**——敌人无法使用卦术·辰生卦气消耗×2·15s（双刃剑） |

### 3.2 坤宫卦阵

| 卦 | 卦阵规则 |
|------|------|
| ䷁ 坤为地 | **"厚德载物"**——全场所有伤害-80%·护盾效果×3·25s（最长） |
| ䷗ 地雷复 | **"七日来复"**——倒计时7秒·结束时辰生回复全部生命+卦气 |
| ䷊ 地天泰 | **"天地交泰"**——全队无敌10s·纯净卦·唯一无代价卦阵 |
| ䷡ 雷天大壮 | **"君子以非礼弗履"**——辰生霸体·不能被任何攻击打断·20s |

### 3.3 核心卦阵（离·震·坎·兑·巽·艮）

| 卦 | 卦阵规则 |
|------|------|
| ䷝ 离为火 | **"明两作·离"**——全场地面被火焰覆盖·敌人持续灼烧·辰生火焰免疫 |
| ䷲ 震为雷 | **"洊雷·震"**——每3秒全场雷击一次·随机目标·辰生雷免疫 |
| ䷜ 坎为水 | **"水洊至·习坎"**——全场移速-30%·辰生在水面滑行(移速+50%)·18s |
| ䷹ 兑为泽 | **"丽泽·兑"**——全场敌人混乱(互殴)·辰生免疫混乱·15s |
| ䷸ 巽为风 | **"随风·巽"**——辰生移速×3·闪避无冷却·攻击后留下风轨·15s |
| ䷳ 艮为山 | **"兼山·艮"**——全场敌人定身·不能移动·辰生可以推/撞他们·20s |

| 卦 | 卦阵规则 |
|------|------|

## 四、变爻——战场上的"逆转"

### 4.1 触发条件

已写入的爻可以被**翻转**（阳变阴·阴变阳）。这意味着已经形成的六爻会发生变化——**卦变了**。

| 触发方式 | 翻转哪一爻 | 说明 |
|---------|:--:|------|
| **崩解触发**（同卦4次命中） | 随机一爻 | "力量太强·爻撑不住了" |
| **BOSS阶段转换** | 最上方一爻 | BOSS强制翻转·"天意变了" |
| **太乙神数成功** | 玩家自选 | 太乙神数完美完成后·弹出"变爻选择"·选一个爻翻转 |
| **被暴击** | 随机一爻 | 重创可能导致"天命偏移" |
| **七星剑·敕令"归"** | BOSS的一爻 | 用敕令"归"→让BOSS回忆真实身份→BOSS的伪爻翻转成真爻 |

### 4.2 变爻的后果

翻转一爻 → 卦变了 → 卦阵效果改变。

```
例：
  当前卦阵：䷝ 离为火（全屏火焰·15秒·已经过了8秒）
  
  崩解触发 → 第四爻被翻转（阴变阳）
  → 卦从 ䷝ 离为火（离上离下）
  → 变为 ䷔ 火雷噬嗑（离上震下）
  → 卦阵从"全屏火焰"切换为"火焰+雷电双属性·集中爆发"
  → 剩余时间刷新为10秒
  
  战场规则在玩家面前"炸开"——从一片火海变成火雷交加。
  这不是预设的——是战斗中"写"出来的。
```

**变爻让卦阵不再是预先设定的——它是活的，随战斗演化的。同一场BOSS战打两次，可能因为变爻的时机不同，出现完全不同的卦阵。**

## 五、卦象占场——脚下的八卦盘

### 5.1 八卦盘是"地面物体"·不是UI

```
按住右键时：
  → 辰生脚下展开八卦盘（直径6m·地面投影·发光的金色纹路）
  → 八卦盘随辰生移动（不是固定在地面上·是跟着辰生的）
  → 鼠标方向 → 对应的卦位从金色变为对应颜色：
    离☲=橙红·震☳=蓝白·巽☴=翠绿·坎☵=深蓝
    艮☶=土黄·坤☷=褐色·乾☰=金色·兑☱=银白
  
  → 下卦按键 → 卦盘上被选中的两个卦位连线（上卦↔下卦·金色电弧连接）
  → 松手 → 卦术从脚下卦盘的卦位位置"涌出"·不是从手上发射
```

**这个视觉效果让"卦"不再是菜单——是一个实体化的阵法。**

### 5.2 八卦盘与战场的关系

八卦盘的方位是相对于**辰生的朝向**的·不是绝对地理方位：

- 离卦(火) = 辰生前方
- 坎卦(水) = 辰生后方
- 震卦(雷) = 辰生右侧
- 兑卦(泽) = 辰生左侧
- 乾卦(天) = 左前
- 坤卦(地) = 左后
- 艮卦(山) = 右前
- 巽卦(风) = 右后

**这与小六爻的6方向鼠标扇区完全对应。** 往上甩 = 前方 = 离卦。

### 5.3 敌人站在卦盘上

敌人站在辰生的八卦盘上时：

```
敌人站在离卦位上 → 被火卦命中时·额外灼烧伤害
敌人站在坎卦位上 → 被水卦命中时·冻结时间翻倍
敌人站在乾卦位上 → 被天卦命中时·击飞距离×2

辰生可以"引诱"敌人走入卦盘的有利位置——再释放克制卦术。
```

**这引入了位置博弈——不只是"选什么卦"·是"敌人在卦盘的哪个位置"。**

## 六、卦vs卦——与BOSS的卦象对抗

### 6.1 BOSS也有六爻

BOSS焦烈（及其他太史阁BOSS）也在书写自己的**伪爻**：

```
BOSS六爻：
              ━━━ 上爻 (白色·伪爻·未完成)
              ━━━ 五爻 (白色·伪爻·已完成)
              ━━━ 四爻 (未定)
              ━━━ 三爻 (白色·伪爻·已完成)
              ━━━ 二爻 (未定)
              ━━━ 初爻 (白色·伪爻·已完成)

BOSS的爻是白色的（伪卦）·写爻速度比辰生慢（约40-50秒完成一个）
```

### 6.2 卦象对抗

当辰生的六爻和BOSS的六爻同时完成时：

```
┌────────────────────────────────────────────┐
│                                             │
│   辰生的卦 ◇──── 对抗 ────◇ BOSS的卦        │
│   ䷾ 水火既济            伪䷝ 白焰离火       │
│                                             │
│   判断：辰生卦"克"BOSS卦                     │
│   → BOSS卦阵崩溃                             │
│   → BOSS全属性-30%·持续20s                   │
│   → BOSS被强制取消正在释放的技能              │
│                                             │
│   演出：                                     │
│   两个卦符在空中碰撞→辰生卦的金色卦符         │
│   变大→吞没BOSS的白色卦符→碎裂               │
│                                             │
└────────────────────────────────────────────┘

如果BOSS卦"克"辰生卦：
  → 全场AOE攻击（伤害=ATK×2.0）
  → 需要闪避或格挡
  → 辰生的卦阵被推迟10秒

如果两卦"比和"（同类·不克不生）：
  → 双方卦阵同时激活
  → 辰生卦阵正常生效·BOSS卦阵也生效
  → 硬碰硬·看谁更狠
```

### 6.3 卦vs卦的五行判定

```
辰生卦的上卦五行 vs BOSS卦的上卦五行：

  辰生卦克BOSS卦（如：离火克兑金）→ 辰生胜
  BOSS卦克辰生卦（如：坎水克离火）→ BOSS胜
  相生关系 → 弱势方获得一次"变爻"机会（重新书写）
  比和 → 双方卦阵同时激活
```

## 七、六爻加速——"速写"爻线

### 7.1 加速写入条件

在某些情况下，爻线写入速度翻倍或立即完成：

| 加速条件 | 效果 |
|---------|------|
| 站在八卦盘中央释放卦术 | 下一爻写入时间-50% |
| 法器切换连携成功 | 对应爻立即写入（跳过累积） |
| 太乙神数成功 | 立即写入2条爻线 |
| 崩解触发 | 立即写入当前未完成的那一爻 |
| 同伴合力技 | 立即写入五爻（君位·同伴即力量） |
| 站在星碑的"卦位"上 | 写入速度×2（仅限道宫内部·星碑房间） |

### 7.2 速写策略

高手可以刻意规划"速写"来在20秒内完成一个卦阵——比正常速度快10秒。

```
速写连段：
  1. 起手离卦(写入二爻·阳)
  2. 切桃木剑(切器连携·四爻立即写入·阳)
  3. 闪避BOSS攻击(三爻写入·阳)
  4. 崩解触发(额外写入当前爻)
  5. 普攻完成(初爻·阳)
  → 五爻已写·只差上爻和五爻
  → 让同伴放技能(五爻写入)·故意格挡(上爻·阳)
  → 15秒·六爻齐·卦阵激活
```

## 八、视觉语言——"让人一眼看到卦"

### 8.1 战场上的卦元素（俯视角可见）

```
持久可见的元素：
  ✅ 屏幕上方·六条爻线（现在是灰色+已写入的亮色）
  ✅ 辰生脚下·八卦盘（演卦时·直径6m·地面光纹）
```

## 十、一个完整的战斗叙事（焦烈战·新版本）

```
0秒: 进入焦烈的BOSS房。
     六条灰色爻线悬浮在战场上空·焦烈的白色伪爻线在对面。
     
5秒: 银针普攻三段完成。初爻⚊ 金色实线落下。"咚——"

10秒: 离卦命中焦烈。二爻⚊ 阳（火=阳）。金色爻线嵌入。

13秒: 闪避焦烈的白焰连射。三爻⚊ 阳。第三道金光。

18秒: 切桃木剑·切器连携成功。四爻⚊ 阳。四爻齐了·虚空中四道金光。

22秒: 焦烈的伪爻也写了四条——白色的。爻线在颤抖——伪的。

25秒: 锻锋释放真火揭露。五爻⚊阳——金焰的阳爻·最亮的一条。

28秒: 焦烈的白焰之墙撞过来·辰生切艮卦格挡——上爻⚊阳·以身承天。

      六爻全亮。
      
      卦阵激活。
      
      ䷝ 离为火。
      
      巨大的䷝卦符从虚空轰入战场地面·金色火光从卦符的每一条爻线喷涌而出。
      整个BOSS房变成金色火海。
      焦烈的白色火焰在金色火焰面前——褪色了。
      卦辞浮现："明两作·离。大人以继明照于四方。"
      
      焦烈（失神）："那……那是什么……"
      
      辰生的离卦伤害×2·火焰免疫·站在火焰上卦气+8/秒。
      
      卦阵持续18秒。
      焦烈在这18秒内·从白焰专家变成一个被真火包围的困兽。

35秒: 崩解触发——第四爻被崩裂·翻转成⚋阴。
      卦变了——从䷝离为火变成了䷔火雷噬嗑。
      火海之中炸开雷电。卦阵从"全屏灼烧"切换为"火雷集中爆发"。

40秒: 焦烈的伪六爻也完成了——伪䷝离为火·白色的。
      
      卦vs卦。
      
      金色䷔ vs 白色伪䷝。
      两个卦符在空中碰撞。
      
      火雷噬嗑（火+雷·阳+阳）vs 伪离为火（火+火·纯阳伪）。
      
      金色卦符吞没了白色——伪卦崩碎。
      焦烈全属性-30%。
      
      他跪在地上。
      手心里——一小团橙色的真火。

50秒: 战斗结束。
```
