## 一、五行枚举（统一标准）

### 1.1 问题

三钱摇卦使用 `WuXing { Metal=0, Water=1, Wood=2, Fire=3, Earth=4 }`（相生序），紫微斗数使用 `WuXingElement { Fire=0, Water=1, Wood=2, Metal=3, Earth=4 }`（河图序）。两个系统的枚举值不对齐，跨系统调用时五行生克判定错误。

### 1.2 统一方案

```csharp
/// <summary>
/// 五行枚举——全系统统一使用。
/// 使用相生序：金生水→水生木→木生火→火生土→土生金。
/// 枚举值 = 生克计算中的索引，不要修改顺序。
/// </summary>
public enum WuXing
{
    Metal = 0,  // 金 ☰☱
    Water = 1,  // 水 ☵
    Wood  = 2,  // 木 ☳☴
    Fire  = 3,  // 火 ☲
    Earth = 4,  // 土 ☷☶
}

/// <summary>
/// 五行生克工具方法（定义在 WuXingExtensions 中，全系统共用）
/// </summary>
public static class WuXingExtensions
{
    /// <summary>相生：我生谁</summary>
    public static WuXing Generates(this WuXing w) => (WuXing)(((int)w + 1) % 5);
    
    /// <summary>相克：我克谁</summary>
    public static WuXing Restricts(this WuXing w) => (WuXing)(((int)w + 2) % 5);
    
    /// <summary>生我者</summary>
    public static WuXing GeneratedBy(this WuXing w) => (WuXing)(((int)w + 4) % 5);
    
    /// <summary>克我者</summary>
    public static WuXing RestrictedBy(this WuXing w) => (WuXing)(((int)w + 3) % 5);

    /// <summary>生克关系：1.5=比和, 1.2=我生/我克(有利), 1.0=平, 0.7=生我/克我(不利)</summary>
    public static float RelationMultiplier(this WuXing self, WuXing other)
    {
        if (self == other) return 1.5f;                        // 比和
        if (other == self.Generates()) return 1.2f;            // 我生→泄气（小幅有利）
        if (other == self.Restricts()) return 1.2f;            // 我克→有利
        if (other == self.GeneratedBy()) return 0.7f;          // 生我→被滋养（对方有利）
        if (other == self.RestrictedBy()) return 0.7f;         // 克我→不利
        return 1.0f;
    }
}
```

## 三、装备槽位体系统一

### 3.1 问题

法器锻造GDD定义**9槽位**（头饰·法衣·主法器·副手法器·项链·手镯·戒指·符箓袋·法印册），装备系统GDD定义**4槽位**（武器·防具·饰品1·饰品2）。两份文档从未说明两套体系的关系。

### 3.2 统一方案

```
辰生（主角）装备体系 —— 使用"法器装备体系"：
┌─────────────────────────────────────────────┐
│  主法器×1    副手法器×1                       │  → 战斗切换（↑←↓→）
│  法衣×1      符箓袋×4                         │  → 全局被动 + 消耗品
│  星君信物×12（全部激活·法印册）               │  → BOSS掉落永久被动
│                                             │
│  ❌ 已删除：头饰·项链·手镯·戒指              │  → 被动效果迁移至法器进阶/命盘
└─────────────────────────────────────────────┘

同伴（12星君NPC）装备体系 —— 使用"同伴装备体系"：
┌─────────────────────────────────────────────┐
│  武器×1      防具×1                           │
│  饰品1×1     饰品2×1                          │
│  信物×1      （自动装备·不可更换）             │
└─────────────────────────────────────────────┘
```

### 3.3 设计理由

- **辰生9槽→简化为3槽（主法器+副手法器+法衣）+2面板（符箓袋+法印册）**：头饰/项链/手镯/戒指的被动效果迁移到法器精通等级（§4.4 法器精通度）和紫微斗数命盘中
- **法衣保留**（唯一的外观变化+全局被动槽）——但简化为每道宫1件（12件），不再有5件同类型选择
- **法印→星君信物合并**：法印（法器锻造GDD 12件）和星君信物（背包系统GDD 12件）合并为"星君信物"——道宫通关直接获得·放入法印册·全部激活
- **同伴装备GDD**：`装备系统GDD.md` 的内容移给同伴使用（12星君NPC每人4件装备）

## 五、伤害公式统一（含所有加成来源）

### 5.1 问题

战斗GDD的伤害公式没有预留"锻造等级"和"命盘加成"的参数。法器锻造和紫微斗数的战斗加成无处插入。

### 5.2 统一公式

```
基础伤害 = ATK × 技能倍率
暴击判定 = Rand(0,1) < 暴击率 ? 1 + 暴击伤害加成 : 1
元素加成 = 1 + 元素增伤率
锻造加成 = 1 + 锻造等级 × 0.03                    ← 新增
命盘加成 = 1 + Σ(紫微斗数·各宫·卦术伤害加成)      ← 新增
启示加成 = 1 + Σ(三钱摇卦·激活的卦象启示)          ← 新增
同伴加成 = 1 + Σ(携带同伴·被动增益)                ← 新增
等级加成 = 1 + clamp(等级差 × 0.03, 0, 0.45)
           （等级差 = 玩家等级 - 敌人等级，负值取0·即仅玩家高于敌人时生效）

最终伤害 = 基础伤害 × 暴击判定 × 元素加成 × 锻造加成 × 命盘加成 × 启示加成
         × 同伴加成 × 等级加成 × (1 - 减伤率) × 伤害浮动
```

### 5.3 加成顺序（乘法叠加·无递减）

所有加成来源为独立乘法因子。无"边际递减"——每个系统的加成都完整生效。这是有意为之：后期玩家通过堆叠多个系统的加成来达成"从被碾压→碾压回去"的成长曲线。

## 六、CoinQuality 枚举——六爻纳币系统钱币类型（2026-08-08 新增）

### 6.1 定义

```csharp
/// <summary>
/// 钱币品质枚举——六爻纳币系统专用。全项目唯一定义。

    YinQian = 2,       // 银钱·100文/枚（1钱银）

    YanShengJinBao = 4 // 厌胜金宝·5000文/枚（半两金+符刻）

/// <summary>

    public static int GetUnitPrice(CoinQuality q) => q switch {
        CoinQuality.TongQian => 1,
        CoinQuality.DangShi => 10,
        CoinQuality.YinQian => 100,
        CoinQuality.JinQian => 1000,
        CoinQuality.YanShengJinBao => 5000,

        CoinQuality.TongQian => 1.00f,
        CoinQuality.DangShi => 1.02f,
        CoinQuality.YinQian => 1.04f,
        CoinQuality.JinQian => 1.06f,
        CoinQuality.YanShengJinBao => 1.10f,

    public static float GetCostReduction(CoinQuality q) => q switch {
        CoinQuality.TongQian => 0.00f,
```
