## 一、六亲系统 → 敌人分类 + 克制链

**百科来源：** 六爻纳甲·六亲（父母·兄弟·妻财·官鬼·子孙）

**当前状态：** 战斗系统没有"敌人类型"概念，只有卦象元素克制
**深化方案：** 将六亲映射为六种敌人类型 + 辰生的六种卦术克制

| 六亲 | 五行生克 | → 敌人类型 | 游戏机制 |
|------|---------|-----------|---------|
| **官鬼** | 克我者 | 威胁型敌人——对你伤害+25% | 克官鬼需用**子孙卦**（震☳·兑☱组合）→ 伤害×1.5 |
| **妻财** | 我克者 | 资源型敌人——掉落+50%，但会逃跑 | 克妻财需用**兄弟卦**（乾☰·离☲组合）→ 阻止逃跑 |
| **父母** | 生我者 | 庇护型敌人——给周围敌人加Buff | 克父母需用**妻财卦**（坤☷·艮☶组合）→ 破除Buff |
| **子孙** | 我生者 | 召唤型敌人——会分裂/召唤小怪 | 克子孙需用**官鬼卦**（坎☵·巽☴组合）→ 阻止分裂 |
| **兄弟** | 同我者 | 镜像型敌人——会复制你上次的卦术 | 克兄弟需用**父母卦**（特殊的第八种卦象组合）→ 破解复制 |

**战斗实现：**
- 辰生打开八卦盘选卦时，敌人头顶显示六亲标记（官鬼=红色👹·妻财=金色💰·父母=蓝色🛡·子孙=绿色🐣·兄弟=黄色👥）
- 用对应的克制卦术命中→触发"六亲破"——额外硬直+伤害+特殊效果
- 这不需要玩家记忆五行生克——颜色标记+图标就够了

## 二、六兽系统 → 日辰轮转 + 战斗Buff

**百科来源：** 六爻纳甲·六兽（青龙·朱雀·勾陈·螣蛇·白虎·玄武）

**当前状态：** 无日辰/时间对战斗的影响
**深化方案：** 每天（游戏内）轮转一种"当值六兽"——辰生和敌人都获得不同的Buff/Nerf

六兽按日干轮转——游戏内每过一天（在星碑休息后），六兽顺延一位：

| 六兽 | 当日Buff（辰生） | 当日Nerf（敌人） | 当日特殊事件 |
|------|-----------------|-----------------|-------------|
| **青龙**（木·大吉） | 卦气恢复×2 | 敌人掉落×1.5 | 喜事——随机获得免费符箓 |
| **朱雀**（火·口舌） | 火卦伤害+25% | 敌人增援概率+50%（"口舌招敌"） | 随机遭遇精英怪 |
| **勾陈**（土·牵连） | 奇门阵法持续+15s | 闪避无敌帧-3 | 地形陷阱增多 |
| **螣蛇**（土·虚惊） | 小六爻方向判定窗口+50%（更宽容） | 迷你地图失效（"怪异扰乱方向感"） | 假宝箱出现 |
| **白虎**（金·血光） | 所有伤害+30% | 受到伤害+30% | 高收益·高风险日 |
| **玄武**（水·盗贼） | 敌人掉落卦气翻倍 | 卦气上限-30%（"被盗"） | 隐藏商人出现 |

**玩家策略：** 可以在星碑处查看明日六兽——如果是白虎日（高伤高受击），适合去打BOSS（爆发高但风险大）；如果是青龙日，适合刷材料和卦气。

## 三、世应系统 → 锁定 + 弱点

**百科来源：** 六爻纳甲·世应（世爻=我·应爻=对方·隔两爻而对）

**当前状态：** 锁定敌人只有Tab切换，无弱点机制
**深化方案：** 引入"世爻"和"应爻"定位——战斗中每个敌人都有一个隐藏的"应爻弱点"

```
战斗开始→辰生的"世爻"位置随机生成（6种位置之一：初→上）
敌人的"应爻"位置 = 世爻位置 + 3（隔两爻）

例：辰生世在初爻 → 敌人应在四爻 → 敌人体表出现4个弱点区域
如果刚好用正确的卦术命中敌人的应爻位置 → "应爻破" → 伤害×2 + 卦气全返
```

**六种世应位置对应的弱点区域：**
| 世爻位置 | 对应的敌人弱点位置（应爻） | 视觉表现 |
|---------|------------------------|---------|
| 初爻（脚/地面） | 四爻（胸/躯干） | 胸口发光的卦位标记 |
| 二爻（小腿/膝） | 五爻（颈/肩） | 颈部发光的卦位标记 |
| 三爻（腰/腹） | 上爻（头顶） | 头顶发光的卦位标记 |
| 四爻（胸/躯干） | 初爻（脚/地面） | 脚下光环 |
| 五爻（颈/肩） | 二爻（小腿/膝） | 膝盖发光 |
| 上爻（头顶） | 三爻（腰/腹） | 腰间发光 |

**与法器系统的配合：** 不同法器攻击的高度范围不同——银针擅长打上三爻（胸·颈·头），七星剑擅长打下三爻（脚·膝·腰），桃木剑均衡。

## 四、飞伏系统 → 卦盘第二层 + 隐藏卦术

**百科来源：** 京房飞伏理论（飞=显·伏=隐·本宫纯卦同位爻=伏神）

**当前状态：** 八卦盘只有一层——选上卦+选下卦
**深化方案：** 八卦盘增加"第二层"——伏神层

```
正常状态：八卦盘显示8个上卦（飞神层）
按住右键+长按空格 → 八卦盘翻转 → 显示"伏神层"

伏神层显示的不是当前卦盘的8个上卦——
而是当前所持法器的"本宫纯卦"的隐藏卦位

例如：持桃木剑（对应震宫·属木）
飞神层 = 正常八卦盘（8个上卦）
伏神层 = 震宫纯卦隐藏卦位（只有2-3个特殊卦位可用）
→ 伏神层的卦术效果与飞神层完全不同
→ 但只能在"飞神被克"时使用（被敌人克制→飞神失效→伏神自动激活）
```

**触发规则（京房飞伏逻辑的游戏化）：**
- 当辰生连续3次被同类型敌人打断卦术→飞神被克→八卦盘自动翻转→伏神层激活
- 伏神层持续10秒→在此期间释放的卦术附带"出伏"效果（伤害×1.5+穿透霸体）
- 10秒后伏神归隐→飞神恢复

**设计意图：** "飞伏"不是常驻的——是"被压制时的反制"——越是处于劣势，隐藏的力量越有机会显露。这与"去伪存真"（大梁宫）的哲学命题完美呼应——被压抑的真卦在伪卦的压迫下反而更强大。

## 五、卦变系统 → 连携链 + 卦术进化

**百科来源：** 虞翻卦变（乾坤→十二消息→诸杂卦的三级生成树）

**当前状态：** 卦术之间没有进化/连携关系
**深化方案：** 特定卦术命中后→下一个特定卦术自动"进化"（伤害+效果升级）

基于虞翻卦变树——每个卦都有"母卦"和"子卦"：

```
离卦䷝（火）的卦变子卦（虞翻谱系中从离衍出的卦）：
  离→旅䷷（火+山）→ 离卦后接艮卦下卦→"火山旅"→灼烧+定身
  离→鼎䷱（火+风）→ 离卦后接巽卦下卦→"火风鼎"→DOT扩散
  离→未济䷿（火+水）→ 离卦后接坎卦下卦→"火水未济"→灼烧+减速

坎卦䷜（水）的卦变子卦：
  坎→节䷻（水+泽）→ 坎卦后接兑卦下卦→"水泽节"→减速+混乱
  坎→屯䷂（水+雷）→ 坎卦后接震卦下卦→"水雷屯"→冻结+突进
  坎→既济䷾（水+火）→ 坎卦后接离卦下卦→"水火既济"→吸血+灼烧
```

**连携链的实现：**
- 八卦盘上，当你选了一个卦术后→八卦盘上高亮显示它的3个"子卦"（卦变谱系中的衍生卦）
- 如果在3秒内释放子卦→子卦升级为"变卦版本"（伤害+30%+额外效果）
- 连续3次子卦连携→触发"三代同堂"→第3卦附带"归魂"效果（全场AOE+卦气全返）

## 六、互体系统 → 卦术隐藏效果

**百科来源：** 互体（取二三四五中四爻重组→发现隐藏卦象）

**当前状态：** 八卦盘选卦后直接释放
**深化方案：** 每次释放卦术时，不仅释放你选的卦——还附带一个隐藏的"互卦效果"

```
你选了离卦上卦☲ + 震卦下卦☳ = 火雷噬嗑䷔
↓ 自动计算互卦：
噬嗑的二三四爻 = 阴·阴·阳 = 艮☶
噬嗑的三四五爻 = 阴·阳·阴 = 坎☵
互卦 = 水山蹇䷦

→ 火雷噬嗑的主要效果：火+雷=灼烧+突进
→ 隐藏的互卦效果（水山蹇=水+山=减速+护盾）：
  敌人被噬嗑击中后→获得一个隐藏的"水山印记"
  → 3秒后印记触发→敌人被减速+辰生获得小型护盾
```

**与梅花易数的关系：** 梅花易数（探索系统）可以"观象"→揭示当前卦术的互体效果→让玩家看到隐藏的信息（"这个卦的互卦是什么"）。

## 九、体用生克系统 → 战斗优势判定

**百科来源：** 梅花易数·体用生克（用生体=大吉·体用比和=吉·体克用=小吉·体生用=泄气·用克体=大凶）

**当前状态：** 无"战术态势"评估
**深化方案：** 战斗开始时自动判定"体用"→根据当前卦术选择给出实时战术建议

```
战斗开始：
  体 = 辰生当前装备的法器五行
  用 = 当前区域/BOSS的五行属性
  
例：辰生持桃木剑（属震宫=木）+ 进入星纪宫（火属性区域）
  体=木·用=火 → 木生火 → "体生用"→ 泄气！
  
  战术建议（UI提示）：你的法器五行在消耗自己去生环境——卦气消耗+20%！
  对策：切换银针（属金）→ 火克金 → "用克体"→ 大凶！
        切换七星剑（属水）→ 水克火 → "体克用"→ 小吉——水克火，你克制这个环境！
```

**HUD显示：** 屏幕左上角显示当前体用关系——五个等级（大吉·吉·小吉·泄气·大凶）——让玩家在进入新区域前就能预判战术优劣。

## 十、纳甲系统 → 法器附魔 + 卦术强化

**百科来源：** 六爻纳甲·纳甲纳支（八卦配天干地支→每爻各有天干地支五行）

**当前状态：** 无法器强化系统
**深化方案：** 每个法器可以"纳甲"——铭刻天干地支以强化特定卦术

```
桃木剑的六个"铭刻槽"对应六爻（从剑尖→剑柄=初爻→上爻）：

铭刻示例：
  初爻槽铭刻"甲子" → 甲=东方青龙·子=水 → 坎卦上卦效果+15%
  五爻槽铭刻"庚申" → 庚=西方白虎·申=金 → 乾卦上卦伤害+20%
  上爻槽铭刻"壬戌" → 壬=北方玄武·戌=土 → 坤卦下卦护盾+30%

铭刻材料：不同道宫掉落不同的"天干石"和"地支晶"
完整纳甲（六爻全满）→ 法器全体卦术伤害+10%
```

## 十一、纳音系统 → 装备词条

**百科来源：** 六十甲子纳音（每两个干支组合对应一种"纳音五行"——如甲子乙丑=海中金·丙寅丁卯=炉中火……共30种）

**当前状态：** 无法器/装备的随机属性系统
**深化方案：** 法器铭刻的天干地支组合→产生"纳音词条"

```
桃木剑五爻槽铭刻"庚申" → 庚申的纳音=石榴木 → 获得词条：
  "石榴木：普攻连段最后一击附加种子——命中后3秒种子爆发→AOE木属性伤害"

甲子=海中金 → "被水卦命中后获得金盾（吸收10%伤害）"
丙寅=炉中火 → "火卦释放时地面残留火焰痕迹（5s）"
戊辰=大林木 → "木卦DOT扩散到附近敌人"
庚午=路旁土 → "移动中释放坤卦护盾值+50%"
```

## 总结：术数对游戏战斗的"厚重度"贡献

当玩家发现：
- 同一个离卦在"消息卦=复䷗"的星纪宫——和——在"消息卦=乾䷀"的实沉宫——**效果完全不同**
- 选中了离卦→八卦盘自动高亮它的3个"子卦"（卦变连携）
- 释放离卦后→屏幕角落浮现"互卦：水山蹇"——因为系统自动计算了互体
- 敌人头顶显示"官鬼👹"标记——你需要用子孙卦克制它（六亲破）
- 今天白虎日——伤害+30%但承伤也+30%——要不要去挑战BOSS？（六兽日辰）

**这时候——玩家不是在玩一个"有中国文化元素的ARPG"——而是在亲身实践一门中国传统术数。** 每一个术数规则都在游戏中有一个精确的、可操作的、有战术意义的映射。

这就是"百科全书→游戏设计"的最深层价值：**让游戏不只是"用到"传统文化，而是"成为"传统文化的一种当代实践形式。**
