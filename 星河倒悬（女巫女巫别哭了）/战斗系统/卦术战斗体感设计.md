# 卦术战斗体感设计——"卦不是技能，是姿态"

> 核心：选卦不是选一个技能然后等释放——是你自己切换了一种身体形态。上卦决定"你是什么"，下卦决定"你怎么打出去"。

---

## 一、卦不是技能·是"姿态"

```
选了离☲火 → 你整个人着了火
  跑起来地上有火焰脚印
  闪避时拖出一条火痕
  普攻第三段剑尖自动迸出火星
  站在你身边的敌人被灼烧
  → 你就是火。不是"放了一个火球"。

选了震☳雷 → 你开始带电
  移动有残影
  闪避变成短距离瞬移（不是翻滚·是消失→出现在三米外）
  普攻hit-stop比平时长2帧（因为雷电麻痹）
  你的剑碰到敌人→自动跳一道电弧到最近的另一个敌人
  → 你不是"用了一个雷招"。你就是雷。

选了巽☴风 → 你轻了
  移速+30%·跳跃高度翻倍
  闪避之后惯性还在——不是停下来·是飘出去
  普攻从4段变成6段（因为剑变轻了·挥得更快）
  声音变了——风在耳边呼啸·敌人吼叫被拉远
  → 你不是"吃了一个加速buff"。你变成了风。
```

## 二、八个上卦 = 八种体感

| 上卦 | 体感关键词 | 移动变化 | 普攻变化 | 闪避变化 |
|------|---------|---------|---------|---------|
| ☲ 离·火 | **侵略** | 身后留下火焰脚印(3秒灭) | 每剑拖金色火尾·第三段迸火星 | 躲避路径残留火焰·烧到路过的敌人 |
| ☳ 震·雷 | **爆发** | 移动有残影·屏幕微微抖动 | hit-stop+2帧·带电弧跳转到近敌 | 短距瞬移(消失→3米外出现) |
| ☴ 巽·风 | **轻盈** | 移速+30%·跳跃高度翻倍 | 连段从4变6(剑变轻)·挥速+50% | 闪避后惯性滑行·风呼啸声 |
| ☵ 坎·水 | **流动** | 动作变柔·脚印带水痕 | 剑身缠绕水流·命中泼溅 | 闪避距离+50%·滑行感 |
| ☶ 艮·山 | **沉重** | 脚步声变闷·不受击退 | hit-stop+3帧·每剑如撞钟 | 不能闪避·改为格挡(减伤80%) |
| ☰ 乾·天 | **碾压** | 移速-10%·但击飞范围+50% | 每剑带击飞·中小敌人弹开 | 闪避变短距冲刺(撞飞路径敌人) |
| ☱ 兑·泽 | **迷惑** | 身后留下不动的残影(1秒) | 命中随机混乱敌人(互殴2秒) | 闪避后原地留残影·敌人攻击残影 |
| ☷ 坤·地 | **守护** | 身周土黄光晕·移速-20% | 每次命中给自身叠护盾 | 闪避距离减半·但闪避全程无敌(无空档) |

## 三、下卦是"怎么用这个形态"

上卦决定你是什么——下卦决定你怎么打出去：

| 下卦 | 打法 | 离☲火形态释放 | 震☳雷形态释放 |
|------|------|-------------|-------------|
| ☰ 乾 | **全力一击** | 蓄力一剑·前方扇形火浪AOE | 瞬移到敌人面前·雷爆 |
| ☱ 兑 | **迷惑** | 火中分出2个残影·敌人互殴 | 雷击中附加混乱效果 |
| ☲ 离 | **灼烧** | 地面留下持续燃烧区域(5秒) | 雷击落地后地面带电(5秒) |
| ☳ 震 | **打断** | 火浪附带击退+眩晕 | 大范围雷暴·群体打断 |
| ☴ 巽 | **连射** | 火焰变连射火针(快速多段) | 雷击变连锁闪电(最多跳5次) |

## 五、选卦的"变身"演出

按住右键选卦→松手确认→转化发生：

```
1. 声音先来（0-0.2秒）
   离卦：剑刃金属共鸣嗡鸣 + 空气灼烧的噼啪声
   震卦：电流滋滋声 + 远处闷雷滚过
   巽卦：风声由远及近·呼啸而过
   坎卦：水滴滴落 + 深水流动的沉闷声
   艮卦：大地深层低沉的隆隆声
   乾卦：金属撞击声·洪钟长鸣
   兑卦：多人低语声·分辨不出内容的耳语
   坤卦：完全安静——然后心跳声放大

2. 剑变化（0.1-0.3秒）
   剑尖亮起→光/火/水/电/风从剑尖蔓延到剑柄
   
3. 人变化（0.2-0.5秒）
   效果从剑蔓延到手臂→肩膀→全身
   头发·衣袍·皮肤边缘发对应颜色的光
   
4. 时间恢复正常流速（0.5秒后）
   你现在就是这个卦的化身
```

## 六、剑和卦的关系——"剑是笔，卦是墨"

| 法器 | 普攻手感 | 卦术释放手感 | 适合的卦术风格 |
|------|---------|------------|-------------|
| **银针** | 轻快·3段像缝纫机·hit-stop极短 | 卦术从针尖射出·细快穿透 | 快速叠状态·频繁换卦 |
| **桃木剑** | 稳重·4段弧斩·hit-stop中等 | 卦术从剑身挥出·宽猛击退 | 群体AOE·破白焰 |
| **铜钱剑** | 连绵·5段像鞭子·hit-stop短但多 | 卦术散成钱雨·散多独立判定 | 刷材料·叠铜钱计数 |
| **七星剑** | 沉重·3段重击·hit-stop最长 | 卦术从天而降·慢狠敕令 | BOSS终结·极限伤害 |

## 七、焦烈BOSS战——完整体感叙事

进门。焦烈站在熔岩平台中央。他嘴里说着白焰比真火先进的那些话。

我没等他说完。按住右键——时间慢了——鼠标往上——离卦☲。食指按1——乾下卦☰。松手。

金色火光从剑尖烧到剑柄再到全身。空气开始噼啪作响。脚下踩过的地面留下暗金色的火焰脚印。

左键。第一剑横斩。桃木剑拖着金色火尾，砍进焦烈胸甲。画面顿了一帧——hit-stop。火星炸开。焦烈往后退了半步，胸甲上残留一道暗金灼痕。

第二剑斜斩。他又退了一步。第三剑纵劈——他的白焰护盾碎了一块。

他抬手——白焰连射。三发白色火球冲我脸。空格闪避。往右一闪——**拖着一道金色火痕**——三发白焰全部打空，撞在我闪避路径的火焰残留上，直接灭了。

贴脸。按住右键——上卦还是离，下卦换震☳。

**我变成了一道雷火。** 剑身同时烧着金火和噼啪蓝色电弧。闪避不再是翻滚——瞬移。我消失在原地，出现在焦烈身后。松右键——一剑刺进后背。火雷同时炸开。焦烈整条血条震动。他被击飞，撞在石柱上滑下来，身上挂满了燃烧和电弧。

白焰全屏大招来了。屏幕变白。

按住右键——上卦选坤☷，下卦选艮☶。**火焰褪去，厚重土黄光晕包裹全身。** 跑动不快了——但每一步都沉重，剑插地面时平台微微震动。白焰撞在护盾上烧不进来。我在白色火海里一步步往前走，脚下在白色地面上压出金色土痕。

走到他面前。最后一下。按住右键+双击Tab——太乙神数。九键。护盾给了我四秒半。

焦烈跪在地上，白焰全灭，手心捧着那一小团橙色的真火。

击杀。

## 八、核心循环

```
左键普攻（积累卦气+hit-stop打击感）
   ↓
按住右键（时间减速·选上卦·选下卦·剑开始发光蓄力）
   ↓
松手（剑带卦术斩出去·重击爆发·hit-stop×2·屏幕震动）
   ↓
看效果（敌人被击退/灼烧/冻结·根据局势决定下一卦选什么）
   ↓
循环
```

**选卦不是点菜单——是换身体。64卦=8种体感×8种打法=64种完全不同的战斗体验。**

## 九、敌人怎么被打——八种受击反馈

"拳拳到肉"不止是打出去的那一下——敌人挨打时的反应才是真正让玩家"感觉到这一拳"的东西。

### 9.1 每种卦术命中时的敌人反应

| 卦 | 敌人反应 | 声音 | 残留效果 |
|------|---------|------|---------|
| ☲ 离·火 | **踉跄后退**·身上着火·慌乱拍打火焰·持续小幅度抖动 | 火焰呼啸+敌人惨叫+布料燃烧的噼啪 | 3秒灼烧·敌人移速-20%·攻击欲望降低 |
| ☳ 震·雷 | **全身僵直**·肌肉痉挛·四肢短暂失控·武器脱手(概率) | 雷劈炸响+嗡鸣余音+敌人闷哼 | 地面小范围电弧残留3秒·路过的敌人也受影响 |
| ☴ 巽·风 | **被推飞**·轻体型敌人直接卷起来·重体型敌人衣袍被掀起遮脸 | 狂风呼啸+衣料猎猎响+敌人惊呼 | 地面气流残留·我方经过移速+20% |
| ☵ 坎·水 | **动作变慢**·像在水底走路·举手投足都沉重 | 深水沉闷声+水泡冒出的咕噜声 | 地面水渍3秒·踩上去的敌人也被减速 |
| ☶ 艮·山 | **弹回去**·如果敌人在攻击中被命中→武器被弹开·双手发麻 | 闷响·像用拳头打石墙的声音 | 地面裂痕3秒·敌人走过受微小伤害 |
| ☰ 乾·天 | **被击飞到空中**·小型敌人腾空翻转·中型敌人双脚离地 | 金属撞击巨响声·洪钟一般的余韵 | 地面凹陷·后续击飞距离+30% |
| ☱ 兑·泽 | **攻击自己人**·混乱中转身·对着最近的同伴猛打一下 | 多个人的混杂低语声·敌人困惑的呢喃 | 地面泛起沼泽纹理·后续混乱成功率+20% |
| ☷ 坤·地 | **打不动你**·你纹丝不动·敌人反而被震退半步·武器弹开 | 闷雷般的地鸣+骨骼受力的低吟 | 你的脚下周围2m成为"稳定区"·队友站在里面不被击退 |

### 9.2 受击的"逐级累积"

同一个敌人被同一种卦连续命中，反应会升级：

```
第1次离卦命中 → 踉跄+身上一小团火·他自己拍了三下灭了
第2次离卦命中 → 整条手臂烧起来·拍不灭了·开始慌张乱跑
第3次离卦命中 → 全身着火·攻击完全停止·只顾逃跑和拍打火焰
第4次离卦命中 → 跪倒在地·火势不可控·BOSS进入"虚弱状态"
```

**连续4次同卦=敌人"崩解"。** 每种卦有不同的崩解效果：火=跪地灼烧·雷=全身麻痹·风=被龙卷吹飞·水=冻结·山=碎甲·天=击飞出战场·泽=永久混乱·坤=完全破防。

### 9.3 卦术命中弱点（变爻位置）的特殊反馈

当卦术恰好打在敌人身上"世应"对应的弱点区域时：

```
命中变爻位置 → 
  hit-stop不是2-4帧·是6-8帧
  画面除了金色闪光外·还有一瞬间的完全静音（0.1秒）
  然后爆发出更大的声响
  敌人不只是被击退——是整个人被"打穿"·身后冒出卦术的穿透特效
  手柄震动不是一次·是"咚——咚——咚"三下·像心跳
```

**这就像《只狼》的完美弹刀那一瞬间——整个世界静止了。** 然后炸开。

## 十、环境交互——你不是在场景里战斗·场景是你的一部分

### 10.1 水

```
你站在水里·选了离卦☲ → 
  脚下的水面开始冒蒸汽·视野变朦胧（3m外模糊）·你在蒸汽里变成一团移动的金光
  敌人看不到你的具体位置·但你也看不清远处
  
你站在水里·选了坎卦☵ → 
  水面上你的移速+20%·卦气恢复+50%
  闪避不再是翻滚——是潜水滑行·距离×2
  
你站在水里·选了震卦☳ → 
  电弧自动扩散到整个水面·在水里的所有敌人被连锁电击
  伤害不高·但每个敌人眩晕1秒
```

### 10.2 火

```
着火的草地/木结构建筑 → 
  选了离卦·火焰吸收到你身上（环境火熄灭·你的离卦伤害+30%）
  选了坎卦·范围自动降雨·周围火焰全灭
  选了巽卦·火借风势·火焰蔓延速度×3
  
焦烈的白焰（特殊场景） →
  选了离卦·可以"喝掉"白焰（吸收转化为卦气·环境白焰消退）
  其他卦·白焰就是纯粹的危险
```

### 10.3 高地/悬崖

```
选了巽卦☴站在悬崖边 →
  跳跃距离×3·可以跨过原本不可能跨过的峡谷
  跳下去的时候缓慢飘落·不会摔伤
  
选了乾卦☰站在高处 →
  往下跳的时候——变成陨石·落地时砸出AOE冲击波
  
选了震卦☳站在金属地面/铁轨 →
  电弧扩大·整个金属地面通电·所有站上面的敌人被连锁
```

### 10.4 雨中

```
下雨时 →
  离卦伤害-20%（火被雨压）
  坎卦伤害+30%（水助水势）
  震卦电弧扩散范围×2（雨水中导电）
  巽卦飞行速度+50%（风雨同行）
```

## 十一、防御手感——不是"不掉血"·是"老子不动"

选了艮卦☶之后，你不再是那个"闪来闪去"的辰生。你变成了一堵墙。

### 11.1 艮卦的防御体感

```
姿态变化：
  重心下沉·双脚微微分开·剑横在身前
  呼吸变慢变深·镜头微微拉近（让你感觉更"重"）
  移动不是走——是"踏"·每一步地上的脚印更深·声音更闷

敌人攻击打在你身上：
  剑撞在你的剑身上 → 火花溅开·你的剑纹丝不动·敌人的剑弹开
  大型攻击·焦烈的白焰撞在你身上 → 
    镜头小幅度后移（模拟冲击力）
    但你的角色没有后退·脚下地面裂开了
    "咚——"一声闷响·像寺庙撞钟
    然后火焰从你身体两侧分成两股·绕过你继续烧·你毫发无伤

  连续防御 → 
    你的脚陷入地面（地面裂痕累积·被压出凹陷）
    敌人越打越累·自己反而出现了"力竭"帧
    你这时候出手——他完全没防备
```

### 11.2 防御中的反击

```
吸收3次攻击后 →
  剑身上凝聚了一层暗金色的"山影"
  下一次卦术释放自动附加300%伤害
  "忍了你三下。够了。"
```

### 11.3 艮卦的音效设计

```
站立不动时 → 只有你自己的呼吸声·被放大
敌人攻击命中 → 闷钟声·每一下音调递升（第一下低·第三下最高）
反击时 → 洪钟碎裂声——然后你自己的呼吸停止·完全安静·剑斩出去
```

## 十二、形态切换的"过门"——从火到水的瞬间

战斗中你切换了卦术——比如从离卦☲切换到坎卦☵。这个瞬间不应该是"火突然消失然后水突然出现"。

### 12.1 切换演出（0.3秒·不可打断·无敌帧）

```
旧卦消退：
  身上的火焰开始往剑尖收束·像倒放的视频·0.15秒
  火焰的声音变小·音调下降
  
碰撞瞬间：
  火遇上水 → "嗤——"蒸汽爆发的声音
  辰生被白雾包裹·0.1秒·完全隐形
  敌人攻击穿过白雾·打空
  
新卦上身：
  剑尖从白色·突然滴下第一滴水·然后整个剑身变成深蓝
  雾气散去·你已经从"一团火"变成了"一道水流"
  声音从蒸汽嗤响切换到深水流动的低鸣
```

### 12.2 连携效果——五行相生相克

```
火☲→水☵（相克·"水火既济"）→ 
  切换时爆发的蒸汽造成一次额外AOE伤害
  敌人在蒸汽中被烫伤+被湿气减速·双debuff

水☵→木☴（相生·"水生木"）→ 
  切换时地面残留的水渍变成藤蔓·定住上面的敌人1秒
  额外+20卦气（"水滋养了木"）

木☴→火☲（相生·"木生火"）→ 
  切换瞬间屏幕边缘燃起火焰·灼烧附近所有敌人
  切换后的第一次火卦伤害+50%

火☲→金☰（相克·"火克金"）→ 
  切换时剑身瞬间变白·高热金属的光芒
  下一次普攻破甲效果+100%

金☰→水☵（相生·"金生水"）→ 
  剑身上的金属光泽液化·变成水
  额外+30卦气

土☷→金☰（相生·"土生金"）→ 
  身上土黄光晕凝结成金属光泽
  切换后第一次卦术释放附带瞬间无敌
```

### 12.3 快速切换的高端玩法

```
高手流：
  离☲(火) → 普攻3段积累灼烧 → 切坎☵(水)
  → 水火既济·蒸汽爆炸打断敌人当前动作
  → 坎☵的水渍减速敌人→ 切巽☴(风)
  → 水生木·地面的水渍变成藤蔓定身
  → 切离☲(火)
  → 木生火·火焰+50%·收割

  三次切换·四卦连携·从灼烧到定身到收割
  → 不是"选了个技能"·是打了一套卦术连招
```

## 十三、更新后的核心循环

```
左键普攻（积累卦气+感受当前卦形态的打击感）
   ↓
观察战场（环境有什么？水？火？悬崖？雨天？）
   ↓
按住右键（时间减速·选上卦决定下一形态·选下卦决定打法）
   ↓
松手（剑带卦术斩出·敌人产生对应的受击反馈+环境交互）
   ↓
看结果（敌人烧起来了？站在水里被电了？被击飞到悬崖下了？）
   ↓
决定是否切换形态（相生连携？相克爆发？还是保持当前形态继续？）
   ↓
循环
```

**现在战斗不只是选卦→放卦——是"你是什么元素"+"你在什么环境"+"敌人现在是什么状态"+"接下来要切什么形态产生连携"——四方决策，每一个选择都有体感反馈。**
