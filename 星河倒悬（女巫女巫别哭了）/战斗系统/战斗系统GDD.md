# 战斗系统 GDD（重构版）——《星河倒悬》

> **重构日期：** 2026-08-01（法器系统整合：2026-08-02）
> **重构依据：** 方案C——单一道士职业 + 卦象渐进解锁 + NPC星君同伴
> **法器整合：** 四法器系统——桃木剑/铜钱剑/七星剑/银针 = 卦术的物理载体
> **原版：** 十职业战斗系统 → **现版：** 一道士深度战斗 + 四法器切换 + 十二同伴协同

---

## 1. 设计概述

### 1.1 核心变更

| 维度 | 原设计（十职业） | 重构后（一道士） |
|------|---------------|---------------|
| 可玩角色 | 10个职业，各有独立操作系统 | 1个道士（辰星卦师），7套子系统 |
| 战斗深度 | 横向铺开（10×中等深度） | 纵向深挖（1×极限深度） |
| 武器/法器 | 各职业绑定固定武器 | 4种法器即时切换，同卦不同器=不同形态 |
| 星君 | 可切换的职业身份 | NPC同伴（AI操控+被动增益） |
| 能力解锁 | 职业切换 | 按章节渐进解锁卦象系统+法器 |
| 开发量 | 10套操作系统、动画、平衡 | 1套操作系统 + 4套普攻模组 + 12个AI行为树 |

### 1.2 设计原则

- **低门槛，高上限：** 小六爻0.3秒甩鼠标即可出招；太乙神数9键零失误封神
- **渐进解锁：** 卦象按章节逐步解锁，法器按章节逐步获得，新手第一章只面对小六爻+4种火卦+银针
- **叙事=玩法：** 每过一个道宫=战斗能力实质性扩展，与剧情觉醒同步。法器获得=同伴赠予/星君传承
- **同伴协同：** 12位星君NPC提供被动增益+AI战斗辅助，不抢主角操作权
- **法器=卦术载体：** 同一个离卦=银针的火焰针雨 / 桃木剑的真火斩 / 铜钱剑的火钱散射 / 七星剑的火敕令。底层卦术系统不变，法器改变卦术的物理形态
- **文化1:1对应：** 每一个卦象、每一种数术、每一件法器都在游戏中有精确的机制映射

### 1.3 战斗体验弧线

```
序章：节奏游戏（小六爻甩鼠标 + 银针普攻）
 ↓  获得桃木剑（星纪宫通关）
第1-4宫：卦象选择（16-32卦选卦配卦）+ 法器双切换（银针↔桃木剑）
 ↓  获得铜钱剑（降娄宫通关）
第5-7宫：多维战术（64卦全解锁 + 奇门遁甲九宫格阵法）+ 法器三切换
 ↓  获得七星剑（鹑火宫通关）
第8-11宫：极限操作（太乙神数按键序列 + 预存卦象连发）+ 法器四切换
 ↓  七星剑"步罡踏斗"（鹑尾宫）
第12宫：终极协同（十二同伴合力 + 重力能力 + 四法器最终奥义）
```

## 2. 玩家幻想

- **指尖掐算，掌控战场：** 按住右键，时间流速降到30%（消耗卦气），八卦盘在指尖展开。敌人动作变慢，而你已在选下一卦。高手不减速也能凭肌肉记忆选卦——省下的卦气就是翻盘的筹码。
- **法器是卦术的"笔"：** 桃木剑斩出离卦=真火斩，铜钱剑洒出离卦=火钱散弹，七星剑敕令离卦=天权星火。同卦不同器，战斗手感完全不同。
- **凭直觉就能玩：** 小六爻模式下，往下甩=后退，往右甩=加速。肌肉记忆就是你的卦盘。不需要任何知识储备。
- **越玩越深：** 从8个符号到64卦全记忆，从银针单法器到四法器无缝切换，从预设阵法到自定义九宫八门布局，从照提示按键到闭眼9键零失误。
- **紫微命盘打造独有build：** 同一个64卦技能配置，换了命盘就是完全不同的效果。同一个离卦，换把剑就是完全不同的手感。你的道士是你的，不是攻略上的。
- **十二位同伴不是背景板：** 锻锋在白焰中为你开路，苏羽闭眼射中你看不到的弱点，石磐报出亡灵的名字让战场逆转。
- **名场面制造机：** 濒死边缘，切换七星剑→步罡踏斗→7步踏完北斗阵→4.5秒完成9键零失误太乙神数→全场逆转。

## 3. 操作基础

### 3.1 通用操作（键鼠）

| 操作 | 按键 | 说明 |
|------|------|------|
| 移动 | `WASD` | 八方向移动 |
| **跳跃** | `空格` | 基础跳跃·离卦形态可二段跳·巽卦形态高度翻倍·乾卦跳下砸地AOE |
| **闪避** | `鼠标右键` 短按 | 按下立刻触发·0帧响应·13帧无敌（闪避后1秒内卦象瞬发） |
| **选卦（时停）** | 按住 `鼠标右键` | 闪避后按着不放→150ms后时停→八卦光环从脚下升起→选卦→松手释放 |
| 选卦·上卦 | 右键按住 + 鼠标在光环上的位置 | 8方向=8卦位 |
| 选卦·下卦 | 右键按住 + `1/2/3/4/Q/E/R/F` | 键盘选下卦（高手向·0.5-0.8秒） |
| 选卦·拖拽 | 右键按住 + 左键按住 | 卦针滑光环·两次松左键选上卦+下卦（直觉向·1.5-3秒·详见 [[卦象选装与选卦交互——完整规格书]]） |
| 对话/交互 | `F` | 长按进入梅花易数观象（非战斗） |
| **普攻** | `鼠标左键` | 当前法器的连段模组（银针3段/桃木4段/铜钱5段/七星3段） |
| **小六爻** | 按住 `右键` + `Shift` | 鼠标6方向→松手释放（0.3s·无减速·紧急时刻用） |
| **奇门遁甲** | 按住 `右键` + `Ctrl` | 1/2/3选预设阵→鼠标选位→松手布阵 |
| **太乙神数** | 按住 `右键` + 双击 `Tab` | 有卦气≥3层时触发→序列按键→松手释放 |
| **法器切换** | `↑` `←` `→` `↓` | ↑=桃木剑 / ←=银针 / →=铜钱剑→七星剑 / ↓=铜钱剑 |
| **法器专属技** | 长按 `鼠标左键` | 银针=点穴 / 桃木=虚空画符 / 铜钱=撒豆成兵 / 七星=步罡踏斗 |
| 重复卦象 | `Q` | 重复上次卦象（短按·伤害-20%·不下卦效果）/ 逆转上下卦（长按） |
| 取消/预存 | `E` | 取消输入（短按）/ 预存卦象至3或4键（长按） |
| 预存释放 | `3` `4` | 瞬发预存的卦象组合 |
| 同伴指令 | `1` `2` | 1=同伴集火 / 2=同伴守护 |

> **右键双击设计：短按闪避·长按选卦。** 闪避在按下瞬间触发（0帧响应·不等150ms）。150ms后如果还没松手→闪避后摇被截断→时停打开→八卦光环升起→开始选卦。闪避和选卦无缝衔接——高手闪避落地刚好光环展开·零停顿。

### 3.2 演卦状态参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 时间减速 | 正常流速的30% | 消耗卦气开启（不再免费） |
| 减速消耗 | 每秒消耗1层卦气 | 卦气=0时 → 按住右键不减速，但卦盘仍可使用 |
| 减速期间移速 | 正常60% | 可缓慢调整位置 |
| 减速期间受伤倍率 | 120% | 高风险——选卦时被打更疼（但比原来的150%缓和） |
| 减速期间霸体 | 无 | 可被强力攻击打断 |
| 打断惩罚 | 卦气保留50%，5秒冷却 | 不再清零——"有成本的战术选择"而不是"惨烈惩罚" |
| 最长持续 | 8秒 | 超时自动释放当前卦象 |

> **设计意图：** 时间减速从"每次按右键免费享受"改为"每秒消耗1层卦气"。

### 3.3 右键选卦——为什么右键独立（2026-08-10更新）

> **右键双击设计：短按闪避·长按选卦。** 闪避在按下瞬间触发（0帧响应·不等150ms）。150ms后如果还没松手→闪避后摇被截断→时停打开→八卦光环升起→开始选卦。闪避和选卦无缝衔接——高手闪避落地刚好光环展开·零停顿。这是黑魂/法环/仁王验证了十几年的方案。

## 4. 法器系统（卦术的物理载体）

> **核心设计理念：法器不是替代卦术——法器是卦术的"笔"。同一个卦，不同法器释放=不同形态、不同手感、不同战术。**

### 4.1 法器总览

| 法器 | 获得时机 | 赠予者 | 定位 | 普攻段数 | 范围 | 卦气/段 | 伤害倍率 |
|------|---------|--------|------|---------|------|---------|---------|
| **银针** | 序章（默认） | 玄伯遗物 | 卦气发动机——快速积累 | 3段→精通4段 | 1.5m | +8 | ×0.6 |
| **桃木剑** | 星纪宫通关 | 锻锋真火重铸 | 均衡法器——普攻与卦术最佳平衡 | 4段→精通5段 | 2.5m/120° | +5 | ×0.85 |
| **铜钱剑** | 降娄宫通关 | 顾锋剑气启发 | 连击法器——持续进攻越打越强 | 5段→精通6段 | 2m | +3 | ×0.7 |
| **七星剑** | 鹑火宫通关 | 玄微子传授 | 重击法器——敕令星辰、高伤慢速 | 3段 | 3.5m | +12 | ×1.3 |

### 4.2 法器对卦术的变形（核心机制）

**同一个卦象，在不同法器下呈现不同的物理形态。卦术的底层逻辑（伤害类型、卦气消耗、冷却时间）不变，但判定方式、视觉效果、操作手感随法器变化。**

以离卦上卦（火）为例：

| 法器 | 卦术形态 | 判定方式 | 特殊效果 |
|------|---------|---------|---------|
| **银针** | 火焰针雨（前方锥形散射） | 多段小判定，适合快速叠加灼烧 | 每针独立暴击判定 |
| **桃木剑** | 真火斩（前方扇形火浪） | 单段大判定，弧面覆盖120°，中距 | 对伪卦/亡灵伤害+25% |
| **铜钱剑** | 火钱散弹（前方随机弹道） | 多枚铜钱各独立判定，每枚小伤害 | 每枚命中+3铜钱计数 |
| **七星剑** | 火敕令·天权星（锁定目标落火柱） | 单体锁定，延迟1秒后火柱落下 | 击中后敕令值+30 |

> **设计要点：** 玩家学了离卦+乾下卦这个组合后，用小六爻甩方向+选卦的肌肉记忆不变——但换一把剑，同一个卦就变成了完全不同的"招式"。这比 64×4=256 种实际效果，远超任何 ARPG 的招式数量，但学习成本 = 0（因为卦象组合的逻辑不变）。

### 4.3 银针——默认法器

**定位：** 卦气发动机。快速积累卦气，为切其他法器释放强力卦术铺路。

**普攻连段：**
- 第1段：胸前平刺（0.25s）
- 第2段：反手挑刺（0.3s）
- 第3段：双手前推刺 → 附带自动演卦（随机小六爻，0.35s）

**卦术变形特征：**
- 所有卦术呈现为"针"的形态（细、快、多）
- 卦术释放速度 +30%
- 卦术范围 -20%
- 卦术每段均为独立小判定（适合叠加元素异常）

**法器专属技——点穴（长按左键蓄力）：**
- 蓄力0.8s → 精准刺击（射程3m，单点判定）
- 头穴：眩晕2s / 手穴：敌人无法施法3s / 腿穴：移速-50%（5s）
- 命中后卦气+20
- 蓄力期间可慢走，不可闪避

**切换时机：** 卦气不足 → 切银针积累；高速敌人 → 银针保持压制。

### 4.4 桃木剑——第一章获得

**定位：** 均衡法器。大多数常规战斗的默认选择。普攻范围大、卦术视觉效果最有"道士感"。

**获得演出：** 星纪宫通关后，玄伯遗物中有一柄断了的桃木剑。锻锋觉醒后用真火重铸剑身——剑刃呈暗金色，剑格刻"彰往察来"。

**普攻连段：**
- 第1段：右下→左上斜斩（0.45s）
- 第2段：左下→右上斜斩（0.5s）
- 第3段：纵劈（0.55s，硬直Lv2）
- 第4段：回旋横斩（0.6s，360°击退周围敌人）

**卦术变形特征：**
- 卦术以"剑斩"形态释放（弧面、穿透、冲击波）
- 卦术范围 = 基准值
- 卦术释放附带一次剑斩的物理伤害（物理+卦术双重判定）
- 特殊属性：对"伪卦/仿品/亡灵"类敌人伤害+25%（斩邪）

**法器专属技——虚空画符（长按左键 + 鼠标方向）：**
- 蓄力0.6s → 剑尖在空中画符（用小六爻6方向选择符型）
- ↑ 火符：前方直线灼烧15m
- ↓ 水符：回复自身20%卦气+清除1个debuff
- ← 雷符：锁定目标头顶落雷
- → 风符：前方5m范围DOT区域（持续8s）
- 画符消耗卦气25，不进入卦盘流程（即时释放）
- 画符期间可慢走，不可闪避

**哲学映射——大梁宫"去伪存真"：**
- 在大梁宫中，桃木剑的"斩邪"获得最大强化——可以斩断伪卦，使被西陆篡改的卦术恢复真貌
- 剑尖画符 = 书写真相的动作

**切换时机：** 大多数常规战斗的默认选择；需要群体控制时切桃木剑。

### 4.5 铜钱剑——第四章获得

**定位：** 连击法器。越打越强——108枚铜钱计数系统驱动的高频战斗风格。

**获得演出：** 降娄宫通关后，顾锋以"剑气"为启发，帮辰生将108枚铜钱以红线串成剑。剑身柔软如鞭，挥动时发出铜钱碰撞的清响。

**普攻连段：**
- 第1段：钱剑刺击（0.3s）
- 第2段：剑身横拍（0.35s）
- 第3段：上挑（0.4s）
- 第4段：鞭状横扫（0.4s，前方180°）
- 第5段：散落回收——108枚铜钱散开→回收（0.5s，铜钱各独立判定，回收时造成二次伤害）

**铜钱计数系统（核心机制）：**

```
每次普攻命中 → 铜钱计数+1
每18枚里程碑触发"通宝"效果：
  18枚：下一次卦术零卦气消耗
  36枚：暴击率+15%（持续至108枚或脱战）
  54枚：铜钱护盾（吸收20%最大生命伤害）
  72枚：下一次法器专属技必暴击
  90枚：当前卦气翻倍
 108枚：全场铜钱雨——对所有敌人造成1.5×ATK伤害，计数归零
```

**卦术变形特征：**
- 卦术附加"钱币"视觉效果（散弹、弹跳、散射）
- 卦术消耗 -20%（铜钱的"财"属性）
- 卦术伤害 -10%
- 卦术命中 +2铜钱计数

**法器专属技——撒豆成兵（长按左键蓄力）：**
- 蓄力0.5s → 铜钱撒落地面 → 形成结界环（直径6m，持续8s）
- 结界内效果：敌人减速30% + 辰生卦气恢复翻倍
- 结界内卦术消耗不受铜钱剑的-20%（即使用标准消耗）
- 冷却：45s

**切换时机：** 单体高血量敌人→叠计数→108枚铜钱雨爆发；需要快速刷卦气时。

### 4.6 七星剑——第八章获得

**定位：** 重击法器。高伤害、慢速度。"敕令"系统——用七星剑命令敌人执行动作。

**获得演出：** 鹑火宫通关后，玄微子将伴随他三千年的七星剑交给辰生。剑身镶嵌七颗宝石对应北斗七星。剑柄刻"天枢·天璇·天玑·天权·玉衡·开阳·摇光"。

**普攻连段：**
- 第1段：双手纵劈（0.7s，硬直Lv3——可击退中甲敌人）
- 第2段：横斩（0.8s，前方180°）
- 第3段：突刺（0.9s，直线5m冲击+穿透）

**敕令系统（核心机制）：**

每次普攻命中积累"敕令值"（对灵体/星君/伪星力敌人×1.5）。敕令值满100后，敌人头顶出现"敕"字标记——此时按住右键不进入卦盘，而是触发敕令（选择方向）：

| 敕令 | 方向 | 效果 | 适用对象 |
|------|------|------|---------|
| 伏 | ↓ | 敌人强制跪下2s，无法行动，受伤+30% | 人类/精英 |
| 退 | ← | 敌人后退5m+恐惧3s | 群体 |
| 破 | ↑ | 破除敌人卦术护盾/阵法/伪卦buff | 卦师类 |
| 归 | → | 伪星力敌人"回忆真实身份"→全属性-30%（60s） | BOSS特殊阶段 |

**卦术变形特征：**
- 卦术以"北斗星光"形态释放（延迟锁定+从天而降或从剑尖射出）
- 卦术范围 +30%
- 卦术释放速度 -40%（剑重）
- 卦术消耗 +30%

**法器专属技——步罡踏斗（长按左键蓄力）：**
- 蓄力0.8s → 进入踏斗姿态 → 按北斗七星方位踏出7步（↑↑←→↑↓→）
- 每一步留下一个星光脚印 → 7步踏完 → 北斗阵激活
- 北斗阵：直径15m，阵内所有卦术零消耗（持续10s）
- 踏斗期间不可闪避，可被强力攻击打断
- 一场战斗限一次（或冷却300s）

**哲学映射——鹑火宫"劳动创造文明"：**
- 七星剑"命令"的不是毁灭，是调遣星辰之力
- 步罡踏斗 = 用身体丈量大地 = 劳动的行为本身
- 配合鲁班语（神机星君）的机关创造——"劳动"和"敕令"都是文明的基石

**切换时机：** BOSS战高端输出；需要破除敌人特殊机制时；追求极限伤害时。

### 4.7 法器切换机制

**切换按键：** 方向键 ↑↓←→（瞬时切换，0.3s冷却防误触）

```
↑ = 桃木剑（最常用，放在最容易按到的位置）
← = 银针（卦气发动机，撤退/回复的直觉方向）
→ = 铜钱剑（前期）/ 七星剑（第八章获得后替换铜钱剑位置）
↓ = 铜钱剑（前后期不变——获得七星剑后，↓保持铜钱剑，→改为七星剑）
```

**切换响应：**
- 切换瞬时完成，当前连段中断，可立刻开始新法器普攻
- 切换不打断演卦（选卦中切法器 = 当前选卦释放时自动使用新法器形态）
- 切换有0.3s冷却（防止误触连切）

**切器连携（进阶机制）：**

切器后1.5s内释放的第一个卦术获得"连携加成"：

| 切法 | 效果 | 战术含义 |
|------|------|---------|
| 银针→桃木剑 | 卦术伤害+25% | "用针攒气→用剑爆伤" |
| 桃木剑→银针 | 卦气消耗-50% | "用剑输出→切针续航" |
| 铜钱剑→桃木剑 | 铜钱计数保留+下次卦术必暴击 | "叠满计数→切剑终结" |
| 任意→七星剑 | 敕令值+50 | "切重器镇压" |
| 七星剑→任意 | 卦气+30 | "北斗余威" |

**手柄映射：**
- 十字键 ↑↓←→ = 法器切换
- LT = 演卦
- LT + RB = 小六爻
- LT + LB = 奇门遁甲
- RB = 普攻
- A = 闪避

### 4.8 法器精通度

每种法器有独立精通等级（使用该法器战斗积累经验）：

| 等级 | 名称 | 效果 |
|------|------|------|
| Lv1 | 初识 | 基础属性 |
| Lv2 | 熟练 | 普攻段数+1（银针3→4、桃木4→5、铜钱5→6、七星不变） |
| Lv3 | 精通 | 专属技冷却-30% |
| Lv4 | 大师 | 切至此法器时，第一个卦术消耗-50% |
| Lv5 | 入化 | 解锁"奥义"连携（特定法器组合的切器连携升级为奥义级效果） |

```
[战斗开始]
    ↓

    ↓

    ↓

# 旧版（Phase 1参考）
基础伤害 = 攻击力 × 技能倍率 × (1 + 等级加成)
暴击伤害 = 基础伤害 × (1 + 暴击伤害加成)    [暴击时]
元素加成 = 暴击伤害 × (1 + 元素增伤)
最终伤害 = 元素加成 × (1 - 减伤率) × (1 + 伤害浮动)

减伤率 = 防御力 / (防御力 + 200 + 等级×10)    [上限80%]
暴击率 = 基础暴击率 + (暴击 - 抗暴) / 100 × 1%    [上限80%，下限5%]
等级加成 = clamp(等级差 × 0.03, 0, 0.45)    [鼓励越级挑战]
```

### 10.4 三爻归真系统（大梁宫解锁）

> **解锁时机：** 大梁宫·第五章
> **核心功能：** 识别太史阁"伪卦"——发现卦盘中被西陆篡改的虚假爻辞，用真卦替换伪卦，使敌人卦术失效并受到反噬。

#### 操作方式

```
战斗中遇到"太史卦师"类敌人时：
  1. 按住右键 → 卦盘展开
  2. 卦盘上被篡改的卦位显示为【红色·抖动·有裂痕】
     （正常卦位=金色·稳定·完整）
  3. 鼠标移到红色卦位 → 自动弹出"辨伪窗口"
     ┌─────────────────────────┐
     │  伪卦·离☲（被篡改）      │
     │  显示：火在上·光明普照    │
     │  真义：火被水压·光明囚禁  │
     │  替换为真卦？             │
     │  [1] 确认归真  [2] 取消   │
     └─────────────────────────┘
  4. 按1确认 → 消耗卦气15 → 卦位从红色变为金色
     → 敌人该卦位的伪卦技能被"反噬"（伤害反弹+眩晕2s）
  5. 三爻全部归真（3个伪卦位被替换）→ 触发"去伪存真"
     → 全场伪卦敌人全属性-30%（持续30s）
```

#### 伪卦位生成规则

| 敌人类型 | 伪卦位数 | 分布 |
|---------|:---:|------|
| 太史学徒 | 1 | 随机上卦位 |
| 太史卦师 | 2 | 1上卦+1下卦 |
| 太史阁老 | 3 | 2上卦+1下卦·切换时随机变化 |
| BOSS（闫序等） | 3-4 | 随时间轮转（每30s重新随机） |

#### 归真效果

| 归真爻数 | 即刻效果 | 持续效果 |
|:---:|------|------|
| 1爻归真 | 敌人该伪卦技能失效+反噬伤害100% ATK | 15s内该敌人无法使用该卦位 |
| 2爻归真 | 反噬范围扩大至周围5m敌人 | 30s内该类型伪卦伤害-25% |
| 3爻归真 | **"去伪存真"触发**：全场伪卦敌人全属性-30% | 持续30s·所有真卦伤害+25% |

#### 交互细节

- **辨伪窗口时间限制：** 2.5秒（与下卦选择窗口一致）·超时=自动关闭·不消耗卦气
- **归真消耗：** 每次15卦气·3爻全归真=45卦气·如果卦气不足=无法归真
- **归真失败惩罚：** 选错真卦（用与伪卦不匹配的真卦确认）→伪卦位"加固"→该卦位本次战斗无法再归真
- **归真熟练度：** 每归真一次+熟练度。熟练度Lv3后→辨伪窗口时间延长至3.5秒·消耗降至10卦气
- **桃木剑加成：** 持桃木剑归真→消耗减半（8卦气/次）·反噬伤害+50%（斩邪被动）

#### 与"去伪存真"哲学命题的关系

"归真"不是消灭——是把被篡改的东西恢复原貌。大梁宫的哲学命题是"去伪存真"：伪卦不是假的能量——是被西陆用技术手段（海溟国的"化史炉"）强行篡改了形态的真卦。归真=让被压抑的真实重新显现。这与大梁宫守史者闫序（推演机的创造者）的剧情弧光直接对应——他一生用推演机模拟历史，最后发现推演机输出的"历史"全是西陆篡改的版本。

## 10.5 伤害公式（统一版）

> **权威版本** · 所有加成来源均在此公式中。详见 `战斗系统/共享系统接口定义.md`。

```
基础伤害 = ATK × 技能倍率
暴击判定 = Rand(0,1) < 暴击率 ? 1 + 暴击伤害加成 : 1
元素加成 = 1 + 元素增伤率
锻造加成 = 1 + 锻造等级 × 0.03
命盘加成 = 1 + Σ(紫微斗数·各宫·卦术伤害加成)
启示加成 = 1 + Σ(三钱摇卦·激活的卦象启示)
同伴加成 = 1 + Σ(携带同伴·被动增益)
等级加成 = 1 + clamp(等级差 × 0.03, 0, 0.45)

最终伤害 = 基础伤害 × 暴击判定 × 元素加成 × 锻造加成 × 命盘加成 × 启示加成
         × 同伴加成 × 等级加成 × (1 - 减伤率) × 伤害浮动
```
