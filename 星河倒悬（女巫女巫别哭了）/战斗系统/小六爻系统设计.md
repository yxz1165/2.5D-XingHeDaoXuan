# 小六爻系统设计——你的第一套卦术

> **定位：** 0门槛入门系统。序章解锁。6方向甩鼠标·0.3秒释放。是玩家从"我什么都不会"到"我能战斗"的桥梁。
> **操作：** 按住右键+Shift → 鼠标向6方向之一甩动 → 松手释放
> **代价：** 不消耗卦气·不进入时停·纯粹肌肉记忆

---

## 一、文化根源——真实的"掐指一算"

### 1.1 传统小六爻

小六爻是中国民间最普及的占卜术之一。不需要蓍草·不需要铜钱·不需要任何工具——只需要自己的左手。

```
左手掌诀：
  食指根部 → 大安（大吉）
  食指指尖 → 留连（凶）
  中指指尖 → 速喜（中吉）
  无名指指尖 → 赤口（凶）
  无名指根部 → 小吉（大吉）
  中指根部 → 空亡（大凶）

占卜时按农历月·日·时三个数字，从寅位（大安）起正月，
顺数至当月→再从此位起初一顺数至当日→再从此位起子时顺数至当时。
最终落在那一位——即为此占的答案。
```

### 1.2 游戏化

辰生不需要农历月日时——他用的是**鼠标甩动的方向**。6个方向对应6个掌诀位。

**设计原则：** 不教玩家"小六爻是什么"——让玩家在甩鼠标的过程中**自己发现**"往上甩会加攻击·往下甩会加移速·往左甩会回血"。肌肉记忆就是最好的教学。

## 二、操作与判定

### 2.1 按键序列

```
1. 按住 Shift（小六爻修饰键）
2. 按住 右键（不用时停·直接进入选方向状态）
   → 或者 SHIFT先按住·再按右键（效果相同）
3. 屏幕中央浮现六分光环（6方向指示器）
4. 鼠标向6个方向之一甩动
5. 松手释放
   
总时间：0.3秒（从按住右键到松手）
```

### 2.2 方向判定算法

以角色朝向为正前方（0°），将360°划分为6个扇区：

| 扇区角度 | 方向 | 卦名 | 判断优先级 |
|:--:|------|------|:--:|
| 330°-360° + 0°-30° | ↑ 上前方 | 大安 | — |
| (-30°)-(+30°) 即前方 | ↑ | 大安 | 最常用·最宽扇区 |
| 30°-90° | ↗ 右前方 | 空亡 | — |
| 90°-150° | → 右方 | 速喜 | — |
| 150°-210° | ↓ 下方/后方 | 留连 | — |
| 210°-270° | ↙ 左后方 | 赤口 | — |
| 270°-330° | ← 左方 | 小吉 | — |

**判定精度：** 从按住右键到鼠标移动距离≥50px开始判定。死区（鼠标未移动）持续0.5秒→自动释放大安（默认）。

**手柄映射：** 右摇杆方向·LT+RB触发·摇杆6分扇区·与鼠标判定完全一致。

### 2.3 视觉指示器

```
按住Shift+右键 → 屏幕中央浮现光环：

    ┌──────────────────────┐
    │                      │
    │     ⬆ 大安           │  ← 金色·最亮
    │   ↗     ↖           │
    │ 空亡   留连          │
    │ →       ←           │
    │ 速喜   小吉          │
    │   ↘     ↙           │
    │     ⬇ 赤口          │
    │                      │
    └──────────────────────┘
    
    光环中央：辰生的银针/剑尖
    鼠标方向 → 对应扇区高亮·其他扇区变暗
    选中扇区 → 卦名浮现·简短效果说明文字一闪
```

**动画时间线：**
- 0ms：Shift+右键按下 → 光环浮现（淡入·100ms）
- 100ms：鼠标开始移动 → 扇区高亮切换（实时跟随鼠标）
- 300ms：松手 → 光环爆开 → 效果生效
- 350ms：光环消散 → 返回正常视角

## 三、六种效果——完整数值表

### 3.1 效果总览

| 方向 | 卦名 | 效果 | 持续 | 冷却 | 卦气消耗 | 使用场景 |
|------|------|------|:--:|:--:|:--:|------|
| ↑ | **大安** | 伤害+20% | 3秒 | 8秒 | 0 | 开怪·爆发前·普攻连段中 |
| ↘ | **留连** | 前方扇形缠绕（3m·60°） | 3秒 | 12秒 | 0 | 被包围·控制增援 |
| ↓ | **速喜** | 移速+40% | 3秒 | 6秒 | 0 | 赶路·追击·逃跑·快速走位 |
| ↙ | **赤口** | 前方直线击退5m+眩晕1.5s | 瞬间 | 15秒 | 0 | 打断敌人施法·推开高危怪 |
| ← | **小吉** | 回复15%最大生命 | 瞬间 | 30秒 | 0 | 保命·BOSS战续航 |
| ↗ | **空亡** | 向后瞬移5m+隐身1s | 1秒 | 20秒 | 0 | 紧急脱战·规避致命AOE |

### 3.2 效果升级轨道

小六爻效果可以随游戏进度升级——不是简单的数值增加，而是"效果形态变化"：

| 卦名 | Lv1（序章） | Lv2（降娄宫） | Lv3（大火宫） |
|------|-----------|-------------|-------------|
| **大安** | 伤害+20%·3s | 伤害+25%·5s | 伤害+30%·5s·**暴击率额外+15%** |
| **留连** | 3m扇形·3s | 5m扇形·3s | 5m扇形·3s·**缠绕后附加1层灼烧** |
| **速喜** | 移速+40%·3s | 移速+40%·5s | 移速+50%·5s·**闪避无敌帧+3** |
| **赤口** | 击退5m·眩晕1.5s | 击退8m·眩晕2s | 击退10m·眩晕2s·**撞墙额外伤害** |
| **小吉** | 回复15%生命 | 回复20%生命 | 回复25%生命·**清除1个debuff** |
| **空亡** | 后闪5m·隐身1s | 后闪7m·隐身1.5s | 后闪10m·隐身2s·**隐身结束自动大安** |

> 升级条件：通关对应道宫后自动升级。不需要额外操作。

## 四、与大八卦盘的关系——什么时候用小六爻·什么时候用64卦

```
小六爻：紧急·即时·不消耗
  - 被包围了 → 留连缠绕
  - 敌人蓄力大招 → 空亡脱战
  - 需要追击 → 速喜加速
  - 血量危险 → 小吉一口
  - 起手第一下 → 大安增伤
  
64卦：预谋·蓄力·消耗卦气
  - 知道敌人弱点火 → 选离卦
  - 需要控制场面 → 选坎卦+艮下卦
  - 积累足够卦气 → 选高消耗高伤害组合
  - BOSS虚弱状态 → 最大化输出连发
```

**高手循环：大安（增伤）→ 3秒内用64卦爆输出 → 大安快结束时切速喜追击。** 小六爻给64卦铺路。

## 五、动画与音效

### 5.1 动画

```
大安（↑）：
  → 辰生左手拇指向食指根部一掐（掐指一算）
  → 金色光环从指尖扩散到全身
  → 持续时间光环在手腕处微微发光
  
留连（↘）：
  → 左手拇指向食指指尖一掐
  → 紫色光环从指尖扩散到前方扇形范围
  → 被缠绕的敌人身上浮现紫色藤蔓纹理

速喜（↓）：
  → 左手拇指向中指指尖一掐
  → 蓝色风痕从指尖绕到腿部
  → 移动时拖出蓝色残影

赤口（↙）：
  → 左手拇指向无名指指尖一掐
  → 红色冲击波从指尖爆发
  → 被击退的敌人拖出红色尾迹

小吉（←）：
  → 左手拇指向无名指根部一掐
  → 绿色光雨从指尖洒落到全身
  → 回血时绿色粒子从地面升起

空亡（↗）：
  → 左手拇指向中指根部一掐
  → 身体颜色褪去·半透明
  → 后闪路径留下短暂的黑色残影
```

### 5.2 音效

```
大安：剑刃出鞘的高频金属声（"锵——"）
留连：藤蔓缠绕的低沉"咯吱"声
速喜：风声由远及近（"呼——"）
赤口：岩石碎裂声（"砰！"）
小吉：水滴落+泉水涌出声
空亡：短暂死寂（0.2秒）·然后风声从近到远
```

### 5.3 手柄震动

```
大安：轻震一次·50ms
留连：中震两次·间隔100ms
速喜：轻震持续·200ms·模拟"风在吹"
赤口：重震一次·100ms
小吉：轻震三次·每次30ms·间隔50ms·像心跳
空亡：完全不震（"消失"了）
```

### 7.1 数据结构

```csharp
[Serializable]
public class XiaoLiuYao {
    public enum Direction {
        Up = 0,       // ↑ 大安
        DownRight = 1, // ↘ 留连  
        Down = 2,      // ↓ 速喜
        DownLeft = 3,  // ↙ 赤口
        Left = 4,      // ← 小吉
        UpRight = 5    // ↗ 空亡
    }
    
    public int level = 1; // 1-3·降娄宫升2·大火宫升3
    
    public static readonly string[] NAMES = { "大安", "留连", "速喜", "赤口", "小吉", "空亡" };
    
    // 冷却计时器(6个独立冷却)
    public float[] cooldowns = new float[6];
    
    // 根据等级获取效果参数
    public static XiaoLiuYaoEffect GetEffect(Direction dir, int level) {
        return dir switch {
            Direction.Up => new XiaoLiuYaoEffect {
                damageBonus = 0.15f + level * 0.05f,  // 0.20/0.25/0.30
                duration = 3f + (level >= 2 ? 2f : 0f), // 3/5/5
                cooldown = 8f,
                extraCrit = level >= 3 ? 0.15f : 0f
            },
            Direction.DownRight => new XiaoLiuYaoEffect {
                coneRadius = 3f + (level >= 2 ? 2f : 0f),
                coneAngle = 60f,
                rootDuration = 3f,
                cooldown = 12f,
                extraDot = level >= 3 // Lv3附加灼烧
            },
            Direction.Down => new XiaoLiuYaoEffect {
                speedBonus = 0.35f + level * 0.05f,
                duration = 3f + (level >= 2 ? 2f : 0f),
                cooldown = 6f,
                extraIFrames = level >= 3 ? 3 : 0
            },
            Direction.DownLeft => new XiaoLiuYaoEffect {
                knockbackDistance = 5f + (level - 1) * 2.5f,
                stunDuration = 1.5f + (level >= 2 ? 0.5f : 0f),
                cooldown = 15f,
                wallDamage = level >= 3
            },
            Direction.Left => new XiaoLiuYaoEffect {
                healPercent = 0.10f + level * 0.05f,
                cooldown = 30f,
                cleanseDebuff = level >= 3
            },
            Direction.UpRight => new XiaoLiuYaoEffect {
                blinkDistance = 5f + (level - 1) * 2.5f,
```

### 7.2 方向判定算法

```csharp
public class XiaoLiuYaoInput {
    private const float DEAD_ZONE = 50f;  // 鼠标移动50px开始判定
    private const float HOLD_TIMEOUT = 0.5f; // 按住不动0.5秒自动大安
    
    public static XiaoLiuYao.Direction DetectDirection(Vector2 mouseDelta) {
        if (mouseDelta.magnitude < DEAD_ZONE) 
            return XiaoLiuYao.Direction.Up; // 默认大安
        
        float angle = Mathf.Atan2(mouseDelta.y, mouseDelta.x) * Mathf.Rad2Deg;
        // 转换为以"上前方"为0°的坐标系
        angle = (angle + 90f + 360f) % 360f;
        
        // 6分扇区判定
        float sector = 360f / 6f; // 60° each
        int index = Mathf.FloorToInt((angle + sector / 2f) % 360f / sector);
        
        return (XiaoLiuYao.Direction)index;
    }
}
```

## 八、与小六爻的入门设计——为什么它是第一套系统

小六爻是玩家学会的第一个战斗系统。不是因为它简单——是因为它**不需要思考**。

```
新手第一次战斗（序章·太史学徒）：
  1. 按住右键+Shift（屏幕中央出现光环——"这是啥？"）
  2. 鼠标往上推（本能的"攻击"方向）
  3. 松手 → 大安·伤害+20%（"哦——往上甩就是加攻击"）
  4. 接下来3秒·伤害数字变大了（"有用！"）
  5. 冷却中·按左键普攻·打死第一只怪（"我会了"）
  
  → 玩家在30秒内·自己发现了小六爻的用法
  → 不需要教学文字·不需要弹窗提示
  → 光环的方向暗示+大安的即时反馈=最好的教学
```
