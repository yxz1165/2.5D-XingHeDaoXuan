# 战斗系统——帧级精确规格书

> **目标：** 从通关到无伤到速通到限制条件花式速通——每一层的体验建立在帧级精确的战斗基础上。
> **参考基准：** 空洞骑士（HK）、黑神话悟空（BMW）
> **设计哲学：** 卦象不是技能，卦象是思维方式。玩家的成长不是手速变快，是卦理参悟变深。

---

# 一、玩家成长金字塔

## 1.1 五个层级

```
Lv1 · 通关者          Lv2 · 无伤者          Lv3 · 速通者
"记住4-8个常用卦"    "BOSS每个阶段用什么卦"  "发现卦术的隐藏位移"
       ↓                    ↓                    ↓
     40小时              200小时              500小时
       
Lv4 · 限制挑战者      Lv5 · 卦理大师
"只用4卦通关"         "闭眼听风辨卦"
       ↓                    ↓
     800小时             2000小时+
```

## 1.2 每层的关键突破

| 层级 | 突破点 | 在星河倒悬中对应什么 |
|:--:|------|------|
| Lv1 通关 | 学会闪避 | 小六爻+银针普攻=可通关·60小时 |
| Lv2 无伤 | 记住BOSS所有攻击的前摇 | 64卦中至少20个卦的精确帧数据 |
| Lv3 速通 | 发现卦术位移效果 | 离卦冲刺·坎卦水下抄近路·巽卦空中风道 |
| Lv4 限制 | 卦象子集最优解 | "只用第1章解锁的4个离卦通关" |
| Lv5 卦理 | 耳听风声+眼见星光=已知卦位 | 全程不减速选卦·太乙神数全关·凭直觉按键 |

# 二、帧级精确参数

## 2.1 帧率基准

```
基准帧率：60fps（PC锁定）
1帧 = 16.67ms
所有时间参数以"帧"为单位（非秒）
```

## 2.2 玩家状态机优先级

```
优先级从高到低（排在前面的可以打断后面的）：

1. 受击硬直（不可取消·最高优先级）
2. 死亡（不可取消）
3. 闪避（按下瞬间生效·取消普攻/卦术前摇）
4. 同伴指令（1键/2键·瞬发）
5. 卦术释放（前摇不可取消·后摇可被闪避取消）
6. 银针普攻（第1段·第2段·第3段各有取消窗口）
7. 法器切换（取消普攻后摇·不取消卦术前摇）
8. 移动（始终可执行·不打断其他动作）
9. 交互（F键·移动中可触发·战斗中优先级最低）
```

## 2.3 闪避——帧精确参数

这是整个战斗手感的基石。参照 HK 的暗影冲刺（Shade Cloak）。

| 参数 | 值 | 说明 |
|------|:--:|------|
| **输入响应延迟** | **0帧** | 按下右键→立刻开始闪避·无输入延迟 |
| **无敌帧开始** | 第1帧 | 按下瞬间无敌帧即生效 |
| **无敌帧结束** | 第13帧 | 共13帧无敌（216.7ms） |
| **闪避总帧数** | 20帧 | 第1-13帧无敌·14-20帧收尾（可被移动取消） |
| **闪避距离** | 4m | 水平位移4m·方向=当前移动输入方向（无输入=向后） |
| **冷却** | 0.8秒（48帧） | 连续闪避之间必须有48帧间隔 |
| **取消窗口** | — | 闪避可以取消普攻后摇和卦术前摇（不能取消卦术释放中） |
| **疲劳惩罚** | 连续3次闪避后 | 第4次闪避无敌帧-5帧（13→8帧）·冷却+0.3秒·连续闪避计数器每1.5秒未闪避重置 |
| **闪避后卦术窗口** | 闪避结束后15帧内 | 释放卦术前摇-5帧（从25帧→20帧）——"闪避后顺发卦术" |

**对比：**
- HK 暗影冲刺：无敌帧约 15 帧（250ms）·冷却 0.5秒
- BMW 完美闪避：无敌帧约 8 帧·触发识破后时间变慢
- **星河倒悬：13帧无敌·0.8秒冷却·闪避后卦术加速——让闪避和卦术形成"闪→卦→闪→卦"的节奏**

## 2.4 银针普攻——帧精确参数

| 段位 | 前摇(帧) | 判定帧 | 后摇(帧) | 可取消于第(帧) | 伤害倍率 | 卦气获取 |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 第1段 | 6 | 7-9（3帧） | 10-20 | 11（闪避）/15（第2段）/20（卦术） | 0.6×ATK | +3 |
| 第2段 | 8 | 9-12（4帧） | 13-25 | 14（闪避）/20（第3段）/25（卦术） | 0.8×ATK | +4 |
| 第3段 | 10 | 11-16（6帧） | 17-34 | 18（闪避）/34（法器切换）/34（卦术） | 1.2×ATK | +6 |

**取消窗口说明：**
- "可取消于第11帧"=在第11帧及之后可以用闪避/第2段/卦术取消剩余的后摇帧
- 越早取消=伤害越低（因为后摇被取消=段位终止时的伤害未变）但可以获得更流畅的连段

**对比设计基准：**
- HK 骨钉：4段连击·每段取消窗口不同
- BMW 棍势：轻击3段×3棍势·识破取消在轻击第3段后
- **星河倒悬：3段普攻×每段3个取消出口（闪避/下段/卦术）=9种取消路径**

## 2.5 选卦系统——帧精确参数

| 参数 | 值 | 说明 |
|------|:--:|------|
| **短按右键** | < 150ms（9帧） | 判定为闪避 |
| **长按右键** | ≥ 150ms（9帧） | 进入选卦状态 |
| **进入选卦延迟** | 第10帧开始 | 长按9帧后·第10帧卦盘展开 |
| **时间减速开始** | 第12帧 | 游戏时间流速降至10% |
| **玩家移速** | 减速期间=正常的50% | 不是完全不能动——减速中可缓慢移动 |
| **卦盘扇区检测** | 鼠标进入扇区30帧（0.5秒减速时间）后锁定 | 锁定后扇区高亮·松开右键=释放 |
| **松键→释放延迟** | 2帧（33ms） | 松开右键后2帧内卦术放出 |
| **取消选卦** | 在扇区锁定前松开右键（<30帧） | 不消耗卦气·不触发冷却·回到常态 |
| **选卦中受伤** | 减速期间受伤×1.5 | 高风险高回报 |
| **高手不减速选卦** | 可设置项·关闭时间减速 | 靠肌肉记忆在实时速度中选卦·不减速=不消耗额外卦气 |

## 2.6 卦术释放——通用帧参数

| 参数 | 基准值 | 说明 |
|------|:--:|------|
| **前摇** | 20-30帧（因卦而异） | 从松右键到判定帧 |
| **判定帧** | 3-8帧（因卦而异） | 伤害判定的帧数 |
| **后摇** | 15-25帧（因卦而异） | 可被闪避取消（从第X帧开始·因卦而异） |
| **冷却** | 见64卦数据规格书 | 单体攻击卦短·AOE卦长 |
| **卦气消耗** | 基准20·因下卦调整±50% | 乾下卦=30·坤下卦=15·其余见数据规格书 |

## 2.7 法器切换——帧参数

| 参数 | 值 | 说明 |
|------|:--:|------|
| **切换前摇** | 8帧 | 法器显现动画 |
| **切换后摇** | 10帧 | 可被移动/闪避取消 |
| **切换冷却** | 1.5秒（90帧） | 不能连切 |
| **切换后卦术窗口** | 切换后15帧内 | 卦术前摇-8帧 |
| **切换中受伤** | 正常受伤 | 无惩罚·但切换后摇中挨打无法取消 |
| **四法器循环** | 1→2→3→4→1 | 按Tab键循环·或独立快捷键 |

# 三、取消窗口优先级系统

## 3.1 全部取消出口一览

```
普攻第1段后摇
    ├→ 闪避（第11帧起）    ← 最常用·闪避取消
    ├→ 普攻第2段（第15帧起）← 继续连段
    └→ 卦术（第20帧起）    ← 闪避→卦术的延迟版

普攻第2段后摇
    ├→ 闪避（第14帧起）
    ├→ 普攻第3段（第20帧起）
    └→ 卦术（第25帧起）

普攻第3段后摇
    ├→ 闪避（第18帧起）
    ├→ 法器切换（第34帧起）
    └→ 卦术（第34帧起）

卦术前摇
    ├→ 闪避（可以·但卦气已消耗·卦术未放出）
    └→ 移动（卦术前摇中可缓慢移动）

卦术后摇
    ├→ 闪避（第X帧起·因卦而异）
    ├→ 法器切换（第Y帧起·因卦而异）
    └→ 普攻（第Z帧起·因卦而异·部分卦术后摇不可被普攻取消）

闪避后摇（第14-20帧）
    ├→ 移动（即刻取消后摇）
    └→ 卦术（闪避结束后15帧内·前摇加速5帧）
```

## 3.2 取消窗口的"速度层级"

这是速通和无伤的关键——每种取消路径的"速度"不同：

| 取消路径 | 从输入到下一次伤害的时间 | 速通/无伤中的用途 |
|------|:--:|------|
| 闪避取消普攻→卦术 | 闪避20帧+卦术前摇15帧=35帧（0.58秒） | 最安全·有13帧无敌窗口覆盖 |
| 普攻第1段→直接卦术 | 后摇取消+卦术前摇25帧=0.42秒 | 更快·但无无敌帧覆盖·无伤禁用 |
| 普攻第3段→法器切换→卦术 | 后摇在34帧被切取消→法器切换8帧→卦术前摇12帧=54帧（0.9秒） | 最慢·但法器切换带来不同的卦术形态 |

**设计意图：** 闪避取消→卦术是"安全窗口"——玩家用闪避的无敌帧渡过后摇+前摇最脆弱的0.3秒。但速通玩家发现——如果站位完美，根本不需要无敌帧，直接普攻→卦术更快——这就构成了速通的"风险换时间"决策。

# 四、Hitbox与受击判定

## 4.1 玩家受击盒

```
玩家受击盒 = 1个胶囊体（Capsule Collider）
  高：1.6m（头顶到膝盖）  ← 不是全身·脚不受击
  半径：0.25m（身体宽度）  ← 比视觉模型窄
  偏移：脚底+0.3m到头顶-0.1m

设计意图：
  - 比视觉模型略小·给玩家"差点被打到"的刺激感
  - 脚不受击=地面AOE可以在玩家跳跃时躲过
  - 闪避中受击盒半径缩小至0.05m（配合13帧无敌=双重保险）
```

## 4.2 玩家攻击判定盒

```
银针普攻：1个Capsule（跟随剑尖）·前向4m·半径0.3m
卦术（远程）：1个Sphere（飞行弹体）·半径0.2m到1.5m不等
卦术（近战）：1个Box（前方扇形）·角度60°·距离3-6m因卦而异
法器专属技：各不相同（见法器数据表）

关键原则：攻击判定盒必须 ≥ 视觉特效大小
反例：HK有时剑刃视觉比判定大·导致视觉上砍到了但没伤害——绝对禁止
```

## 4.3 BOSS受击盒与攻击判定

```
BOSS受击盒分为：
  - 身体：1个大Capsule·全卦术可命中
  - 弱点（如有）：1个Sphere·仅在特定阶段激活·暴击率翻倍
  - 护甲（如有）：受击盒外的Collider层·吸收伤害·不触发受击反馈

BOSS攻击判定盒：
  - 必须在攻击前摇的第1帧就完全显示
  - 红色区域=伤害判定（站在上面必定受伤）
  - 黄色区域=预警区域（站在上面不受伤·但1秒后变成红色）
  - 攻击判定盒的大小和形状必须在视觉上可见
```

## 4.4 不可有"必中"攻击

这是无伤挑战可能性的底线：

```
所有敌人攻击必须满足以下至少一项：
  ① 有≥15帧的前摇动画（玩家可以在15帧=250ms内反应并闪避）
  ② 攻击判定盒在生成前有地面预警（红色/黄色范围指示器）
  ③ 攻击方向/范围可预判（敌人面朝方向=攻击方向）

绝对禁止：
  ① 零帧伤害（出现在玩家面前的瞬间就造成伤害）
  ② 全屏不可闪避AOE（必须有安全区域）
  ③ RNG决定的可闪避性（同一攻击不能"有时可闪有时不可闪"）
  ④ 追踪攻击的曲率超过玩家移速的2倍（不能完全无法甩开）
```

# 五、输入系统

## 5.1 输入响应

```
输入→动作的流水线（每帧执行一次）：

帧N：   读取所有输入设备状态
帧N：   输入缓冲检查（在缓冲窗口内的输入=立即执行）
帧N+1： 更新动作状态机（根据优先级）
帧N+1： 开始动作前摇的第1帧
帧N+2： 视觉反馈（特效·动画·音效）开始

从按键到视觉反馈：恒定2帧延迟（33ms）——在任何运行环境下不可超过3帧
```

## 5.2 输入缓冲窗口

参照 HK 的输入缓冲系统——这是"手感好"的关键：

| 动作 | 缓冲窗口 | 说明 |
|------|:--:|------|
| 普攻连段 | 10帧 | 在第1段后摇结束前10帧内按下攻击键=自动接第2段 |
| 闪避缓冲 | 8帧 | 在受击硬直/硬直结束后8帧内按下右键=硬直一结束立刻闪避 |
| 卦术缓冲 | 15帧 | 在闪避第14帧（无敌结束前1帧）按下右键并拖拽=闪避结束立刻选卦 |
| 法器切换缓冲 | 5帧 | 在普攻第3段后摇结束前5帧按下切换键 |
| 交互缓冲 | 20帧 | 靠近交互对象时20帧内按键=自动交互 |

## 5.3 禁止输入吞掉

```
以下情况不能"吞"玩家输入（HK式的硬直中按键无效——不做）：
  ❌ 受击硬直中按下闪避→硬直结束后闪避 = 不吞，直接缓冲
  ❌ 卦术后摇中按下普攻→后摇结束后普攻 = 不吞，缓冲
  ❌ 选卦中想取消→闪避 = 立即取消（卦气已消耗）
  ❌ 切换法器后立刻卦术→有15帧窗口·不吞

唯一不缓冲的情况：
  技能冷却中→按键不响应（但冷却结束前8帧内按键会缓冲）
```

# 六、受击反馈（Hit Response）

## 6.1 硬直等级

| 等级 | 触发条件 | 硬直帧数 | 可缓冲闪避窗口 | 视觉反馈 |
|:--:|------|:--:|:--:|------|
| Lv1 | 轻攻击（杂兵普攻） | 8帧 | 第6帧起 | 身体微晃·银针振动 |
| Lv2 | 中攻击（精英普攻） | 15帧 | 第10帧起 | 身体后仰·短暂击退1m |
| Lv3 | 重攻击（BOSS普攻·卦术直接命中） | 22帧 | 第15帧起 | 身体飞退3m·地面裂痕 |
| Lv4 | 致命攻击（BOSS大招） | 35帧 | 第20帧起 | 身体抛飞5m·落地弹起1次·黑白色调 |
| Lv5 | 特殊（虚噬攻击·第11-12章） | 45帧 | 第30帧起 | 身体透明化·周围星空特效·无法被同伴援护 |

## 6.2 Hitstop（顿帧）

参照 BMW 的"打中了有反馈"：

| 命中类型 | 顿帧(帧) | 说明 |
|------|:--:|------|
| 普攻击中敌人 | 2帧 | 轻微的"叮"感 |
| 普攻第3段命中 | 4帧 | 最后的"砰"感·更重 |
| 卦术命中 | 3-6帧（因卦而异） | 火卦=长顿帧·水卦=无顿帧 |
| 暴击 | 8帧 | 明显的"贯穿"感·画面微震 |
| 处决（影怜同伴技） | 20帧 | 长顿帧+画面变暗+BOSS特写 |
| 破盾/破甲 | 12帧 | 金属碎裂音·碎片粒子 |
| 五行相克触发 | 8帧 | 金光一闪·五行符文浮现 |

**设计基准：** HK 的 hitstop 约 3-6 帧·BMW 的 hitstop 约 4-8 帧（重击时可达12帧）。星河倒悬 hitstop 整体偏轻——因为卦术频率高，hitstop太长会影响连携节奏。

## 6.3 画面震动（Screen Shake）

| 触发 | 强度 | 衰减 | 说明 |
|------|:--:|:--:|------|
| 普攻命中 | 0 | — | 无震动 |
| 卦术命中 | 1-3 | 线性·0.3秒 | 因卦而异·火卦最重 |
| 暴击 | 4 | 线性·0.5秒 | |
| BOSS大招 | 8 | 指数·0.8秒 | 配合手柄震动 |
| 同伴大招 | 5 | 线性·0.3秒 | |
| 星碑激活 | 2 | 指数·1秒 | 低频嗡鸣感 |
| 环境破坏 | 3-6 | 线性·不等 | |

震动强度 0-10 级。所有震动可设置为关闭/50%/100%。

# 七、卦象的隐藏位移效果——速通设计

这是 Lv3 速通玩家才发现的维度。官方不写在教程里——让社区自己发现。

## 7.1 有位移效果的卦术

| 卦术 | 位移效果 | 距离 | 帧数 | 速通用途 |

# 八、无伤挑战设计标准

## 8.1 BOSS攻击的可闪避性检查清单

每个BOSS的每个攻击必须通过以下检查：

```
□ 前摇 ≥ 15帧（250ms）—— 人类平均反应时间200ms+执行闪避50ms
□ 攻击方向 = 面朝方向（或180°·不会突然反向）
□ 攻击判定的范围<全屏（必须有安全区）
□ 攻击判定在视觉上完全对应特效（无隐形判定）
□ 追踪弹体有最大追踪角度（不能180°拐弯跟踪）
□ AOE攻击有≥30帧的地面预警
□ 连段攻击每段之间有≥8帧间隙（给闪避窗口）
□ 攻击不会在玩家闪避无敌帧中触发额外效果（不会"惩罚闪避"）
```

## 8.2 无伤评级系统（内置·可在通关后解锁）

| 评级 | 条件 | 额外奖励 |
|:--:|------|------|
| S | 无伤（0受伤）+ 不使用同伴援护 | 星晶×1（仅首次） |
| A | 无伤（0受伤） | 称号"卦术不侵" |
| B | 受伤≤3次 | 无额外奖励 |
| C | 通关 | 无额外奖励 |

## 8.3 BOSS回忆模式（通关后解锁）

在任意已通关道宫的星碑前，可选择"回忆BOSS战"——重新挑战该BOSS。此模式下：
- 所有装备/等级/卦术保持当前状态（不受该章当时的限制）
- 击败后显示帧精确数据：总帧数/受伤次数/连击最高数/卦术使用数
- 支持幽灵录像——可录制自己的一场战斗并分享卦码给其他玩家挑战

# 十一、战斗的艺术性——手感设计

## 11.1 "手感"是什么

好的战斗手感 = 五件事：

1. **输入到视觉的恒定延迟**（我们的基准：2帧=33ms，不可超3帧）
2. **受击反馈的层次感**（Lv1到Lv5硬直·不同hitstop·不同屏幕震动）
3. **取消窗口的"节奏线"**（普攻→闪避→卦术→闪避→普攻·形成循环）
4. **声音的同步性**（命中音效和伤害数字同一帧出现·不能音画不同步）
5. **控制器/键鼠的统一手感**（键鼠和手柄的操作延迟不能有差异）

## 11.2 声效帧同步要求

| 声效 | 触发帧 | 说明 |
|------|:--:|------|
| 普攻挥动声 | 前摇第1帧 | 剑刃开始动就有声音 |
| 普攻命中声 | 判定帧第1帧 | 和hitstop同步—帧 |
| 闪避声 | 闪避第1帧 | 和无敌帧开始同步—帧 |
| 卦术释放声 | 松右键后第2帧 | 和卦术判定帧同步 |
| 受击声 | 受击硬直第1帧 | |
| BGM节奏变化 | BOSS进入下一阶段时 | 不是切歌·是同一首BGM变化节奏/增加乐器 |

## 11.3 BH（Bad Hit）检测

每次玩家受伤时，系统记录：

```
原因分类：
  - 前摇太短（<15帧）—— BOSS攻击设计问题
  - 闪避失败（玩家闪避了但判定帧在无敌帧结束后）—— 闪避时机问题
  - 贪刀（玩家在攻击后摇中被击中·取消窗口内未闪避）—— 玩家操作问题
  - 站位错误（AOE预警时未移动）—— 玩家决策问题
  - 不可闪避（无预警/零帧伤害）—— 严重设计问题·必须修复
  - 连段间隙不足（<8帧）—— BOSS连招设计问题
```

在开发测试阶段持续收集BH数据，不断调整BOSS帧参数。

# 十二、验证清单

## 12.1 无伤可行性验证

每做完一个BOSS，必须有人（开发人员或测试者）完成该BOSS的无伤挑战。

每做完一章，必须有测试者尝试"用卦术位移效果跳过非必要战斗"——记录最短时间，对比设计中的理论速通时间。差异>50%说明有BUG或设计问题。

## 12.3 帧参数校准

每完成一个可玩版本，用高速摄像机（或引擎内置帧分析工具）逐帧检查：
- 输入到动作的帧数是否恒定2帧
- 无敌帧是否确实在第1-13帧有效
- 取消窗口是否在正确的帧位置
- hitstop是否与伤害数字同一帧

## 13.1 银针——极速刺击·针形态

**获得：** 序章（初始武器）
**五行：** 金
**战斗哲学：** 快。天下武功唯快不破。银针是唯一可以在普攻中无缝穿插卦术的法器。
**适合：** 速通（最快攻速·最短后摇）·连击挑战（高Hit数）·新手（容错高·后摇短）

### 普攻——3段极速刺击

| 段位 | 前摇(帧) | 判定帧 | 后摇(帧) | 可取消于(帧) | 伤害 | 卦气 | 硬直等级 |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 第1段 | 6 | 7-9（3帧） | 10-20 | 11(闪避)/15(第2段)/20(卦术) | 0.6×ATK | +3 | Lv1 |
| 第2段 | 8 | 9-12（4帧） | 13-25 | 14(闪避)/20(第3段)/25(卦术) | 0.8×ATK | +4 | Lv1 |
| 第3段 | 10 | 11-16（6帧） | 17-34 | 18(闪避)/34(法器切换)/34(卦术) | 1.2×ATK | +6 | Lv2 |

**银针专属特性——针尖：** 第3段最后一帧（第16帧）命中时，如果命中位置在敌人受击盒的边缘（最外侧0.1m），触发"针尖暴击"——伤害翻倍（2.4×ATK）。这是速通中银针的核心输出手法——精确控制距离。

**银针卦术变形——"针"形态：** 用银针释放卦术时，卦术的判定变成多段小判定（每段独立计算暴击），而非单段大判定。例：离卦用银针放=不是一道火柱，是18根小型火焰针散开。散开角度=15°锥形。

| 银针卦术参数 | 非银针 | 银针 | 说明 |
|------|:--:|:--:|------|
| 判定段数 | 1段 | 3-18段（因卦而异） | 离卦18段·坤卦3段 |
| 每段伤害 | 100% | 12%-40%（因段数而异） | 18段=每段12%·总伤害不变但可暴击概率翻倍 |
| Hitstop | 3-6帧 | 每段1-2帧 | 连续顿帧=密集的"叮叮叮"声=银针特有手感 |
| 卦气消耗 | 基准 | +5% | 多段判定=更多卦气消耗 |

**银针在速通中的角色：** 最快的攻速=最短的普攻窗口=可以在闪避后1帧内开始普攻恢复卦气。速通玩家的卦气管理核心工具。

## 13.2 桃木剑——均衡弧斩·斩形态

**获得：** 星纪宫通关（第1章）
**五行：** 木
**战斗哲学：** 稳。桃木剑是四法器中唯一有"必定暴击帧"的武器——特定帧内命中必定暴击。
**适合：** 无伤（稳定伤害·可预测暴击）·BOSS战（弧斩范围大·不需要精确站位）·初期（第1章获得·陪你走最久）

### 普攻——4段均衡弧斩

桃木剑是唯一有4段普攻的法器。第4段=必定暴击。

| 段位 | 前摇(帧) | 判定帧 | 后摇(帧) | 可取消于(帧) | 伤害 | 卦气 | 硬直等级 |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 第1段 | 8 | 9-12（4帧） | 13-24 | 14(闪避)/18(第2段)/24(卦术) | 0.5×ATK | +4 | Lv1 |
| 第2段 | 10 | 11-15（5帧） | 16-30 | 17(闪避)/22(第3段)/30(卦术) | 0.7×ATK | +5 | Lv1 |
| 第3段 | 12 | 13-18（6帧） | 19-38 | 20(闪避)/28(第4段)/38(卦术) | 0.9×ATK | +6 | Lv2 |
| **第4段** | **16** | **17-22（6帧）** | **23-46** | **24(闪避)/46(卦术无取消·必须打完)** | **1.5×ATK·必定暴击** | **+10** | **Lv3** |

**桃木剑专属特性——斩邪：** 第4段是唯一"不可被玩家取消"的普攻段位——一旦进入前摇就必须打完。但这意味着它是"必定暴击"——暴击率=100%。所以它的取消惩罚是设计的一部分——你赌第4段命中，成功了=暴击+高卦气，失败了（被BOSS打断）=吃满46帧的后摇+可能受伤。这是无伤玩家的核心博弈——在BOSS的哪个攻击间隙中插入第4段。

**桃木剑卦术变形——"斩"形态：** 卦术判定从点/球变成弧形面——宽度增加50%，但距离减少30%。桃木剑斩出的离卦不是一道火柱，是一道弧形火刃——同时覆盖前方120°的区域。

| 桃木剑卦术参数 | 非桃木剑 | 桃木剑 | 说明 |
|------|:--:|:--:|------|
| 判定形状 | 点/球/直线 | 弧形面（120°·距离减30%） | 弧形=覆盖更大的横向范围 |
| 伤害 | 100% | 80%（范围更大=单目标伤害降低） | 但可以同时命中多个敌人 |
| 对虚噬/伪卦伤害 | 100% | **125%** | 桃木=斩邪·对篡改之物有克制 |
| 卦气消耗 | 基准 | -5% | 桃木是"木"·木生火=卦气效率提升 |

**桃木剑在无伤中的角色：** 必定暴击的第4段=无伤玩家用来最快击杀BOSS的核心工具。但第4段不能取消=必须在精确知道BOSS攻击间隙的情况下使用。这形成了无伤桃木剑玩家的核心节奏——BOSS攻击→闪避→第1-3段→判断间隙→如果够大=插入第4段（暴击）→如果不够=提前闪避取消。

## 13.3 铜钱剑——连击鞭状·散形态

**获得：** 降娄宫主线（第4章）
**五行：** 金
**战斗哲学：** 散。铜钱剑是四法器中唯一有"连击计数系统"的武器——铜钱计数越高，伤害越高。108枚铜钱全部收集后解锁终极形态。
**适合：** 高连击挑战·清杂兵·刷材料（铜钱掉落+20%）·限制挑战（铜钱计数=自创限制·计数越低伤害越低=增加难度）

### 普攻——5段连击鞭状

| 第1段 | 10 | 11-14（4帧） | 单体·直线 | 15-28 | 16(闪避)/22(第2段)/28(卦术) | 0.3×ATK/敌 | +2/敌 |

**伤害示例：** 如果前4段总共击中了8个敌人（群战中），第5段鞭梢伤害=0.4+8×0.3=2.8×ATK。单挑BOSS时（每段1敌），5段总命中=5，第5段=0.4+5×0.3=1.9×ATK。

**铜钱计数系统：** 108铜钱收集=永久累积。每收集一枚铜钱，铜钱剑普攻伤害+0.1%（108枚=+10.8%）。全部108枚收集后，铜钱剑进入"满贯"形态——第5段鞭梢必定暴击。

**铜钱剑卦术变形——"散"形态：** 卦术从集中单点变成散弹——弹跳型判定。同卦同伤害，但可以在敌人之间弹跳。弹跳次数=铜钱计数/10（最大10次）。

**无伤终极Build：** 大六壬·预读命运（槽1）+ 五行·生克连锁（槽2）+ 小六壬（槽3）。大六壬让所有BOSS攻击前摇+5帧=更多时间闪避+五行更容易触发崩解=更快击杀=受伤机会更少+小六壬无敌帧+2=总共15帧无敌帧=和HK暗影冲刺一样长。

## 23.3 键鼠vs手柄延迟对比

| 操作 | 键鼠延迟 | 手柄延迟 | 差异 |

| 闪避 | 0帧 | 0帧（RT模拟值>0.5立即触发） | 无差异 |

| 敌人伤害 | 基准 | ×1.3 | — |
| 敌人血量 | 基准 | ×1.2 | — |
| 卦术前摇 | 基准 | 基准（不变） | 玩家自选限制中不影响卦术前摇 |

# 二十五、手感调校——逐帧校准清单

## 25.1 每帧必须检查的八项

引擎内置逐帧调试模式——开发期间持续运行：

```
帧调校检查清单（每完成一个动作必须逐帧验证）：

□ 1. 输入帧: 按键输入在帧N被读到
□ 2. 状态机响应帧: 动作状态机在帧N+1切换
□ 3. 动画开始帧: 动作动画在帧N+2开始（第一帧动画可看到）
□ 4. 无敌帧激活帧: 闪避无敌帧在闪避第1帧激活
□ 5. 判定帧: 普攻/卦术判定在第X帧激活（和设计一致）
□ 6. hitstop触发帧: hitstop在判定帧第1帧触发
□ 7. 音效帧: 命中音效和hitstop同一帧
□ 8. 伤害数字帧: 伤害数字和hitstop同一帧（不能晚1帧）
```

## 25.2 已知的手感陷阱

| 陷阱 | 表现 | 修复 |
|------|------|------|
| 输入吞掉 | 玩家在闪避后立刻按普攻·但普攻没出来 | 检查缓冲窗口是否生效·缓冲计数器是否被意外清零 |
| 延迟累积 | 玩30分钟后输入延迟从2帧变成4帧 | 检查Unity的InputSystem是否有帧累积问题·每15分钟强制刷新Input Buffer |
| 判定盒漂移 | 卦术判定盒在60fps下比30fps下略大（浮点精度问题） | 锁定60fps·禁止可变帧率·判定盒使用FixedUpdate而非Update |
| 连击中断 | 第3段普攻后无法取消→卦术·取消窗口失效 | 检查状态机优先级·是否有Bug导致后摇提前结束但未触发取消出口 |
| Hitstop影响其他敌人 | BOSS的hitstop暂停了所有敌人·但玩家hitstop只暂停自己和敌人 | 检查hitstop的时间层——玩家的hitstop只影响被命中的敌人和玩家自己 |
