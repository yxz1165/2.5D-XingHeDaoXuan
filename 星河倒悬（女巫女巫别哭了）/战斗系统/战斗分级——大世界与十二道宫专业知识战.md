# 战斗分级——大世界简版 vs 十二道宫专业知识战

> **核心问题：** 大世界清怪和道宫BOSS战用同一套战斗系统→道宫没有"门槛感"和"神圣感"。
> **解决方案：** 大世界只用基础卦术。进入道宫=进入一种"术数维度"——每座道宫是一种真实中国传统术数体系的实战化表达。从道宫入口开始，战斗规则就变了。
> **专业知识来源：** 每种术数体系的设计基于其真实的历史规则和操作方法——不是"贴皮"。

## 大世界·Lv0——基础战斗

大世界野外和普通副本内**不激活**以下系统：
- ❌ 六爻战场（屏幕上方无爻线）
- ❌ 卦阵激活
- ❌ 变爻
- ❌ 卦vs卦对抗
- ❌ 八卦盘地面投影（演卦时仅在UI层面显示·无地面光效）

大世界只保留：
- ✅ 小六爻（6方向甩鼠标）
- ✅ 基础卦术（已解锁的卦·选方向+按键）
- ✅ 普攻·闪避·切法器·连携
- ✅ 敌人弹窗和硬直
- ✅ 梅花易数观象（探索用）

**效果：** 大世界战斗快速、直接、不拖节奏。玩家在外面是"清怪"心态。进入道宫才切换到"全力以赴"模式。

## 十二道宫·Lv2/Lv3——专业知识战斗

### 道宫一：星纪宫——小六壬掌诀

**专业知识：小六壬（小六爻的完整术数体系）**

小六壬是道家最基础的占卜术——不需要工具，只用左手掌诀。六个掌诀位（大安、留连、速喜、赤口、小吉、空亡）在食指/中指/无名指的指节上。

#### 道宫专属机制：掌诀占场

进入星纪宫后，战场上出现六个**发光的地面区域**——对应六个掌诀位。这些区域不是固定的UI标记——是地面上的真实光纹（像烧红的烙印）。

```
战场布局（俯视角）：

      大安(食指根)          留连(食指尖)
          ○                     ○
          
                   速喜(中指尖)
                       ○
                    
          ○                     ○
      小吉(无名指根)        赤口(无名指尖)
       
                   空亡(中指根)
                       ○

六个区域按左手掌诀的相对位置排列在战场上。
每个区域直径约4m·地面光纹为金色篆书字体。
```

#### 掌诀位效果

| 掌诀 | 地面颜色 | 辰生站在上面 | 敌人站在上面 |
|------|:--:|------|------|
| **大安** | 金色 | 伤害+30%·卦气恢复×2 | 受到伤害+30% |
| **留连** | 暗红 | 被缠绕·移速-30% | 被缠绕·移速-30%（双方均受影响·凶位） |
| **速喜** | 翠绿 | 移速+40%·闪避无敌帧+5 | 攻速+40% |
| **赤口** | 血红 | 伤害×1.5·但持续掉血5%/秒 | 伤害×1.5·持续掉血（双方·凶位） |
| **小吉** | 银白 | 每2秒回复8%生命 | 每2秒回复5%生命 |
| **空亡** | 漆黑 | 隐身·不被锁定·但卦气每秒-10 | 移速-50%·攻击欲望-80%（凶中之凶） |

#### 敌人机制：掌诀行者

星纪宫内的太史阁敌人学会了利用掌诀位——他们会主动站到对自己有利的位置（大安/小吉），并试图把辰生推入凶位（留连/赤口/空亡）。

#### BOSS战：焦烈——白焰覆盖掌诀

焦烈会定期用白焰覆盖一个掌诀位——白焰覆盖后该位置效果反转（吉变凶·凶变吉）。辰生需要用离卦真火"烧掉"白焰来恢复掌诀位的正常效果。

### 道宫二：玄枵宫——太极阴阳翻转

**专业知识：太极图·阴阳消长**

太极图的核心思想：阳中有阴（白中黑点）、阴中有阳（黑中白点）、阴阳互相转化、物极必反。

#### 道宫专属机制：太极战场

玄枵宫的战斗地面是一幅巨大的**太极图**（直径约20m·铺满BOSS房和主要战斗区域）。

```
太极图分为：
  - 白色区域（阳） = 外圈+阳鱼（白色大半）
  - 黑色区域（阴） = 阴鱼（黑色大半）
  - 阳中阴眼 = 白鱼中的黑色圆点（直径3m）
  - 阴中阳眼 = 黑鱼中的白色圆点（直径3m）

太极图不是静止的——它在缓慢旋转（约60秒转一圈）。
```

#### 太极位效果

| 位置 | 效果 |
|------|------|
| **阳区（白色）** | 伤害+40%·受到伤害+40%·卦气消耗-30% |
| **阴区（黑色）** | 伤害-30%·受到伤害-30%·卦气恢复×3 |
| **阳中阴眼（黑点）** | 站在上面3秒→触发"物极必反"→阳区效果瞬间翻转为阴区效果（全屏） |
| **阴中阳眼（白点）** | 站在上面3秒→触发"物极必反"→阴区效果瞬间翻转为阳区效果（全屏） |

#### "翻转"机制

辰生站在阳中阴眼上3秒 → 全屏阴阳翻转：
- 原本白色的阳区变为黑色（阴区效果）
- 原本黑色的阴区变为白色（阳区效果）
- 所有在阳区的敌人突然受伤害-30%（他们还在习惯性地以为站在阳区=伤害高）
- 太极图旋转方向反转

**每场BOSS战通常有2-3次翻转。** 翻转的时机由玩家控制——站眼3秒。

#### 敌人机制：阴阳使者

玄枵宫内的敌人会识别阴阳区——远程敌人站在阳区输出，近战敌人用盾击把辰生推到阳区（让辰生受伤害+40%）。

#### BOSS战：林青黛——太极之舞

林青黛（岁星星君对应·弓手）被西陆改造后的形态：
- 林青黛站在阴中阳眼上 → 整个太极图锁定·不旋转
- 她站在阴区（安全·低伤害）射箭
- 玩家必须想办法站到阳中阴眼 → 翻转 → 把阴区变成阳区 → 她突然受伤害+40%
- 翻转后她被迫移动到新的阴区 → 玩家再次追逐阳中阴眼
- 战斗的核心不是"打伤害"——是**争夺太极眼的控制权**

### 道宫三：娵訾宫——五行生克矩阵

**专业知识：五行生克·生数成数**

五行相生（金→水→木→火→土→金）和相克（金→木→土→水→火→金）是中医、命理、风水的共同基础。

#### 道宫专属机制：五行矩阵

娵訾宫的战斗地面被划分为**五块区域**，每块标记一个五行符号（地面上的发光篆书：金水木火土）。

```
五块区域的排列按"相生序"围成一圈：

              火 (南)
        木 (东南)  土 (西南)
        水 (北)    金 (西)

区域之间以"生"和"克"的连线相连：
  - 生连线 = 绿色光路·走上去获得卦气
  - 克连线 = 红色光路·走上去受到伤害
```

#### 五行矩阵规则

| 规则 | 说明 |
|------|------|
| **相生移动** | 从一个区域走到它"生"的区域（如火→土）→获得卦气+15·移速+30%·持续3秒 |
| **相克移动** | 从一个区域走到它"克"的区域（如火→金）→下一个卦术伤害+50% |
| **被生** | 站在一个被当前法器属性"生"的区域→卦气恢复翻倍 |
| **被克** | 站在一个被当前法器属性"克"的区域→防御-50%·非常危险 |
| **区域污染** | 敌人死亡后会"污染"所在区域·该区域五行属性随机改变 |

#### 五行属性如何确定？

辰生的"当前五行"由**当前法器和当前上卦**共同决定：

| 法器 | 基础五行 | 卦象叠加 |
|------|:--:|------|
| 银针 | 金 | 上卦五行+下卦五行取"生"关系 |
| 桃木剑 | 木 | 斩邪时变金 |
| 铜钱剑 | 金 | 铜钱计数每18枚→五行顺生一位 |
| 七星剑 | 土（北斗属土） | 敕令时变对应五行 |

#### 敌人机制：五毒使者

娵訾宫内的敌人各绑定一个五行属性。杀死火属性敌人→火区域被污染→火区域随机变成其他五行。玩家需要管理"五行地图"——保持有利区域不被污染。

#### BOSS战：卫重——五毒阵

卫重（地隐星星君对应·方术士）的五毒阵覆盖整个战场：
- 五个毒阵分别对应五行
- 每个毒阵持续喷发对应五行属性的毒气
- 金毒=破甲·水毒=迟缓·木毒=缠绕·火毒=灼烧·土毒=沉重
- 站在毒阵的"克星"区域 → 毒阵对你无效
  - 如：火毒阵 → 站在水区域→免疫火毒
- BOSS每损失20%生命 → 五毒阵旋转重新排列 → 玩家重新找安全位置

### 道宫四：降娄宫——八卦方位占场

**专业知识：后天八卦方位·卦位属性**

八卦在地理空间中的排列（后天八卦：离南坎北·震东兑西·乾西北坤西南·艮东北巽东南）。

#### 道宫专属机制：八卦战场

降娄宫的战斗地面是巨大的**后天八卦图**（直径约24m）。

```
             离☲(南·火)
   巽☴(东南·风)   坤☷(西南·地)
震☳(东·雷)    中宫    兑☱(西·泽)
   艮☶(东北·山)   乾☰(西北·天)
             坎☵(北·水)
```

**地面上的卦位不是平面贴图——是从地面升起的微光·约30cm高的光柱。**

#### 卦位效果

在卦位上释放卦术：

| 释放位置 | 释放卦术 | 效果 |
|---------|---------|------|
| 站在离位(南) | 释放离卦(火) | 同卦共鸣 → 伤害×2 |
| 站在离位(南) | 释放坎卦(水) | 卦位相冲 → 释放者被击退+自伤10%HP |
| 站在坤位(西南) | 释放坤卦(地) | 同卦共鸣 → 护盾×2 |
| 站在任意位 | 释放与卦位五行相生的卦 | 伤害×1.5 |
| 站在中宫 | 释放任意卦 | 无加成·但六爻写入速度×2 |

#### 卦位连线

站在两个卦位之间连线的交点上释放卦术 → 触发"双卦共鸣"：
- 站在离位和震位之间的中点 → 释放火雷噬嗑 → 伤害×3
- 但站位极其精确（判定范围仅1m直径）

#### 敌人机制：卦位守护者

降娄宫内的敌人会守护特定的卦位——站在卦位上时防御翻倍。需要用克制卦术把他们"打"出卦位。

#### BOSS战：金无痕——剑碑卦阵

金无痕（太白星君对应·剑士）将降娄宫的三十二座剑碑插在八卦方位的交点上。每座剑碑有独立的卦属性。

- 玩家每摧毁一座剑碑→该卦位从战场上消失→八卦图出现空缺
- 空缺越多→BOSS的"剑阵"越弱
- 但摧毁剑碑需要站在对应的卦位上用克制卦术
- BOSS会不断修复被摧毁的剑碑（每30秒修复一座）
- 战斗的核心是**卦位争夺**——谁控制了八卦图，谁就控制了战场

### 道宫五：大梁宫——三爻归真·辨伪

**专业知识：卦辞爻辞真伪·京房八宫卦**

此宫的专业知识系统已在 `战斗系统GDD.md` §10.4 中完整设计。核心是：
- 太史阁敌人使用**被篡改的伪卦**
- 辰生可以使用"三爻归真"——识别卦盘上的红色伪卦位·用正确的真卦替换
- 三爻全部归真 → 全场伪卦敌人崩溃

此处不重复设计。补充大梁宫的道宫专属环境：**推演机的模拟空间**。

#### 大梁宫环境机制：推演机模拟

大梁宫内部不是固定的空间——是推演机（司史闫序造的超级计算机）模拟的**不断重排的迷宫**。每15秒房间布局重新排列一次。

- 墙壁移动 → 通路改变
- 卦位标记（卦盘参考点）保留·但位置随房间移动
- 需要梅花易数（长按F）在每次重排后重新扫描房间布局

### 道宫六：实沉宫——奇门遁甲阵法

**专业知识：奇门遁甲·九宫八门·天盘地盘**

奇门遁甲是最高级别的数术之一——包含天盘（九星）、地盘（九宫）、人盘（八门）、神盘（八神）四层叠加。

#### 道宫专属机制：四层阵法叠加

实沉宫的战斗区域被划分为一个**九宫格**（洛书九宫·戴九履一·左三右七·二四为肩·六八为足）。

```
    ┌───┬───┬───┐
    │ 4 │ 9 │ 2 │
    ├───┼───┼───┤
    │ 3 │ 5 │ 7 │
    ├───┼───┼───┤
    │ 8 │ 1 │ 6 │
    └───┴───┴───┘
```

这个九宫格叠加了四层信息：

**第一层·地盘（固定）——九宫数**

| 宫位 | 数字 | 五行 | 效果 |
|:--:|:--:|:--:|------|
| 坎一宫(北) | 1 | 水 | 迟缓领域 |
| 坤二宫(西南) | 2 | 土 | 护盾领域 |
| 震三宫(东) | 3 | 木 | 攻速领域 |
| 巽四宫(东南) | 4 | 木 | 移速领域 |
| 中五宫 | 5 | 土 | 卦气领域 |
| 乾六宫(西北) | 6 | 金 | 暴击领域 |
| 兑七宫(西) | 7 | 金 | 混乱领域 |
| 艮八宫(东北) | 8 | 土 | 定身领域 |
| 离九宫(南) | 9 | 火 | 灼烧领域 |

**第二层·天盘（随时间旋转）——八门**

八门每45秒按顺时针方向移动一个宫位：

| 门 | 到达宫位时的效果 |
|----|------|
| **休门** | 该宫位的辰生回血8%/秒·敌人无法进入 |
| **生门** | 该宫位的伤害×3 |
| **伤门** | 该宫位的所有人（含辰生）每秒受8%ATK伤害 |
| **杜门** | 该宫位移速-70%·封技能 |
| **景门** | 该宫位被强光照亮·隐形敌人现形 |
| **死门** | 该宫位任何人HP<30%时即死 |
| **惊门** | 该宫位所有人恐惧·无法控制地乱跑 |
| **开门** | 该宫位无敌·净化一切debuff |

**第三层·人盘——辰生和敌人的站位**

辰生可以通过奇门遁甲阵法（按住右键+Ctrl）**改变八门的落位**——将自己需要的门"引"到当前位置。

**第四层·神盘——八神随剧情解锁**

每通过实沉宫内的一个区域解锁一位八神（值符、螣蛇、太阴、六合、白虎、玄武、九地、九天），每位八神给所在宫位额外的效果。

#### BOSS战：尉迟疆——军阵vs奇阵

尉迟疆（镇星星君对应·将军）以**古代军阵**对抗奇门阵法：
- 尉迟疆的士兵占据固定的四个宫位（形成方阵）
- 士兵在宫位上获得阵法加成
- 玩家需要使用奇门遁甲改变八门位置→将死门移到士兵所在的宫位→"用阵法破军阵"
- BOSS每阶段改变军阵布局→玩家重新布置奇门

### 道宫七：鹑首宫——六爻纳甲

**专业知识：六爻纳甲·世应·六亲·六兽**

这是六爻预测的核心——给每个爻配上干支、六亲、六兽。完整的六爻排盘包括：纳甲（天干地支）→ 安世应 → 配六亲 → 安六兽。

#### 道宫专属机制：完整的六爻战场

在鹑首宫，**六爻战场系统首次完整激活**（在大世界中不激活·前面的道宫仅部分激活）。

每条已写入的爻线现在不止有阴阳——还有完整的"纳甲"信息：

```
战场上的六爻（示例）：
  ┌────────────────────────────────────────────┐
  │ 上爻 ⚋ 阴 · 白虎(凶) · 妻财(财富)          │
  │ 五爻 ⚊ 阳 · 青龙(吉) · 官鬼(权力)          │
  │ 四爻 ⚋ 阴 · 玄武(暗) · 父母(庇护)          │
  │ 三爻 ⚊ 阳 · 朱雀(明) · 兄弟(同伴)          │
  │ 二爻 ⚋ 阴 · 勾陈(稳) · 子孙(延续)          │
  │ 初爻 ⚊ 阳 · 螣蛇(变) · 妻财(财富)          │
  │                                              │
  │  世爻：四爻(辰生)  应爻：初爻(BOSS)          │
  └────────────────────────────────────────────┘
```

#### 六亲对战斗的影响

| 六亲 | 若此为世爻 | 效果 |
|------|------|------|
| **父母** | 世爻 | 所有护盾×2·治疗+50% |
| **兄弟** | 世爻 | 同伴伤害×2·同伴死亡-50卦气惩罚 |
| **官鬼** | 世爻 | 对BOSS伤害+40% |
| **妻财** | 世爻 | 卦气消耗-50%·资源全部减半 |
| **子孙** | 世爻 | 暴击率+20%·闪避+5帧 |
| **无** | 应爻(BOSS) | BOSS获得相反的六亲对立效果 |

#### 六兽对爻线的影响

| 六兽 | 对应爻线 | 该爻使用卦术时的效果 |
|------|:--:|------|
| **青龙** | 5爻 | 卦术附带一次额外伤害（50%ATK） |
| **朱雀** | 3爻 | 卦术命中后留下火区（3s） |
| **勾陈** | 2爻 | 卦术后获得3秒超级霸体 |
| **螣蛇** | 初爻 | 卦术附带恐惧效果 |
| **白虎** | 上爻 | 卦术伤害+50%·但自己也受伤5%HP |
| **玄武** | 4爻 | 卦术后隐身2秒 |

#### 六爻完成后的纳甲卦阵

当六爻全部完成时，卦阵效果不仅取决于**卦象本身**——还取决于**各爻的六亲和六兽分布**。

```
例：
  卦象：䷾ 水火既济
  六亲：子孙·官鬼·父母·妻财·兄弟·妻财
  六兽：螣蛇·勾陈·朱雀·玄武·青龙·白虎
  
  → 卦阵效果 = 水火既济基础效果
            + 官鬼世爻（对BOSS+40%）
            + 青龙加身的五爻（额外伤害）
            + 白虎的上爻（暴击但自伤）
  
  → 这个卦阵是"高输出高风险"类型
```

#### BOSS战：镜魇——世应互换

镜魇（计都星君对应·暗影）的特殊能力：
- 每当他受到一定伤害 → **世爻和应爻交换**
- 辰生的世爻变成了应爻·BOSS的应爻变成了世爻
- 所有六亲效果瞬间颠倒（辰生原本的父母庇护 → 变成了官鬼压制）
- 玩家需要在爻线交换后重新调整策略
- 战斗中爻线交换2-3次·每次战斗都是不同的六亲分布

### 道宫八：鹑火宫——紫微斗数命盘显化

**专业知识：紫微斗数·十二宫·十四主星·四化**

紫微斗数用命盘12宫×14主星×辅星×四化（化禄/化权/化科/化忌）来推算命运。

#### 道宫专属机制：命盘战场

鹑火宫的BOSS房地面是辰生自己的**紫微命盘**——开头生成的命盘·以巨大的光影投射在地面上（直径约24m·12宫围绕中宫）。

站在自己命盘的某个宫位上 → 该宫位的主星效果被"激活"——在战场上一段时间内持续生效：

| 宫位 | 激活效果（以命宫紫微+兄弟宫天梁为例） |
|------|------|
| **命宫** | 全卦术伤害+10%（紫微主星） |

- 攻击辰生命盘中的**化忌宫位**——想让辰生被迫站到自己的"厄运位置"上
- 用技能污染命盘的某一宫（该宫位暂时失效·持续30秒）
- 迫使辰生在被污染的命盘中战斗——少了一个宫位的支撑

**玩家需要：** 熟悉自己命盘→利用化禄/化权/化科的强宫→避开化忌宫→保护被污染的宫不被BOSS利用。

### 道宫九：鹑尾宫——太乙神数·时间序列

**专业知识：太乙神数·时间中的因果链**

太乙神数在 `战斗系统GDD.md` §5.4 和 `太乙神数终极系统设计.md` 中已有完整设计。这是按键序列的高风险终极技能系统。

鹑尾宫的独特之处在于：**时间是可见的**。

#### 道宫环境机制：时间沙漏

鹑尾宫内的不同房间的**时间流速不同**：
- 有些房间时间×0.5（慢动作·给玩家更多反应时间）
- 有些房间时间×2.0（快进·敌人攻速翻倍）
- 房间之间的过渡区域时间正常

玩家需要利用时间流速差异——在慢房间规划·在快房间执行。

#### BOSS战：商羽——时间删除

商羽拥有"删除时间"的能力——可以把玩家的卦术"从时间中擦除"：
- 你的卦术刚释放→商羽删除→卦术从未发生过 > 卦气照扣·伤害为零
- 唯一的对抗方式：**太乙神数**——太乙神数是"超越时间"的卦术·商羽无法删除

这场BOSS战的核心：你必须用太乙神数打败他。基础卦术只是铺垫——真正的伤害来自太乙神数。

### 道宫十：大火宫——五音十二律

**专业知识：五音（宫商角徵羽）·十二律吕**

中国古代音乐体系。五音对应五行（宫=土、商=金、角=木、徵=火、羽=水）。十二律吕对应一年十二个月。

#### 道宫专属机制：音律战场

大火宫的地面是巨大的**音律石板**。每块石板上刻着一个音名（宫商角徵羽×高低八度=10种石板）。踩上去会发出对应的音符。

```
战斗中：
  - 踩不同石板 → 发出不同音符
  - 踩特定顺序的石板 → 触发"音律卦阵"
  - 如：宫→徵→羽 → 触发"土生火·火被水克" → 在此区域内伤害类型变换
```

#### BOSS战：伪乐——五音之战

伪乐（天音星君对应·乐师·被扭曲者）用五音攻击：
- 宫音(土) → 地动·击倒
- 商音(金) → 金属风暴·破甲
- 角音(木) → 藤蔓缠绕·定身
- 徵音(火) → 火焰灼烧
- 羽音(水) → 冰锥·迟缓

BOSS弹窗——在释放前，相应的石板会先发光。玩家需要：
1. 识别发光的石板（判断BOSS要用哪个音）
2. 跑到对应的克制石板上（用五行相克）
3. 在克制石板上释放对应卦术 → 打断BOSS的音攻

**这需要同时具备：音律知识 + 五行知识 + 快速反应。**

### 道宫十一：析木宫——大六壬·天地盘

**专业知识：大六壬·天地盘·十二天将·十二地支**

大六壬是"三式"之首（太乙、奇门、六壬），是所有数术中体系最庞大的。核心是天地盘——天盘（十二天将）在地盘（十二地支）上旋转。

#### 道宫专属机制：天地盘战场

析木宫的整个战斗空间是一个巨大的**双层旋转盘**：

```
天盘（上层·旋转） = 十二天将
  贵人·螣蛇·朱雀·六合·勾陈·青龙
  天空·白虎·太常·玄武·太阴·天后

地盘（下层·固定） = 十二地支
  子·丑·寅·卯·辰·巳·午·未·申·酉·戌·亥

天盘在地盘上顺时针旋转·约每30秒转一格（一个地支位）
```

#### 天地盘战斗效果

辰生和敌人脚下的"天将+地支"组合决定了该位置的效果：

| 天将 | 地支 | 组合效果 |
|------|:--:|------|
| 贵人 | 子 | 卦气消耗-50% |
| 螣蛇 | 午 | 火焰伤害×2 |
| 白虎 | 申 | 暴击伤害×3（但自身防御清零） |
| 青龙 | 辰 | 移速×2·跳跃高度×3 |
| 玄武 | 亥 | 隐身·不被锁定 |
| 天空 | 戌 | 虚无·不受任何地面效果影响 |
| … | … | 12天将×12地支=144种组合 |

#### 四课三传

大六壬的核心排盘是"四课三传"。在析木宫BOSS战中：

- BOSS拥有四课（四个信息位）——分别代表：BOSS当前的攻击计划、BOSS的弱点、BOSS的下一个行动、BOSS的终极技能
- 辰生拥有三传（三个行动位）——分别代表：初传（你该做的第一件事）、中传（第二件）、末传（最终行动）
- 四课三传每60秒重新"排盘"一次（天地盘旋转到位后生成）
- **遵循三传的顺序攻击BOSS的弱点 → 造成巨额伤害**

#### BOSS战：商徵——时间与命运

商徵（析木星君对应·拥有时间能力·最终被扭曲者）可以"看到"三传：
- 商徵知道辰生接下来应该做什么
- 他会试图阻止辰生完成三传
- 如果辰生仍能完成三传 → 证明"命运可以被改变" → 商徵的力量来源（对命运的恐惧）被打破

- 这是对玩家全部旅程的最终考试
