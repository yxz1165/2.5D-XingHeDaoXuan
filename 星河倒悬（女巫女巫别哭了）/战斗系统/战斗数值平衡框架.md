## 二、玩家成长曲线

### 2.1 等级与基础属性

| 等级 | ATK | 生命 | 卦气上限 | 卦气恢复(战斗) | 防御 | 暴击率 |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 1(序章) | 30 | 300 | 100 | 2/s | 10 | 5% |
| 10(星纪宫) | 55 | 550 | 110 | 2.3/s | 22 | 6% |
| 20(降娄宫) | 95 | 850 | 125 | 2.7/s | 38 | 8% |
| 30(实沉宫) | 145 | 1200 | 145 | 3.2/s | 58 | 10% |
| 40(鹑火宫) | 210 | 1600 | 170 | 3.8/s | 82 | 12% |
| 50(大火宫) | 290 | 2100 | 200 | 4.5/s | 112 | 14% |
| 60(寿星宫) | 390 | 2700 | 240 | 5.3/s | 150 | 16% |

**成长公式：**
```
ATK_Lv = 30 × (1 + 0.045)^(Lv-1)       ≈ Lv60=30×13.0=390
HP_Lv  = 300 × (1 + 0.038)^(Lv-1)      ≈ Lv60=300×9.0=2700
卦气上限_Lv = 100 + floor((Lv-1) × 2.37) ≈ Lv60=240
```

### 2.2 DPS曲线（仅玩家·不含连携加成）

```
基准DPS = 银针普攻DPS + 卦术DPS

银针普攻DPS(Lv) = ATK(Lv) × 0.6(银针倍率) × 1.5(每秒攻击次数·3段/2s)
卦术DPS(Lv) = ATK(Lv) × 1.5(平均卦术倍率) × 0.15(每秒卦术次数·考虑冷却+选卦时间)

Lv1 总DPS ≈ 30×0.9 + 30×0.225 = 27 + 6.75 = 33.75
Lv60 总DPS ≈ 390×0.9 + 390×0.225 = 351 + 87.75 = 438.75

成长倍数：438.75/33.75 = 13.0×
```

### 2.3 连携对DPS的乘数效应

```
连携乘数 = 1.0(基准) × 相生连携(1.1-1.4) × 切器连携(1.0-1.25) × 崩解(1.0-2.0特殊)

普通玩家(偶尔连携): ×1.3   → DPS = 基准×1.3
熟练玩家(经常连携): ×2.0   → DPS = 基准×2.0
高玩(全程连携):     ×3.5   → DPS = 基准×3.5

→ 高玩比普通玩家快2.7倍·不是靠等级压制·是靠操作
```

### 3.2 减伤率公式

```
减伤率 = DEF / (DEF + 200 + Lv×10)
上限80%·下限0%

例：太史守卫(Lv7·DEF25)
减伤率 = 25/(25+200+70) = 25/295 = 8.5%
加上盾牌正面格挡(DEF×4=100) 
→ 减伤率 = 100/(100+200+70) = 100/370 = 27%

辰生(Lv1·ATK30)打太史守卫(减伤8.5%):
  普攻第1段伤害 = 30 × 0.6(银针) × (1-0.085) = 16.5

击杀时间(TTK):
  太史守卫HP200 / DPS(≈33.75×0.5·因为守卫格挡) ≈ 12秒 ✓（在目标8-15秒范围内）
```

### 3.3 BOSS战DPS验证（焦烈·阶段一）

```
辰生(Lv10·ATK55)打焦烈(Lv12·DEF25):
  减伤率 = 25/(25+200+120) = 7.2%
  
  卦术(离+乾·195%ATK·10s冷却):
    伤害 = 55 × 1.95 × (1-0.072) × 1.15(锻锋被动) = 114.4
    实战频率≈每12s一次(非CD一到就放·需等安全窗口)
    DPS = 114.4 / 12s = 9.5

  普攻DPS(银针·ATK55×0.6×1.5):
    原始 = 55×0.6×1.5 = 49.5
    减伤后 = 49.5 × (1-0.072) = 45.9
    选卦时间占25% → 有效 = 45.9 × 0.75 = 34.4

  理论DPS ≈ 9.5 + 34.4 = 43.9

  ⚠ 实战修正：玩家不可能100%时间输出·需闪避/走位/等弹窗
    实战输出占比 ≈ 50-60%（新手偏低·高玩偏高）
    实战DPS(新手) = 43.9 × 0.50 = 22.0
    实战DPS(高玩) = 43.9 × 0.60 = 26.3

焦烈总HP=2500(HUD显示一条·实际三段合计750+750+1000):
  新手: 2500/22.0 = 113.6s + 7s(阶段转换演出) ≈ 2.0分钟
  高玩: 2500/26.3 = 95.1s + 7s ≈ 1.7分钟
  高玩含连携(×1.5): 2500/(26.3×1.5) = 63.4s + 7s ≈ 1.2分钟

  → 新手约2分钟·高玩约1-2分钟 ✅（第一BOSS·后续BOSS HP更高·战斗更长）
  
后期BOSS(寿星宫·HP≈8000·Lv60):
  实战DPS(Lv60·含连携) ≈ 438.75 × 0.55 × 1.5(连携) ≈ 362
  8000/362 = 22s(高玩) → 8000/(362×0.55) = 40s(新手)
  → 需大幅提升后期BOSS HP: 建议寿星宫BOSS HP≈12000-15000
    使战斗保持在3-5分钟
```

## 五、卦气经济

### 5.1 卦气流转模型

```
战斗开始: 卦气 = 满(100)
  │
  ├─ 小六爻: -15~25/次·平均每6秒用1次 → -3.3/s
  ├─ 八卦卦术: -20~42/次·平均每8秒用1次 → -3.75/s
  ├─ 卦气自然恢复: +2/s(战斗)
  ├─ 银针普攻: 每段+8·每秒约+12
  ├─ 闪避后卦术瞬发: 省去时停消耗·间接+卦气效率
  │
  └─ 净卦气变化/秒 = +2(恢复) +12(普攻) -3.3(小六爻) -3.75(卦术) = +6.95/s
  
  → 正常战斗是卦气正向循环（普攻赚得比卦术花得多）
  → 疯狂放卦会亏卦气 → 需要穿插普攻积累 → 形成"攒→花→攒"节奏
```

### 5.2 太乙神数卦气门槛

```
太乙神数Lv1: 卦气≥3层(30)  → 新手用3键·门槛低
太乙神数Lv2: 卦气≥5层(50)  → 中期用5键·需有意识积累
太乙神数Lv3: 卦气≥9层(90)  → 终局用9键·需满卦气+完美管理

设计意图：太乙神数不是"冷却到了就可以用"——
必须在前面的战斗中高效管理卦气·才能在关键时刻放出大招
```

### 6.2 法器切换的机会成本

```
切换法器 = 0.3s冷却·无伤害输出
  → 不切换·持续输出 = 基准DPS
  → 频繁切换·追求连携 = DPS×1.5(连携加成) - 切换时间损失(约5%总时间)
  → 净收益 ≈ +42% DPS

但切换的冷却(0.3s)防止了"每秒切一次"的滥用
→ 最优切换频率 ≈ 每5-8秒切一次（在卦术冷却期间切换）
```

## 九、伤害上限与溢出保护

### 9.1 一击上限

```
单发伤害上限: BOSS最大生命的15%
  → 焦烈2500HP→单发伤害不超过375
  → 防连携乘数叠加导致的OTK（一确杀）

太乙神数例外: 
  Lv3完美·生命<30%即死 → 不受此限（本来就是750HP即死·约焦烈总HP30%）
```

### 9.2 DOT上限

```
同类型DOT不叠加（取最高值）
不同类型DOT可共存:
  灼烧(火) + 穿透(风) + 麻痹(雷) → 三个DOT同时跳·但各自独立

DOT总伤害占比 < 总伤害的30%（防"叠满DOT走人"成为最优解）
```

## 十、调参优先级

游戏开发中数值调整的优先顺序：

### P0：影响核心体验
1. **卦术基础伤害倍率**（8个上卦的150%/120%/180%……）
2. **卦气消耗/恢复**（影响"攒→花→攒"节奏）
3. **敌人HP**（影响TTK·战斗节奏）
4. **闪避无敌帧**（13帧是否合理？）

### P1：影响战斗深度
5. **连携乘数**（相生×1.1-1.4是否太强/太弱）
6. **下卦修正值**（乾+30%伤害 vs 坤-30%消耗的选择压力）
7. **法器DPS差异**（4法器是否各有使用场景）
8. **同伴DPS占比**（15-25%范围）

### P2：影响长期体验
9. **等级成长曲线**（太快→中后期无聊·太慢→刷级疲劳）
10. **元素反应系数**
11. **崩解阈值**（4次是否合适）
12. **难度梯度**（每宫+15-40%是否平滑）

## 十一、测试建议

### 11.1 纸面测试（开发前）

```
在Excel/Google Sheets中建立战斗模拟器：
  - 输入：玩家Lv/法器/卦术选择/连携频率
  - 输出：DPS·卦气净变化·TTK·受伤预测
  - 验证：
    ✓ 所有敌人TTK在目标范围内
    ✓ 卦气经济是正向循环
    ✓ 没有"最强卦术"（每种卦在不同场景下最优）
    ✓ BOSS战时间在3-6分钟
```

### 11.2 原型测试（开发中）

```
1. 小六爻手感测试：6方向甩鼠标·0.3秒识别·30人测试
2. 单卦DPS测试：1种上卦+1种下卦 vs 训练假人·记录实际DPS
3. 连携窗口测试：不同帧数的取消窗口·玩家能否稳定触发
4. BOSS节奏测试：焦烈三阶段·计时·记录死亡位置分布热图
```

### 11.3 平衡调整的原则

```
1. 先调机制·后调数值
   → 机制问题不能用数值掩盖（如：某卦术用的人少→先看是不是不好玩·不是先加伤害）

2. 玩家感知比数学正确更重要
   → 20%伤害提升如果玩家"感觉不到"→加到30%
   → 如果某数值"数学最优"但玩家感觉不好玩→调整

3. 永远保留调参空间
   → 所有数值标注"基准值"·通过配置表读取·不硬编码

4. 每次只调一个参数
   → 同时调3个参数→不知道哪个起效了
```
