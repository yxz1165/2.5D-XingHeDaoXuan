## 一、数据字段说明

每个卦象条目包含以下标准化字段：

```
┌──────────────────────────────────────────────────────┐
│ ID          │ 卦象唯一ID（1-64）                       │
│ 卦符         │ Unicode卦符（䷀-䷿）                     │
│ 技能名       │ 游戏内显示名称                           │
│ 上卦/下卦    │ 枚举值 + 按键                           │
│ 解锁章节     │ 道宫名称                                │
│ 设计层级     │ 核心卦(16) / 标准卦(32) / 稀有卦(16)      │
│                                                      │
│ 【伤害】                                              │
│ 伤害倍率     │ ATK乘数                                │
│ 伤害类型     │ 物理/元素/混合                           │
│ 段数         │ 单段/多段                               │
│ 暴击修正     │ 额外暴击率加成                           │
│                                                      │
│ 【判定】                                              │
│ 判定类型     │ 扇形/直线/圆形/锁定/自身                 │
│ 范围         │ 米（扇形=半径+角度·直线=宽×长·圆形=半径）  │
│ 射程         │ 米（远程卦术的飞行距离·0=近战）           │
│ 穿透         │ 是/否（是否穿透敌人继续飞行）             │
│                                                      │
│ 【帧数据·60fps基准】                                   │
│ 启动帧       │ 按下到判定出现                           │
│ 活跃帧       │ 判定持续帧数                             │
│ 结束帧       │ 判定结束到可行动                         │
│ 总帧数       │ 启动+活跃+结束                           │
│ Hit-Stop帧   │ 命中暂停帧数                             │
│                                                      │
│ 【控制效果】                                           │
│ 硬直等级     │ Lv1抖动/Lv2硬直/Lv3击退/Lv4浮空/Lv5击倒  │
│ 击退距离     │ 米                                     │
│ 异常状态     │ 灼烧/麻痹/穿透/沉重/破甲/迟缓/混乱/护盾   │
│ 异常值       │ 累积值（满100触发异常状态）               │
│ 异常持续     │ 秒                                     │
│                                                      │
│ 【资源】                                              │
│ 卦气消耗     │ 基准值（受乾坤下卦调整）                  │
│ 冷却时间     │ 秒                                     │
│ 全局冷却     │ 卦术GCD·秒（影响连携流畅度）              │
│                                                      │
│ 【法器变形参数】                                       │
│ 银针变形     │ 判定·范围·特殊效果                        │
│ 桃木剑变形   │ 判定·范围·特殊效果                        │
│ 铜钱剑变形   │ 判定·范围·特殊效果                        │
│ 七星剑变形   │ 判定·范围·特殊效果                        │
│                                                      │
│ 【连携数据】                                           │
│ 互卦         │ 释放后触发的隐藏互卦                     │
│ 卦变连携     │ 推荐的下一卦连接                          │
│ 崩解累计值   │ 对敌人崩解条的填充量                      │
└──────────────────────────────────────────────────────┘
```

## 二、全局常量

| 常量 | 值 | 说明 |
|------|-----|------|
| 基准卦气消耗 | 20 | 所有卦术以此为基准，上下卦调整 |
| 卦术全局CD | 0.3s | 任意卦术释放后的最小间隔 |
| 基础伤害乘数 | 1.0 | ATK×技能倍率=原始伤害 |
| 异常状态阈值 | 100 | 累积到此值触发异常状态 |
| 崩解阈值 | 4次 | 同卦连续命中触发崩解 |
| 崩解条衰减 | 每秒-1次 | 超过4秒未命中→崩解累计归零 |

## 三、下卦参数修正表

下卦影响所有挂在此下卦上的卦术参数：

| 下卦 | 按键 | 伤害修正 | 卦气修正 | CD修正 | 范围修正 | 硬直修正 |
|------|:--:|:--:|:--:|:--:|:--:|:--:|
| ☰ 乾 | `1` | ×1.30 | +50% | +2s | +20% | +1级 |
| ☱ 兑 | `2` | ×1.00 | +30% | +0s | +0% | +0级 |
| ☲ 离 | `3` | ×1.00 | +20% | +0s | +0% | +0级 |
| ☳ 震 | `4` | ×1.00 | +20% | +1s | +0% | +1级 |
| ☴ 巽 | `Q` | ×0.90 | +10% | -3s | +30% | -1级 |
| ☵ 坎 | `E` | ×0.85 | +30% | +0s | +0% | +0级 |
| ☶ 艮 | `R` | ×0.80 | +15% | +0s | -20% | +2级 |
| ☷ 坤 | `F` | ×0.90 | -30% | -2s | +0% | +0级 |

> **使用方式：** 卦术基础值 × 下卦修正 = 实际值。
> 例：离上卦基础伤害150%·配乾下卦(×1.30) → 195% ATK。
