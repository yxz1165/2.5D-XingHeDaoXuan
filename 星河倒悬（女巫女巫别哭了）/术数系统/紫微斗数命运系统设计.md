# 紫微斗数命运系统——完整的先天命运与运势流转

> **定位：** 非战斗系统。战斗外使用。开局生成独一无二的命盘，贯穿全程影响战斗倾向、同伴亲和、剧情分支、经济策略。与三钱摇卦形成双层占卜——三钱问"今日"，紫微问"此生"。

---

## 一、系统概述

### 1.1 与三钱摇卦的分工

```
三钱摇卦：短期运势
  触发：星碑处·每次BOSS战前
  效果：本卦+变卦→即时Buff·持续到下次休息
  改变：随时可重摇
  问的是："这一战怎么打"

紫微命盘：长期命运
  触发：开局生成·终生不变
  效果：12宫主星+四化流转→全局被动
  改变：不可改·但四化每过宫流转
  问的是："你这个人注定擅长什么"
```

### 1.2 命盘对游戏的影响总览

| 影响维度 | 具体表现 |
|---------|---------|
| **战斗倾向** | 命宫主星决定默认卦术伤害加成方向 |
| **同伴亲和** | 夫妻宫·兄弟宫影响同伴好感度增长速度 |
| **剧情分支** | 特定命盘配置解锁隐藏对话/额外选项 |
| **经济策略** | 财帛宫影响商人价格·掉落率 |
| **生存能力** | 疾厄宫影响生命上限·回复效果 |
| **卦气经济** | 官禄宫影响卦气上限·恢复速度 |
| **每宫策略** | 四化流转→每座道宫的Buff/Nerf不同 |

## 二、开局排盘——每个玩家天生不同的命盘

### 2.1 生成时机

```
新游戏 → 序章·云岫教学幻境 →

云岫："辰生，你的生辰——告诉母亲。"
  
  界面弹出：年柱·月柱·日柱·时柱
  默认使用系统当前时间换算为农历
  玩家可选择"使用默认"或手动调整
  
  ↓ 紫微斗数排盘算法
  
  自动生成：
    12宫 × 主星分布
    辅星分布
    四化标注（化禄·化权·化科·化忌各落位）
```

### 2.2 排盘算法

**简化版——无需完整实现紫微斗数排盘。使用预生成模板库。**

```
预生成120种命盘模板（覆盖最常见的命盘格局）：
  紫微在命宫 × 12地支位 = 12种
  紫微在兄弟宫 × 12地支位 = 12种
  ...（覆盖紫微在12宫的每一种）

每种模板包含：
  - 12宫各宫的主星（确保没有同宫冲突）
  - 辅星分布
  - 四化落位

玩家开局时随机从120种模板中抽取1种。
或者：根据玩家选择的"生日" → 哈希值 → 映射到模板ID → 确保同生日=同命盘。
```

## 四、四化系统——不是固定的，是流动的

### 4.1 四化的含义

| 四化 | 含义 | 效果 | 
|:--:|------|------|
| **化禄** | 好运·增加 | 该宫位效果×2 |
| **化权** | 权力·控制 | 该宫位效果变为"主动技能"·可手动激活·冷却180s |
| **化科** | 名声·声誉 | 该宫位效果+50%·且社区卦码分享时被标记为"推荐命盘" |
| **化忌** | 厄运·压制 | 该宫位效果被压制为-50% |

### 4.2 四化随大限流转

每通关3座道宫→四化同时移动到下一个宫位：

```
开局： 化禄在命宫·化权在官禄·化科在福德·化忌在财帛

↓ 通关星纪+玄枵+娵訾（前3宫）

第1轮：化禄→兄弟·化权→交友·化科→父母·化忌→疾厄

↓ 通关降娄+大梁+实沉

第2轮：化禄→夫妻·化权→田宅·化科→命宫·化忌→迁移

... 以此类推·12宫循环
```

### 4.3 化忌的"负面"也可以被利用

```
财帛宫化忌（商人价格翻倍）→ 
  对策：用坤下卦减消耗 + 多刷精英怪（不受商人价格影响）
  或者：干脆这个阶段不买东西·攒钱等下个阶段

疾厄宫化忌（生命上限-20%）→ 
  对策：多带石翁（土卦减伤）·多用艮卦形态
```

**化忌不是"废了"——是"这个阶段你得换个打法"。** 这迫使玩家不能一套Build用到底。

## 六、与三钱摇卦的衔接

### 6.1 流日运势与摇卦的叠加/对冲

```
备战界面 →

左面板：今日流日运势
  命宫紫微 + 官禄宫天机化禄
  → 火卦伤害+15%·卦气恢复+20%

右面板：三钱摇卦
  摇出本卦䷝离为火 → 
    离+离=比和："今日流日与本卦比和——运势叠加"
    → 火卦额外+10%·总共+25%
  
  如果摇出本卦䷜坎为水 →
    离（火）vs 坎（水）= 水火相克：
    "流日化忌克本卦——运势对冲"
    → 火卦+15%被水卦抵消·只剩+5%
    → 但坎卦效果+20%（因为今日流日把力量"逼"到水卦去了）
    → 建议切换到水卦Build
```

### 6.2 流日运势的计算

```
流日 = 游戏内当前日期（从开局开始计数）mod 60 → 对应六十甲子日起卦

根据当日起卦的日干·日支 → 
  确定当日四化落位（不同于先天四化）
  确定当日"贵人星"（额外+10%的那个主星）

显示在备战界面·每过一天自动更新
```

## 七、与同伴系统的衔接

### 7.1 好感度的命盘影响

```
基础好感度增长 = 固定值 + 命盘修正

夫妻宫天同 → 锻锋好感+30%速度
  → 本来通关星纪宫后锻锋好感度=2级
  → 有命盘修正后=2.6级→取整为3级（提前解锁高级被动）

兄弟宫七杀 → 所有同伴好感度基础值+1
  → 开局时所有已解锁同伴不是0级·是1级

```
特定命盘配置 → 额外对话选项：

public static class ZiweiChartGenerator {
    private static List<ZiweiDestiny> _templates; // 120种预生成模板
    
    /// <summary>
    /// 根据生辰八字生成命盘。同八字永远返回同命盘（确定性）。
    /// </summary>
    public static ZiweiDestiny Generate(int year, int month, int day, int hour) {
        int templateId = CalculateTemplateId(year, month, day, hour);
        return _templates[templateId].Clone();
    }
    
    public static ZiweiDestiny GenerateRandom() {
        return _templates[Random.Range(0, 120)].Clone();
    }
    
    /// <summary>
    /// 模板ID计算公式——与Generate()使用完全相同的哈希。
    /// 统一为: (year*10000 + month*100 + day*100 + hour) % 120
    /// 确保"同八字=同命盘"，跨所有调用路径一致。
    /// </summary>
    public static int CalculateTemplateId(int year, int month, int day, int hour) {
        // 统一哈希公式——与Generate()完全一致
        // year*10000确保年份主导分布·month*100/day*100/hour线性叠加
        // 取模120映射到120种预生成模板
        return (year * 10000 + month * 100 + day * 100 + hour) % 120;
    }
}

public class ZiweiCombatModifier {
    // 在进入战斗时调用——根据命盘计算本次战斗的所有修正
    public static CombatModifiers Calculate(BattleContext context) {
        var mod = new CombatModifiers();
        var destiny = context.Player.Destiny;
        int gameDay = context.GameDay;
        
        // 1. 命宫卦术加成
        var mingStar = destiny.PalaceStars[(int)GongWei.Ming];
        mod.ElementDamageBonus = GetMingGongBonus(mingStar);
        
        // 2. 官禄宫卦术强度
        var guanLuStar = destiny.PalaceStars[(int)GongWei.GuanLu];
        mod.SkillDamageBonus = GetGuanLuBonus(guanLuStar);
        
        // 3. 财帛宫经济
        var caiBoStar = destiny.PalaceStars[(int)GongWei.CaiBo];
        mod.LootBonus = GetCaiBoBonus(caiBoStar);
        
        // 4. 流日运势
        var (enhanced, suppressed) = destiny.GetDailyFortune(gameDay);
        if (enhanced == GongWei.GuanLu) mod.SkillDamageBonus *= 1.2f;
        if (suppressed == GongWei.GuanLu) mod.SkillDamageBonus *= 0.8f;
        
        // 5. 四化修正（取所有宫位的四化×当前大限的倍率）
        for (int i = 0; i < 4; i++) {
            var target = destiny.SiHuaTargets[i];
            float multiplier = destiny.GetPalaceMultiplier(target, gameDay);
            ApplySiHuaToMod(mod, target, (SiHua)i, multiplier);
        }
        
        return mod;
    }
}

            return "对冲——流日运势克制本卦·建议换Build或改日再来";

[Serializable]
public class ZiweiDestiny {
    // === 核心数据 ===
    public int templateId;                             // 0-119
    public ZiweiStar[] palaceStars = new ZiweiStar[12]; // 12宫主星
    public GongWei[] siHuaTargets = new GongWei[4];     // [0]=化禄·[1]=化权·[2]=化科·[3]=化忌
    public int[] auxiliaryStars = new int[3];            // 0-2个辅助星曜ID(0-9)
    
    // === 出生信息 ===
    public int birthYear, birthMonth, birthDay, birthHour; // 农历
    
    // === 运行时状态 ===
    public int currentDaXian = 0;                       // 0-3
    
    // === 计算函数 ===
    
    // 计算今日流日运势（返回增强宫位和被压制宫位）
    public (GongWei enhanced, GongWei suppressed) GetDailyFortune(int gameDay) {
        int dayMod = gameDay % 60;
        GongWei enhanced = (GongWei)((dayMod + (int)palaceStars[0]) % 12);
        GongWei suppressed = (GongWei)((dayMod + 6) % 12); // 对冲宫位
        return (enhanced, suppressed);
    }
    
    // 获取某宫位在当前大限+四化+流日下的综合倍率
    public float GetPalaceMultiplier(GongWei palace, int gameDay) {
        float result = 1.0f;
        for (int i = 0; i < 4; i++) {
            if (siHuaTargets[i] == palace) {
                switch ((SiHua)i) {
                    case SiHua.HuaLu: result *= 2.0f; break;
                    case SiHua.HuaJi: result *= 0.5f; break;
                    case SiHua.HuaKe: result *= 1.5f; break;
                }
            }
        }
        var (enhanced, suppressed) = GetDailyFortune(gameDay);
        if (palace == enhanced) result *= 1.2f;
        if (palace == suppressed) result *= 0.8f;
        
        // 大限修正（当前大限主导宫位获得额外加成）
        GongWei daXianDominant = currentDaXian switch {
            0 => GongWei.Ming,
            1 => GongWei.XiongDi,
            2 => GongWei.GuanLu,
            3 => GongWei.FuDe,
            _ => GongWei.Ming
        };
        if (palace == daXianDominant) result *= 1.25f; // 大限主导+25%
        
        return result;
    }
    
    // chaptersCompleted: 已通关的道宫数量(1-13)
    // 大限切换与四化流转同步·阈值与SiHuaRotator.ShouldRotate()一致
    // ShouldRotate触发于4·7·10 → 大限切换也对应这些章节后
    public int GetDaXianForChapter(int chaptersCompleted) {
        if (chaptersCompleted < 4) return 0;   // 序章→玄枵(1-3宫)·命宫大限
        if (chaptersCompleted < 7) return 1;   // 娵訾→实沉(4-6宫)·兄弟宫大限
        if (chaptersCompleted < 10) return 2;  // 鹑首→大火(7-9宫)·官禄宫大限
        return 3;                                // 析木→寿星(10-13宫)·福德宫大限
    }
    
    public string GetPersonalityLabel() {
        var star = palaceStars[(int)GongWei.Ming];
        return star switch {
            ZiweiStar.ZiWei => "天生帝王星",
            ZiweiStar.TianJi => "智谋过人",
            ZiweiStar.TaiYang => "光明正大",
            ZiweiStar.WuQu => "生来战士",
            ZiweiStar.QiSha => "战将之命",
            _ => "天命未定"
        };
    }
}

## 二十一、四化算法——精确的数学描述

```csharp
public static class SiHuaRotator {
    // 四化的初始落位（开局时固定·随模板不同）
    // siHuaTargets[0]=化禄·[1]=化权·[2]=化科·[3]=化忌
    
    // 每通关3座道宫·四化同步移动到下一个宫位
    // 移动规则：每个四化目标宫位 = (原宫位 + 1) % 12
    
    public static void RotateSiHua(ZiweiDestiny destiny) {
        for (int i = 0; i < 4; i++) {
            int current = (int)destiny.siHuaTargets[i];
            destiny.siHuaTargets[i] = (GongWei)((current + 1) % 12);
        }
    }
    
    // 检查是否需要流转（在道宫通关后调用）
    // 参数 chaptersCompleted: 已通关的道宫数量（序章=1·星纪宫=2·…·寿星宫=13）
    // 四化在通关第4个道宫（娵訾·完成后chaptersCompleted==4）时第一次流转
    // 之后每3个道宫流转一次：4·7·10
    public static bool ShouldRotate(int chaptersCompleted) {
        return (chaptersCompleted >= 4) && ((chaptersCompleted - 1) % 3 == 0);
        // 等价于：chaptersCompleted ∈ {4, 7, 10}
    }
    
    // 获取某宫位当前的四化状态
    public static SiHua? GetSiHuaAtPalace(ZiweiDestiny destiny, GongWei palace) {
        for (int i = 0; i < 4; i++) {
            if (destiny.siHuaTargets[i] == palace) return (SiHua)i;
        }
        return null; // 此宫位没有四化
    }
    
    // 卦术伤害修正——委托给ZiweiDestiny.GetPalaceMultiplier
    // 取命宫和官禄宫的四化倍率之积
    public static float GetDamageMultiplier(ZiweiDestiny destiny, int gameDay) {
        float mingMultiplier = destiny.GetPalaceMultiplier(GongWei.Ming, gameDay);
        float guanMultiplier = destiny.GetPalaceMultiplier(GongWei.GuanLu, gameDay);
        // 只取四化修正(不含大限加成)·避免重复计算
        return mingMultiplier * guanMultiplier;
    }
}
```

## 二十四、120种模板的平衡设计原则

1. **每命盘有强项有弱点**：命宫+官禄都强→财帛或疾厄必有化忌。开局强→中期弱。输出最强→生存最弱
2. **化忌均匀分布**：每个宫位在120种模板中恰好出现约10次化忌
3. **同伴亲和均匀**：14同伴各在夫妻宫出现约8-9次
4. **卦术倾向均匀**：每种卦术倾向各约8-10种模板·确保社区多样性
