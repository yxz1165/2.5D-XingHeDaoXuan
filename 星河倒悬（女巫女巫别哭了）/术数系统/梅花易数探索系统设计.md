# 梅花易数探索系统设计——万物皆可起卦·观象揭示隐藏

> **定位：** 非战斗探索系统。长按F进入观象状态，消耗卦气揭示周围隐藏要素。是卦术系统在"探索"维度的延伸——三钱摇卦问战斗·紫微斗数问命运·梅花易数问环境。
> **操作：** 长按F（非战斗） → 观象状态 → 40m范围揭示隐藏 → 消耗卦气

---

## 一、文化根源——真实的梅花易数

### 1.1 邵雍与梅花易数

梅花易数由北宋哲学家邵雍（1011-1077）创立。传说邵雍在赏梅时，见两只麻雀在梅枝上争斗后双双坠地，觉其怪异，便以时间起卦，推算出次日将有一少女来此折梅并摔伤。次日果然应验。从此"梅花易数"得名。

**核心思想：万物皆可起卦。** 年月日时可以起卦，听到的声音可以起卦，看到的字数可以起卦，风吹的方向可以起卦——世间一切现象，都是卦象的显现。

### 1.2 梅花易数的三要素

```
体卦：代表占卜者自身（静的一方）
用卦：代表外界/所问之事（动的一方）
互卦：从本卦中间四爻抽出的隐藏卦象·代表事物内部结构

体用生克：
  用生体 → 大吉·外界有利
  体用比和 → 吉·和谐顺遂
  体克用 → 小吉·自身能掌控·但需费力
  体生用 → 不吉·自身消耗
  用克体 → 大凶·外界不利
```

### 2.1 操作

```

  进入观象状态
    ↓

    ↓

    隐藏通道·暗门·可破坏墙壁 → 发金色光
    隐藏宝箱·埋藏物品 → 发金色光
    环境陷阱（毒气区·落石区·崩裂冰面） → 发红色光
    剧情线索（残碑文字·隐藏壁画·星君记忆碎片） → 发蓝色光
```

## 三、体用生克——观象时的自动卦象解读

### 3.1 机制

每次观象不仅揭示隐藏——还会自动以当前环境"起卦"：

```
起卦方式：
  上卦 = 当前道宫的五行属性 → 映射为八卦
  下卦 = 当前时间的秒数 % 8 → 映射为八卦
  动爻 = 辰生当前面向的方向 → 映射为1-6
  
  → 自动生成一个"环境卦象"
  → 判断体用生克
  → 在观象状态下显示解读
```

### 3.2 体用生克对观象效果的影响

| 体用关系 | 对观象的影响 |
|---------|------------|
| **用生体**（大吉） | 揭示范围×1.5·揭示时间+3秒·所有隐藏要素发光更亮 |
| **体用比和**（吉） | 正常揭示·范围·时间不变 |
| **体克用**（小吉） | 揭示范围正常·但隐藏通道·暗门额外发光 |
| **体生用**（泄气） | 卦气消耗+50%·但揭示范围不变 |
| **用克体**（凶） | 揭示范围-10m·陷阱特别高亮（也算是"预警"） |

## 四、互卦——深层隐藏

### 4.1 互卦机制

观象揭示的是"表层隐藏"（飞神层）。某些更深的隐藏（伏神层）需要通过互卦来揭示：

```
第一次观象 → 揭示40m范围·消耗10卦气（表层）
  ↓ 如果本区域内存在"深层隐藏"...
画面提示："此象未尽·互卦藏机——再观一次？"
  ↓
第二次观象（在10秒内·同一位置） → 
  自动生成互卦（取本卦中间四爻重组）
  消耗20卦气·揭示"深层隐藏"：
    ★ 隐藏BOSS的巢穴入口
    ★ 星君记忆碎片（剧情关键）
    ★ 终极宝箱
    ★ 锻造材料·星晶矿脉
```

### 4.2 互卦概率

每个道宫约有5-8个"深层隐藏"点。第一次观象只有50%概率触发"此象未尽"的提示（体用生克影响概率）。触发后，玩家可以选择是否消耗20卦气进行互卦揭示。

```
体用生克 → 影响互卦触发概率：
  用生体：80%触发
  体用比和：50%触发
  体克用：30%触发
  体生用：20%触发
  用克体：10%触发（但如果有·必定是高价值隐藏）
```

## 五、起卦方式——四种触发

除了手动长按F，梅花易数还可以通过以下方式"被动"触发：

### 5.1 时间起卦

```
每过一个整时辰（游戏内2小时 ≈ 现实2分钟·星碑休息推进时间·默认TimeManager.gameHourPerRealMinute=60）：
  → 屏幕边缘浮现微弱的卦象图案（不打断操作）
  → 提示："申时·坤卦当值——此时观象效果最佳"
  → 如果玩家在此刻使用观象 → 自动体用比和·不消耗卦气
```

### 5.2 环境起卦

```
进入特定环境时自动提示：
  站在水边 → 坎卦·"水主隐伏——此处或有不为人知的深处"
  站在山顶 → 艮卦·"山主静止——也许是时候停下来看看"
  站在火旁 → 离卦·"火主光明——黑暗中的东西会被照亮"
```

### 5.3 声响起卦

```
听到特定声音时自动触发：
  远处鸟鸣 → 巽卦·"风入松林——高处有东西"
  水滴滴落 → 坎卦·"水滴石穿——地下有空洞"
  金属碰撞 → 乾卦·"金刚不坏——附近有锻造遗迹"
```

### 5.4 足迹起卦

```
经过隐藏要素附近时·辰生脚下浮现微弱卦象光圈：
  靠近隐藏宝箱5m → 脚下一闪离卦红光
  靠近隐藏通道3m → 脚下一闪坤卦黄光
  靠近危险陷阱2m → 脚下一闪坎卦蓝光
  
  → 不消耗卦气·纯提示·引导玩家使用手动观象
```

## 六、完整实现代码

```csharp
[Serializable]
public class MeiHuaYiShu {
    public int level = 1;
    public float cooldownTimer = 0f;
    
    // === 观象配置 ===
    public float GetRange() => level switch { 1=>20f, 2=>30f, 3=>40f, _=>40f };
    public float GetDuration() => level switch { 1=>3f, 2=>5f, 3=>8f, _=>8f };
    public float GetQiCost() => level switch { 1=>15f, 2=>12f, 3=>10f, _=>10f };
    public float GetCooldown() => 15f;
    
    // === 起卦 ===
    public static (int upper, int lower, int movingYao) QiGua(int daoGongId, int gameSeconds, float playerDirection) {
        int upper = daoGongId switch {
            0=>2, 1=>3, 2=>7, 3=>0, 4=>5, 5=>6, 6=>2, 7=>2, 8=>5, 9=>2, 10=>3, 11=>7, _=>0
        }; // 道宫→上卦
        int lower = gameSeconds % 8;
        int movingYao = ((int)(playerDirection / 60f) % 6) + 1; // 朝向→动爻1-6
        return (upper, lower, movingYao);
    }
    
    // === 体用生克判定 ===
    public enum TiYongResult { YongShengTi, TiYongBiHe, TiKeYong, TiShengYong, YongKeTi }
    
    public static TiYongResult JudgeTiYong(int upper, int lower, int movingYao) {
        bool movingInUpper = movingYao >= 4; // 动爻在上卦=用卦
        int tiWuXing = movingInUpper ? lower % 5 : upper % 5; // 体卦五行
        int yongWuXing = movingInUpper ? upper % 5 : lower % 5; // 用卦五行
        
        if (tiWuXing == yongWuXing) return TiYongResult.TiYongBiHe;
        if ((tiWuXing + 1) % 5 == yongWuXing) return TiYongResult.YongShengTi;  // 用生体
        if ((tiWuXing + 2) % 5 == yongWuXing) return TiYongResult.YongKeTi;     // 用克体
        if ((yongWuXing + 1) % 5 == tiWuXing) return TiYongResult.TiShengYong;  // 体生用
        if ((yongWuXing + 2) % 5 == tiWuXing) return TiYongResult.TiKeYong;     // 体克用
        return TiYongResult.TiYongBiHe;
    }
    
    // === 互卦生成 ===
    public static (int upper, int lower) GenerateHuGua(int benUpper, int benLower) {
        // 本卦 = 上卦+下卦两个三画卦·共六爻
        // 互卦 = 取二三四五爻重组·二三四→下互·三四五→上互
        // 简化：本卦上下卦ID各对应三爻·取中间四爻
        int benUpperBits = benUpper; // 3bit
        int benLowerBits = benLower; // 3bit
        // 合并为6爻(6bit)·取bit1-4(中间四爻)
        int combined = (benUpperBits << 3) | benLowerBits;
        int huLower = (combined >> 1) & 0x7; // bit1-3 = 下互
        int huUpper = (combined >> 2) & 0x7; // bit2-4 = 上互
        return (huUpper, huLower);
    }
    
    // === 观象执行 ===
    public static MeiHuaResult PerformObservation(int level, int daoGongId, int gameSeconds, float direction, float qiCurrent) {
        var (upper, lower, movingYao) = QiGua(daoGongId, gameSeconds, direction);
        var tiYong = JudgeTiYong(upper, lower, movingYao);
        
        float baseRange = level switch { 1=>20f, 2=>30f, 3=>40f, _=>40f };
        float baseCost = level switch { 1=>15f, 2=>12f, 3=>10f, _=>10f };
        
        // 体用修正
        float rangeMultiplier = tiYong switch {
            TiYongResult.YongShengTi => 1.5f,
            TiYongResult.YongKeTi => 0.75f,
            _ => 1.0f
        };
        float costMultiplier = tiYong switch {
            TiYongResult.TiShengYong => 1.5f,
            TiYongResult.YongShengTi => 0.8f,
            _ => 1.0f
        };
        
        return new MeiHuaResult {
            range = baseRange * rangeMultiplier,
            qiCost = baseCost * costMultiplier,
            tiYong = tiYong,
            upperGua = upper,
            lowerGua = lower,
            huGua = GenerateHuGua(upper, lower),
            canHuGua = tiYong == TiYongResult.YongShengTi || tiYong == TiYongResult.TiYongBiHe
        };
    }
}

public class MeiHuaResult {
    public float range;
    public float qiCost;
    public MeiHuaYiShu.TiYongResult tiYong;
    public int upperGua, lowerGua;
    public (int upper, int lower) huGua;
    public bool canHuGua; // 是否可以触发互卦
}
```

## 九、邵雍哲学——梅花易数的世界观如何成为游戏叙事

### 9.1 "以物观物"——邵雍的核心思想

邵雍在《皇极经世》中提出"以物观物"的认识论。不是"以我观物"（从自己的角度去看世界），而是放下自我，让事物自身的规律显现出来。

**游戏化：** 辰生在观象时，不是"用眼睛看"，而是"让卦象自己浮现"。隐藏的通道不是被你发现的——是卦象把它揭示出来的。你是卦象的"通道"，不是卦象的"主人"。

```
邵雍原文：        → 游戏化：
"以物观物·性也"    长按F时·辰生闭眼·不是用眼睛看
"以我观物·情也"    正常状态·看到的是太史阁想让你看到的世界
"性公而明·情偏而暗"  观象状态看到的是"真实"·正常状态看到的是"被篡改后的现实"
```

### 9.2 梅花易数的哲学基调——与三钱摇卦的区别

```
三钱摇卦：你主动去"问天"·扔铜钱·等人间给你答案
梅花易数：你被动去"观"·等天地自己告诉你答案
  → 三钱是"求签"·梅花是"顿悟"
  → 三钱是"仪式"·梅花是"感知"
```

## 十一、与奇门遁甲的衔接——"布阵之前先知敌"

梅花易数和奇门遁甲在探索中有协同效应：

```
进入新区域 →
  1. 梅花易数·观象 → 揭示隐藏敌人位置·数量·类型
  2. 根据揭示的信息 → 决定奇门遁甲阵法类型和放置位置
  3. 在敌人必经之路上布阵 → 进入战斗时阵法自动触发
  
  例：观象揭示前方有5个太史阁哨兵（3个近战·2个远程）
      → 在路口布下休门·治疗阵（回复）+ 杜门·减速阵（控制远程）
      → 开战·近战敌人冲过来踩进减速阵·远程被控制
      → 我站在治疗阵里输出
```

### 11.1 梅花→奇门衔接的数值

| 观象结果 | 奇门遁甲加成 |
|---------|------------|
| 用生体 | 阵法效果+30%·阵法范围+5m |
| 体用比和 | 阵法预设切换无需卦气 |
| 用克体 | 阵法持续时间-30%·但阵法伤害+20%（"被逼急了"） |

## 十五、被动触发详解——四种起卦方式的完整设计

### 15.1 时间起卦——免费观象

游戏内每2小时（建议现实20分钟），画面底部浮现时辰卦象提示。此时观象不消耗卦气·自动体用比和·范围×1.5。

```
子时☵坎·水下通道揭示×2 | 丑时☶艮·陷阱最亮 | 寅时☳震·隐藏通道自动发光
卯时☲离·发光距离+10m | 辰时☱兑·药材发光×2 | 巳时☰乾·锻造材料×2
午时☲离·互卦触发100% | 未时☴巽·隐藏信息发光×2 | 申时☷坤·全类别发光
酉时☱兑·宝箱发光×2 | 戌时☶艮·敌人轮廓更清 | 亥时☵坎·互卦范围+5m
```

```

金属碰撞→乾卦·锻造材料标记

宝箱5m→脚下一闪离卦红光 | 通道3m→坤卦黄光 | 陷阱2m→坎卦蓝光+震动
```
