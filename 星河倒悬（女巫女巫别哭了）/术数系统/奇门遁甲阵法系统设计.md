# 奇门遁甲阵法系统设计——九宫八门·运筹帷幄

> **定位：** 战斗中的战场控制系统。按住右键+Ctrl布阵，预设3套阵法战中一键放置。是卦术系统在"空间"维度的延伸——八卦选卦决定"你是什么"，奇门阵法决定"战场是什么"。
> **解锁：** 实沉宫（第6章·持久战·群众路线）
> **操作：** 按住右键+Ctrl → 1/2/3选预设阵 → 鼠标选位置 → 松手布阵

---

## 一、文化根源——真实的奇门遁甲

### 1.1 三式之首

奇门遁甲是中国古代最高层次的预测学之一，与太乙神数、大六壬并称"三式"。传说起源于黄帝战蚩尤——九天玄女授黄帝奇门遁甲之术，黄帝以此战胜蚩尤。

**"奇门遁甲"四字拆解：**
- **奇**：三奇——乙、丙、丁（天上的三个"奇兵"）
- **门**：八门——休、生、伤、杜、景、死、惊、开（人间的八个"门户"）
- **遁**：隐藏、遁去——六甲隐藏在六仪之下
- **甲**：六甲——甲子、甲戌、甲申、甲午、甲辰、甲寅（天上的"元帅"）

### 1.2 游戏化

辰生的奇门遁甲不是"预测"——是"布局"。他在战场上放置九宫格阵法，每一格是一个"门"。敌人踏入不同的门，遭遇不同的命运。**奇门遁甲从"占卜术"变成了"阵地战"。**

## 二、核心机制——九宫格战场

### 2.1 操作流程

```
非战斗（营地/星碑）：
  打开阵法编辑 → 在九宫格上预设最多3套阵法
  每套阵法 = 9个格子 × 各选1个八门 = 9门配置
  保存为1/2/3键

战斗中：
  按住右键+Ctrl → 地面显示九宫格虚影
  1/2/3键选预设阵 → 鼠标移动虚影到目标位置
  松手 → 阵法落地·实体化·开始生效
  布阵时间：1-2秒·此期间可被攻击打断
  消耗卦气：30
  冷却：60秒
```

### 2.2 九宫格规格


## 六、阵法生克——不是孤立的

### 6.1 八门之间的相生相克

```
八门五行：
  休门(坎☵水)·生门(艮☶土)·伤门(震☳木)·杜门(巽☴木)
  景门(离☲火)·死门(坤☷土)·惊门(兑☱金)·开门(乾☰金)

相邻两门五行相生 → 两门效果各+20%
相邻两门五行相克 → 被克门效果-30%
（"相邻"指九宫格中相邻的格子·含对角线）

中宫(5)无门·不可放置八门·自动为"休门"
```

### 6.2 优化策略

```
最优阵型示例——"生生不息阵"：
  生门(艮土·中上) + 休门(坎水·中下·水生木?不·土克水=-30%)
  → 调整为：生门(艮土·中上) + 开门(乾金·右下·土生金=开门+20%)
  → 阵型核心：生门(伤害+25%·+20%相生=30%) + 开门(3秒无敌·+20%相生=3.6秒)

敌对利用：
  敌人在"死门(坤土·中左)"和"伤门(震木·中中)"之间徘徊
  → 木克土·死门效果-30%
  → 改变阵型·将死门和杜门(巽木)放在一起·木生火≠不克土
  → 需要理解五行才能在阵型编辑中获得最大收益
```

## 八、完整实现代码

```csharp
[Serializable]
public class QiMenDunJia {
    public int level = 1;
    public const int GRID_SIZE = 3; // 3×3九宫格
    public const float CELL_SIZE = 5f; // 每格5m
    public const float BASE_DURATION = 45f;
    public const float BASE_QI_COST = 30f;
    public const float COOLDOWN = 60f;
    
    // 八门枚举
    public enum Door { Xiu=0, Sheng=1, Shang=2, Du=3, Jing=4, Si=5, JingMen=6, Kai=7 }
    // 九星枚举
    public enum Star { TianPeng, TianRui, TianChong, TianFu, TianQin, TianXin, TianZhu, TianRen, TianYing }
    // 八神枚举
    public enum Deity { ZhiFu, TengShe, TaiYin, LiuHe, BaiHu, XuanWu, JiuDi, JiuTian }
    
    // 单个阵格
    [Serializable] public struct Cell { public Door door; public bool isCenter; }
    
    // 预设阵法
    [Serializable] public class Formation {
        public string name;
        public Cell[,] grid = new Cell[GRID_SIZE, GRID_SIZE];
        public Star star;
        public int TotalQiCost() {
            int cost = 0;
            for (int r = 0; r < GRID_SIZE; r++)
                for (int c = 0; c < GRID_SIZE; c++)
                    if (!grid[r,c].isCenter)
                        cost += GetDoorQiCost(grid[r,c].door);
            return cost;
        }
    }
    
    public Formation[] presets = new Formation[3];
    
    // 八门卦气消耗
    public static int GetDoorQiCost(Door d) => d switch {
        Door.Xiu => 5, Door.Sheng => 8, Door.Shang => 10, Door.Du => 6,
        Door.Jing => 7, Door.Si => 12, Door.JingMen => 8, Door.Kai => 10, _ => 0
    };
    
    // 八门五行（用于生克判定）: 休水·生土·伤木·杜木·景火·死土·惊金·开金
    public static int GetDoorWuXing(Door d) => d switch {
        Door.Xiu => 4, Door.Sheng => 2, Door.Shang => 0, Door.Du => 0,
        Door.Jing => 1, Door.Si => 2, Door.JingMen => 3, Door.Kai => 3, _ => 0
    };
    // 五行：0=木·1=火·2=土·3=金·4=水
    
    // 五行生克判定
    public static bool IsGenerating(int a, int b) => (a + 1) % 5 == b; // a生b
    public static bool IsOvercoming(int a, int b) => (a + 2) % 5 == b; // a克b
    
    // 计算阵法内相生链加成
    public static float GetSynergyBonus(Formation f, int row, int col) {
        float bonus = 1.0f;
        Door myDoor = f.grid[row, col].door;
        int myWuXing = GetDoorWuXing(myDoor);
        // 检查8个相邻格
        int[] dr = {-1,-1,-1,0,0,1,1,1};
        int[] dc = {-1,0,1,-1,1,-1,0,1};
        for (int i = 0; i < 8; i++) {
            int nr = row + dr[i], nc = col + dc[i];
            if (nr>=0 && nr<3 && nc>=0 && nc<3 && !f.grid[nr,nc].isCenter) {
                int neighborWuXing = GetDoorWuXing(f.grid[nr,nc].door);
                if (IsGenerating(neighborWuXing, myWuXing)) bonus += 0.20f; // 邻生我+20%
                if (IsOvercoming(neighborWuXing, myWuXing)) bonus -= 0.30f; // 邻克我-30%
            }
        }
        return bonus;
    }
    
    // 随机八神
    public static Deity RollDeity() {
        float roll = UnityEngine.Random.value;
        if (roll < 0.15f) return Deity.ZhiFu;
        if (roll < 0.27f) return Deity.TengShe;
        if (roll < 0.39f) return Deity.TaiYin;
        if (roll < 0.51f) return Deity.LiuHe;
        if (roll < 0.61f) return Deity.BaiHu;
        if (roll < 0.71f) return Deity.XuanWu;
        if (roll < 0.86f) return Deity.JiuDi;
        return Deity.JiuTian;
    }
}
```

### 14.1 不同敌人对阵法反应

### 14.2 阵法血量与敌人攻击

```
阵法血量 = 辰生最大生命 × 0.5（基础）
+ 田宅宫加成（紫微斗数）
+ 天柱九星（免疫攻击）

敌人攻击阵法的优先级：
  1. BOSS·优先攻击生门和休门（对我方增益最大）
  2. 精英·攻击最近的门
  3. 杂兵·不攻击阵法·直接追击玩家

阵法被完全摧毁 →
  60秒冷却·期间不可布新阵
  地上留下"阵法残骸"·15秒后消失
  残骸区域·敌人移速+10%（"破阵之后·敌人乘胜"）
```

## 十七、测试验证

```csharp
[Test] public void Formation_SynergyBonus_Correct() {
    var f = new QiMenDunJia.Formation();
    f.grid[0,0] = new QiMenDunJia.Cell { door = QiMenDunJia.Door.Sheng }; // 生门·土
    f.grid[0,1] = new QiMenDunJia.Cell { door = QiMenDunJia.Door.Kai };   // 开门·金
    // 土生金 → 生门对开门 +20%
    float bonus = QiMenDunJia.GetSynergyBonus(f, 0, 1);
    Assert.AreEqual(1.20f, bonus, 0.01f);
    // 反过来·金不克土·也无生 → 开门对生门无加成
    float bonus2 = QiMenDunJia.GetSynergyBonus(f, 0, 0);
    Assert.AreEqual(1.0f, bonus2, 0.01f);
}

[Test] public void DeityRoll_Distribution() {
    int[] counts = new int[8];
    for (int i = 0; i < 100000; i++) counts[(int)QiMenDunJia.RollDeity()]++;
    Assert.AreEqual(0.15f, counts[0]/100000f, 0.01f); // 值符15%
    Assert.AreEqual(0.10f, counts[4]/100000f, 0.01f); // 白虎10%
    // 总和=100%
    Assert.AreEqual(1.0f, counts.Sum()/100000f, 0.001f);
}

[Test] public void AllDoors_HaveValidWuXing() {
    for (int d = 0; d <= 7; d++) {
        int wx = QiMenDunJia.GetDoorWuXing((QiMenDunJia.Door)d);
        Assert.IsTrue(wx >= 0 && wx <= 4);
    }
}
```
