# 术数系统——五音·节奏共鸣

> **认知框架：节奏共鸣。** 战斗不只是视觉——是听觉。宫商角徵羽=土金木火水。BOSS的攻击=一段音乐。你踩石板=你在这段音乐中加入自己的声部。当你的声音和BOSS的声音形成和声——共鸣触发。
> **核心问题："BOSS用徵音（火）——我站在角音（木）的石板上。木生火·共鸣。"** → 听到·识别·踩石·共鸣。
> **最出彩时刻：** BOSS三段徵音连发——你踩角音→木生火·共鸣·第一段被吸收→踩羽音→水克火·打断·第二段被反噬→踩宫音→火生土·转化·第三段变成你的护盾。三个音符·三段操作。你没出一剑。BOSS的火焰自己把自己灭了。

---

## 一、你"看到"的战场

```
装备"五音十二律"术数（占用1槽）后：

道宫的地面出现10种音律石板（宫商角徵羽×高低八度）。
每块石板约2m×2m·表面刻着音名字符（篆书）。

BOSS释放技能前——
对应的石板会先发光（1-1.5s弹窗）：
  徵音(火)石板=橙红
  商音(金)石板=银白
  角音(木)石板=翠绿
  羽音(水)石板=深蓝
  宫音(土)石板=土黄

踩发光的石板→发声→与BOSS的音形成互动。
```

## 二、五音互动规则

| BOSS用 | 你踩 | 关系 | 效果 |
|------|:--:|------|------|
| 徵音(火) | 角音(木) | **木生火·共鸣** | BOSS技能威力-50%·你吸收的威力转化为卦气 |
| 徵音(火) | 羽音(水) | **水克火·打断** | BOSS技能被打断·反噬伤害 |
| 徵音(火) | 宫音(土) | **火生土·转化** | BOSS技能转化为你的临时护盾 |
| 商音(金) | 宫音(土) | **土生金·共鸣** | BOSS技能威力-50% |
| 商音(金) | 徵音(火) | **火克金·打断** | BOSS技能被打断 |
| … | … | … | 五音×五行·全部遵循生克规则 |

## 三、不只是"踩"——是"跳舞"

```
不是踩一个石板。
是踩一串石板。

例：BOSS的徵音三连弹——三发火球·间隔0.5秒。
  你的操作：
    第1发=踩角音（木生火·共鸣·吸收）
    第2发=踩羽音（水克火·打断·反噬）
    第3发=踩宫音（火生土·转化·护盾）
  
  三次踩踏·三个音符·脚底发光·地面上留下你的"足迹旋律"。
  三次操作用时约1.5秒。
  你的角色在石板上跳跃——像在跳舞。
```

## 四、组合旋律——进阶

某些石板序列触发"和弦效果"：

| 序列 | 和弦 | 效果 |
|------|------|------|
| 宫→徵→羽 | 大地→烈火→深渊 | 全屏地震+火焰+冰霜·三重AOE |
| 角→羽→宫 | 生长→暗流→归藏 | 全队回血+净化+护盾 |
| 徵→商→角 | 焚金·生木 | 对BOSS破甲+打断+缠绕·"三段控" |

## 五、思维模式

```
五音玩家："我的武器不是剑。是耳朵。

          BOSS放技能之前——石板先发光。
          我听到徵音（火）的石板在嗡鸣——高频·刺耳。
          BOSS要用火。
          
          我跑到角音（木）的石板上——
          咚——踩下去·低沉的木音。
          木生火·共鸣。
          BOSS的火打到我身上——但火光在碰到我之前变成了绿色的光粒。
          被角音吸收了。
          
          然后我跳到羽音（水）的石板上——
          叮——清脆的水音。
          水克火·打断。
          BOSS的第二发火球在飞行中炸开——反噬到他身上。
          
          第三发——宫音（土）·嗡——深沉的土音。
          火生土·转化。
          火球变成了一圈土黄色的护盾·裹住了我。
          
          三连音。
          BOSS放了三发火球。我踩了三个石板。
          他的攻击变成了我的资源。
          
          我没出剑。我出的是音。"
```

## 六、与其他术数的搭配

| 搭配 | 效果 |
|------|------|
| +太极 | 翻转时·石板上的音名全部反转（宫↔羽·商↔角·徵不变） |
| +六爻 | 每次踩石板=写入对应爻线（角=初爻·徵=二爻……） |
| +大六壬 | 天地盘可以预测BOSS下一次用哪个音 |

## 七、为什么有人选这个

```
五音玩家："战斗是音乐。BOSS在演奏·我在和声。

          我不需要最快的闪避——
          我需要听出BOSS用徵音还是商音。
          然后踩正确的石板。
          
          当我的脚和BOSS的技能在同一瞬间落下——
          那是和声。是最美的共鸣。
          那一刻我不是在打架——我是在合奏。"
```
