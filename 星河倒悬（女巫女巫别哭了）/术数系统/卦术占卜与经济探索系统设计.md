# 卦术占卜与经济探索系统——卦象不只是战斗·更是"问事决疑"之道

> **定位：** 将八卦六十四卦的"占卜"本义融入游戏的探索、经济、资源获取系统。卦术从战斗工具扩展为"世界交互方式"——寻宝靠卦、问商靠卦、择路靠卦、知天命靠卦。

## 一、总纲——设计哲学与核心原则

### 1.1 为什么卦术不能只是战斗技能

八卦六十四卦诞生于三千年前的占卜传统。周文王演卦、孔子作十翼、京房创纳甲——这些东西最初不是用来"打人"的，是用来**"问天"**的。

古人占卜问什么？
- 问出行吉凶（"利涉大川"）
- 问失物所在（"七日得"）
- 问收成丰歉（"大有"卦名本身就是丰收）
- 问婚丧嫁娶（"归妹"）

如果我们的游戏只把卦术做成"技能特效"——那玩家学到的只是"离卦=火球术"。他永远不会理解为什么古代商人出门前要请卦师占一卦。

**我们要的是：玩家在游戏中潜移默化地学会"用卦问事"。**

打完这个游戏的人应该能：
- 看到"震卦"想到的不只是"雷系伤害"，而是"变动·警觉·东方"
- 看到"艮卦"想到的不只是"防御"，而是"停止·山·藏"
- 用排卦的方式思考问题——"现在的情况是什么卦？它会怎么变？"

战斗系统让卦术"有用"，探索系统让卦术"有意义"。

### 1.2 核心设计原则

| 原则 | 含义 | 反面教材 |
|------|------|---------|
| **卦象是线索·不是GPS** | 占卜告诉你方向和特征，不告诉你坐标。玩家仍需要探索 | 直接在地图上标注❓=毁了占卜的意义 |
| **消耗资源换信息** | 每次占卜消耗卦气/铜钱/时间。免费=不值钱 | 无消耗占卜→玩家无脑狂按→无聊 |
| **精度有波动·不是每次都准** | 变爻·命盘·时间影响精度。偶尔不准反而增加真实感 | 永远100%准确→玩家不再自己观察环境 |
| **好的卦象>坏卦象·但坏卦也有用** | 凶卦有代价但有额外收益 | 随机惩罚→玩家只挑好的→失去策略性 |
| **占卜深度分层** | 新手用小六爻快速判断·老手用六十四卦精细定位·大师用互卦发现隐藏 | 所有级别用一套系统→新手懵逼·老手无聊 |
| **与世界观一致** | 为什么辰生能"算"?因为十二星君的力量·因为紫微命盘·因为母亲留下的星轨残卷 | 没有叙事依据的魔法寻宝=脱离世界观 |

### 1.3 子系统总览

本系统包含**八大子系统**，覆盖经济和探索的全部环节：

```
卦术占卜×经济探索
│
├── 子系统一：卦占宝箱          ← 核心·用卦象寻找隐藏宝箱
├── 子系统二：小六爻寻宝        ← 快速·战斗中瞬判宝箱位置
├── 子系统三：梅花易数·观象寻宝  ← 沉浸·看环境中的自然卦象暗示

├── 子系统五：变爻精度系统       ← 随机·变爻数影响占卜准确度

├── 子系统七：卦问吉凶           ← 战前·BOSS风险评估·高风险高回报
└── 子系统八：卦问商机           ← 策略·预测商人折扣·杀敌掉落
```

## 二、卦占宝箱——寻宝占卜系统（核心系统一）

### 2.1 系统概述

**触发方式：** 站在星碑前 → 按F → 选择"卦问财帛" → 三钱摇卦 → 得卦象 → 卦象给出宝箱方位和环境特征。

**核心流程：**
```
1. 接近星碑 → 交互
2. 普通星碑：[刻星] [摇卦问卜] [卦问财帛] [休息] [锻造] [丹鼎]
   BOSS门前星碑额外增加：[⚡卦问吉凶]
3. 选"卦问财帛" → 消耗20卦气 + 5文铜钱（三枚铜钱是"供品"）
4. 三钱摇卦——6次甩鼠标→本卦+变卦浮现
5. 卦象解读面板弹出 → 显示方位提示+环境特征+精确度
6. 玩家接受提示 → 探索世界→ 在提示指向的区域寻找宝箱
7. 找到宝箱 → 额外奖励（比普通宝箱多1-3星晶）
```

**消耗设计：**
- 每次占卜消耗20卦气 + 5文铜钱
- 卦气不足 → 不可占卜（防止无限刷）
- 铜钱不足 → 可以用卦气替代（30卦气）
- 同一区域24游戏小时内不刷新新的卦占宝箱（每个区域1-3个·总限量）

**为什么消耗铜钱？**
传统文化中，请卦师占卜要付"卦金"——不是卦师贪钱，而是"不付费的卦不灵"。这是一种心理契约：你认真付费，我才认真解卦。游戏中也一样——免费占卜玩家不会认真读提示，5文钱很少但建立了"这次占卜有价值"的心理锚点。

### 2.2 八卦寻宝——八个方向的提示系统

八卦本身代表八个方位（先天八卦·后天八卦混用·游戏化简化）：

| 卦 | 方位 | 环境特征 | 寻找线索示例 |
|----|:--:|------|------|
| ☰ **乾** | 西北 | 高处·金属·圆形物体旁 | "西北有高台·其上有圆石·石下有藏" |
| ☷ **坤** | 西南 | 平地·土中·方正物体旁 | "西南平土·方石之下·掘地三尺" |
| ☳ **震** | 东 | 高处·震动·声响处 | "东方有枯木·曾被雷劈·根下有物" |
| ☴ **巽** | 东南 | 风大处·树木·高处 | "东南风口·古树之冠·鸟巢之侧" |
| ☵ **坎** | 北 | 水边·低洼·暗处 | "北有溪流·水声最响处·石下暗格" |
| ☲ **离** | 南 | 火旁·光亮·热处 | "南方熔岩·冷却的火山石·缝中有光" |
| ☶ **艮** | 东北 | 山脚·止处·岩壁 | "东北山麓·路尽之处·岩壁可碎" |
| ☱ **兑** | 西 | 水泽·湿地·凹陷 | "西有泥沼·枯莲之下·淤泥中有硬物" |

**方位判定方法：**
站在触发占卜的星碑处 → 以星碑朝向为"北" → 卦象指示的方向 = 游戏内相对方位
（不依赖现实指南针——星碑本身就是"北极星"的象征，面朝星碑=面朝北）

### 2.3 上下卦组合——从模糊到精确

单独一个八卦只能给出"8选1"的方向——太粗略。真正的寻宝占卜需要**上下卦组合**：

**上卦 = 方位（8选1）**
**下卦 = 可交互对象/地形特征（8选1）**

| 下卦 | 可交互对象/地形特征 |
|:--:|------|
| ☰ 乾 | 金属物体（断剑·铁砧·铜钟·齿轮） |
| ☷ 坤 | 土地/地面（可挖掘的土堆·松软地面·方形石板） |
| ☳ 震 | 树木/木质（空心树·枯木·树根·被雷劈的树） |
| ☴ 巽 | 风/气流（风口·风中飘动的旗帜·风车·风铃） |
| ☵ 坎 | 水源（溪流·瀑布·水井·水池·水缸） |
| ☲ 离 | 火光/亮光（火把·熔岩·萤火虫群·镜面反光） |
| ☶ 艮 | 岩石/山体（岩壁·巨石·石堆·山洞） |
| ☱ 兑 | 水面/沼泽（浅滩·泥沼·水洼·湖泊） |

**组合示例：**
- 上卦☲离（南）+ 下卦☵坎（水源）→ "南方·溪流交汇处"
- 上卦☳震（东）+ 下卦☶艮（岩石）→ "东方·山脚巨岩之下"
- 上卦☰乾（西北）+ 下卦☱兑（水泽）→ "西北·枯井之中"

**总共 8×8 = 64 种组合 = 对应64卦的完整寻宝提示。每个卦名本身就是一个"暗号"。**

## 三、小六爻寻宝——战斗中的快速判断（核心系统二）

### 3.1 与小六爻战斗系统的区分

战斗中小六爻是**6方向甩鼠标→6种战斗效果**。探索中小六爻是**同一套操作→6种寻宝判断**。操作相同，但场景不同→效果不同。

**触发条件：** 非战斗状态·按住右键+Shift → 鼠标6方向甩 → 松手释放 → 不产生战斗效果，改为寻宝判断

**为什么是同一个操作？**
让玩家在探索时自然地使用小六爻来"探路"——就像他战斗时用小六爻来"探敌"一样。肌肉记忆相通。

### 3.2 六种寻宝判断

| 爻象 | 效果名 | 寻宝含义 | UI表现 | 持续时间 |
|------|------|------|------|:--:|
| 🟢 **大安** | 平安·近在眼前 | 20m范围内有可交互宝箱/隐藏物 | 屏幕边缘泛绿光·方向指示器出现淡绿色箭头 | 15秒 |
| 🟡 **留连** | 滞留·需要解谜 | 有宝箱但无法直接到达·需要绕路/解谜/特殊能力 | 屏幕泛黄·目标方向出现黄色波纹 | 20秒 |
| 🔴 **速喜** | 快速·唾手可得 | 30m范围内·不需要战斗就能拿到 | 屏幕出现红色亮点·快速闪烁后消失 | 8秒 |
| ⚪ **赤口** | 危险·不是宝箱 | "宝箱"其实是拟态怪/陷阱/埋伏 | 屏幕泛白·那个方向的"宝箱"图标变为骷髅 | 立即发现 |
| 🟣 **小吉** | 小有收获 | 不是宝箱·是材料堆/可采集的资源点 | 紫色粒子飘向资源方向 | 25秒 |
| ⚫ **空亡** | 空无·什么都没有 | 当前区域无隐藏物 | 屏幕微暗·卦气消耗返还50% | 瞬时 |

### 3.3 小六爻寻宝的限制与策略

```
消耗：每次5卦气（战斗小六爻的2倍——非战斗时卦气更充裕·适当提高）
冷却：30秒共冷却（但可连甩·第二次起-50%精度）
精度递减：
  第1次：90%准确
  第2次（30秒内）：70%准确
  第3次（30秒内）：50%准确 → 恢复倒计时30秒
  第4次及以后：精度降至30%·且卦象提示变为"卦气已浊·待清气复"

最高境界：
  高手不甩小六爻也能凭环境细节判断宝箱位置
  小六爻是"确认"而不是"发现"
  就像真实占卜——有经验的卦师不需要每次都起卦，他已经能从"象"中读出来了
```

### 3.4 战斗中的"无心插柳"

如果玩家在战斗中用小六爻打出了特定效果，战斗结束后如果有宝箱在附近：

```
战斗中甩出"赤口"击退敌人 →
  战斗胜利后画面弹出："赤口所向·其处有诈" → 那个方向的宝箱是拟态怪！

战斗中甩出"大安"增伤 →
  战斗胜利后："大安所在·平安有藏" → 那个方向有真正的宝箱
```

这种"无心插柳"让战斗和探索之间产生意外的联系——这也是古人"即占即用"的卦术使用方式。

## 四、梅花易数·观象寻宝（核心系统三）

### 4.1 梅花易数的根本原理——"万物皆可成卦"

梅花易数由宋代邵雍创立，其核心思想是：**天地间一切事物都可以转换为卦象。** 看到三只鸟 → 数3→离卦。听到五声钟响 → 数5→巽卦。看到断墙 → 艮卦。

在游戏中实现这个思想：**环境中到处都是卦象暗示，但需要进入"观象"模式才能看到。**

### 4.2 观象模式——操作与视觉

```
操作：
  非战斗状态·长按F（1.5秒蓄力）→ 进入观象模式

观象模式特征：
  时间减速至30%流速（类似战斗选卦·免费但移动变慢）
  画面变为水墨风格·饱和度-70%·对比度+30%
  辰生左手掐诀（食指·中指·无名指快速点算·模拟"掐指一算"）
  周围环境中被卦象标记的物体发出柔和的金色光芒

退出：
  松F键 → 退出观象·或卦气耗尽自动退出
  被敌人攻击 → 强制退出观象（画面闪红·辰生受击硬直）
```

### 4.3 万物类象——环境中的卦象暗号

游戏中预设了大量"卦象暗号"（万物类象），散布在环境各处。玩家在观象模式下能看到它们发光。不在观象模式下它们也存在——但需要玩家自己"看"出来。

#### 数字卦——通过"数"起卦

|------|:--:|:--:|------|
| 树上的乌鸦 | 1只 | ☰乾 | 树根下有宝·乾为天·最顶端的树冠 |
| 溪流中的踏脚石 | 2块 | ☱兑 | 下游沼泽有宝·兑为泽 |
| 枯枝上的鸟巢 | 3个 | ☲离 | 枯枝被雷劈过的痕迹·离为火为闪电 |
| 方碑上的刻字 | 4行 | ☳震 | 方碑可推动·震为动 |
| 风车上的叶片 | 5片 | ☴巽 | 风车下有暗格·巽为风为入 |
| 水井的井壁石 | 6块 | ☵坎 | 井底有隐藏通道·坎为水为陷 |
| 山脚下的人形石 | 7尊 | ☶艮 | 第七尊石后可破坏·艮为山为止 |

**"为什么是这些数字？"**
因为邵雍的梅花易数中，数字1-8分别对应先天八卦：1乾·2兑·3离·4震·5巽·6坎·7艮·8坤。游戏中的设计师在环境中"藏"了这些数字——不是随机的，是有意为之。

### 4.4 三要十应——即时灵感的触发

梅花易数除了"观物起卦"，还有一种更高级的用法——**"三要十应"**。简单说就是：你正在算一件事，突然发生了什么——那个"突然发生的事"本身就是答案。

游戏中实现为**"灵感触发"系统**：

```
当玩家在观象模式下观察到一个卦象暗号时 →
  系统随机（概率=梅花易数等级÷10）触发"灵感连锁"：

  例：玩家在观象·看到溪流中2块踏脚石（☱兑卦） →
    灵感触发 → 2秒后一只水鸟从泽中飞起·落在一棵枯树上 →
    枯树的位置 → 宝箱就在那棵树下
```

这种"灵感连锁"让探索变得像破案——从A线索跳到B线索，最后找到宝箱。这正是梅花易数最迷人的地方：**万物互联，一叶知秋。**

### 4.5 梅花易数成长系统

梅花易数是辰生的被动能力，随游戏进度成长：

| 等级 | 解锁条件 | 观象范围 | 灵感触发率 | 额外效果 |
|:--:|------|:--:|:--:|------|
| Lv1 | 序章·云岫教学 | 15m | 5% | 数字卦可见·单色发光 |
| Lv2 | 通关玄枵宫 | 20m | 10% | 形状卦可见·双色发光 |
| Lv3 | 通关降娄宫 | 25m | 15% | 声音卦可见·声音带波纹 |
| Lv4 | 通关实沉宫 | 30m | 20% | 灵感连锁触发·可追踪2次连锁 |
| Lv5 | 通关大火宫 | 40m | 30% | 三要十应全开·可看到"卦象之间的连线" |

## 五、互卦·双重揭示（核心系统四）

### 5.1 互卦寻宝原理

互卦是从本卦中提取的"隐藏信息"。本卦6爻，取第2、3、4爻组成下卦，取第3、4、5爻组成上卦——这就得到了互卦。

在寻宝中：
- **本卦** → 揭示"明面"宝箱（普通宝箱，铜钱+普通材料）
- **互卦** → 揭示"暗面"宝藏（稀有宝箱，星晶+稀有材料+法器材料）

**一个地点，两个宝藏，两个卦象。**

### 5.3 互卦寻宝的代价

## 六、变爻精度系统（核心系统五）

### 6.1 变爻如何影响寻宝精度

在古代占卜中，"变爻"代表不确定因素。变爻越多，事情越"不稳定"。在寻宝中：

| 变爻数 | 概率 | 精度等级 | 宝箱等级 | 提示特征 | 找到后的特殊效果 |
|:------:|:--:|:--:|:--:|------|------|
| **0变爻** | 17.8% | ⭐⭐⭐⭐⭐ 精准 | Lv3铜箱 | 方位+距离+特征全部精确·20m内 | 卦气恢复+10（"天意坚定"奖励） |
| **1变爻** | 35.6% | ⭐⭐⭐⭐ 良好 | Lv2木匣~Lv3铜箱 | 方位精确·距离±5m·特征模糊化 | — |
| **2变爻** | 29.7% | ⭐⭐⭐ 可为 | Lv2木匣 | 方位±45°模糊·距离"近/中/远"·特征用同义词替换 | 打开宝箱时变爻位置触发生效 |
| **3变爻** | 13.2% | ⭐⭐ 粗糙 | Lv1瓦罐~Lv2木匣 | 方位±90°模糊·可能出现反义 | 额外获得变爻位数×10文铜钱 |
| **4变爻** | 3.3%  | ⭐ 模糊 | Lv1瓦罐 | 提示中出现一组矛盾（"东南或西北"）·需要玩家自己判断 | 额外获得1星晶 |
| **5变爻** | 0.44% | ⭐ 极模糊 | Lv1瓦罐~Lv2木匣 | 提示阴晦不明·"天机不泄"·只能看到模糊的光影 | 宝箱内有稀有材料 |
| **6变爻** | 0.02% | ⭐⭐⭐⭐⭐ **天命** | **Lv5天命宝箱** | 全部6个变爻效果同时激活·宝箱升级为金色 | 必定史诗级材料+5-10星晶·解成就 |

### 6.2 变爻模糊机制详解

**1-2变爻·方位偏移：**
```
实际宝箱在正南（离卦·180°）
1变爻 → 提示"南方偏东南"（180°±22.5°）→ 仍可找到
2变爻 → 提示"西南方位有火光"（180°±45°即135°-225°）→ 需要多搜索
```

**3-4变爻·特征替换：**
```
3变爻 → 本应提示"水中"→ 提示变为"低洼"或"潮湿"（近义词替换）
4变爻 → 提示出现矛盾："南有水声·或北有泽"（两个方向都可能）
        需要玩家结合环境判断：南边确实有水声·北边是枯泽——选南边
```

**5变爻·谜语化：**
```
提示不再是直白的方位+特征，而是一首"卦辞诗"：

  "火在雨中行，石上开花处。
   不是南方路，向东三步顾。"

玩家需要解读：
  "火在雨中行"=离卦（火）+坎卦（水）=䷿火水未济=水火交界处
  "石上开花"=岩壁附着红色地衣（形似花）
  "不是南方"=否定最明显的方向
  "向东三步"=在否定之后给出真相
  
   → 找到：熔岩区边缘·冷泉旁·红色地衣覆盖的岩壁下
```

**6变爻·天命直接显现：**
```
全屏金光·辰生的星纹全部亮起·眼前出现一条金色的光路→
直通宝箱所在。不需要解谜。不需要找。
"天命加身——天意已决。"
（0.02%概率·约5000次占卜才遇到1次·全游戏最稀有的非战斗事件）
```

### 6.3 玩家如何"应对"变爻精度

高级玩家会利用变爻机制来优化寻宝策略：

```
策略一："低变爻留·高变爻重摇"
  1-2变爻→接受·可以用经验找到
  3-4变爻→如果卦气充裕就重摇·卦气紧张就接受
  5变爻→接受·即使模糊·稀有材料值得
  6变爻→永远接受——0.02%！天命宝箱不可错过

策略二："变爻位置的信息价值"
  初爻变→根基动摇→"宝箱可能在地面而非高处"
  上爻变→天命垂怜→"宝箱可能已经被打开了一部分·处于暴露状态"

策略三："变爻与紫微命盘的叠加"
  如果命盘中有"文曲"（重摇消耗-10卦气）→重摇成本更低·可接受更低精度
  如果命盘中有"天机"（巽卦DOT+15%）→可摇更多巽卦·因为巽=风=灵气充沛=卦象更清晰（巽卦寻宝固有+1精度等级）
```

            int huGuaId = CalculateHuGua(shakeResult.benGuaId);

                chainHuGuaId, result.hiddenTreasure?.position ?? result.surfaceTreasure.position, 0);
        }

        result.accuracy = accuracyByChangingYao[Mathf.Clamp(changingCount, 0, 6)];

    /// <summary>
    /// 根据卦象计算宝箱位置
    /// </summary>
    private TreasureLocation CalculateTreasureLocation(
        int hexagramId, Vector3 origin, int changingCount) {
        
        var loc = new TreasureLocation();
        int upperTrigram = hexagramId / 8;  // 上卦(0-7)
        int lowerTrigram = hexagramId % 8;  // 下卦(0-7)
        
        // 上卦→方位
        loc.direction = (TrigramDirection)upperTrigram;
        float baseAngle = GetDirectionAngle(loc.direction);
        
        // 变爻模糊化
        float angleOffset = changingCount switch {
            0 => 0f,
            1 => Random.Range(-22.5f, 22.5f),
            2 => Random.Range(-45f, 45f),
            3 => Random.Range(-90f, 90f),
            4 => Random.Range(-135f, 135f),
            5 => Random.Range(0f, 360f), // 完全随机方向
            6 => 0f, // 天命·精准
            _ => 0f
        };
        loc.actualAngle = baseAngle + angleOffset;
        
        // 距离（变爻越多越模糊）
        float baseDistance = Random.Range(30f, 80f);
        float distanceFuzz = changingCount * 15f;
        loc.distance = baseDistance + Random.Range(-distanceFuzz, distanceFuzz);
        
        // 下卦→交互对象类型
        loc.interactableType = (InteractableType)lowerTrigram;
        
        // 计算实际坐标
        float rad = loc.actualAngle * Mathf.Deg2Rad;
        loc.position = origin + new Vector3(
            Mathf.Sin(rad) * loc.distance, 0, Mathf.Cos(rad) * loc.distance);
        
        return loc;
    }
    
    /// <summary>
    /// 计算互卦（第2-5爻重组）
    /// hexagramId编码：从三钱摇卦ShakeResult继承·bit0=初爻·bit5=上爻
    /// </summary>
    private int CalculateHuGua(int hexagramId) {
        // 提取6爻·bit序与三钱摇卦ShakeResult.benGuaId一致
        bool[] yao = new bool[6];
        for (int i = 0; i < 6; i++) {
            yao[i] = (hexagramId & (1 << i)) != 0; // true=阳爻·bit0=初爻
        }
        
        // 下卦：第2,3,4爻（索引1,2,3）
        int lower = 0;
        if (yao[1]) lower |= 1;
        if (yao[2]) lower |= 2;
        if (yao[3]) lower |= 4;
        
        // 上卦：第3,4,5爻（索引2,3,4）
        int upper = 0;
        if (yao[2]) upper |= 1;
        if (yao[3]) upper |= 2;
        if (yao[4]) upper |= 4;
        
        return upper * 8 + lower; // 0-63
    }
    
    /// <summary>
    /// 根据变爻数确定宝箱等级
    /// </summary>
    private TreasureTier DetermineTreasureTier(int changingCount) {
        return changingCount switch {
            0 => TreasureTier.CopperBox,       // 精准·Lv3
            1 or 2 => TreasureTier.WoodBox,    // 良好·Lv2
            3 => TreasureTier.Pottery,          // 粗糙·Lv1
            4 or 5 => TreasureTier.Pottery,     // 模糊·Lv1（但额外星晶/材料）
            6 => TreasureTier.DestinyBox,       // 天命·Lv5
            _ => TreasureTier.WoodBox
        };
    }
    
    /// <summary>
    /// 生成卦象寻宝提示语
    /// </summary>
    private string GenerateHexagramClue(int hexagramId, int changingCount) {
        var clue = DivinationClueTable.GetClue(hexagramId);
        
        if (changingCount == 6) {
            return "天命加身——天意已决。" + clue.fullText + "【光路显现】";
        }
        if (changingCount >= 4) {
            return clue.riddleText; // 谜语化提示
        }
        if (changingCount >= 2) {
            return clue.vagueText; // 模糊化提示
        }
        return clue.fullText; // 精确提示
    }

### 12.1 与三钱摇卦系统的关系

本系统**复用**三钱摇卦的操作（6次甩鼠标→得卦），但在不同场景中调用不同的"解卦逻辑"：

| 场景 | 摇卦操作 | 解卦逻辑 | 卦象用途 |
|------|:--:|------|------|
| 星碑·摇卦问卜 | 三钱摇卦 | §5.2运势叠加计算 | 战斗Buff+代价 |
| 星碑·卦问财帛 | 三钱摇卦 | §2.4寻宝提示表 | 宝箱方位+特征 |
| 星碑·卦问吉凶 | 三钱摇卦 | §8.3吉凶判定表 | BOSS风险+奖励 |
| 商人·卦问商机 | 三钱摇卦 | §9.1折扣判定 | 商人折扣预测 |

**共享的数据结构：** `ShakeResult`（本卦ID·变卦ID·变爻位图）在四个场景中通用。不同的是后续的"解卦"层——战斗Buff系统、寻宝提示表、吉凶判定表、折扣表。

### 12.2 与梅花易数探索系统的关系

原有的 `梅花易数探索系统设计.md` 定义了"长按F观象·40m揭示隐藏"。本系统与它的关系是：

| 功能 | 梅花易数（原有） | 卦术占卜（本系统新增） |
|------|------|------|
| **寻宝方式** | 被动·进入观象模式后环境物体自动发光 | 主动·摇卦获得提示·按提示去寻宝 |
| **依赖** | 高·需要理解万物类象 | 低·跟提示走就行 |
| **精确度** | 高·直接看到位置 | 中·方位+特征·需要自己找 |
| **消耗** | 无卦气消耗 | 消耗卦气+铜钱 |
| **深度** | Lv1-5·范围+灵感率成长 | 变爻·互卦·连互卦·三重揭示 |
| **使用频率** | 高频·随时可用 | 中频·每次星碑可占 |

> **设计意图：** 梅花易数是被动的"看"（观象·万物类象·全身感知），卦术占卜是主动的"问"（摇卦·三枚铜钱·精神专注）。一阴一阳·相辅相成。
