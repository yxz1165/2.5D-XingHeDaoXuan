# 大五帝钱收集系统——五枚横跨两千年的古币

> **定位：** 铜钱剑专属收集升级系统。五枚古币散落在五座道宫深处，每枚激活一个被动，五枚集齐后铜钱剑终极觉醒。探索+收集+武器进化的三位一体。

---

## 一、什么是大五帝钱

中国钱币史上五枚最传奇的古币，跨越秦、汉、唐、宋、明五个盛世。现实中藏家将它们串在一起挂于门前辟邪镇宅——五朝帝王之气汇聚一线。

```
秦半两（前221年）→ 第一个统一王朝的货币·外圆内方在此定型
汉五铢（前118年）→ 使用739年·中国历史上流通最久的铸币
唐开元（621年） → 开创"通宝"钱制·从此不再标重量·只标年号
宋宋元（960年） → 赵匡胤开国钱·宋代三百年繁华的起点
明永乐（1408年）→ 郑和带往西洋·中国的第一枚"世界货币"
```

---

## 二、五枚古币分布

每枚古币藏在对应道宫的最深处，需要互卦揭示（梅花易数二次观象）才能找到。

| 古币 | 道宫 | 藏匿地点 | 线索 |
|------|------|---------|------|
| **秦半两** | 实沉宫 | 古战场·地下兵道尽头·秦军都尉遗骸旁 | 地面散落半两钱·跟随钱迹 |
| **汉五铢** | 大梁宫 | 书市地下三层·焚书坑幸存铁箱 | 箱上刻五铢钱图案·需坎卦破锁 |
| **唐开元** | 玄枵宫 | 水乡·古运河沉船·船舱暗格 | 船头挂开元通宝铜牌 |
| **宋宋元** | 大火宫 | 戏曲舞台·VIP包间壁画后·宋代乐师遗物 | 壁画右下角有宋元通宝纹样 |
| **明永乐** | 析木宫 | 陨石坑最深处·与析木遗言同藏 | 陨石坑边缘有永乐通宝压痕 |

## 三、每枚古币的效果

装备铜钱剑时，每枚已获得的五帝钱自动激活其被动：

| 古币 | 被动效果 | 激活条件 |
|------|---------|---------|
| **秦半两** | 铜钱剑普攻附带5%破甲·累计可叠加3层（15%） | 获得后自动激活 |
| **汉五铢** | 铜钱计数速度+25%（每次普攻命中+1.25计数） | 同上 |
| **唐开元** | 铜钱护盾吸收量+15%·54枚时触发（原18枚·降低触发门槛） | 同上 |
| **宋宋元** | 108铜钱雨伤害+30% | 同上 |
| **明永乐** | 撒豆成兵结界范围+5m（6m→11m） | 同上 |

## 四、五帝共鸣——五枚集齐

五枚全部收集后，在星碑处选择"五帝共鸣"：

```
铜钱剑 → 五帝铜钱剑（终极形态）

变化：
  普攻段数：5段→6段（鞭状横扫之后追加一次五帝齐射）
  铜钱计数上限：108→216（翻倍）
  108铜钱雨→五帝钱雨：伤害×2·范围覆盖整个奇门阵法
  撒豆成兵→五帝结界：减速60%（原30%）+ 持续12秒（原8秒）
  外观：剑身镶嵌五枚金色古币·挥动时拖出五种不同朝代的铜钱残影
```

## 五、发现流程（以秦半两为例）

```
实沉宫·古战场。
梅花观象→地面散落几枚半两钱·微弱金光指示方向。
跟随钱迹→地下兵道入口（互卦揭示）。
兵道内·秦军都尉遗骸旁→一枚完整的秦半两·插在胸甲上。
辰生拾起→半两在掌心微微发热。画面浮现秦军的最后一刻——
"咸阳...还在吗？"那位都尉在死前把半两按进胸口。
取出时，铜钱已经被血浸成了暗红色。
```

**每枚古币的发现就是一段微型叙事。** 不只是"找到道具"——是"读到历史"。
