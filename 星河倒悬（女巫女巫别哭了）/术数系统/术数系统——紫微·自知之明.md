# 术数系统——紫微·自知之明

> **认知框架：自知之明。** 你的命盘在开局就定好了——不是你能选的。十二宫主星·四化落位·化禄在命宫是好事·化忌在财帛宫是挑战。紫微斗数不是让你"变强"——是让你"认识自己"。知道自己的优势在哪里·弱点在哪里。顺势而为。
> **核心问题："我的化忌在哪里？"** → 查看自己的命盘→知道哪个宫位被压制→避开它·或者在它的压制下找到新的打法。
> **最出彩时刻：** 你的化忌在财帛宫——商人价格翻倍·但卦气消耗减半。你无法用"买装备堆数值"的方式变强——但你学会了用更少的卦气释放更多卦术。化忌不是"废了"——是"你得换个打法"。

---

## 一、你"看到"的战场

```
装备"紫微斗数"术数（占用1槽·开局生成·不可卸下但可调大限）后：

道宫的BOSS房地面会出现你的紫微命盘投影（直径约20m）。
十二宫围绕中宫·每宫的亮度不同：
  - 化禄所在宫 → 最亮·金色光柱
  - 化权所在宫 → 亮·蓝色光柱·可手动激活（主动技能）
  - 化科所在宫 → 中等亮度·白色光柱
  - 化忌所在宫 → 暗·红色光柱·站在上面效果反转

站在不同宫位上→该宫的效果被"激活"（持续到你离开或4秒后·可刷新）：
  命宫(紫微)=全卦术+5%均衡
  官禄宫(贪狼)=卦术伤害+15%·卦气消耗+15%
  疾厄宫(天相)=异常状态时间-50%
  ...共12宫·每个玩家的命盘主星不同·同一宫效果不同
```

| 财帛宫 | 经济 | 商人价格-20%（武曲）【化忌在此=价格+20%·但卦气消耗-50%】 |
| 疾厄宫 | 生存 | 异常状态时间-50%（天相） |
| 迁移宫 | 移动 | 移速+15%·闪避距离+20%（天机） |

| 田宅宫 | 营地 | 休息回复+50%（天府） |

## 三、化忌——双刃剑

化忌不是惩罚——是**个性化挑战**：

| 化忌所在 | 反转效果 | 玩家的应对 |
|------|------|------|
| 财帛宫 | 商人价格+20%·但卦气消耗-50% | 不买东西·靠卦术输出 |
| 疾厄宫 | 异常状态时间+50%·但生命上限+30% | 多带石翁(净化)·用艮卦格挡 |
| 官禄宫 | 卦术伤害-10%·但闪避无敌帧+5 | 走闪避反击流·不用卦术主输出 |
| 迁移宫 | 移速-15%·但站在一个宫位上=宫位效果×2 | 站定输出·不频繁换位 |

**化忌=你的个人课题。别人不用面对的问题·你要面对。但面对之后——你在这个维度上反而比没有化忌的人更强。**

## 四、四化流转

每通关3座道宫→四化同时移到下一个宫位。每3座宫·你的"好宫位"和"坏宫位"都变了——强制调整策略。

## 五、思维模式

```
紫微玩家："别人的命盘我不管。我只管我自己的。

         我的化忌在疾厄宫——异常状态时间+50%。
         毒·灼烧·冻结·混乱——对我都比对别人久。
         所以我不和别人比"谁扛得久"——我比"谁先打死对方"。
         
         我的化禄在官禄宫——卦术伤害+20%。
         我的化权在福德宫——每60秒自动解debuff+可手动激活×2。
         
         这不是"Build优化"——是"认识自己"。
         化忌让我脆弱·但也让我知道我必须速战速决。
         化禄让我强大·但只有在我承认自己的脆弱之后。
         
         紫微斗数不是让你变强的术数——
         是让你不再用别人的标准衡量自己的术数。"
```

## 六、与其他术数的搭配

| 搭配 | 效果 |
|------|------|
| +太极 | 翻转时·化禄和化忌互换（短暂的好运） |
| +六爻 | 命盘十二宫=六爻战场的"背景地图" |
| +太乙 | 化忌在官禄宫→太乙神数的风险更高·但成功后伤害翻倍 |

## 七、为什么有人选这个

```
紫微玩家："我不需要最强的卦。我需要最了解的自己。
          化忌不是惩罚——是命盘在告诉我：你在这个地方要小心。
          化禄不是buff——是命盘在告诉我：这是你的路。
          我的卦码不是"最强的配置"——是"最适合我的命的配置"。
          别人的Build再好·不适合我的命盘。"
```
