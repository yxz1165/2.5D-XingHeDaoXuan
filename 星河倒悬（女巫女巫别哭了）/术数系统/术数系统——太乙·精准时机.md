# 术数系统——太乙·精准时机

> **认知框架：精准时机。** 太乙神数不是"放技能"——是"赌一个窗口"。4.5秒内输入3/5/9键零失误。成功=全场逆转。失败=卦气减半。这个术数奖励的不是操作多——是你在压力下能不能稳住。
> **核心问题："就是现在——出手！"** → 识别窗口·按序列·零失误。
> **最出彩时刻：** 9键零失误·全屏时停·敌人的血条在你按下最后一个键之前就开始崩了——因为命运已经决定了。

---

## 一、你"看到"的战场

```
装备"太乙神数"术数（占用1槽）后：

激活条件：卦气≥30（3键）/ 50（5键）/ 90（9键）
激活操作：按住右键 + 双击Tab

进入太乙模式：
  屏幕边缘出现金色边框·微微脉动
  敌人速度降到20%（不是暂停·是极慢）
  屏幕中央出现按键序列（3/5/9键·随机生成）
  4.5秒倒计时开始
  你需要：看完序列·记住·输入·零失误
```

## 二、三级效果

| 等级 | 键数 | 解锁 | 成功效果 | 失败效果 |
|:--:|:--:|------|------|------|
| Lv1 | 3键 | 鹑火宫 | 全场眩晕4s+伤害×2·15s | 卦气-30（退回触发前） |
| Lv2 | 5键 | 鹑尾宫 | 全场眩晕4s+伤害×2.5+奇门阵法刷新 | 卦气保留50%+30s冷却 |
| Lv3 | 9键 | 大火宫 | HP<30%即死 / 否则伤害×3.5+全冷却刷新 | 卦气保留50%+HP归1（不致死） |

## 三、为什么失败不是"惩罚"——是"选择"

```
传统动作游戏的"大招"设计问题：
  风险太高→玩家永远不用→大招变成摆设。

太乙神数的设计：
  失败=卦气保留50%+冷却30s（Lv2/3）
  → 你还有半管卦气·你可以继续战斗
  → 代价是真实的——但不足以让你"永远不用"
  → 你愿意尝试·因为"万一成功了呢"
  
  Lv3 9键·失败=HP归1但不致死
  → 你赌了·输了·还剩一口气
  → 你接下来必须完美闪避·没有容错率
  → 赌输了不是"重来"——是"接下来更难"——但你还活着
```

## 四、思维模式

```
太乙玩家："我不布阵。不看天地盘。不站太极眼。

          我只需要一件事——
          在正确的0.5秒·按下正确的9个键。
          
          前方是焦烈的白焰全屏。
          我没有时间闪避了。
          但我有4.5秒——比他的白焰覆盖全屏的时间多1.5秒。
          
          右键+Tab。
          9键序列出现。
          倒计时开始。
          
          一·二·三·四·五·六·七·八·九。
          
          白焰吞没全屏——
          但太乙神数在白焰之前0.3秒触发了。
          
          全屏时停。
          焦烈的火焰被冻结在半空中。
          我的最后一键落下。
          
          不是'我打败了焦烈'——
          是'我在他的火焰吞没我之前的一瞬间·按下了正确的键'。"
```

## 五、与其他术数的搭配

| 搭配 | 效果 |
|------|------|
| +六爻 | 太乙成功=立即写入2条爻线·加速卦阵 |
| +奇门 | 太乙成功=所有阵法冷却刷新 |
| +紫微 | 化忌在命宫→太乙失败惩罚翻倍·但成功伤害×4（双倍赌注） |
| +大六壬 | 天地盘可以预测"最佳太乙窗口"——初传位置=安全窗口出现时间 |

## 六、为什么有人选这个

```
太乙玩家："我不想知道敌人的弱点。不想布阵。不想看天地盘。

          给我一个窗口。给我九个键。
          赌我能不能在4.5秒内按对。
          
          如果对了——命运站在我这边。
          如果错了——我还活着·再来一次。
          
          太乙不是术数——是赌注。
          赌的不是'Build对不对'——赌的是'我能不能在压力下稳住'。"
```
