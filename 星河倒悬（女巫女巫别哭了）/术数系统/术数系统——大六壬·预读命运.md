# 术数系统——大六壬·预读命运

> **认知框架：预读命运。** 大六壬是所有数术中体系最庞大的——天地盘·十二天将·十二地支·四课三传。战场上双层盘在旋转。你的工作不是"反应"——是"预读"。天地盘告诉你BOSS接下来要做什么。你提前站在安全位上。BOSS打空。
> **核心问题："初传在申·中传在午·末传在辰——BOSS的攻击路线是这条。"** → 看天地盘·读三传·提前走位。
> **最出彩时刻：** 四课三传重新排盘——初传=白虎在申=BOSS三秒后冲锋——你已经站在申位对面——中传=青龙在午=冲锋后BOSS露出破绽——你已经在午位——末传=天空在辰=破绽后·虚无·你必须在辰位收手。三个位置·三秒·一秒不差。你不需要闪避——因为你在BOSS出招之前就不在那里了。

## 一、你"看到"的战场

```
装备"大六壬"术数（占用2槽·最复杂）后：

道宫地面出现双层旋转盘（直径约24m）：

天盘（上层·12天将·顺时针旋转·30秒/格）：
  贵人·螣蛇·朱雀·六合·勾陈·青龙
  天空·白虎·太常·玄武·太阴·天后

地盘（下层·12地支·固定）：
  子·丑·寅·卯·辰·巳·午·未·申·酉·戌·亥

天地盘组合=144种天将×地支组合。
站在不同的组合位上=不同效果。
```

## 二、四课三传

这是大六壬的核心排盘——战斗中的"预言系统"：

```
四课（BOSS信息）：
  第一课：BOSS当前的攻击计划（接下来3秒）
  第二课：BOSS的弱点位置
  第三课：BOSS的下一个行动（3-10秒后）
  第四课：BOSS的终极技能预告

三传（你的行动指引）：
  初传：你该做的第一件事（位置/动作）
  中传：第二步
  末传：最终步

四课三传每约60秒重新排盘一次（天地盘旋转到新位置）。
排盘时——屏幕中央浮现短暂的"盘局"（3秒·可跳过）。
```

## 三、三传追踪

```
三传在小地图上显示为三个标记点（初=金色·中=蓝色·末=紫色）。

完成初传=移动到初传标记位置→标记变为✓→卦气+15
完成中传=移动到中传标记位置→✓→下一个卦术必定暴击
完成末传=移动到末传标记位置→✓→BOSS的一课被"打破"·效果根据打破了哪一课：
  - 打破第一课=打断BOSS当前技能
  - 打破第二课=BOSS弱点暴露·暴击率+30%·10s
  - 打破第三课=BOSS的下一个行动取消
  - 打破第四课=BOSS的终极技能被沉默30s

三传不需要"完美顺序"——可以只完成初传和中传·不完成末传。
但完成全部三传=四课全破=BOSS进入"天命已尽"状态·全属性-50%·持续20s。
```

## 四、天将×地支组合效果（部分）

BOSS房内·天地盘每30秒转一格。转盘前的5秒和转盘后的战斗完全不同。

| 组合 | 效果 |
|------|------|
| 白虎+申 | 白虎主杀+申=金·站在此位=伤害×3·但自身也受50%额外伤害 |
| 青龙+辰 | 青龙主吉+辰=土·站在此位=卦气恢复×3 |
| 玄武+亥 | 玄武主暗+亥=水·站在此位=隐身·不被锁定 |
| 贵人+子 | 贵人主贵+子=水·站在此位=全队无敌5s（每场战斗仅一次） |
| 天空+戌 | 天空主虚无+戌=土·站在此位=不受任何地面效果影响 |

## 五、思维模式

```
大六壬玩家："我的闪避键不是空格。是天地盘。

          天地盘在转。30秒一格。现在白虎在申位。
          申位在哪？西南方。
          
          四课三传排盘了：
          初传→申。初传=我应该站的位置=申位。
          但白虎在申——伤害×3但我也承受50%额外伤害。
          这是命运在说：站在申位·全力一击·但你必须扛住。
          
          中传→午。午位是青龙——吉位·卦气恢复×3。
          末传→辰。天空在辰——虚无·不受地面效果影响。
          
          所以我的路线是：
          申（高风险高回报·全力一击）→
          午（恢复·卦气回满）→
          辰（安全·准备下一轮）。
          
          我没看BOSS的血条。没看自己的卦气。
          我只看天地盘。
          
          命运告诉我下一步在哪里。
          我的工作——是走到那里。"
```
