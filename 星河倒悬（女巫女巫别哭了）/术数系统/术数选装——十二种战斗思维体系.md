# 术数选装——十二种战斗思维体系

> **不是"Build多样性"。是"思维体系的多样性"。**
> 奇门玩家在用棋盘理解战场。大六壬玩家在用钟表理解战场。五音玩家在用乐器理解战场。
> 同一个BOSS·不同术数系统=不同的战斗画面。这就是分享卦码的意义——分享的不是配置·是"我怎么想的"。

---

## 一、核心理念

### 1.1 术数不是buff——是"看战场的方式"

```
传统设计：
  装备"火系精通"→火属性伤害+20%
  装备"冰冻强化"→冰冻时间+50%
  → 这是数值·不是思维

选装设计：
  装备"太极"→你看到战场上阴阳在流转·你在等待翻转的时机
  装备"大六壬"→你看到天地盘在旋转·你在预读BOSS的下一步
  装备"五音"→你看到石板在发光·你踩着节拍跳舞
  → 同一个人·同一个BOSS·换一个术数系统=换了一种理解战斗的方式
```

### 1.2 十二种术数 = 十二种认知框架

| 术数 | 认知框架 | 核心问题 | 时间感 | 空间感 | 操作感 |
|------|------|------|:--:|:--:|:--:|
| **小六壬** | 掌诀直觉 | "现在是什么情况？" | 瞬间 | 6方向 | 甩鼠标 |
| **太极** | 辩证翻转 | "阴阳什么时候转化？" | 流动 | 太极图 | 站眼翻转 |
| **五行** | 关系连锁 | "火生土·土生金·金克什么？" | 中等 | 五区域 | 走位引连锁 |
| **八卦** | 空间位置 | "我站离位·面向谁？" | 静态 | 八卦图 | 占位·推敌 |
| **三爻归真** | 辨伪求真 | "这个卦是真的还是假的？" | 反应 | 卦盘UI | 识别替换 |
| **奇门遁甲** | 多层战略 | "休门在哪个宫？" | 长线·30s/局 | 九宫格 | 拖拽布阵 |
| **六爻纳甲** | 叙事因果 | "我在写一个什么故事？" | 整场战斗 | 爻线上方 | 动作写爻 |
| **紫微斗数** | 自知之明 | "我的化忌在哪里？" | 全局·不变 | 命盘地面 | 规避化忌位 |
| **太乙神数** | 精准时机 | "就是现在——出手！" | 4.5秒赌注 | 键位 | 按键序列 |
| **五音十二律** | 节奏共鸣 | "BOSS用徵音·我站角音。" | 音乐节拍 | 音律石板 | 踩石发音 |
| **大六壬** | 预读命运 | "初传在申·下一步在午。" | 60秒轮回 | 双层旋转盘 | 读盘追踪 |
| **天道归一** | 万物一体 | "奇门+六爻+紫微——三者重叠。" | 所有 | 所有 | 综合 |

### 1.3 思维多样性的四个维度

八种术数不是八种"打法"——是**四种认知维度的不同组合**：

| 维度 | 极端一 | 极端二 |
|------|------|------|
| **时间** | 小六壬=瞬间直觉 | 奇门遁甲=30秒长远布局 |
| **空间** | 八卦=微观·1m级站位 | 大六壬=宏观·整场旋转 |
| **风险** | 紫微斗数=认知自己·顺势 | 太乙神数=赌4.5秒·逆天 |
| **信息** | 小六壬=6个选项 | 六爻纳甲=六爻×六亲×六兽=复杂网络 |

**每个玩家可以在每个维度上找到自己舒服的位置。** 这就是"她觉得大六壬好·他觉得奇门好"的根源——不是哪个强·是哪个符合她的思维方式。

## 二、思维之间如何平衡

### 2.1 不是DPS平衡——是"出彩方式"平衡

| 术数 | 最出彩的时刻 | 你会在什么时候觉得"这个系统太棒了" |
|------|------|------|
| 小六壬 | 0.3秒·贴脸·肌肉记忆甩出完美空亡躲大招 | 你需要的不是思考·是反应 |
| 太极 | 全场阴阳翻转·BOSS站在阳区被你翻成阴区·傻眼 | 你看懂了"物极必反" |
| 五行 | 一个火卦连锁引爆了全场五行·五个敌人同时被各自的克星命中 | 你看到了关系网 |
| 八卦 | 把BOSS一步步推进兑位·然后放兑卦·混乱·BOSS打自己 | 你控制了空间 |
| 三爻归真 | 三爻全归真·伪卦BOSS崩了·"去伪存真"大字浮现 | 你识别了谎言 |
| 奇门遁甲 | 休门+生门+开门三重叠·全队无敌+双倍伤害+净化 | 你布了一个完美的局 |
| 六爻纳甲 | 六爻全·卦阵激活·你亲手"写"出来的卦象改变战场规则 | 你创造了一个故事 |
| 紫微斗数 | 你的化忌在财帛·你知道这场不能耗——速战速决·赢了 | 你认识你自己 |
| 太乙神数 | 9键零失误·全屏时停·敌人血条直接清空 | 你赌赢了 |
| 五音十二律 | 踩石板刚好和BOSS的音攻形成和声——BOSS被自己的音震晕 | 你听懂了音乐 |
| 大六壬 | 天地盘告诉你BOSS的下一个动作——你提前站在了安全位·BOSS打空 | 你预读了命运 |
| 天道归一 | 全部术数同时生效·你在三个系统的交点上打出了终极一击 | 你理解了一切 |

### 2.2 术数之间的互斥与兼容

**3个槽位的选择规则：**

| 规则 | 说明 |
|------|------|
| **互斥** | 六爻纳甲(2槽)和大六壬(2槽)不能同时装备·两者都太强 |
| **互补** | 太极(1槽)+五行(1槽)=阴阳生克·翻转触发连锁 |
| **增强** | 八卦(1槽)+奇门(1槽)=八卦占场上的九宫阵法·空间叠加 |
| **无关** | 紫微(1槽)+太乙(1槽)=自我认知+精准时机·不互相影响 |

## 三、分享的不是Build——是"我怎么想的"

### 3.1 卦码携带的不只是配置

```
卦码 = 装备配置 + 术数选择 + 思维注解

作者备注（社区可见·120字以内）：
  "太极不是'等翻转'——是'引发翻转'。
   你站在阳中阴眼上3秒=全屏翻转。
   我的理解是：在BOSS站阳区(高伤害)的时候翻转→把他翻到阴区(低伤害+自己受伤害+40%)
   →他从'输出状态'变成'被输出状态'。
   太极不是防御术数——是进攻术数。"
```

```

  适合： [焦烈战▼] [速刷▼] ...

  🔥 奇门·休生开三重叠     👍3,241  作者：阵法师
```

## 四、设计约束

### 4.1 每个术数系统必须满足

- [ ] 有独特的"认知框架"（不只是独特的buff）
- [ ] 改变玩家"看战场"的方式（视觉或信息或规则）
- [ ] 有专属的"最出彩时刻"
- [ ] 即使不装备·大世界战斗依然完整（术数=道宫内才发光）
- [ ] 玩家可以理解"为什么别人喜欢这个系统"（即使自己不用）
