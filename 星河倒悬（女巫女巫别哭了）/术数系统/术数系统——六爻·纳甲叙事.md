# 术数系统——六爻·纳甲叙事

> **认知框架：叙事因果。** 每一场战斗都是一个正在被"书写"的卦象。你的每一个动作——普攻、卦术命中、闪避、切法器——都在写入一条爻线。六条爻线写满=卦阵从天而降=战场规则改变。你在写一个故事·故事的高潮是卦阵激活的那一刻。
> **核心问题："我在写一个什么故事？"** → 每一次有意义的行动都在推进叙事。
> **最出彩时刻：** 六爻全亮·卦阵激活——䷾水火既济·卦符从虚空轰入战场·卦辞在战场上空浮现·"初吉终乱·柔得中也"——整个战场变成你的卦阵·规则改写。

---

## 一、你"看到"的战场

```
装备"六爻纳甲"术数（占用2槽·因为太强）后：

战场上方悬浮着六条爻线（屏幕上方·水平排列·半透明）：
  ═══ 上爻 (灰色虚线·未定)
  ═══ 五爻 (未定)
  ═══ 四爻 (未定)
  ═══ 三爻 (未定)
  ═══ 二爻 (未定)
  ═══ 初爻 (未定)

每条爻被写入时→灰色变金色(阳⚊)或蓝色(阴⚋)·坠落动画·光波扩散。

爻线上还有"纳甲"信息（小字标注）：
  - 六亲标签：父母·兄弟·官鬼·妻财·子孙
  - 六兽标签：青龙·朱雀·勾陈·螣蛇·白虎·玄武
  - 世爻标记：哪一爻代表你
  - 应爻标记：哪一爻代表BOSS
```

## 二、爻线写入规则

| 动作 | 写哪爻 | 阴阳 | 说明 |
|------|:--:|:--:|------|
| 普攻连段完成 | 初爻 | 阳 | "第一击·根基" |
| 卦术命中 | 二爻 | 卦术属性定 | 火雷天=阳·水地山=阴 |
| 闪避成功 | 三爻 | 阳 | "动在腰腹" |
| 切法器连携 | 四爻 | 切换方向定 | 银针→桃木=阳·桃木→银针=阴 |
| 同伴技能触发 | 五爻 | 阳 | "君位·同伴即力量" |
| 被击中/格挡 | 上爻 | 被=阴·挡=阳 | "天命" |

## 三、六爻完整——卦阵激活

六爻全部写入后·约2.5秒演出：
- 六爻从屏幕上方坠落至地面·化作卦符投影（8m直径）
- 卦名浮现（甲骨文→金文→隶书→简体）
- 卦辞文字漂浮
- 卦阵效果激活·持续15-25秒
- 卦阵结束后六爻重置·新一轮书写

## 四、六亲和六兽

每条爻写入时随机分配六亲+六兽（按传统纳甲规则·不是真随机·但玩家体感是"命运的分配"）：

| 六亲 | 若为世爻（辰生） | 若为应爻（BOSS） |
|------|------|------|
| 父母 | 护盾×2·治疗+50% | BOSS防御翻倍 |
| 兄弟 | 同伴伤害×2 | BOSS召唤小怪加强 |
| 官鬼 | 对BOSS伤害+40% | BOSS攻击+40% |
| 妻财 | 卦气消耗-50% | BOSS掉落翻倍（战后） |
| 子孙 | 暴击率+20%·闪避+5帧 | BOSS暴击率+20% |

| 六兽 | 该爻释放卦术时 |
|------|------|
| 青龙(5爻) | 额外伤害50%ATK |
| 朱雀(3爻) | 留下火区3s |
| 勾陈(2爻) | 3秒霸体 |
| 螣蛇(初爻) | 附带恐惧 |
| 白虎(上爻) | 伤害+50%·自伤5%HP |
| 玄武(4爻) | 隐身2s |

**六爻全写入后·卦阵效果=∑(卦象基础效果+六亲分布+六兽分布)。没有两场完全相同的卦阵。**

## 五、卦vs卦（BOSS也有六爻）

BOSS同时书写自己的伪六爻。两方六爻完成→卦vs卦对决：
- 辰生卦克BOSS卦→BOSS卦崩·全属性-30%
- BOSS卦克辰生卦→全场AOE·需闪避
- 比和→双方卦阵同时激活·硬碰硬

## 六、变爻

崩解·BOSS阶段转换·太乙神数成功→已写入的爻被翻转→卦变了→卦阵变了。
战斗中卦阵可能变化1-2次·不可预测。

## 七、思维模式

```
六爻玩家："我不是在打怪。我是在写故事。

         初爻·青龙·妻财 —— 开局顺利·资源充沛。
         二爻·勾陈·官鬼 —— 遭遇强敌·正面交锋。
         三爻·朱雀·子孙 —— 闪避中反击·灵光一闪。
         四爻·玄武·兄弟 —— 法器切换·同伴出击。
         五爻·白虎·妻财 —— 君位决战·全力一击。
         上爻·螣蛇·父母 —— 天命垂怜·卦阵降临。

         六条爻串起来——䷾水火既济。
         卦辞说：'初吉终乱·柔得中也。'
         
         前8秒·双倍伤害。
         后8秒·反噬自身。
         
         我知道这个故事怎么结束。
         我必须在8秒内解决战斗。
         
         这不是'连招'——这是'叙事'。"
```

## 八、为什么有人选这个

```
六爻玩家："卦不是技能。卦是故事的章节。
          每一场战斗结束·我回头看那六条爻——
          那就是这场战斗的'卦辞'。
          
          青龙在初爻·白虎在上爻。
          始于祥瑞·终于暴烈。
          
          我没有'选择这个Build'——我'活出了这个卦'。"
```
