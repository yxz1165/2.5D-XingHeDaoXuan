# 术数系统——八卦·空间占场

> **认知框架：空间位置。** 战场不是空白的——是八卦。站在离位=火的力量加持。把敌人推进兑位=混乱。把BOSS推进死门=终结。
> **核心问题："我站在哪里？敌人在哪里？我要把他推到哪里？"** → 站对位置·放卦·击退·连锁。
> **最出彩时刻：** BOSS从乾位→被你的震卦击退→滑到兑位→你立刻切兑卦释放→混乱触发→BOSS转身砍了自己的召唤物。你没打他。他打了他自己。你只是站对了位置。

---

## 一、你"看到"的战场

```
装备"八卦"术数（占用1槽）后：

道宫内的战场地面出现后天八卦图（直径约20m·大世界不显示）。
  八个卦位按后天八卦排列·每个卦位是一个直径3m的发光区域。

卦位效果：
  离☲(南·火) — 站此位放火卦=伤害×1.5
  坎☵(北·水) — 站此位放水卦=冻结时间翻倍
  震☳(东·雷) — 站此位放雷卦=击退距离×2
  兑☱(西·泽) — 站此位放泽卦=混乱时间翻倍
  乾☰(西北·天) — 站此位放天卦=击飞高度×2
  坤☷(西南·地) — 站此位放地卦=护盾×2
  艮☶(东北·山) — 站此位放山卦=定身时间翻倍
  巽☴(东南·风) — 站此位放风卦=穿透·无视防御
  中宫 — 卦气恢复×2·无卦位加成

注意：站在不对应的卦位放卦——无加成。
     站在相冲的卦位放卦（如：站在离位放坎卦=火vs水）
     → 卦术反噬·自身受伤10%HP·卦气-20。
```

## 二、卦位不只加成——还可以"推人"

```
八卦不是只有"站上去"——还有"把敌人推进去"。

  敌人站在乾位（天=击飞×2）→
  你用震卦（雷=击退最大的卦）打他→
  他被击退→飞进了兑位（泽=混乱）→
  触地的一瞬间·兑卦的光环亮起→他被混乱→转身攻击最近的敌人

这是八卦的核心战术：不是"打伤害"——是"打位置"。
```

## 三、卦位之间的连线

```
两条连线有特殊效果：
  
  离位↔坎位（火↔水·南北中轴）：
    站在这条线上放卦→触发"水火既济"→吸血15%
  
  震位↔兑位（雷↔泽·东西中轴）：
    站在这条线上放卦→触发"雷泽归妹"→同伴伤害+30%

两个卦位连线的中点（精确位置·约1m直径的圆形区域）：
    站在这上面放卦→"双卦共鸣"→伤害×3
```

## 四、思维模式

八卦玩家眼中的战斗是**棋盘**：

```
"焦烈站在乾位（天）。他用白焰·我用离卦（火）。
 火克金（离火克乾金）——我在克制位打他·伤害×1.5。

 但他每30秒会冲锋·从乾位冲到坤位（地）。
 坤位=护盾×2。他在坤位时特别硬。

 所以我的节奏是：
   他在乾位→我站离位·疯狂输出。
   他冲锋→我切震卦·在他冲到坤位的路上打他。
   他被击退到兑位→混乱·他自己打自己。
   然后我回到离位·等他下一轮。"

这不是'打BOSS'——是'在棋盘上推棋子'。
```

## 六、为什么有人选这个

```
八卦玩家："给我一张地图。给我八个位置。
          我不需要最强的卦——我需要最对的位置。
          BOSS很强·但他站在错误的位置上。
          我的工作就是——把他推到正确的位置。"
```

八卦奖励的是**空间思维**。你关心的是"谁在哪里"——位置对了·剩下的卦术自然生效。
