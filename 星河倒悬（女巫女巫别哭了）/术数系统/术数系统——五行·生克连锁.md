# 术数系统——五行·生克连锁

> **认知框架：关系连锁。** 万物不是孤立的——你放出的每一个卦都在关系网中激起涟漪。火生土·土生金·金克木——你打中了一个敌人·五个敌人同时受影响。
> **核心问题："火生土·土生金·金克什么？"** → 放一个卦·连锁反应自动传播。
> **最出彩时刻：** 一个离卦打在火属性敌人身上——火生土·连锁到旁边的土属性敌人——土生金·连锁到金属性敌人——金克木·连锁到木属性BOSS——四个连锁同时跳伤害数字。全场都在燃烧。

---

## 一、你"看到"的战场

```
装备"五行"术数（占用1槽）后：

敌人头顶出现五行标记（金水木火土·对应颜色）。
战场地面可能出现五行区域（仅道宫内部）。

关键视觉：
  放卦命中敌人 → 一道光从被命中的敌人身上射出
  → 沿着地面飞向另一个敌人
  → 颜色按五行相生的顺序变化（火=红·土=黄·金=白·水=蓝·木=绿）
  → 连锁最多跳3次·每次伤害递减30%
```

## 二、五行生克规则

### 2.1 相生连锁（火→土→金→水→木→火）

```
用火卦命中火属性敌人：
  → 火生土 → 连锁到最近的土属性敌人·造成火卦伤害×0.7
  → 土生金 → 连锁到最近的金属性敌人·伤害×0.49
  → 金生水 → 连锁到最近的水属性敌人·伤害×0.34
  → 三次连锁完成·总共伤害=1.0+0.7+0.49+0.34=2.53倍的单卦伤害

但如果战场上没有土属性敌人：
  → 连锁中断·只打了一个
```

### 2.2 相克爆发（火→金·金→木·木→土·土→水·水→火）

```
用火卦命中金属性敌人：
  → 火克金 → 触发"相克爆发"
  → 对该敌人的伤害×1.5
  → 连锁不继续（相克是终点·不是起点）
  → 但对克制目标有额外效果：火克金=破甲·金克木=打断·木克土=破盾·土克水=定身·水克火=冻结
```

### 2.3 敌人五行属性

| 敌人类型 | 典型五行 |
|------|:--:|
| 冰原狼·冰牙狼王 | 水 |
| 太史学徒·守卫·校尉 | 火（白焰=伪火·被真火克） |
| 海溟暗卫 | 水·金 |
| 焦烈 | 火（伪火）→阶段三·真火被唤醒 |
| 林青黛 | 木 |
| 卫重·五毒阵 | 五行各一 |

## 三、思维模式

五行玩家眼中的战斗是一个**关系网**：

```
"太史学徒是火属性·守卫是金属性·副官是火属性。

 我用离卦打学徒（火克火=无克制·标准伤害）→
 但是！火生土——连锁跳到了旁边那块土属性的地面区域→
 土生金——连锁跳到了太史守卫（金属性）→
 金克木——如果我此时切巽卦（木）打守卫→克制爆发×1.5！

 这不是'先打谁'的问题——是'谁和谁有生克关系'的问题。"
```

五行玩家不只是打敌人——他们在**编织关系网**。最优的攻击顺序不是"先打最弱的"——是"先打能连锁到最多的"。

---

## 四、五行区域（道宫内）

部分道宫（娵訾宫等）地面有五行区域。站在上面改变效果：

| 区域 | 站在上面时 |
|------|------|
| 火区 | 火卦伤害+30%·自身持续灼烧 |
| 水区 | 水卦迟缓翻倍·自身移速-20% |
| 木区 | 木卦DOT×2·自身卦气恢复-50% |
| 金区 | 金卦暴击+30%·自身防御-30% |
| 土区 | 土卦护盾×2·自身攻速-30% |

**五行区域可以被"污染"——敌人死后在该区域留下尸骸·区域属性随机改变。**

## 六、为什么有人选这个

```
五行玩家："八卦是空间。五行是关系。
          我不需要站在正确的位置——我需要打正确的人。
          一个卦·五个数字跳出来。
          全场都在燃烧·因为我看到了他们之间的连线。"
```

五行奖励的是**关系思维**。你不需要操作最快——你需要理解金水木火土之间的生克网络。打对了起点·连锁会替你做剩下的。
