# 术数系统——三爻·辨伪归真

> **认知框架：辨伪求真。** 太史阁的卦不是真的——是被西陆用化史炉篡改过的伪卦。你能看到伪卦在卦盘上是红色的、有裂痕的。归真它——用正确的卦替换被篡改的卦。三爻全归真=去伪存真=伪卦敌人崩溃。
> **核心问题："这个卦是真的还是假的？"** → 识别红色的伪卦位·消耗卦气归真。
> **最出彩时刻：** 太史阁老的卦盘上有三个红色伪卦位——你一爻归真·二爻归真·三爻归真——"去伪存真"四个大字浮现。全场伪卦敌人全属性-30%。你用的不是更强的卦——是真实的卦。真相本身就是武器。

---

## 一、你"看到"的战场

```
装备"三爻归真"术数（占用1槽）后：

遇到太史阁卦师类敌人时：
  → 按住右键·八卦光环展开
  → 光环上·某些卦位是红色的·有裂痕·微微抖动
    （正常卦位=各自颜色·稳定·完整）
  → 敌人的伪卦位·就是红色的那些

鼠标移到红色卦位→光环上弹出辨伪窗口（2.5秒）：
  ┌──────────────────────────┐
  │ 伪卦·离☲（被篡改）       │
  │ 显示：火在上·光明普照     │
  │ 真义：火被水压·光明囚禁   │
  │                          │
  │ [1] 归真·卦气-15         │
  └──────────────────────────┘

按1确认→卦位从红色变为金色→卦位裂纹愈合→
敌人该卦位的伪卦技能被"反噬"（伤害反弹+眩晕2s）
```

## 二、归真效果

| 归真数 | 效果 |
|:--:|------|
| 1爻归真 | 敌人该伪卦技能失效+反噬伤害100%ATK |
| 2爻归真 | 反噬范围扩至周围5m·该类型伪卦伤害-25%·30s |
| 3爻归真 | **"去伪存真"触发**·全场伪卦敌人全属性-30%·所有真卦伤害+25%·持续30s |

## 三、思维模式

```
三爻归真玩家："八卦不是拿来打人的。
                八卦是一面镜子——映照出什么东西是假的。
                太史阁把离卦的'火'篡改成'白焰'。
                我做的不是'用更大的火打败他的白焰'。
                我做的是——指出他的火不是真的。
                
                归真不是攻击。
                归真是——让被篡改的东西恢复原貌。
                
                伪卦不是假的能量——是被西陆强行扭曲的真卦。
                归真的瞬间·真卦自己会反噬。"
```

## 四、敌人伪卦配置

| 敌人 | 伪卦数 | 分布 |
|------|:--:|------|
| 太史学徒 | 1 | 随机上卦位 |
| 太史卦师 | 2 | 1上卦+1下卦 |
| 太史阁老 | 3 | 2上卦+1下卦·每30s随机变化 |
| BOSS（闫序等） | 3-4 | 随时间轮转 |

## 五、与其他术数的搭配

| 搭配 | 效果 |
|------|------|
| +六爻纳甲 | 归真一爻=同时写入一爻（加速卦阵） |
| +太极 | 归真时·太极图微闪·被归真的卦位附近的阴阳区变色 |
| +紫微 | 化忌所在的宫位如果有伪卦——归真难度×2·但归真成功后伤害加成翻倍 |
