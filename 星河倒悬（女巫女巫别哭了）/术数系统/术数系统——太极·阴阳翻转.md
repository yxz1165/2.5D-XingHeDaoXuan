# 术数系统——太极·阴阳翻转

> **认知框架：辩证翻转。** 阴阳不是两种状态——是同一个东西在旋转。阳到了极点就是阴。弱到了极点就是强。看懂了太极图·就看懂了战场。
> **核心问题："阴阳什么时候转化？"** → 站到太极眼上·三秒·翻转。
> **最出彩时刻：** BOSS站在阳区疯狂输出——你站在阴眼上·三·二·一·全场翻转。阳变阴。BOSS从+40%伤害变成-30%伤害+受伤害+40%。他的优势变成了他的陷阱。他还没反应过来。

---

## 一、你"看到"的战场

```
装备"太极"术数（占用1槽）后：

战场上出现太极图（只在道宫内部显示·大世界不显示）。
  白色区域（阳）·黑色区域（阴）·缓缓顺时针旋转。
  阳中阴眼 = 白鱼中一个黑色圆点（直径3m）
  阴中阳眼 = 黑鱼中一个白色圆点（直径3m）

站在阳区：伤害+40%·受到伤害+40%
站在阴区：伤害-30%·受到伤害-30%
站在阳中阴眼3秒：全场阴阳翻转·阳变阴·阴变阳
站在阴中阳眼3秒：全场阴阳翻转·阴变阳·阳变阴

太极图旋转一周约60秒。
```

## 二、翻转的战术含义

```
翻转前：                翻转后：
  阳区=高输出高风险       阳区变成阴区=低输出高防御
  阴区=低输出高防御       阴区变成阳区=高输出高风险
  BOSS在阳区虐你          BOSS突然发现自己站在阴区
  你在阴区苟活            你发现自己站在阳区

这不是数值buff——是"局面颠覆"。
翻转不会造成伤害。
翻转改变的是"谁在有利位置·谁在不利位置"。
```

## 三、思维模式

太极玩家眼中的战斗是一个**呼吸的太极图**：

```
"BOSS冲过来——他进入了阳区。伤害很高·我得闪开。
 但他站在阳区上的时间越长·阳气越盛·阳极生阴。
 我绕到阳中阴眼——开始数：一、二、三。
 翻转。
 BOSS还在出招——但他脚下的阳区已经变成阴区了。
 他伤害掉了一截·他自己还没发现。
 现在轮到我了。"

太极玩家不是"反应快"——是"看懂了流动"。
他们在等——不是等BOSS露出破绽·是等阴阳自己翻转。
```

## 四、翻转的代价和限制

| 限制 | 说明 |
|------|------|
| 站眼3秒 | 站在太极眼上3秒才能触发·期间不能攻击·可以慢走 |
| 冷却 | 每次翻转后30秒冷却·不能连续翻转 |
| 可被打断 | 站眼期间被BOSS重击→打断·翻转不触发·冷却减半 |
| BOSS也能站眼 | 如果BOSS站到另一个太极眼上3秒→BOSS也可以翻转·把你的阳区翻走 |

## 五、与其他术数的搭配

| 搭配 | 效果 |
|------|------|
| +五行 | 翻转触发时·五行区域全部逆生（火区变水区·金区变木区） |
| +八卦 | 翻转时八卦方位旋转180°·离位变坎位·所有卦位颠倒 |
| +小六壬 | 翻转时·掌诀位的吉凶全部反转 |
| +紫微 | 翻转时·化禄化忌互换（化忌变化禄·短暂的好运） |

## 六、为什么有人选这个

```
太极玩家："我不需要最锋利的剑。
          我只需要在正确的时间·站在正确的位置。
          等三秒。
          然后——万物翻转。"
```

太极不是防御术数。不是进攻术数。太极是**时机术数**。它奖励的不是操作快——是**看懂了阴阳什么时候到极点**。
