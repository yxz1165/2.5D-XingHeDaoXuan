# 术数系统——奇门·多层战略

> **认知框架：多层战略。** 战场不是一层——是四层。天盘的八门在转·地盘的九宫固定·人盘是你和敌人的站位·神盘随剧情觉醒。四层叠加=无数种组合。你的工作是——在正确的时间·把阵法放在正确的位置。
> **核心问题："休门在哪个宫？"** → 看天盘旋转·等休门到位·布阵。
> **最出彩时刻：** 休门+生门+开门三重叠加在同一个九宫格——全队无敌+双倍伤害+净化——三道光柱从地面升起——这是你三十分钟前就预设在星碑处的阵法。你不是在"战斗"——你是在"收网"。

---

## 一、你"看到"的战场

```
装备"奇门遁甲"术数（占用1槽）后：

道宫内的战场地面出现九宫格（洛书九宫·约15m×15m·大世界不显示）。

天盘·八门（每45秒顺时针移一格）：
  休门·生门·伤门·杜门·景门·死门·惊门·开门
  每个门给它所在的宫位一个效果。

地盘·九宫（固定）：
  坎一(水)·坤二(土)·震三(木)·巽四(木)·中五(土)
  乾六(金)·兑七(金)·艮八(土)·离九(火)

人盘·你和敌人：
  谁站在哪个宫=谁受那个宫+门的双重效果

神盘·八神（随道宫进度解锁）：
  值符·螣蛇·太阴·六合·白虎·玄武·九地·九天
  每位神给所在宫位额外效果
```

## 二、八门效果

| 门 | 效果 |
|------|------|
| **休门** | 阵内友方每秒回复2%生命 |
| **生门** | 阵内友方伤害+25% |
| **伤门** | 阵内敌方每秒受5%ATK伤害 |
| **杜门** | 阵内敌方移速-40%·无法闪避 |
| **景门** | 阵内敌方隐形可见·暴击伤害+50% |
| **死门** | 敌方进入受高额伤害·HP<30%即死 |
| **惊门** | 敌方恐惧2秒·乱跑不可控 |
| **开门** | 友方进阵清除debuff+3秒无敌 |

## 三、思维模式

```
奇门玩家的战斗不是"即时反应"——是"长远布局"：

"我在星碑处预设了三套阵法。
 阵法1：休门+生门+开门=全队续航+输出+无敌
 阵法2：死门+伤门+景门=对BOSS极限输出
 阵法3：杜门+惊门=控制·清杂兵

 现在进入BOSS房。
 天盘的休门在艮宫·生门在中宫·开门在离宫。
 三者不重叠——今天不是阵法1的日子。
 
 但死门在震宫·伤门在坤宫·景门在兑宫。
 三者呈三角形——我在三角形的重心放阵法2。
 
 BOSS走位进入了阵法范围。
 死门触发·伤门触发·景门触发。
 BOSS被高额伤害+每秒DOT+暴击×1.5围攻。
 
 这不是'我操作好'。
 这是'我在正确的时间·把阵法放在了正确的位置'。"
```

## 四、预设阵法（非战斗配置）

星碑/落星村 → 打开奇门编辑器 → 在九宫格上拖拽八门 → 保存为预设：

```
预设最多3个。战斗中按Ctrl+1/2/3→选预设→鼠标选放置位置→松手布阵。

和原来"战中临时选八门位置"比起来：
  战中只需1-2秒（选预设+放位置）
  原来需要3-5秒（选宫位+选门+位置）
  → 效率翻倍·实用度大幅提升
```

## 五、与其他术数的搭配

|------|------|
| +八卦 | 八卦方位和九宫格叠加·卦位+八门=64种组合 |
| +六爻 | 卦阵激活时·阵法范围内的六爻写入速度×2 |
| +太乙 | 太乙神数成功→所有阵法冷却刷新 |

## 六、为什么有人选这个

```
奇门玩家："我不是在打架。我是在下棋。
          每一场BOSS战·进门前我先看天盘。
          今天的休门在哪里？生门在哪里？
          然后我决定——带哪三套阵法。
          
          进战斗之后·我的工作不是'输出'——
          是'把BOSS引到我在三个小时前就预设好的陷阱里'。"
```
