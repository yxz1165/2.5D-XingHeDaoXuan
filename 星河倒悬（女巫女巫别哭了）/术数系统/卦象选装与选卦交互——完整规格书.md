# 卦象选装与选卦交互——完整规格书

> **核心创新：卦不是"学会了就有"的被动技能——卦是选装的。** 像装备一样选择哪些卦出战、哪些术数系统激活、哪些法器携带。所有选择编码进卦码。战斗中的选卦不是从64个里挑——是从你装备的4×4里挑。

## 一、选卦交互——视觉与操作

### 1.1 进入选卦状态

```
流程：
  1. 战斗中·卦气≥20 → 按住 鼠标右键
  2. 0.1s → 时间流速降到30%
  3. 0.15s → 音效触发（见§1.4）
  4. 0.2s → 五彩半透明白色八卦光环从辰生脚下升起
  5. 0.3s → 光环稳定在辰生半腰位置·缓缓顺时针旋转
  6. 辰生站在光环圆心的太极位·可以慢速移动（移速60%）
  7. 选卦开始
```

### 1.2 八卦光环的视觉

```
光环规格：
  - 直径：约3m（辰生身高1.7m·光环到腰·约1m高）
  - 材质：半透明发光·五彩（白金为主·边缘泛青/赤/黄/白/黑五色微光）
  - 旋转：顺时针·约8秒转一圈·不是匀速（在卦位处微微停顿·像齿轮卡位）
  - 八个卦位：光环上有8个光点·每个光点是一个卦符（☰☷☲☵☳☴☶☱）
    - 光点大小：约20cm直径（在92px角色上=约11px·可见但不大）
    - 光点颜色：离☲=微红·坎☵=微蓝·震☳=微青·巽☴=微绿
               艮☶=微黄·坤☷=微褐·乾☰=微金·兑☱=微银
  - 太极位：光环圆心·辰生脚下·黑白双鱼微光
  - 半透明度：约60%——可以看到光环后面的敌人·但不完全透明
```

### 1.3 两种选卦方式

#### 方式A：纯鼠标拖拽（直觉向·新手友好）

```
操作序列：
  1. 按住右键 → 光环出现
  2. 再按住左键 → 光标变成一个"卦针"（金色小三角形·指向光环方向）
  3. 移动鼠标 → 卦针在光环上滑动
     → 经过卦位时·卦位高亮（放大到150%·光点变亮）
     → 卦位发出轻微的"嗡——"声（每个卦位音高不同·离卦最高·坎卦最低）
  4. 停在乾卦☰上 → 松开左键（但不松右键！）
     → 乾卦位从光环上"弹出"——变成一个大一圈的光球·颜色变成浓郁的金色
     → 卦位和光环圆心（太极位）之间拉出一条金色光线
     → "咚——"一声低沉的确认音
     → 上卦选定：乾☰
  5. 再次按住左键 → 卦针再次激活
     → 移动到坤卦☷上 → 松左键
     → 坤卦位也"弹出"·变成浓郁的褐色光球
     → 乾卦和坤卦之间拉出第二条金色光线
     → "咚——"第二声确认
     → 下卦选定：坤☷
  6. 两个卦位之间形成完整的金色电弧连接
     → 卦象确认：䷀ 乾为天（上乾下乾？不对——乾上坤下=䷋ 天地否）
     → 光环上两个卦位高亮·其余六个卦位变暗
  7. 松开右键 → 卦术释放
     → 光环碎裂成粒子·两个卦位的光球融合→涌入辰生体内
     → 时间恢复·卦术打出

  取消（中途反悔）：
    - 只选了上卦·还没选下卦 → 按E或右键松开再按→取消·卦气保留
    - 选完两个都确认了 → 无法取消·只能释放
    - 紧急闪避（空格）→ 取消选卦·卦气保留·进入闪避
```

#### 方式B：鼠标方向+键盘按键（高效向·高手）

```
操作序列：
  1. 按住右键 → 光环出现
  2. 鼠标移到光环上对应的方向
     → 上卦由鼠标在光环上的位置决定：
       鼠标在光环上方 → 离☲
       鼠标在光环下方 → 坎☵
       鼠标在光环右方 → 震☳
       ...（8方向对应8卦位·光环随辰生朝向旋转·总是上=离）
  3. 同时按键盘：
       1/2/3/4/Q/E/R/F → 下卦
  4. 松右键 → 释放

  时间：约0.5-0.8秒（比方式A快·适合连携）

  高手可以在光环升起的0.3秒内完成选择——光环还没转完一圈·卦术已经打出去了。
```

#### 两种方式的对比

| | 方式A·鼠标拖拽 | 方式B·方向+键盘 |
|------|------|------|
| 操作 | 左键滑光环·两次选择 | 鼠标定上卦·键盘定下卦 |
| 时间 | 1.5-3秒 | 0.5-0.8秒 |
| 视觉 | 卦位弹出·金线连接·仪式感 | 光环闪一下·快捷 |
| 适合 | 新手·探索·非紧急 | 高手·连携·竞速 |
| 卦气消耗 | 标准 | 标准（不因快而便宜） |
| 光环表现 | 完整·华丽 | 光环微闪·更透明 |

### 1.4 音效设计

| 时机 | 音效 | 描述 |
|------|------|------|
| 光环升起 | 法器专属音（§1.5） | "铮——"剑鸣·"叮——"针鸣 |
| 卦针经过卦位 | 微弱的"嗡——" | 8个卦位·8个音高（对应八卦五行·离=火=高音·坎=水=低音） |
| 选定上卦 | "咚——"低音 | 钟声·确认感 |
| 选定下卦 | "咚——"第二声 | 音高比第一个高半度 |
| 两卦连线完成 | "嘤——"高频余韵 | 两根金线碰撞的泛音 |
| 松手释放 | 法器+卦术组合音 | 离卦+桃木剑=火+剑鸣·坎卦+银针=水+针鸣 |
| 取消选卦 | 短促的吸气声或法器归鞘声 | 光环碎裂的清脆玻璃声 |

### 1.5 不同法器的光环差异

| 法器 | 音效 | 光环变化 | 卦位光点变化 |
|------|------|------|------|
| **银针** | "叮——"清脆针鸣 | 光环更细·更透明·旋转更快（5秒/圈） | 光点小·尖锐·星形 |
| **桃木剑** | "铮——"悠长剑鸣 | 光环标准·带微弱的木纹纹理 | 光点标准·圆形 |
| **铜钱剑** | "哗啦——"铜钱碰撞 | 光环上多了一层铜钱虚影·像108枚铜钱串成的环 | 光点=铜钱形（方孔圆钱） |
| **七星剑** | "嗡——"低频星力嗡鸣 | 光环最宽·最亮·最慢（12秒/圈）·带北斗七星微光坠饰 | 光点=星形·七芒星 |

## 二、卦象选装系统——卦是装备

### 2.1 核心理念

```
传统设计：64卦全部可用 → 战斗中从64个里面选 → 太多·选不过来

选装设计：你"装备"4种上卦+4种下卦出战
         → 战斗中只有4×4=16种卦术可选·属于你的Build
         → 回星碑/营地切换装备→换一套卦象=换一种打法

类比：
  不是"学会了64个技能·战斗中从64个里挑"
  是"装备了16个技能·战斗中从16个里挑·回营地换装备=换Build"
```

### 2.3 术数系统详解（可装备的"被动/主动"）

这不是"被动技能"——是改变战斗规则的系统模块。类似《Hades》的Keepsake或《仁王》的守护灵。

| 术数系统 | 解锁 | 槽位占用 | 效果 |
|------|:--:|:--:|------|
| **小六壬** | 序章 | 常驻·不占槽 | 小六爻6方向瞬发·始终可用 |
| **太极·阴阳** | 玄枵宫 | 1槽 | 闪避后自动太极翻转·阴/阳区切换·站太极眼3秒=全屏翻转 |
| **五行·生克** | 娵訾宫 | 1槽 | 卦术命中附带五行连锁：相生→卦气+5·相克→伤害×1.3 |
| **八卦·占场** | 降娄宫 | 1槽 | 演卦光环变大(4m)·光环卦位有额外加成·站对应卦位放卦=伤害×1.5 |
| **三爻·归真** | 大梁宫 | 1槽 | 可识别伪卦·归真反噬·对太史阁敌人伤害+25% |
| **奇门·遁甲** | 实沉宫 | 1槽 | 可布阵(Ctrl+右键)·预设阵法保存·九宫八门 |
| **六爻·纳甲** | 鹑首宫 | 2槽 | 激活完整六爻战场·爻线·六亲·六兽·卦阵·卦vs卦（占用2槽·因为太强） |
| **紫微·斗数** | 鹑火宫 | 1槽 | 命盘效果常驻·四化流转·化忌宫位=双刃剑·不能卸下·但可以选择"激活哪个大限" |
| **太乙·神数** | 鹑尾宫 | 1槽 | 解锁太乙神数按键序列·高风险高回报 |
| **五音·十二律** | 大火宫 | 1槽 | 音律石板可见·可踩音触发效果·对音系敌人额外伤害 |
| **大六壬·天地盘** | 析木宫 | 2槽 | 激活天地盘战场·四课三传可见·可读取BOSS行动（占用2槽） |
| **梅花·易数** | 大梁宫 | 0槽 | 观象范围+20m·常驻被动·不占槽位（和物件的联动能力） |

## 三、卦码——卦符即编码

> 卦码不是字母数字——卦码就是卦符本身。一个Build=八个真实的六十四卦符号。详见 [[卦码系统/卦码Build系统设计]]。

```
䷀䷝䷜䷲䷸䷖䷁䷊

每卦6条爻=6bit·8卦=48bit=完整Build。
第8卦是校验卦。

你可以"读"它：
  ䷀(乾·始) → ䷝(大有·丰收) → ䷜(未济·未完成)
  → ䷲(震·动荡) → ䷸(巽·顺从) → ䷖(剥·剥落)
  → ䷁(坤·承载) → ䷊(泰·通达)
  
"始于天·终于泰。"
这是一个只有懂卦的人才能读的故事。
而这恰好也是你的Build。
```

### 4.1 整合影响

### 4.2 右键双击：闪避与选卦共用一个键

```
右键短按 = 闪避（按下瞬间触发·0帧响应·不等150ms）
右键长按 = 选卦（150ms后时停打开→光环升起→开始选卦）

完全保留原有设计：
  - 紧急闪避：右键点一下立刻松开 = 闪避
  - 闪避接卦术：闪避时按着不放 → 落地时刚好光环展开
  - 原地选卦：右键按住不动 → 150ms后光环升起
```
