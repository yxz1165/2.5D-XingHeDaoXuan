# 紫微斗数命盘 ↔ 十二道宫：双宫映射设计

> **问题：** 游戏中存在两个"十二宫"——紫微斗数的命盘十二宫（内在成长系统）和天文的十二道宫（外在关卡系统）。它们目前毫无关联，但名字都叫"宫"——玩家迟早会问："它们是什么关系？"
>
> **方案：** 通关一座道宫 → 解锁对应命盘宫位 → 星君觉醒后留下星耀 → 玩家可将星耀放入该命宫获得被动加成。让外十二宫（道宫）和内十二宫（命盘）形成叙事与机制的双重呼应。

## 二、为什么这样映射

### 2.1 父母宫 ← 星纪宫

> **传统含义：** 父母、长辈、出身、遗产、与生俱来的东西
> **道宫呼应：** 星纪宫是辰生第一次接触母亲云岫记忆的地方，也是玄伯遗书指引的第一站。锻锋觉醒时——星晷上的"彰往察来"四个字，正是"知道从哪里来，才能知道往哪里去"。

**解锁效果：** 父母宫开启后，初始星耀自动放入——**天梁星**（云岫的残留意念）。效果：战斗开始时获得1层卦气。

### 2.2 迁移宫 ← 玄枵宫

> **传统含义：** 出行、变动、外部环境、向外探索
> **道宫呼应：** 苏羽被诊断"半盲"——不是看不清近处，是看得太远了。"实践出真知"的本质就是走出原有认知边界——这就是"迁移"。

**解锁效果：** 苏羽的岁星星耀可放入迁移宫。效果：闪避距离+1.5m，闪避后移速+10%（3秒）。

### 2.3 田宅宫 ← 娵訾宫

> **传统含义：** 家宅、土地、根基、不动产
> **道宫呼应：** 石翁说"外因是条件，内因是根据"。大地=根基=家。西陆毒化的矿脉搬不走——因为土的本质在内不在外。

**解锁效果：** 石翁的地隐星耀可放入田宅宫。效果：阵法血量+40%，阵法范围+15%。

### 2.4 官禄宫 ← 降娄宫

> **传统含义：** 事业、功名、社会成就、技艺
> **道宫呼应：** 顾锋的剑=最高的技艺。金无痕被骗练删改版剑谱=技艺可以被篡改，但真正的剑气来自内心。"捉主要矛盾"就是把事情做对的第一能力。

**解锁效果：** 顾锋的太白星耀可放入官禄宫。效果：暴击率+8%，暴击伤害+15%。

### 2.5 财帛宫 ← 大梁宫

> **传统含义：** 财富、资源、价值判断
> **道宫呼应：** "去伪存真"的核心就是辨别真假价值。鲁班语发现推演机的输入数据被篡改——这不是"算错了"，是"用假币在真市场上交易"。精算和算假账是两回事。

**解锁效果：** 鲁班语的神机星耀可放入财帛宫。效果：卦气上限+15，卦气恢复速度+25%。

### 2.6 交友宫 ← 实沉宫

> **传统含义：** 朋友、社交、下属、民众
> **道宫呼应：** 石磐一个一个报出阵亡者的名字——"战争的伟力之最深厚的根源，存在于民众之中"。交友宫在紫微斗数中又称"奴仆宫"，管的是所有非血亲的社会关系——而石磐正是用"叫出每一个人的名字"把这些人变成了兄弟。

**解锁效果：** 石磐的镇星星耀可放入交友宫。效果：所有同伴伤害+12%，同伴复活时间-20秒。

### 2.7 疾厄宫 ← 鹑首宫

> **传统含义：** 疾病、灾厄、身体承受力
> **道宫呼应：** 矛盾的同一性——毒草可以变成肥料。影脸上的刺青是被迫刻下的，但在她接受自己之后，刺青裂开露出星光。疾病与健康不是对立的——它们可以相互转化。

**解锁效果：** 影的计都星耀可放入疾厄宫。效果：受负面状态影响时，每秒回复1%生命（负面状态下卦气消耗-20%）。

### 2.8 福德宫 ← 鹑火宫

> **传统含义：** 福报、精神满足、内心安宁
> **道宫呼应：** 冥婆在石桥上烧了几百年的火——不是因为有俸禄，不是因为有人感谢。"劳动不是苦。劳动是证明你活过。"最高级的福报不是享受——是在劳动中找到意义。

**解锁效果：** 冥婆的玄冥星耀可放入福德宫。效果：每击杀一个敌人回复3%生命。濒死时获得一次"冥火护佑"（5秒无敌，每场战斗一次）。

### 2.9 子女宫 ← 鹑尾宫

> **传统含义：** 子女、后代、创造力、生命延续
> **道宫呼应：** 析木星君已彻底消散——"旧的死去，新的生长"。辰生接下他的重力能力，就是"子女"的隐喻——不是生物学上的子女，是文明传承意义上的后代。新陈代谢——上一代把力量交给下一代。

**解锁效果：** 析木星君的残影（无独立星耀，而是激活子女宫的"继承"机制）。效果：辰生获得重力能力——闪避附带微量重力伤害，普攻第三段牵引周围敌人。

### 2.10 夫妻宫 ← 大火宫

> **传统含义：** 配偶、亲密关系、深度理解
> **道宫呼应：** 形式与内容——阮心的一句话揭示了整个游戏的情感内核。当她说"人也一样"时——她不是在说音乐。她是在说人和人之间最深的理解。真正的"夫妻"不是形式上的结合——是内容上的相知。这也是明月暗线的情感呼应——三千年的等待，是内容穿透了时间的形式。

**解锁效果：** 阮心的天音星耀可放入夫妻宫。效果：与同伴距离<5m时双方伤害+15%（"心心相印"）。

### 2.11 命宫 ← 寿星外围（玄微子/辰星卦师）

> **传统含义：** 自我、核心本质、命运主轴
> **道宫呼应：** 命宫在传统紫微中是最重要的一宫。游戏把它放在倒数第二宫解锁——因为"我是谁"是整部游戏最核心的问题，不能一开始就回答。玄微子校准星图时说："你的星盘和云岫的一样——但你的命宫不在织女，在辰星。你是道士。你一直是。"这是辰生第一次完整知道自己的身份。

**解锁效果：** 玄微子的辰星星耀（唯一可放入命宫）。效果：所有卦象伤害+10%。更关键的是——**命宫解锁后，前面10个命宫中的星耀效果全部提升50%。** 因为"知道了自己是谁"之后，所有的力量都找到了中心。

### 2.12 兄弟宫 ← 寿星宫（终章·全员）

> **传统含义：** 兄弟姐妹、同辈、手足之情
> **道宫呼应：** 十二位同伴聚齐，在寿星宫同时吟诵母亲的长诗。这一刻，辰生和十一位星君转世者的关系已经超出了"同伴"——他们是兄弟。十二个人的力量汇聚在一起对抗商徵的"时间删除"——攻击可以从时间中抹去，意义不能。兄弟不是血缘决定的——是共同的目标和共同的牺牲决定的。

**解锁效果：** 终章特殊效果——兄弟宫解锁后，所有12宫的星耀效果同时激活（不再受"只能激活两个命宫"的限制）。命盘完整体——十二宫全亮。

```
☆☆ = 命宫（双星标记，核心宫位）
```

### 3.2 规则

| 规则 | 说明 |
|------|------|
| **解锁** | 通关对应道宫→命盘对应宫位解锁→自动获得该星君的专属星耀 |
| **放置** | 每个命宫只能放一颗星耀（当前解锁的星君专属星耀） |
| **激活上限** | 同时只能激活**2个**命宫的星耀效果（第11宫解锁后提升为4个，终章全激活） |
| **切换** | 在安全区域（星碑/城镇）可自由切换激活哪个命宫 |
| **命宫特殊性** | 命宫（第11宫解锁）获得星耀后，所有已激活命宫的星耀效果×1.5 |

### 3.3 为什么设计"同时只能激活2个"

- **避免数值膨胀：** 12个被动同时生效=数值崩坏
- **鼓励build思考：** 玩家需要根据当前敌人类型选择激活哪两个命宫
- **命盘完整体=终章奖励：** 终章全激活是叙事的最高潮在机制上的体现

## 五、叙事与机制的同步成长

玩家在通关过程中的体验变化：

| 阶段 | 道宫进度 | 命盘状态 | 玩家的感受 |
|------|---------|---------|-----------|
| 序章 | 0/12 | 命盘未开启 | "这是什么？" |
| 前3宫 | 星纪-娵訾 | 3宫解锁，可激活1个 | "星君的力量在帮我" |
| 中4宫 | 降娄-鹑首 | 7宫解锁，可激活2个 | "需要选择——带哪个星君的力量去打这一宫" |
| 后3宫 | 鹑火-大火 | 10宫解锁，可激活2个 | "选择越来越难——想要的能力太多" |
| 第11宫 | 寿星外围 | 11宫解锁→命宫点亮→激活上限提升到4 | "终于知道自己是谁了。一切都不一样了。" |
| 终章 | 寿星 | 12宫全亮全激活 | "十二个人的力量，现在都在我身上。" |

## 六、与战斗系统的接口

紫微命盘系统通过以下方式与战斗系统交互：

```
通关道宫 → 解锁命宫 + 获得星耀
    ↓
安全区域（星碑/城镇）→ 打开命盘界面 → 选择激活2个命宫
    ↓
进入战斗 → 激活的星耀被动效果生效
    ↓
战斗中不可切换命盘（保持build选择的严肃性）
    ↓
BOSS门前星碑 → 可以重新调整激活的命宫（针对不同BOSS调整策略）
```

**特殊交互：**
- **命宫激活后（第11宫）** → 所有卦象技能增加微弱的紫色光效（紫微星的颜色）
- **兄弟宫激活后（终章）** → 辰生在使用卦象时，身后短暂浮现对应星君的残影轮廓
