# 术数系统——小六壬·掌诀直觉

> **认知框架：掌诀直觉。** 不思考。不分析。不规划。六个方向=六种肌肉记忆。你的身体比你的大脑先知道答案。
> **核心问题："现在是什么情况？"** → 甩鼠标·0.3秒·答案自动浮现。
> **最出彩时刻：** 贴脸·BOSS大招砸下来·你的手比眼快——甩出空亡·隐身穿过·BOSS打在空气里。

---

## 一、你"看到"的战场

```
激活小六壬（不占槽位·始终可用）后：

屏幕没有多余的UI。
没有爻线。没有卦盘。没有时间轴。

只有——
  按住右键+Shift → 六个方向的光环在鼠标周围闪现
  ↑ = 大安·金色
  ↘ = 留连·暗红
  ↓ = 速喜·翠绿
  ↙ = 赤口·血红
  ← = 小吉·银白
  ↗ = 空亡·漆黑

鼠标甩动·光环消失·效果即时生效。
整套流程：0.3秒。
```

## 二、六掌诀详解

| 掌诀 | 方向 | 颜色 | 效果 | 冷却 | 思维含义 |
|------|:--:|:--:|------|:--:|------|
| **大安** | ↑ | 金色 | 3秒内伤害+20% | 8s | "现在是最好的时机·进攻" |
| **留连** | ↘ | 暗红 | 前方扇形缠绕3秒 | 12s | "先困住他·再想" |
| **速喜** | ↓ | 翠绿 | 3秒内移速+40% | 6s | "跑！追！逃！" |
| **赤口** | ↙ | 血红 | 前方直线击退+眩晕1.5s | 15s | "把他打退·打断他" |
| **小吉** | ← | 银白 | 回复15%生命 | 30s | "一口气" |
| **空亡** | ↗ | 漆黑 | 向后闪避+隐身1s | 20s | "消失在虚空中" |

## 三、为什么有人选这个

```
小六壬玩家："我不想知道64卦在干什么。
              我只想知道——下一秒我该往哪边甩。
              给我六个方向。剩下的事我的身体知道。"

这种人：
  - 觉得"选卦太慢了"
  - 不思考弱点克制·凭直觉打
  - 战斗中身体的反应比大脑更快
  - 小六壬不是"弱化版八卦"——是"另一种战斗哲学"

在道宫中：
  小六壬+掌诀占场=绝配
  六个掌诀位铺在地上·你不只是在甩鼠标——
  你也在"踩位"。
  站在大安位上甩大安=双倍增伤。
  把敌人推到空亡位上=敌人被虚空吞噬。
```

## 四、与其他术数的搭配

| 搭配 | 效果 |
|------|------|
| +太极 | 掌诀位效果可以被太极翻转反转（大安变凶·空亡变吉） |
| +五行 | 掌诀命中附带五行连锁 |
| +六爻纳甲 | 每个掌诀命中=写入一爻（小六壬也能写爻·加速卦阵） |

## 五、进阶技巧

- **大安起手→普攻三段→取消→速喜追击→普攻→小吉回复。** 一套流畅的"起手-追击-保命"循环
- **空亡不是逃命用的——是贴脸用的。** 隐身穿到BOSS身后→切桃木剑→离卦背击
- 六个掌诀位如果铺在道宫地上（星纪宫·掌诀占场），学会"用方向选掌诀+用走位踩掌诀"双重操作
