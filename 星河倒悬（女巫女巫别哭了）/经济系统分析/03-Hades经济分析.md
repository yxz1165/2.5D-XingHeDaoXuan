# 经济系统分析 #03：Hades

> **类型：** Roguelike · 动作 · 多周目
> **经济模型：** 6货币分层·跨局永久保留·"失败≠归零"
> **分析日期：** 2026-08-04
> **对星河倒悬参考价值：** ⭐⭐⭐⭐⭐ 核心参考

---

## 一、货币设计——最精妙的"6货币分层"

### 1.1 货币全景

Hades 使用6种货币，分四个层级：

| 层级 | 货币 | 死亡后 | 用途 | 单局获取量 |
|:--:|------|:--:|------|:--:|
| **局内** | 💰 银币（Obol） | ❌ 全丢 | 局内商店买恩赐/道具/回血 | 100-500 |
| **跨局·基础** | 💎 暗黑宝石 | ✅ 保留 | 魔镜天赋·永久属性 | 50-150 |
| **跨局·基础** | 💚 宝石 | ✅ 保留 | 装修冥府·便利设施 | 15-40 |
| **跨局·初期** | 🔑 冥府钥匙 | ✅ 保留 | 解锁武器·天赋层 | 3-6→0-2 |
| **跨局·社交** | 🍷 仙酒 | ✅ 保留 | 送NPC·好感度·解锁剧情 | 2-5 |
| **跨局·终局** | 💎 泰坦之血 | ✅ 保留 | 武器形态·终极追求 | 1-3 |
| **跨局·终局** | 💠 钻石 | ✅ 保留 | 后期装修·乐师乐谱 | 0-2 |

### 1.2 分层的经济学逻辑

**为什么需要6种货币？** 因为Roguelike面临一个独特的问题：

```
如果只有1种货币：
  玩家在某局中"刷钱"→下一局开局就有10000金币
  → 局内商店随便买→没有紧张感
  → "局内资源管理"这个核心玩法被破坏

如果用6种货币分层：
  银币→局内·死亡全丢→每局都是"从零开始"的紧张
  暗黑宝石→跨局·但用途单一（只有魔镜）→只能买永久属性
  宝石→跨局·但只能装修→不能买战斗能力
  钥匙→早期用完就没了→后期溢出·不破坏平衡
  仙酒→绑定社交→强制你与NPC互动
  泰坦之血→极稀有→终局追求
```

**6种货币不是"设计过度"——是"每种货币只解决一个问题"。**

## 二、货币详解

### 2.1 银币（局内货币·死亡全丢）

```
银币是唯一"局内"货币——死亡=清空

单局获取：100-500（视恩赐和房间选择）
局内消费：
  卡戎商店：恩赐(~150)·回血(~50)·力量石榴(~100)
  卡戎之井：随机物品(50-100)
  临终商店（冥河）：昂贵但强力(200-400)

设计精妙之处：
  每局你都在算——"我有280银币·是买雅典娜的冲刺恩赐(150)?
   还是留着等冥河的钻石(200)?"
  这个计算随着游戏的进程不断重复·不会无聊
```

### 2.2 暗黑宝石（主跨局货币）

```
全解锁需求：35,365暗黑宝石
单局获取：50-150（视热度·武器·恩赐）

魔镜天赋树：24个天赋·每个6-20级
  关键天赋：
    死亡蔑视（多一条命）：1,530暗黑·约10-15局
    传奇血统（稀有恩赐概率）：2,500暗黑·约20局
    暗之攫握（背刺伤害）：3,000暗黑·约25局

魔镜每级都有"二选一"——同一行有两个变体：
  火焰之魂（普攻+20%）vs 暗影之魂（背刺+50%）
  奥林匹亚恩惠（开局随机恩赐）vs 暗之恩惠（开局随机黑暗）
  
  这个二选一创造了永久的Build决策
```

### 2.3 宝石（装修·便利·长期消耗）

```
全解锁需求：约25,000+宝石
单局获取：15-40（基数5/房间·升级后可到20+）

用途：
  冥府装修：恢复喷泉·宝石矿·展示柜
  工作订单：自动生成资源·钓鱼点·奖励翻倍
  乐师乐谱：解锁BGM·纯装饰

关键设计：
  宝石的获取基数极低（5/房间）
  但可以堆叠恩赐放大：
    波塞冬的"海洋的馈赠"→宝石/暗黑/银币+50-65%
    卡俄斯的"繁盛"→暗黑/宝石+75-200%
  
  堆叠后单局可获取500+宝石
  这是给"懂得优化经济"的玩家一个糖吃
```

### 2.4 冥府钥匙（初期紧缺·后期溢出）

```
总需求：约50把（解锁武器+天赋层）
单局获取：初期3-6·后期0-2（因为天赋层全开后钥匙不再生成）

钥匙是"前紧后松"的完美范例：
  前5-10局：钥匙极度珍贵·每一把都要精打细算
  10-20局：钥匙逐渐充裕·开始有备用
  20局以后：钥匙全解锁·不再需要→钥匙房间+20银币（替代奖励）

这个设计避免了"后期溢出货币无用"的问题——
它直接让这种货币在完成使命后"退役"
```

### 2.5 仙酒（社交货币）

```
总需求：约150+（送所有NPC到满好感）
单局获取：2-5

用途：
  送NPC=解锁对话·剧情·隐藏内容
  每个NPC需要5-7瓶仙酒才能满好感
  杜莎（美杜莎）=送仙酒→好感→解锁她的支线
  阿喀琉斯=送仙酒→解锁帕特洛克罗斯的故事
  塔纳托斯=送仙酒→改变他对扎格列欧斯的态度

仙酒是"情感经济"——你不为变强而送·你为"我想知道她的故事"而送
```

### 2.6 泰坦之血 + 钻石（终局货币）

```
泰坦之血：
  全解锁需求：326（全武器·全形态·全等级）
  单局获取：1-3（首杀BOSS+热度奖励）
  用途：解锁/升级武器形态
    初始形态：免费
    第二形态：1血
    第三形态：2血
    第四形态：3血
    满级：每个形态再+5血

钻石：
  总需求：约50+
  单局获取：0-2（冥河商店·钓鱼·热度奖励）
  用途：后期装修·乐谱·少数关键道具
  
  "钻石"的设计哲学：极其稀有→每次看到都心跳加速→即使后期也兴奋
```

## 三、跨货币兑换——"不让一种货币统治一切"

### 3.1 可怜经纪人的兑换系统

冥府的"可怜经纪人"提供有限的货币转换：

```
兑换比率（不可逆）：
  1 泰坦之血 = 1,000 宝石
  1 泰坦之血 = 100 冥府钥匙
  1 泰坦之血 = 20 仙酒
  1 钻石 = 500 宝石
  1 仙酒 = 5 钥匙
  100 宝石 = 1 钥匙
  500 宝石 = 1 仙酒
  1,000 宝石 = 1 钻石
  10 钥匙 = 1 仙酒
  
兑换是单向的——从稀有→常见
泰坦之血可以换成宝石·但宝石不能换成泰坦之血
```

### 3.2 为什么是单向兑换

```
双向兑换→玩家会"套利"→找到最优兑换路径→只刷一种货币
单向兑换→"往下容易·往上不可能"
  →玩家必须去打泰坦之血（打高热度·打BOSS）
  →不能靠"刷宝石然后换成泰坦之血"来逃避挑战
  
单向兑换 = 逼你去玩高难度内容
```

## 四、资源循环——"失败≠归零"的核心哲学

### 4.1 每局的经济循环

```
[进入地狱] → 银币=0·恩赐=空·武器=所选形态
  ↓
[清理房间] → 选银币/暗黑/宝石/钥匙/仙酒/恩赐·四选一
  ↓          ↑ 这是每局最核心的决策——"我要什么？"
  ↓
[卡戎商店] → 消费银币·"买还是不买？"
  ↓
[BOSS战] → 胜利→获得泰坦之血/钻石（首杀）·银币奖励
  ↓
[死亡] → 银币=0·恩赐=空·但暗黑/宝石/钥匙/仙酒/血/钻石全部保留
  ↓
[回到冥府] → 消费暗黑（魔镜）·消费宝石（装修）·送仙酒（社交）
  ↓
[再次出发] → 带着更强的魔镜天赋·更豪华的冥府·更深的NPC关系
```

### 4.2 "失败≠归零"的心理效果

```
传统Roguelike：
  死了 → 一切都丢了 → "白打了" → 沮丧 → 退出游戏

Hades：
  死了 → 银币丢了（可惜）
       → 但暗黑宝石拿到了150个（魔镜快升级了！）
       → 但那个NPC终于收下了我的仙酒（好感度+1！）
       → 但我解锁了关刀的新形态（下周目试试！）
       → "死得值！" → 立刻开始下一局
```

**这就是 Hades 经济系统的终极成就——它让失败变得有趣。** 你死了，但你带回来了一些东西。你不是"失败了"——你是"完成了这一趟，带回了一些收获"。

## 五、行为引导

### 5.1 引导：你需要做选择

```
每个房间通关后——四选一：
  💰 银币（这局强·下局归零）
  💎 暗黑（这局不帮·下局更强）
  💚 宝石（长期投资·不直接影响战斗）
  🔑 钥匙（解锁更多选择）
  
  没有"正确"答案·只有"你的策略"
  
  新手："我要银币·买恩赐·这局活下去！"
  中期："暗黑宝石·升级魔镜·打得更远！"
  老手："宝石吧·冥府装修快完工了"
  大师："钥匙（已经不需要了）+20银币（替代奖励）"
```

### 5.2 引导：高难度=高回报

```
普通通关（0热度）：BOSS掉1泰坦之血（首杀）
热度1-5：BOSS掉1血（每次·可重复）
热度6-10：BOSS掉2血
热度11-15：BOSS掉3血

→ 你打不过热度15？
→ 没关系·打热度6也能拿到2血·慢慢积累
→ 但你想快点满级武器形态？
→ 那就去挑战更高热度

这就是"胡萝卜"——不强迫你·但诱惑你
```

### 5.3 引导：与NPC建立关系

```
仙酒=社交货币
你不送仙酒→NPC永远把你当陌生人
你送仙酒→NPC对你敞开心扉→解锁隐藏剧情→改变故事结局

扎格列欧斯（主角）无法靠武力获得NPC的真心——
他必须花"时间"和"仙酒"。

这个设计让社交成为"经济决策"的一部分：
  "这瓶仙酒是送给阿喀琉斯（据说能解锁帕特洛克罗斯的故事）
   还是送给塔纳托斯（我想看他们的感情线）？"
```

## 六、对"星河倒悬"的具体启示

### 6.1 最核心的启示：货币分层

| Hades层级 | Hades货币 | 星河倒悬对应 |
|:--:|------|------|
| **局内·死亡丢失** | 银币 | ← 不需要·星河倒悬不是Roguelike |
| **永久·基础成长** | 暗黑宝石 | ← 卦气上限·命盘解锁 |
| **永久·便利/装饰** | 宝石 | ← 星碑传送·星碑休息效果·营地升级 |
| **初期紧缺·后期溢出** | 冥府钥匙 | ← 五帝钱（5枚·收集完就没用了） |
| **社交绑定** | 仙酒 | ← 同伴好感度礼物（星君信物） |
| **终局追求** | 泰坦之血+钻石 | ← **星晶**（核心·永远稀缺） |

### 6.2 可以借鉴的

| 借鉴点 | Hades做法 | 星河倒悬应用 |
|--------|---------|-------------|
| **"失败≠归零"** | 银币丢·暗黑保留 | 铜钱丢20%·星晶永不丢·卦气可恢复 |
| **单向兑换** | 泰坦之血→宝石·不可逆 | 星晶不可用铜钱买·"往下容易·往上不可能" |
| **货币生命周期** | 钥匙前期紧缺后期退役 | 五帝钱收集完退役·转化为卦气加成 |
| **社交货币** | 仙酒=情感投资 | 星君信物·好感度礼物·解锁隐藏剧情 |
| **终局无底洞** | 326泰坦之血 | 七星剑锻造+9+九天星晶·法器共鳴 |
| **四选一房间** | 银币/暗黑/宝石/钥匙 | 不需要·星河倒悬是连续世界不是房间制 |

### 6.3 不适合借鉴的

| 不借鉴 | 原因 |
|--------|------|
| **局内货币丢失** | 星河倒悬有存档系统·不是Roguelike·死亡只掉铜钱20-30% |
| **房间经济决策** | 星河倒悬是连续开放世界·不是离散房间 |
| **6种货币** | 太多了·星河倒悬已有铜钱+星晶+材料·够用 |
