# 经济系统分析 #09：冰汽时代 (Frostpunk)

> **对星河倒悬参考价值：** ⭐⭐⭐⭐ 道宫生存压力·道德抉择的经济化

## 一、货币设计——"没有钱"的世界

### 1.1 资源即货币

冰汽时代**没有传统意义上的"货币"**。在这个冰封末世，金币毫无意义。

真正的"货币"是五种生存资源：

| "货币" | 用途 | 稀缺度 | 没了的后果 |
|------|------|:--:|------|
| 🔥 **煤炭** | 能量塔燃料·供暖 | ⭐⭐⭐⭐⭐ 最稀缺 | **所有人冻死** |
| 🍞 **食物** | 防止饥饿 | ⭐⭐⭐⭐ | 饥饿→不满→死亡 |
| 🪵 **木材** | 建筑·研究·升级 | ⭐⭐⭐ | 无法扩建·科技停滞 |
| ⚙️ **钢材** | 高级建筑·机器人 | ⭐⭐⭐ | 无法生产高级设施 |
| ⚗️ **蒸汽核心** | 机器人·高级建筑 | ⭐⭐⭐⭐⭐ 最珍贵 | 丧失自动化能力 |

### 1.2 "希望"和"不满"——两种非物质的"经济指标"

冰汽时代有一个**独特的双轨社会指标**：

```
希望（Hope）：
  像"正向货币"——积累希望来解锁更好的法律和决策
  +希望：满足需求·签善法·教堂布道·不加班
  -希望：饿死人·冻死人·签恶法·加班加到死

不满（Discontent）：
  像"负向货币"——控制不满来防止暴动
  +不满：加班·24小时轮班·童工·汤食（稀粥）·尸体不埋
  -不满：满足需求·减少工时·酒馆·角斗场
```

**希望和不满不是"数值"——是"道德温度计"。** 它们衡量的是：你作为一个领导者的每一个决定——在生存和道德之间——你选择了什么。

## 二、资源循环——"每一块煤都有代价"

### 2.1 煤炭——全游戏最核心的"货币"

```
煤炭的来源：
  煤矿（需要工人·24小时运作）
  炭窑（木材→煤炭·效率低·但木材可再生）
  蒸汽煤矿（需要蒸汽核心·效率极高·但蒸汽核心极其珍贵）
  机器人煤矿（不需要工人·全天24小时·但需要蒸汽核心）

煤炭的消耗：
  能量塔（核心·每小时的煤耗随温度降低而增加）
  蒸汽枢纽（扩展供暖范围）
  温室（食物生产需要供暖）

温度越低 → 煤耗越高 → 需要更多工人采煤 → 其他岗位缺人 → 产量下降 → 整体衰退

这就是冰汽时代的"死亡螺旋"。
```

### 2.2 "温度曲线"——看不见的经济手

冰汽时代的经济被一个看不见的变量控制——**外界温度**。

```
第1天：-20°C → 能量塔低功率 → 煤耗低 → 可以多派工人去采集其他资源
第10天：-50°C → 能量塔必须全功率 → 煤耗暴涨 → 抽调更多人采煤
第20天：-80°C → 暴风雪来临 → 所有户外工作停止 → 只能靠库存活着
            → "你存的煤够撑过这场暴风雪吗？"
```

**这是"自然环境通胀"——由天气驱动的资源压力，而不是由玩家消费驱动的。**

## 三、道德经济——"值得吗？"

### 3.1 法律之书——用道德换效率

冰汽时代最令人不安的设计是**法律系统**：

| 法律 | 效果 | 代价 |
|------|------|------|
| 📜 **应急班次** | 工人工作24小时不停 | +不满·可能过劳死 |
| 👶 **童工** | 儿童可以在煤矿/厨房工作 | 这违背了你的良心 |
| 🍜 **汤食** | 食物消耗减半 | 食物质量差·+不满 |
| ⚕️ **激进治疗** | 病人更快恢复 | 截肢（永久在岗人数减少） |
| 💀 **尸体处理** | 尸体→肥料·器官 | 亵渎尸体 |
| 🚨 **宣传中心** | 大幅+希望·-不满 | **你在操控人们的思想** |
| 🔚 **新秩序** | 终极控制 | **你成为了暴君** |

每一个法律都是一道选择题：**"为了活下去——我愿意走多远？"**

### 3.2 "值得吗？"——通关后的终极拷问

冰汽时代最著名的设计：**通关后——游戏会问你一句话。**

```
"我们活下来了。但值得吗？"
```

然后它列出了你签过的每一条恶法，每一个冻死的人，每一个被截肢的孩子。

```
如果答案是"不"——你不是输了游戏。
你是赢了游戏——但输了人性。
```

**这就是"道德经济"——经济的终点不是"钱够不够"——是"我们对得起自己吗"。**

## 四、对"星河倒悬"的具体启示

### 4.1 道宫的"生存压力"——类比冰汽时代

每座道宫可以有动态的"环境压力"——类似冰汽时代的温度曲线：

| 道宫 | 环境压力 | 压力效果 | 缓解方式 |
|------|------|------|------|
| 星纪 | 极寒 | 移速-20%·非火卦伤害-15% | 离卦·火卦技能·锻锋被动 |
| 娵訾 | 毒瘴 | 持续掉血·视野缩小 | 五毒阵破解·石翁大地净化 |
| 鹑首 | 黑暗 | 完全无法看到·依赖听觉 | 影的刺青发光·声音定位 |
| 实沉 | 怨念 | 卦气持续流失 | 解放士兵亡魂·石磐擂鼓 |
| 析木 | 重力 | 移速-50%·跳跃禁用 | 承受·坚持·觉醒后反转 |

### 4.2 "希望与不满"——同伴士气系统

星碑营地的同伴可以有一个"士气"系统：

```
同伴士气（Morale）：
  类似冰汽时代的希望/不满双轨

+士气：带该同伴出战·送好感度礼物·对话·营地升级
-士气：长期不带出战·该同伴对应道宫通关后冷落·战斗中死亡

士气高（≥80）：同伴被动增益×1.5
士气低（<30）：同伴拒绝出战·留在营地
士气=0：同伴离开（去星碑·不会回来·除非你去找ta）
```

### 4.3 "值得吗？"——道宫通关后的反思

每座道宫通关后，可以有一个简短的"觉醒之间"反思：

```
星纪宫通关后·觉醒之间：

锻锋问你："焦烈最后一句话你听到了吗——'火为什么是热的'。
          我这四千年一直在想——被洗脑的人·算不算有罪？"
          
玩家选择：
  A. "不算。他只是被太史阁骗了。" → 锻锋好感+2
  B. "他选择了相信——所以有罪。" → 锻锋沉默·好感不变·但获得星晶+1
  C. "我不知道。" → 锻锋说："我也不知道。但你会想明白的。"
```
