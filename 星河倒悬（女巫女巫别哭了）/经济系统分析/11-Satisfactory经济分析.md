# 经济系统分析 #11：Satisfactory

> **类型：** 3D工厂 · 自动化 · 垂直建造
> **经济模型：** 零货币·无限资源节点·垂直分层·"好看即正义"
> **分析日期：** 2026-08-04
> **对星河倒悬参考价值：** ⭐⭐⭐ 法器锻造"层级"·多层道宫·垂直供应链

---

## 一、货币设计——"无限资源节点"取代了货币

Satisfactory 和 Factorio 一样——**没有货币**。但两者的资源哲学截然不同：

| 维度 | Factorio | Satisfactory |
|------|------|------|
| 资源节点 | 有限（矿脉有储量·会枯竭） | **无限**（矿脉永不枯竭·固定产出速率） |
| 核心压力 | 扩张（找新矿） | **效率**（提高现有矿脉的利用率） |
| 空间 | 2D平面（无限地图） | 3D立体（可以往高处建） |
| 瓶颈 | 矿脉枯竭 → 必须扩张 | 传送带速度 → 必须升级 |

**Satisfactory 的矿脉永远不会枯竭。** 你不需要"找新矿"——你需要"让矿脉产出更快"。

---

## 二、垂直整合——3D空间的经济学

### 2.1 "往上建"改变了经济模型

```
Factorio（2D）：扩张=更多土地·更多矿脉·更长的传送带
Satisfactory（3D）：扩张=更多楼层·更高建筑·利用垂直空间

一个铁板生产线的 Satisfactory 式布局：
  第1层：采矿机（地面·靠近矿脉）
  第2层：熔炉（铁矿石→铁锭）
  第3层：构造器（铁锭→铁板）
  第4层：组装机（铁板→强化铁板）
  第5层：制造商（强化铁板→模块化框架）
  
  所有层之间用垂直传送带连接
  矿脉在1层·最终产品在5层
  中间不需要"远距离运输"
```

### 2.2 层级=经济深度

```
Satisfactory 的制造层级：

Tier 1（初期）：铁板·铜板·混凝土
Tier 2：强化铁板·转子·模块化框架
Tier 3：钢梁·钢管·重型模块化框架
Tier 4：电机·计算机·电路板
Tier 5：超级计算机·重型框架·无线电控制单元
Tier 6：涡轮电机·热沉·电磁控制杆
Tier 7：核 pasta · 暗物质晶体 · AI 限制器
Tier 8：最终太空电梯材料

每升一个Tier：
  需要的新材料≈前一级的2-3倍
  需要的工厂复杂度≈前一级的3-5倍
  单靠手搓不可能完成——必须建完整的自动化工
```

**对星河倒悬的映射：** 法器的9级进阶就像 Satisfactory 的8个Tier——每一级都需要上一级的"产出"作为下一级的"投入"。

## 三、"好看即正义"——“效率不是唯一的追求

### 3.1 为什么 Satisfactory 玩家愿意花100小时建一个"好看"的工厂

```
Factorio 的驱动力："它必须工作"（效率至上·能跑就行）
Satisfactory 的驱动力："它必须好看"（90°直角·对称·颜色编码·玻璃地板）

为什么？
  因为 Satisfactory 是第一人称3D——
  你建的工厂就在你眼前
  你走在里面·看着传送带在你头顶运行
  你会因为"两根传送带没有对齐"而感到不适
  你会拆掉一整层工厂重来——只因为"不够对称"

→ "美"成了比"效率"更高级的驱动力
```

**对星河倒悬的映射：** 法器锻造界面应该有视觉满足感——看到你的桃木剑从Lv+1→Lv+9的视觉效果变化（从普通木剑→发光桃木→星辉缠绕）。

## 四、对"星河倒悬"的具体启示

### 4.1 法器的"Tier式进阶"

类比 Satisfactory 的Tier系统：

```
法器Tier系统：
  Tier 1（对应 Satisfactory Tier 1-2）：银针·桃木剑（基础法器）
  Tier 2（Tier 3-4）：铜钱剑·基础阵法（需要锻造）
  Tier 3（Tier 5-6）：七星剑·高级阵法（需要稀有材料）
  Tier 4（Tier 7-8）：七星剑+9·太乙神数（终极法器）

每次Tier升级需要：
  前一Tier的产出（材料）
  新Tier的特殊材料（新道宫独占）
  特定星君的赠予（剧情绑定）
```

### 4.2 "垂直锻造"——道宫的层级设计

道宫可以有物理上的"层级对应"：

```
星纪宫（Tier 1）：
  物理层级：地面层（冰原）→ 中层（冰火交界）→ 深层（火山核心）
  锻造层级：青铜→铁→淬火青铜
  → 越深入=越高Tier的材料

降娄宫（Tier 2）：
  物理层级：剑冢海滩→断剑平原→剑碑群→忘川巨剑（垂直！）
  每个层级解锁更高Tier的锻造材料
```
