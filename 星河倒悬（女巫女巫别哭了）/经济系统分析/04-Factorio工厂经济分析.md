# 经济系统分析 #04：Factorio

> **类型：** 工厂自动化 · 资源链 · 无限扩展
> **经济模型：** 纯材料经济·无货币·全自动化·递归复杂度
> **分析日期：** 2026-08-04
> **对星河倒悬参考价值：** ⭐⭐⭐⭐ 法器锻造材料链设计

---

## 一、货币设计——"不需要货币"的经济系统

### 1.1 零货币经济

Factorio **没有任何形式的"钱"**。没有金币，没有水晶，没有代币。

```
"钱"在 Factorio 中被替换为：

  铁板 = 最基础的"货币"
  铜板 = 第二"货币"
  绿电路板 = 中级"货币"
  红电路板 = 高级"货币"
  蓝电路板 = 终极"货币"
  科技包 = "经验值"——投入→解锁新配方
```

### 1.2 为什么不需要钱

在 Factorio 中，所有东西都是"造出来的"而不是"买来的"：

```
你需要一个采矿机 →
  采矿机 = 铁板×9 + 铜板×5 + 电路板×3
  铁板 = 铁矿×1（采掘）→在熔炉中烧→铁板
  铜板 = 铜矿×1→熔炉→铜板
  电路板 = 铁板×1 + 铜线×3
  铜线 = 铜板×1

→ 所有原材料归根结底来自矿脉
→ 矿脉 = 地图上的资源（无限·但每个矿脉有储量上限）
→ 所以你的"钱" = 开采效率 × 时间
```

**为什么这种设计对星河倒悬很重要？**

因为星河倒悬的锻造系统本质上就是 Factorio 的材料链。法器不是"买"来的——是用矿石→锻造→铭刻→纳甲一步步"造"出来的。

## 二、资源链——"递归深度"是衡量复杂度的唯一标准

### 2.1 Factorio的典型制造链

```
科技包1（红瓶·最简单）：
  铜板×1 + 铁齿轮×1
  铁齿轮 = 铁板×2

科技包2（绿瓶）：
  传送带×1 + 机械臂×1
  传送带 = 铁板×1 + 铁齿轮×1
  机械臂 = 铁板×1 + 铁齿轮×1 + 电路板×1
  电路板 = 铁板×1 + 铜线×3
  铜线 = 铜板×1

科技包3（蓝瓶·中等复杂度）：
  红电路板×1 + 引擎×1 + 硫磺×1
  红电路板 = 绿电路板×2 + 塑料×2 + 铜线×4
  绿电路板 = 铁板×1 + 铜线×3
  塑料 = 石油气×1 + 煤×1
  引擎 = 铁齿轮×1 + 钢管×1 + 铁板×2
  钢管 = 铁板×1
  硫磺 = 石油气×3 + 水×30

  蓝瓶的递归深度：约6-7层
  从铁板追溯到铁矿→约4-5次转化
```

### 2.2 递归深度 = 经济复杂度

```
红瓶：递归深度 2 → 初学者·手搓即可
绿瓶：递归深度 4 → 需要基本传送带线
蓝瓶：递归深度 7 → 需要完整的工厂布局
黄瓶：递归深度 10+ → 需要机器人·火车·多工厂协调
白瓶：递归深度 ∞ → 无限科技·需要巨型工厂

经济深度不是"有多少种东西"——
而是"造一个东西需要经过多少次转化"。
```

### 2.3 对星河倒悬法器锻造的映射

```
Factorio：铁板→铁齿轮→传送带→绿电路板→红电路板→蓝电路板
星河倒悬：青铜→精炼青铜→法器胚→淬火法器→铭刻法器→纳音法器→共鸣法器→+9法器

每个阶段：
  └→ 需要特定材料（类似 Factorio 的中间产品）
  └→ 需要特定工序（类似 Factorio 的组装机）
  └→ 可能有概率失败（锻造不是100%成功·类似 Factorio 的品控）
  └→ 每加一级·材料需求翻倍或改变（类似科技包升级）
```

## 三、通胀控制——"稀缺性转移"

### 3.1 Factorio的资源稀缺性随时间变化

```
游戏初期（0-2小时）：
  稀缺资源：铁板·铜板（没建好矿场）
  充裕资源：煤（到处都有）
  
游戏中期（2-10小时）：
  稀缺资源：石油·塑料·红电路板
  充裕资源：铁板·铜板（自动化了）
  
游戏后期（10-50小时）：
  稀缺资源：蓝电路板·速度模块·机器人框架
  充裕资源：基础矿物（矿场覆盖全图）
  
游戏终局（50+小时）：
  稀缺资源：白瓶科技·UPS（计算资源！）
  充裕资源：除了UPS·一切都是无限的
```

**稀缺性不是被"消灭"了——是"转移"了。**

在星河倒悬中：
```
星纪宫（初期）：
  稀缺：青铜·铁
  充裕：无·什么都缺
  
降娄宫（中期）：
  稀缺：精铁·钢·秘银
  充裕：青铜·铁
  
鹑火宫（后期）：
  稀缺：陨铁·星核·九天星晶
  充裕：精铁·钢·秘银
```

### 3.2 瓶颈原理

Factorio 的任何生产线都有一个"瓶颈"——最慢的那个环节：

```
你的绿电路板生产线：
  铜线（3台组装机）→每小时3600根
  电路板（2台组装机）→每小时2400块
  但如果铜板供应不足→铜线产出降到1800/小时→电路板只有1200/小时
  
  瓶颈从"电路板组装机不够"变成了"铜板不够"
```

**在星河倒悬中：**
法器锻造的瓶颈不应该总是"缺星晶"——应该在不同阶段有不同的瓶颈：
- 初期瓶颈：缺青铜（去星纪宫矿洞刷）
- 中期瓶颈：缺精铁（去降娄宫剑冢刷）
- 后期瓶颈：缺星核（去寿星宫刷·或摇卦揭示隐藏位置）

## 四、风险机制——"工厂停摆"的恐惧

### 4.1 Factorio的"风险"不是战斗——是"供应中断"

```
你的铁板生产线：
  每天消耗铁矿3000
  你的矿场储量：铁矿100,000 → 还能用33天
  
  "33天"在你的脑海中挥之不去
  你告诉自己"我应该在铁矿用完之前找到新矿脉"
  
  但你正在建蓝瓶生产线……
  然后又去修铁路……
  然后又去处理虫族入侵……
  
  突然——33天后——铁板停产了
  铁板停产 → 齿轮停产 → 传送带停产 → 绿瓶停产 → 科技停滞
  → 你在打虫族·子弹用完了 → 不能造子弹 → 虫族摧毁了你的工厂
  
  这就是 Factorio 的"死亡"
  不是 HP 归零——是"铁板停产"
```

### 4.2 虫族=外部风险

虫族攻击你的工厂→破坏生产线→生产中断→资源链断裂。这是 Factorio 版的"BOSS战"。

## 五、对"星河倒悬"的具体启示

### 5.1 法器锻造材料链设计

借鉴 Factorio 的递归深度概念：

```
银针 → 不需要锻造·天生的法器（序章）

桃木剑：
  Lv+1：青铜×3 + 桃木×1 → 深度2
  Lv+3：精炼青铜×2 + 雷击桃木×1（需要雷卦采集）→ 深度3
  Lv+5：淬火青铜×2 + 千年雷击木×1（需要奇门遁甲揭示位置）→ 深度5
  Lv+7：陨铁×1 + 星核×1（需要互卦揭示隐藏矿脉）→ 深度7
  Lv+9：九天星晶×1（需要连互卦）→ 深度10·终局追求

乾坤圈（奇门遁甲·阵法法器）：
  Lv+1：铁×5 + 磁石×2 → 深度3
  Lv+5：磁化钢×3 + 星晶碎片×2 → 深度6
  Lv+9：陨铁环×1 + 九天星晶×2 → 深度12（比桃木剑更深·因为阵法更复杂）
```

### 5.2 材料瓶颈轮转

| 阶段 | 稀缺材料 | 获取方式 | 充裕材料 |
|------|------|------|------|
| 星纪→娵訾 | 青铜·铁 | 矿洞·星纪宫冰原矿脉 | 无 |
| 降娄→实沉 | 精铁·钢·秘银 | 降娄宫剑冢·实沉宫战场遗址 | 青铜·铁 |
| 鹑首→大火 | 陨铁·星核 | 互卦揭示·鹑火宫机关城核心 | 精铁·钢·秘银 |
| 析木→寿星 | 九天星晶·星君碎片 | 连互卦·寿星宫化史炉废墟 | 陨铁·星核 |

### 5.3 Factorio"主总线"思路

Factorio 玩家会把所有关键材料放在一条"主总线"上：

```
[铁矿]→[铁板]═══╦═══[齿轮]═══[传送带]
                  ╠═══[钢管]═══[引擎]
                  ╚═══[电路板]══[红电路板]
[铜矿]→[铜板]═══╦═══[铜线]═══╝
                  ╚═══[低密度结构]
```

在星河倒悬中——法器锻造界面应该有类似的"材料树"可视化：

```
青铜 ──→ 精炼青铜 ──→ 淬火青铜 ──→ ＋5法器
  │          │              │
  └→铁      └→星晶         └→陨铁（需要互卦揭示矿脉位置）
```
