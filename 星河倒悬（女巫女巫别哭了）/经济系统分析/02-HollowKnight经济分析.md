# 经济系统分析 #02：Hollow Knight

> **类型：** Metroidvania · 横版动作 · 单存档
> **经济模型：** 单货币·死亡掉落·文物保险·精确总量控制
> **分析日期：** 2026-08-04
> **对星河倒悬参考价值：** ⭐⭐⭐⭐⭐ 核心参考

## 一、货币设计——极简的"吉欧"体系

### 1.1 单货币哲学

Hollow Knight 只使用**一种货币**——吉欧（Geo）。没有第二货币，没有材料货币，没有高级货币。**就一种。**

```
吉欧的来源：
  ├─ 杀敌掉落（1/5/25吉欧·随敌人等级）
  ├─ 破坏吉欧矿脉（一次性·各区域固定数量）
  ├─ 宝箱/隐藏区域（一次性）
  ├─ 出售文物给里姆（一次性·按文物不同价格不同）
  ├─ 竞技场试炼（可重复·1000/2000/3000吉欧）
  └─ 拯救幼虫的奖励（一次性·幼虫之父给钱）

吉欧的用途：
  ├─ 在商人处买护符/道具/地图
  ├─ 升级骨钉（武器）
  ├─ 购买护符槽位
  ├─ 开启鹿角虫车站/长椅
  └─ 修复易碎护符（可重复消费）
```

### 1.2 为什么单货币可行

单货币能在 Hollow Knight 中完美运作，因为：

| 条件 | Hollow Knight 的满足方式 |
|------|------|
| **总消费量可控** | 全解锁约需69,000吉欧·设计师精确计算过 |
| **产出节奏可控** | 敌人掉落少（1-25）·文物一次性·竞技场可刷但后期才开 |
| **有持续消耗口** | 易碎护符修复（120-350吉欧/次·可重复） |
| **世界观自洽** | 吉欧是"圣巢的化石贝壳"——这个世界崩坏后残留的货币 |

### 1.3 第二层货币：文物系统（死亡保险）

文物是 Hollow Knight 经济系统中最精妙的设计：

| 文物 | 卖给里姆的价格 | 获取地点 |
|------|:--:|------|
| 漫游者日记 | 200 | 各处·最常见 |
| 圣巢印章 | 450 | 王国边缘·深邃巢穴 |
| 国王神像 | 800 | 古老盆地·白色宫殿 |
| 奥术之蛋 | 1200 | 各处隐藏·极稀有 |

**文物=不掉落的吉欧。** 文物在背包里永远不会因死亡丢失。玩家可以把文物当作"定期存款"——攒着不卖，需要大量吉欧时一次性变现。

```
策略对比：
  菜鸟玩家：拿到文物马上卖→吉欧→可能死→全丢了
  聪明玩家：囤文物→需要买关键物品时→一次性卖够→立即花光→不持有大量吉欧
  骨灰玩家：文物+竞技场反复刷→凑齐36000吉欧→一次买断不屈护符
```

## 二、资源循环

### 2.1 Taps（吉欧来源）——极其克制

| 来源 | 类型 | 吉欧量 | 重复性 |
|------|:--:|:--:|:--:|
| 普通敌人 | 可重复 | 1-25/只 | 但极其低效·杀50只=250吉欧 |
| 吉欧矿脉 | 一次性 | 5-420/处 | 探索完即无 |
| 宝箱 | 一次性 | 50-500/个 | 分散在各处 |
| 文物出售 | 一次性 | 200-1200/件 | 全游戏约30-40件文物 |
| 竞技场试炼 | 可重复 | 1000/2000/3000 | 后期解锁·效率最高 |
| 幼虫奖励 | 一次性 | 随数量递增 | 全游戏46只幼虫 |

**Hollow Knight 的产出极其克制。** 大部分游戏时间里，玩家都在"攒钱"而不是"花钱"。这种稀缺感是刻意设计的——让你珍惜每一块吉欧矿脉。

### 2.2 Converters（吉欧转化）

```
吉欧 → 永久升级（骨钉·护符槽·鹿角虫车站）
       → 可消耗道具（护符·地图标记·钥匙）
       → 修复费用（易碎护符·可重复）
```

### 2.3 Drains（吉欧流失）

| Drain | 影响 | 设计意图 |
|------|------|------|
| **死亡掉落** | 全丢·需要跑尸取回·二次死亡=永久丢失 | 制造紧张感·类似魂系但更温和（地图更小·跑尸更容易） |
| **灵魂破碎** | 跑尸失败→灵魂容器碎裂→最大灵魂减少1/3 | 双重惩罚——不仅丢钱·还降低战斗能力 |
| **易碎护符修复** | 120-350吉欧/次 | 无限重复消费·终局吉欧出口 |

## 三、通胀控制——"精确计算"的隐形之手

### 3.1 全解锁费用精确计算

社区玩家精确计算了全解锁所需吉欧：

| 类别 | 吉欧 |
|------|--:|
| 鹿角虫车站 | 1,560 |
| 长椅过路费 | 800 |
| 骨钉升级（0→4级） | 7,050 |
| 柯尼法的地图 | 1,079 |
| 伊塞尔达的商店 | 1,780 |
| 易碎护符（军团之胃） | 986~1,286 |
| 萨鲁巴的护符/槽位 | 5,410 |
| 斯莱的商店 | 9,260 |
| 竞技场解锁 | 1,350 |
| 奥罗的剑技 | 800 |
| 容器碎片（喷泉） | 3,000 |
| **不屈护符（神之驯服者）** | **36,000** |
| **总计** | **~69,000** |

### 3.2 不屈护符——终局的"无底洞"

**36,000吉欧——占全游戏吉欧消费的53%。**

这是 Hollow Knight 经济系统最厉害的一招。当你花完了前面33,000吉欧买完了所有东西——你以为吉欧已经没用了——然后你遇到了神之驯服者。

```
不屈力量（力量护符的不屈版）= 15,000吉欧
不屈之心（生命护符的不屈版）= 12,000吉欧
不屈贪婪（贪婪护符的不屈版）= 9,000吉欧
────────────────────────────────
合计                                36,000吉欧
```

这36,000吉欧需要：
- 刷竞技场第三试炼12次（3,000×12=36,000·每次约15-20分钟→约3-4小时）
- 或者刷普通敌人——大约需要杀7,200只普通敌人

**"我已经通关了——但我还要回去刷竞技场。"** ——这就是终局经济黑洞的作用。给完美主义玩家一个继续玩的理由。

## 四、风险机制——"死亡恐惧"的银河城版本

### 4.1 死亡掉落系统

```
死亡 →
  所有吉欧掉落在死亡点（一个黑色灵魂浮在空中）
  灵魂容器破碎 → 最大灵魂减少1/3
  
  你必须从最后坐过的长椅复活 →
  跑回死亡点 →
  击败你的"暗影"（一个会攻击你的黑色分身）→
  取回吉欧·修复灵魂容器
  
  如果在跑尸途中再次死亡 →
  旧暗影消失（包含旧吉欧）→
  新暗影生成（包含新吉欧）→
  旧吉欧永久丢失
```

### 4.2 与魂系的对比

| 维度 | 黑暗之魂/艾尔登法环 | Hollow Knight |
|------|------|------|
| 丢失内容 | 所有灵魂/卢恩 | 所有吉欧+1/3灵魂容量 |
| 跑尸距离 | 长·可能5-10分钟 | 短·通常1-3分钟 |
| 取回方式 | 触碰血迹 | 击败暗影 |
| 二次死亡 | 旧灵魂消失 | 旧暗影+旧吉欧消失 |
| 难度 | 高（路上的敌人重置了） | 中（地图小·捷径多） |
| 保险机制 | 牺牲戒指 | 文物不掉落+银行（虽然是骗局） |

### 4.3 米莉贝儿的银行——叙事化经济设计

这是游戏史上最精彩的"经济叙事"设计之一：

```
迷雾峡谷·米莉贝儿银行：
  存入100吉欧即可开户
  最多可存4,500吉欧
  死亡后存款仍在（不像持有的吉欧会丢！）
  
  听起来很安全？
  
  当你存够2,500吉欧后——
  米莉贝儿卷款跑路。
  银行变成空壳。门外挂了个"歇业"的牌子。
  
  追踪她到欢愉之屋 →
  发现她在泡温泉 →
  攻击她 → 她掉出约1.5倍的存款（3,750吉欧）
  
  她惊恐地说："我只是借去周转一下！"
```

**这个设计的经济学意义：**
- 告诉玩家"没有绝对安全的财富存储"
- 但给你一个"追回财富"的机会（而且还有利息）
- 让"银行"从一个冰冷的机制变成了一个有人物的故事
- 用叙事告诉你：**在这个世界，没有什么是可以完全信任的**

## 五、行为引导

### 5.1 引导：探索而非战斗

```
Hollow Knight：杀一只普通虫=2吉欧·升级骨钉=250~4000吉欧

结论：靠杀敌升级是痴人说梦。你必须探索。
     └→ 找吉欧矿脉（一次性·但量大）
     └→ 找文物（一次性·但值钱）
     └→ 找宝箱（一次性·最好的东西都在隐藏区域）
```

### 5.2 引导：风险自评

```
"我身上有2,000吉欧。前方是深邃巢穴——我没去过的地方。"
  
  选项A：继续前进 → 可能死·可能找到新的吉欧矿脉
  选项B：回头去泪城找斯莱买东西 → 安全·但跑路浪费时间
  选项C：先去卖掉背包里的文物→再决定
  
  每一个玩家都在练习"风险评估"这个核心技能。
```

### 5.3 引导：消费而非囤积

游戏用死亡系统反复告诉你：**花掉它。**

```
持有吉欧 = 有风险（死亡会丢）
花钱 = 零风险（骨钉升级永远不丢·护符永远不丢）

所以——每到一个新商店→立刻花光。这是最优策略。
```

## 六、对"星河倒悬"的具体启示

### 6.1 可以借鉴的

| 借鉴点 | Hollow Knight做法 | 星河倒悬应用 |
|--------|-----------------|-------------|
| **精确总量控制** | 全解锁69000吉欧·设计者心中有数 | 估算全法器锻造+9需多少铜钱/星晶·严格控制 |
| **终局经济黑洞** | 不屈护符36000吉欧=53%总消费 | 七星剑锻造+9需要大量星晶+九天星晶·占50%以上 |
| **文物=不掉落货币** | 文物在背包不掉·卖店换吉欧 | 星晶不掉落·铜钱掉20-30%·但星晶不能"卖"只能"用" |
| **单一货币哲学** | 只有吉欧·清晰简单 | 铜钱+星晶双层·已经是极简 |
| **银行叙事化** | 米莉贝儿骗局·经济=故事 | 太史阁化史炉——敌人正在"烧钱"——星晶被投入化史炉转换成青焰能量 |
| **跑尸取回** | 击败暗影取回吉欧 | 星碑前死亡→在星碑处复活·星碑保留70%铜钱 |

### 6.2 独特的星河倒悬适配思路

**"太史阁化史炉"——敌人也在消费星晶：**

```
游戏中后期发现：
  太史阁的化史炉正在燃烧星晶来制造青焰——
  那些你杀死的太史阁敌人身上应该掉落的星晶
  被他们"提前用掉了"
  
  叙事→经济映射：
  第1-3宫：太史阁敌人掉星晶较多（化史炉还没烧到他们）
  第4-6宫：发现化史炉·部分太史阁敌人不掉星晶（"被抽走了"）
  第7-9宫：海溟暗卫掉星晶（他们掠夺了太史阁的库存）
  第10-12宫：商徵和国师——他们身上掉海量星晶·因为化史炉就是他们在烧
```
