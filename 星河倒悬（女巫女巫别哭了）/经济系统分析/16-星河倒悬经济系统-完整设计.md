# 星河倒悬——完整经济系统设计

> **设计依据：** 15款全球优秀游戏经济系统分析 + 卦术占卜与经济探索系统 + 共享接口定义
> **设计日期：** 2026-08-04

---

## 〇、设计总纲——"每一文钱都有重量"

### 0.1 核心设计目标

```
1. 铜钱会痛（死亡丢20-30%·但不会全丢）
   └→ 借鉴：Elden Ring的死亡掉落·Hollow Knight的温和版
   
2. 星晶永远稀缺（最珍贵的货币·不可购买·不可刷）
   └→ 借鉴：Hollow Knight的终局黑洞·Hades的泰坦之血
   
3. 锻造=核心经济循环（材料→锻造→铭刻→消费·闭环）
   └→ 借鉴：Factorio的材料链·流放之路的通货即消耗品
   
4. 卦术驱动经济决策（寻宝靠卦·问商靠卦·每日运势引导行为）
   └→ 借鉴：星露谷的季节节奏·动物森友会的每日配额
   
5. 12座道宫=12个经济节奏（物价·材料·稀缺性各有不同）
   └→ 借鉴：星露谷的四季节奏·Anno 1800的阶层需求
```

## 一、货币体系——双层货币 + 锻造通货

### 1.1 铜钱（Copper Coin）——日常货币

| 维度 | 设计 | 借鉴来源 |
|------|------|------|
| **来源** | 杀敌掉落·卖材料·任务奖励·宝箱·日卦加成 | Elden Ring（杀敌） + 星露谷（多元收入） |
| **用途** | 买锻造材料·符纸·丹药·星碑传送(50文)·摇卦(5文)·修理 | Hollow Knight（吉欧） |
| **死亡惩罚** | 掉落20-30%·在死亡点星碑取回·二次死亡=永久丢失那部分 | Elden Ring（魂系死亡）+ 自制（温和版） |
| **携带上限** | 无硬上限·但死亡惩罚随携带量递增 | 自制 |
| **通胀控制** | 12道宫物价1.0→2.5·修理费随装备等级暴涨 | 巫师3（区域物价） + Hollow Knight（修理费） |

**铜钱死亡惩罚细则：**

```
死亡时：
  携带铜钱 ≤ 100文：掉落20%（新手保护·损失极小）
  携带铜钱 100-500文：掉落25%
  携带铜钱 500-2000文：掉落30%
  携带铜钱 > 2000文：掉落30% + "太史阁巡逻队"概率出现在死亡点附近（低级敌人·干扰跑尸）

跑尸取回：
  回到死亡点 → 星碑处出现一个"遗落铜钱堆" → 按F取回
  如果在取回前再次死亡 → 之前的遗落铜钱消失 → 新的遗落铜钱生成（只包含本次死亡掉落的铜钱）
  → 二次死亡=上次的铜钱永久丢失

取回失败后·星碑提示：
  "铜钱已散·太史阁巡逻队收走了它们"
  → 叙事化惩罚·不是冰冷的数字归零
```

**为什么不是全丢？**
Elden Ring全丢太硬核。星河倒悬面向更广的玩家群。掉20-30%——你能感觉到痛，但不致命。这也鼓励你"常花钱"而不是"囤着铜钱"（借鉴Hollow Knight的引导逻辑）。

### 1.2 星晶（Star Crystal）——稀有货币

| 维度 | 设计 | 借鉴来源 |
|------|------|------|
| **来源** | BOSS首杀·隐藏宝箱·三钱摇卦寻宝·互卦深层·专属互动卦 | Hades（泰坦之血·极稀有） + Hollow Knight（不屈护符） |
| **用途** | 高端锻造·法器铭刻·法器共鸣·法器+9→+10终极突破 | Hades（武器形态升级） |
| **死亡惩罚** | **永不丢失**（类似Hollow Knight的文物） | Hollow Knight（文物=不掉落货币） |
| **可购买？** | **不可**（类似Hades泰坦之血不能买） | Hades（单向兑换·不可逆） |
| **可兑换？** | **不可用铜钱兑换**（"往下容易·往上不可能"） | Hades（单向兑换） |
| **通胀控制** | 全游戏限量（每座道宫约5-15枚·总计约100-120枚） | Hollow Knight（精确总量控制） |

**星晶的全游戏分布：**

| 来源 | 数量 | 说明 |
|------|:--:|------|
| 12个BOSS首杀 | 2-5/个·约48枚（详见§2.3 BOSS表） | BOSS战核心奖励 |
| BOSS专属互动卦 | 1/次·约12枚（12个BOSS各1·基础约67%概率触发） | 高风险高回报 |
| 三钱摇卦寻宝（互卦） | 0-3/道宫·约20枚 | 卦术探索驱动 |
| 隐藏宝箱（梅花易数观象） | 0-2/道宫·约15枚 | 环境探索驱动 |
| 连互卦至暗宝藏 | 1/道宫·12枚 | 终极探索·每宫仅1次 |
| 九天星阵特殊事件 | 5枚 | 终局内容 |
| **总计** | **约112枚** | 精确控制 |

### 1.3 锻造通货——消耗品即货币

借鉴流放之路的"通货即消耗品"设计：

| 锻造通货 | 功能 | 稀有度 | 获取方式 |
|------|------|:--:|------|
| **青铜矿石** | 基础锻造·Lv+1~+3 | 常见 | 星纪宫矿洞 |
| **精炼青铜** | 中级锻造·Lv+3~+5 | 不常见 | 锻造台合成（3青铜→1精炼） |
| **陨铁** | 高级锻造·Lv+5~+7 | 稀有 | 降娄宫·鹑火宫·BOSS掉落 |
| **星核** | 顶级锻造·Lv+7~+9 | 极稀有 | 互卦寻宝·鹑尾宫·析木宫 |
| **九天星晶** | 终极突破·Lv+9→+10 | 传奇 | 寿星宫·连互卦·特定日卦日 |
| **铭刻石** | 给法器增加一条随机铭文 | 稀有 | 大梁宫书市·三钱摇卦奖励 |
| **纳音石** | 重roll一条铭文的数值 | 稀有 | 大火宫幻音楼·隐藏区域 |
| **共鸣石** | 两件法器词缀合并 | 极稀有 | 连互卦奖励·析木宫 |
| **星辉淬火液** | 修复休眠法器 | 不常见 | 星碑·任何道宫·花费铜钱制作 |

**这些"锻造通货"的经济学意义：**
- 它们本身就是消费品——用了就消失（类比流放之路的改造石）
- 不会囤积（因为"用了可能变强·也可能变弱"——存在赌博成分）
- 消耗=从经济中永久消失=反通胀（类比流放之路的通货循环）

## 二、收入体系——"杀敌·探索·BOSS·同伴"四支柱

### 2.1 支柱一：杀敌掉落（稳定·可刷·但效率递减）

| 敌人类型 | 铜钱 | 材料 | 星晶 | 刷怪衰减 |
|------|:--:|------|:--:|------|
| 杂兵 | 5-20文 | 普通材料·50%概率 | 0 | 前20只正常·21-50只掉钱-30%·51+只触发巡逻队 |
| 精英 | 30-80文 | 稀有材料·30%概率 | 0-1 | 衰减更慢·前10只正常 |
| BOSS | 100-300文 | 史诗材料·100% | 2-5 | 首杀全奖·重复打不掉星晶·铜钱-50% |

**刷怪衰减机制（借鉴巫师3"牛魔防卫军"）：**

```
玩家在短时间内反复刷同一区域的同类型敌人：

第1-20只（正常）：
  → 无衰减·正常掉落

第21-50只（衰减）：
  → 铜钱掉落-30%
  → 屏幕提示："学徒身上的铜钱被你搜刮完了"（叙事化）

第51-100只（巡逻队）：
  → 铜钱掉落降至30%（-70%惩罚）
  → 太史阁巡逻队出现（精英怪·等级比当前区域高5-10级）
  → 干扰刷怪·击败巡逻队不掉星晶

第100+只之后：
  → 该区域该敌人类型不再掉落铜钱（材料仍掉落）
  → 引导玩家去新区域
```

**为什么这样设计？**
- 允许刷·但不鼓励反复刷同一区域（不有趣）
- 用叙事包装惩罚（"巡逻队"·"搜刮完了"）而不是冰冷的数值
- 自然引导玩家去新区域（类似Elden Ring的区域卢恩密度梯度）

**总计一把法器Lv+1→+9：约5300铜钱·29星晶·跨越5-7座道宫的材料（以上为单次成功成本·不含失败重试）**

> **⚠️ 重要：以上为"一次成功"成本。锻造存在失败概率（见《17-经济系统深度扩展》§11），期望成本约10,950铜钱·51星晶。下文的"4法器+9"分析已用期望成本校正。**

全游戏有4把主法器（银针·桃木剑·铜钱剑·七星剑）+8把副手法器。如果玩家追求全法器+9：

| 视角 | 单法器星晶 | 4主法器星晶 | vs 全游戏总量(112) | 结论 |
|------|:--:|:--:|:--:|------|
| 简单成本（一次成功） | 29 | 116 | 104% | 4把全+9理论可行·但需几乎完美运气 |
| **期望成本（含失败·保底）** | **51** | **204** | **182%** | **4把全+9不可能·2把已达极限** |

**这个设计确保：**
1. 一把法器+9是舒适可达目标（期望51星晶·占总量约46%）
2. 两把主法器+9需要精心规划和全探索（期望102星晶·占总量约91%）
3. 三把以上主法器+9几乎不可能（需要153+星晶）——玩家必须在法器之间做出真正的取舍
4. "选择哪把法器优先+9"是游戏中最核心的经济决策之一

## 四、物价体系——12道宫·12个经济节奏

### 4.1 道宫物价系数

## 七、终局经济——"九天星阵"

### 7.1 终极目标设计

借鉴Hollow Knight的"不屈护符=53%总消费"和戴森球计划的"戴森球=终极出口"：

**九天星阵 = 星河倒悬的终极经济目标**

```
解锁条件：
  ✅ 全部12座道宫通关
  ✅ 至少一把法器达到Lv+9
  ✅ 收集全部12位同伴的星君信物
  ✅ 收集至少50枚星晶（全游戏约100枚·需要50%的收集率）
  ✅ 在寿星宫星碑前·三钱摇卦摇出特定卦（䷀乾或䷊泰或䷾既济·约1/21概率）
  ✅ 消耗10枚九天星晶（全游戏仅12枚·需要83%的收集率）

仪式过程：
  寿星宫星碑 → 九天星阵仪式 →
  法器升华为"九天星辰剑/九天星辰针/九天星辰钱/九天星辰图"
  
  外观变化：法器化为星光·周围环绕行星轨道（戴森球视觉）
  属性变化：全卦术伤害+50%·卦气消耗-50%·太乙神数9键时间延长至6秒
  卦象变化：互卦·连互卦·变爻全解锁·不再消耗卦气

终极效果：
  你的法器不再只是一件武器——
  它是你走过十二座道宫·收集了十二位同伴的信物·
  摇过无数次三钱卦·在每一个星碑前做出选择的证明
```

### 7.2 为什么需要"终极出口"

借鉴Hollow Knight——不屈护符36000吉欧占全游戏53%消费——给了玩家一个"通关后还在玩"的理由。

借鉴戴森球计划——戴森球是"你永远可以再多造一层"的目标。

星河倒悬的"九天星阵"=62.5%的星晶全消耗（10/16件法器的星晶量）+ 83%的九天星晶收集率。它不是一个"顺便完成"的目标——是你必须有意识地追求的东西。

## 九、防刷机制——"不让玩家无聊"

### 9.1 四大防刷设计

| 防刷方式 | 机制 | 借鉴 |
|------|------|------|
| **效率递减** | 同区域同敌人刷超过20只→铜钱掉落递减→50只后几乎不掉 | 巫师3·牛魔防卫军 |
| **巡逻队干扰** | 刷超过50只→精英巡逻队出现→等级压制刷怪玩家 | 自制·叙事包装 |
| **BOSS无重复奖励** | BOSS首杀全奖·重复击杀不掉星晶·铜钱-50% | Elden Ring·追忆只能拿一次 |
| **每日配额** | 星晶寻宝每区域24h冷却·日卦每天自动更换 | 动物森友会·每日限量 |

### 9.2 防刷哲学

我们不"禁止"刷——我们"引导不刷"。刷怪本身没有错——但反复刷同一只怪很无聊。我们让刷怪的成本（巡逻队·效率递减）高于"去探索新区域"的成本——玩家自然会选择更有趣的路。
