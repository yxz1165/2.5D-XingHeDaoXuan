## 十、物资系统——完整属性数据表

### 10.1 设计方法论：为什么每件物资需要12个属性

游戏经济系统崩溃最常见的三个原因：（1）某材料通货膨胀——因为掉落太多而用途太少；（2）某材料永远不够——因为掉落太少而用途太多；（3）背包管理崩溃——因为堆叠上限不合理导致玩家频繁跑仓库。

12个属性构成一个自洽的物资定义：

| 属性 | 作用 | 缺失的后果 |
|------|------|------|
| **稀有度等级** | 决定掉落概率的数量级 | 掉落"凭感觉设"→供需失衡 |
| **基础卖价** | 卖给商人的基准价格 | 玩家不知道该留该卖 |
| **基础买价** | 从商人处购买的价格 | 商人定价无依据 |
| **买/卖价比** | 交易效率 | 套利漏洞或经济死循环 |
| **堆叠上限** | 同格可携带数量 | 背包管理体验崩塌 |
| **重量** | 占负重比例 | 负重系统形同虚设 |
| **主要掉落来源** | 哪些敌人/区域产出 | 玩家不知道该去哪刷 |
| **掉落概率基数** | 基础掉率 | 同上 |
| **主要用途** | 消费出口 | 供需匹配 |
| **用途消耗量级** | 每次使用消耗多少 | 供需失衡 |
| **是否是锻造链上游** | 是否可加工为高级材料 | 材料链断裂 |
| **道宫解锁** | 在哪座道宫首次出现 | 进度门控 |

**价格推导逻辑：**

```
基础定价公式：
  卖价 = 稀有度基数 × 获取难度系数 × 用途广度系数
  
  稀有度基数：常见=2, 不常见=5, 稀有=15, 极稀有=40, 传奇=100
  获取难度系数：矿脉采集=1.0, 精英掉落=1.5, BOSS掉落=2.0, 连互卦=3.0
  用途广度系数：单用途=1.0, 双用途=1.3, 多用途=1.6
  
  例：陨铁=15(稀有)×2.0(BOSS)×1.3(锻造+铭刻)=39→取整40→卖价120(3×40)
  实际卖价最终经过"体感调整"——让数字"看起来对"
```

**买/卖价比设计哲学：**

```
常见材料(铜矿/铁矿)：买价=卖价×2.5
  → 卖了再买回来亏60% → 鼓励"采矿"而非"倒卖"
  
稀有材料(精炼铁)：买价=卖价×3.0
  → 卖了再买回来亏67% → 更强烈的"别卖"信号
  
不可购买材料(陨铁/星核/九天星晶)：
  → 最高价值只能"打"出来 → 流放之路哲学
```

## 十一、锻造概率模型——风险与保险的数学

### 11.1 为什么锻造需要概率

如果锻造只是"交材料=升级"，那经济系统就变成了一个计算器——玩家只需要算出最短路径。没有情绪，没有故事。

概率带来：
- **赌博的快感**（"这次会不会成？"）
- **失败的痛苦**（"炸了！我的陨铁！"）
- **成功的狂喜**（"+9了！四块陨铁一次过！"）
- **社区谈资**（"我+7到+8炸了5次你敢信？"）

但概率不能无限——我们需要保底机制防止极端倒霉。

### 11.3 期望成本计算（简化模型·精确值标注差异）

> **注意：** 以下推导使用简化模型——将 "从降级等级恢复到目标等级" 的期望次数近似为1次。精确模型中，恢复步骤本身也存在失败概率，实际期望值比简化模型高约5-8%。设计文档层面，简化模型已足够指导方向；开发时建议用蒙特卡洛模拟验证精确值。

```
定义：
  C(n) = 从+(n-1)锻造到+n的期望材料成本
  p(n) = +(n-1)→+n的成功率
  cost(n) = 单次尝试的材料成本
  penalty(n) = 失败时的额外损失（以材料成本计·含降级损失）

期望尝试次数 E(n) = 1/p(n)（无保底·单次独立试验）

考虑降级惩罚后：
  E_actual(n) = 1/p(n) + (1-p(n))/p(n) × P_degrade × E(recovery)
  其中 P_degrade 是失败时降级的概率（+4以下=0, +5以上=1）
  E(recovery) 是从降级后的等级恢复到目标等级的期望成本

简化计算（假设降级后只需重试一级）：

+0→+3（无降级风险）：
  E(+1)=1.00次, E(+2)=1.05次, E(+3)=1.11次
  总期望尝试次数：约3.2次
  总期望材料：约3×青铜 + 5.25×青铜 + 2.2×精炼青铜 + 1.1×桃木
  ≈ 8.25青铜 + 2.2精炼青铜 + 1.1桃木

+4→+5（有降级风险·最低+3）：
  E(+5) = 1/0.7 + 0.3/0.7 × E(+4→+5重试) 
  设 x = 从+4到+5的期望尝试次数
  x = 1 + 0.3×(1 + x)  （失败→降级到+3→需要先回+4→再试+5）
  x = 1 + 0.3 + 0.3x
  0.7x = 1.3
  x ≈ 1.86次尝试（含失败恢复）
  
  同理 +6→+7（50%成功率·降级到+5）：
  x = 1 + 0.5×(1/0.7 + x)  （失败→降到+5→需要1/0.7次回+6）
  x = 1 + 0.71 + 0.5x
  0.5x = 1.71
  x ≈ 3.42次尝试
```

**各等级实际期望成本表（含降级恢复）：**

| 等级 | 期望尝试次数 | 期望铜钱成本 | 期望星晶成本 | 期望稀有材料成本 |
|:--:|:--:|:--:|:--:|------|
| +0→+3 | 3.2 | ~250 | 1 | 青铜~15·桃木~2 |
| +3→+5 | 2.9 | ~800 | 3 | 精炼青铜~5·雷击桃木~1.5·千年雷击木~1.2 |
| +5→+7 | 5.3 | ~2,400 | 12 | 陨铁~5·星核~5·暗影精华~1.5 |
| +7→+9 | 8.8 | ~7,500 | 35 | 陨铁~10·星核~10·九天星晶~3·星辉~1·量子碎片~1 |
| +0→+9 期望总计 | ~20 | ~10,950 | ~51 | — |

**关键发现：**
- 一把法器+0→+9的期望星晶成本（51）远超全游戏星晶（约112）的45%
- 期望铜钱成本（~10,950）远超简单加法（5,300）的2倍——因为降级惩罚
- 这意味着玩家平均只能将约2把法器升到+9——这正是设计目标

### 11.4 情绪峰值设计

锻造过程的情绪曲线：

```
+0→+3（成功率90-100%）：
  情绪：轻松·"这很简单"
  设计意图：新手期——让玩家建立"锻造=好事"的正向关联
  
+3→+5（成功率70-80%）：
  情绪：微紧张·第一次失败
  设计意图：引入失败概念——但代价很低（不掉级）
  
+5→+7（成功率50-60%）：
  情绪：真正的紧张——"别掉别掉"
  设计意图：核心体验——成功=巨大满足·失败=真实痛苦
  
+7→+9（成功率25-40%）：
  情绪：极度紧张——手心出汗
  设计意图：终局体验——每一次尝试都是一个故事
  
+9→+10（成功率10%）：
  情绪：传奇——如果成功·这是你游戏生涯最难忘的时刻之一
  设计意图：终极赌博——不是为了数值·是为了"我做到了"的证明
```

### 11.5 铭刻系统经济模型（词缀概率分布）

铭刻 = 给法器增加一条随机词缀。借鉴流放之路的崇高石。

**词缀池（Tier分布）：**

| 词缀等级 | 概率 | 效果范围 | 例子 |
|:--:|:--:|------|------|
| T1（普通） | 45% | 小数值加成 | 火卦伤害+3%~6% |
| T2（魔法） | 30% | 中等数值或双属性 | 火卦伤害+7%~12%·或·火卦+4%+暴击+2% |
| T3（稀有） | 15% | 高数值或特殊效果 | 火卦伤害+13%~18%·或·火卦消耗-15% |
| T4（传说） | 7% | 极高数值或机制改变 | 火卦伤害+19%~25%·或·火卦可触发两次（20%概率） |
| T5（神话） | 3% | 改变玩法 | 火卦暴击时·刷新所有火卦冷却·或·火卦击杀扩散灼烧 |

**铭刻石期望价值：**

```
设玩家追求"至少T3以上"的铭文：
  单次铭刻达到T3+概率 = 15%+7%+3% = 25%
  期望铭刻次数达到T3+ = 1/0.25 = 4次
  期望铭刻石消耗 = 4枚

设玩家追求"至少T4以上"的铭文：
  单次铭刻达到T4+概率 = 10%
  期望铭刻次数 = 10次
  期望铭刻石消耗 = 10枚

设玩家追求T5特定词缀（假设T5有3种·每种1%概率）：
  期望铭刻次数 = 100次
  → 全游戏铭刻石不够·不可能全T5
```

**铭刻策略空间设计：**

每件法器最多承载3条铭文。当法器已有3条铭文时，新铭刻会随机替换其中一条——这意味着：
- 玩家需要在"保留现有不错的词缀"和"冒险追求更好的词缀"之间抉择
- 铭刻的边际价值随词缀数递减（第一条提升最大·第三条最小）
- 4件主法器×3条铭文=12条铭文需要管理——策略深度足够

### 11.6 纳音系统——可控的随机

纳音石 = 重roll一条铭文的数值（不改变词缀类型和Tier）。

与铭刻的关键区别：
- **铭刻**：改变词缀（不可逆·高风险·可能从T4掉到T1）
- **纳音**：只改数值（低风险·不会降Tier·但可能roll到低值）

**纳音的期望价值：**

```
假设一条T4铭文"火卦伤害+19%~25%"当前值为20%（最低值附近）
纳音重新roll：
  均匀分布[19%, 25%] → 7个可能的整数值
  期望新值 = (19+20+21+22+23+24+25)/7 = 22%
  期望提升 = 22%-20% = 2%
  
  但如果不幸roll到19%→损失1%·如果幸运roll到25%→获得5%

这就是纳音石的赌博魅力：
  - 不会全输（Tier不变·最差也只是低值）
  - 全赢的诱惑（+5%的终局提升在手感上很明显）
  - 期望是正的（+2%）——所以理性玩家应该使用
  - 但全游戏纳音石只有10-18枚——不够全部roll到顶值
```

**纳音石的消费上限：**

4件主法器×3条铭文=12条铭文需要纳音优化
如果每条铭文平均需2-3次纳音才能roll到满意的数值：
12×2.5=30次→需要30枚纳音石
全游戏只有10-18枚→只能优化约4-6条铭文
→玩家必须选择哪些词缀值得花纳音石

## 十三、铜钱供给-需求数学验证

### 13.1 为什么需要数学验证

游戏经济系统最常见的失败模式：玩家玩到后期，铜钱堆积如山无处可用（通胀崩溃），或者铜钱永远不够（通货紧缩崩溃）。我们需要证明：全游戏铜钱总供给 ≈ 全游戏铜钱总需求，且偏差在可控范围内。

```
  → 但其中约60%可通过跑尸取回：6,000×0.4=2,400文实际损失
  → 加上熟练玩家死亡更少·新手死亡更多：
  新手(30次死亡)：约3,600文实际损失
  熟练(15次死亡)：约1,200文实际损失
  风险损失小计（平均）：约2,400文

━━━━━━━━━━━━━━━━━━━━━━━━━━━
铜钱总需求（全游戏·平均玩家）：
  33,000 + 15,000 + 12,400 + 2,400 = 62,800文

铜钱总供给（全游戏·全探索）：
  39,000文
  
供需缺口：62,800 - 39,000 = -23,800文
```

### 13.4 供需分析——缺口意味着什么

**23,800文的缺口看起来很大，但这实际上是设计目标，不是bug。**

```
缺口来源分析：

1. 锻造期望成本（33,000文）包含了降级惩罚的期望值——
   但"幸运"玩家可以远低于期望成本，"倒霉"玩家会高于期望成本。
   这个"期望成本"是概率加权后的——不是每个玩家都会花这么多。

2. 供给估算（39,000文）基于"全探索"但未计入重复刷怪——
   实际上玩家可能在某些道宫重复刷1-2小时。
   每额外刷1小时≈200-500文额外收入。
   如果玩家在全游戏中额外刷了约15-20小时的怪（分布在各道宫），
   额外收入约3,000-10,000文——可以填补缺口。

3. 缺口=设计工具：
   缺口23,800文 → 玩家需要约50-80小时的游戏时间中
   额外花15-20小时进行"经济行为"（刷怪/卖材料/跑商）
   → 这15-20小时不是"无聊的刷"·而是分散在12座道宫中的探索和战斗
   → 每座道宫平均只需额外刷1-1.5小时
```

**缺口验证（三种玩家类型）：**

| 玩家类型 | 铜钱供给 | 铜钱需求 | 净结余 | 结果 |
|------|:--:|:--:|:--:|------|
| 速通玩家（只做主线·50%探索） | ~20,000文 | ~35,000文 | -15,000文 | 🔴 钱不够→必须刷/卖·或只锻造1法器 |
| 标准玩家（80%探索·偶尔刷） | ~40,000文 | ~50,000文 | -10,000文 | ⚠️ 略不够→刚好够2法器+9·需要取舍 |
| 完美玩家（100%探索·适度刷） | ~56,000文 | ~65,000文 | -9,000文 | ⚠️ 略不够→2-3法器+9可达·需最优策略 |

**结论：铜钱"永远刚好不够"——这是设计目标。借鉴Hollow Knight——玩家通关时总是觉得"再给我5000吉欧就好了"。**

## 十六、卦术经济ROI分析——投入产出比计算

### 16.1 各种占卜方式的期望收益

```
定义：
  ROI = (期望收益 - 成本) / 成本
  
  铜钱ROI：投入铜钱·获得铜钱等价物
  时间ROI：投入时间·获得收益/时间单位
  星晶ROI：投入资源·获得星晶的概率
```

#### 16.1.1 卦问财帛（星碑占卜）

```
单次投入：
  成本：20卦气 + 5文铜钱
  卦气机会成本：20卦气≈价值约30文（1卦气≈1.5文·基于回气丹价格换算）
  总成本等价：约35文

期望收益：
  卦占宝箱（铜钱）：平均200文（Lv1-Lv3宝箱的加权平均）
  卦占宝箱（星晶）：约15%概率获得1-2星晶
  星晶期望：0.15×1.5 = 0.225星晶/次
  
  但需要考虑"找宝箱的时间成本"——平均约3-5分钟
  时间ROI：200文/4分钟 = 50文/分钟（高于杀敌的30文/分钟）
  
  铜钱ROI：(200-35)/35 = 471% → 极高
  但受限于：每区域24h冷却·每区域1-3个卦占宝箱·总限量
```

#### 16.1.2 小六爻快速寻宝

```
单次投入：
  成本：5卦气（≈7.5文）
  时间成本：0.5秒（战斗中瞬发）

期望收益：
  仅提示方向·不直接给宝箱
  需要玩家自行搜索（额外3-10分钟）
  最终找到的可能是普通宝箱（80文）或卦占宝箱（200文）
  
  期望：60%普通+40%卦占 = 0.6×80+0.4×200 = 128文
  但减去"不占卜也能找到"的宝箱（约1/3是自然发现）：
  增量收益 = 128 × 2/3 = 85文

铜钱ROI：(85-7.5)/7.5 = 1033% → 极高·因为成本极低
但受限于：冷却30秒·卦气恢复速度
```

#### 16.1.3 互卦追问暗面（双重宝箱揭示）

```
单次投入：
  成本：50卦气 + 10文铜钱
  前提条件：必须先通过"卦问财帛"找到明面宝箱并开启
  总成本等价：约85文

期望收益：
  互卦宝箱（铜钱）：平均400文
  互卦宝箱（星晶）：约40%概率获得2-5星晶
  星晶期望：0.4×3.5 = 1.4星晶/次
  
  互卦宝箱的星晶收益是卦问财帛的6.2倍（1.4 vs 0.225）
  
铜钱ROI：(400-85)/85 = 371%
星晶ROI：1.4星晶/85文等价 = 0.016星晶/文等价 → 极高
但：必须先找到明面宝箱·每区域最多1-2个互卦·总限量约24个全游戏
```

#### 16.1.4 卦问商机（商人折扣预测）

```
单次投入：
  成本：10卦气（≈15文）
  
期望收益：
  预测今日某商人有随机折扣（5%-30%·持续24游戏小时）
  平均折扣：15%
  如果玩家利用折扣购买了价值500文的商品：
  节省：500×15% = 75文
  
铜钱ROI：(75-15)/15 = 400%（如果利用折扣）
铜钱ROI：-100%（如果不利用折扣——浪费了10卦气）
  
设计意图：不强迫·但如果善用·收益可观
```

#### 16.1.5 每日日卦（免费·自动）

```
单次投入：
  成本：0（自动·每天第一次开游戏触发）
  
期望收益：
  战斗加成（伤害/卦气/闪避等）：全天持续
  经济价值折算（以伤害+10%为例）：
    如果当天打了一小时战斗·击杀约60只敌人
    伤害+10%→节省约6只敌人的战斗时间（约2分钟）
    时间节省价值：约500文（按50文/分钟计算·但这是虚的）
  
  经济加成（铜钱掉落+10%）：当天多获得约50-150文
  
总经济价值：约50-200文/天（取决于日卦类型和玩家当天行为）
年化（游戏内30天）：约1,500-6,000文
```

### 16.2 卦术经济行为策略矩阵

| 玩家目标 | 推荐卦术策略 | 预期额外收益 | 需要投入 |
|------|------|:--:|:--:|
| 快速获取铜钱 | 小六爻寻宝（高效）+卦问财帛（高回报） | +3,000-5,000文/全游戏 | 卦气管理 |
| 最大化星晶 | 卦问财帛→互卦追问暗面（每次不漏） | +10-15星晶/全游戏 | 每道宫探索时间+30% |
| 省钱购物 | 卦问商机（每次去商人前占卜） | 节省2,000-4,000文 | 10卦气/次 |
| 降低死亡损失 | 卦问吉凶（BOSS战前） | 减少5-10次死亡 | 25卦气/次 |
| 随缘·不主动 | 每日日卦被动享受 | +1,500-6,000文等价 | 0 |

### 16.3 卦气作为经济资源的价值

```
卦气上限：初始100·每通关一座道宫+20（最大340）

卦气恢复：
  自然恢复：2卦气/秒（非战斗状态）
  战斗恢复：1卦气/5秒（战斗状态）
  星碑休息：瞬间回满+下一次死亡铜钱损失减半
  丹药恢复：回气丹=30卦气·爆气丹=卦气无限15秒

卦气的经济价值：
  1卦气≈1.5文（基于最经济的卦术使用方式：卦问财帛·20卦气→200文期望收益）
  但卦气的真正价值在于"限量"——一天内卦气只能恢复有限次
  
  每日卦气总预算（假设游戏日=2小时现实时间）：
    自然恢复：2×7200秒×2卦气/秒=28,800卦气（实际游戏内不会达到·玩家在战斗）
    实际可用：约5,000-10,000卦气/游戏日
    
  最优卦气使用策略：
    1. 卦问财帛（20卦气/次·每日1-3次·不同区域）
    2. 小六爻寻宝（5卦气/次·战斗中随时用）
    3. 卦问吉凶（25卦气/次·BOSS战前1次）
    4. 剩余卦气→战斗使用（八卦盘·小六爻·阵法）
    
  卦气不足的惩罚：
    → 不能占卜→当日宝箱错过→可能永久失去
    → 战斗只能用普攻→难度陡增→死亡风险↑
    → 卦气是"每日活动配额"的隐性表达
```

| **阶段5：富裕** | 35-50h | 鹑首-大火 | 铜钱6,000-12,000·铜钱不再是瓶颈·星晶和稀有材料是 | "铜钱不重要了·我要陨铁" |

## 十九、词缀经济系统——铭文的市场

### 19.1 词缀设计空间

借鉴流放之路的词缀系统，但大幅简化（星河倒悬不是刷子游戏）：

**词缀结构：**
```
前缀（Prefix）：影响伤害/卦术效果（最多2条）
后缀（Suffix）：影响防御/资源/辅助（最多2条）
法器天生词缀：每件法器有1条固定词缀（不可移除·不可改变）
```

**完整词缀池（设计为约80条·有足够深度但不至于让玩家迷失）：**

#### 前缀池（40条·分5个Tier）

| Tier | 数量 | 效果范围 | 例子 |
|:--:|:--:|------|------|
| T1 | 12条 | 单属性小加成 | 火卦伤害+3%-6%·水卦伤害+3%-6%·所有卦术伤害+2%-4% |
| T2 | 10条 | 单属性中加成/双属性 | 火卦伤害+7%-12%·火卦和水卦+4%-7% |
| T3 | 8条 | 单属性大加成/特殊条件 | 火卦伤害+13%-18%·满卦气时全伤害+8%-12% |
| T4 | 6条 | 机制级加成 | 火卦伤害+19%-25%·火卦暴击时刷新冷却(10%-20%概率) |
| T5 | 4条 | 改变玩法 | 火卦暴击扩散灼烧·火卦击杀回复50%卦气 |

#### 后缀池（40条·分5个Tier）

| Tier | 数量 | 效果范围 | 例子 |
|:--:|:--:|------|------|
| T1 | 12条 | 小数值防御/资源 | 生命+3%-5%·卦气上限+5%-8% |
| T2 | 10条 | 中等防御/资源 | 闪避无敌帧+1-2帧·卦气恢复+8%-12% |
| T3 | 8条 | 高数值/条件防御 | 生命低于30%时减伤+15%-20%·死亡铜钱掉落-5%-8% |
| T4 | 6条 | 机制级防御 | 闪避时释放一次小范围震卦（10s冷却） |
| T5 | 4条 | 改变生存方式 | 濒死自动触发空亡·每战1次·或·受致命伤时消耗全部卦气免死 |

### 19.2 完美词缀的期望成本

```
假设玩家追求的"准完美"配置：
  4件主法器×3条铭文（前缀最多2+后缀最多2·但只有3槽·所以是2前1后或1前2后）
  每条铭文至少T3以上
  
  期望铭刻次数达到T3+：4次/条
  12条铭文需要：12×4=48次铭刻
  全游戏铭刻石约15-25枚→只够铭刻48次的31-52%
  
  → 只能追求约5-8条T3+铭文·其余接受T1-T2
  
  如果追求T4+（期望10次/条）：12×10=120次→完全不可能
  如果追求特定T5（期望100次/条）：完全不可能
  
"完美词缀"是一个永远达不到的目标——这确保玩家在通关后仍有追求。
但主线不需要完美词缀——T1-T2就能通关。
```

## 二十、死亡惩罚经济学——深层分析

### 20.1 为什么是20-30%而不是其他数字

```
备选方案分析：

方案A：0%惩罚（不掉铜钱）
  效果：死亡无代价→玩家不谨慎→战斗不紧张→胜利无成就感
  适用：纯休闲游戏
  不适用：星河倒悬（魂系血统·需要紧张感）

方案B：100%惩罚（全丢·不可取回）
  效果：死亡=归零→极度紧张→但可能劝退大量玩家
  适用：最硬核的Roguelike
  不适用：星河倒悬（面向更广的玩家群·不能只服务硬核）

方案C：Elden Ring式（100%·可跑尸取回）
  效果：死亡=全丢→必须跑尸→失败=永久丢失→极度紧张
  优点：魂系经典·社区接受度高
  缺点：对更广玩家群来说太硬核

方案D：我们的方案（20-30%·可跑尸取回·二次死亡永久丢失该部分）
  效果：
    - 玩家感到"痛"（20-30%是真实损失）但不"绝望"
    - 跑尸取回=有挽回机会→激励玩家"再试一次"
    - 二次死亡=永久丢失→但只丢20-30%·不是全部
    - 铜钱超过2000时触发巡逻队→抑制"囤钱"行为→引导消费
    
  为什么是20-30%：
    - 10%：太轻·"无所谓"→失去死亡惩罚意义
    - 20%：刚好有感觉·"嗯我丢了100文·下次小心"
    - 25%：核心值·"痛·但还可以接受"
    - 30%：上限·"很多钱的时候·真的痛"
    - 50%：太重·"一半都没了！"→可能劝退
    - 分段阶梯（100以内20%·500以上30%）给新手保护
```

### 20.2 死亡惩罚的数学——如何引导"常花钱"

```
假设玩家携带1,000文铜钱·面临两个选择：
  A：把钱花掉（买锻造材料·锻造）
  B：继续携带（准备在下一个商人处消费）

期望损失分析：
  如果选择B·在到达下个商人前死亡概率约15-25%（取中点20%）
  期望损失：1,000文×20%×25% = 50文（范围37.5-62.5文）
  
  如果选择A·把钱花掉：
  实际损失：0文（花掉的钱已经转化为装备提升）
  装备提升→战力提升→死亡概率降低→进一步减少未来损失
  
结论：死亡惩罚在引导玩家"花掉铜钱"而非"囤积铜钱"
这恰好符合我们的设计目标——"让经济流动起来"
```

### 20.3 死亡惩罚与玩家行为塑造

| 铜钱携带量 | 死亡损失 | 玩家行为反应 |
|:--:|:--:|------|
| <100文 | <20文 | "无所谓·小钱" |
| 100-500文 | 25-125文 | "有点痛·下次小心" |
| 500-2,000文 | 125-600文 | "真的痛·该花钱了" |
| >2,000文 | >600文+巡逻队 | "赶紧花！锻造！买材料！别囤！" |

**这正是死亡惩罚的设计目标——不是惩罚玩家，而是引导玩家做出更有趣的经济决策。**

## 二十一、材料递归深度——Factorio式的锻造树分析

### 21.1 为什么需要递归深度

借鉴Factorio的材料链设计。"递归深度"=从最原始材料到最终产品需要经过多少道加工步骤。

递归深度越深→经济系统越有层次感→玩家的"制作满足感"越强。

## 二十二、经济系统的边界条件与崩溃预防

### 22.1 防止铜钱通胀崩溃

```
通胀崩溃定义：玩家后期铜钱多到没用→经济失去意义

预防机制：
1. 锻造+铭刻的沉没成本——铜钱永远有出口（锻造失败=铜钱消失）
2. 法器修理费随等级暴涨（+1修20文→+9修500文）
3. 后期道宫物价更高（寿星宫物价×2.5）
4. 冥界商人的铜钱→星晶转化（10,000文→1星晶·终局黑洞）
5. 铭刻石赌博——"万一这次出T5呢？"→持续铜钱消耗
```

### 22.2 防止星晶通胀崩溃

```
星晶通胀崩溃定义：星晶太多·玩家可以无脑全+9→失去选择的意义

预防机制：
1. 总量精确控制（112枚·每个都有文档追踪——见§14.1）
2. 不可购买·不可兑换（向下不可逆）
3. 锻造+9→+10消耗10枚九天星晶（终极黑洞）
4. 全法器+9需要约384星晶（见原文档§3.3）——5倍于全游戏星晶总量
```

### 22.3 防止材料通胀崩溃

```
材料通胀崩溃定义：某种材料多到没用→失去稀缺性→探索动力下降

预防机制：
1. 每种材料都有多个用途（不只用于锻造）
2. 卖价远低于买价（卖=亏·不鼓励卖→但也不会堆积太多）
3. 堆叠上限限制（不会堆到999+）
4. 后期锻造需要的材料跨越多个道宫→每种材料都不会完全无用
```

### 22.4 极端情况测试

| 极端情况 | 概率 | 影响 | 系统应对 |
|------|:--:|------|------|
| 完美锻造（全部一次成功） | 约3% | 铜钱剩余5,000-8,000文 | 铭刻石/纳音石成为新出口 |
| 极端倒霉（全部吃保底） | 约5% | 铜钱赤字15,000+文 | 需要刷怪/卖材料·引导更多战斗 |
| 玩家从不锻造 | 约1% | 铜钱堆积20,000+文 | 主线BOSS难度不依赖锻造·但支线/隐藏需要 |
| 玩家只锻造一件法器 | 约30% | 铜钱刚好·星晶充裕 | 剩余星晶可用于铭刻/纳音铭文优化 |
| 玩家没发现铭刻系统 | 约10% | 铭刻石堆积 | 无影响·铭刻不是主线必要 |
| 玩家发现铜钱换星晶（冥界商人） | 约20% | 大量铜钱蒸发 | 这正是设计目标——终局铜钱出口 |

## 二十三、开发用数据速查表

### 23.1 所有经济计算公式汇总

```csharp
// ===== 基础价格计算 =====
float GetBasePrice(Material material) {
    return material.RarityBase * material.AcquisitionDifficulty * material.UtilityBreadth;
}

// ===== 商人实际售价 =====
float GetSellPrice(Material material, Merchant merchant, int daoGongIndex) {
    float basePrice = material.BuyPrice;
    float daoGongMultiplier = GetDaoGongPriceMultiplier(daoGongIndex); // 复用正确数组·而非线性公式
    float merchantBonus = merchant.Type == material.BestMerchant ? 1.25f : 1.0f;
    float relationshipDiscount = 1.0f - merchant.Relationship * 0.05f; // 0% → 25%
    return basePrice * daoGongMultiplier * merchantBonus * relationshipDiscount;
}

// ===== 商人收购价 =====
float GetBuyPrice(Material material, Merchant merchant) {
    return material.SellPrice * (merchant.Type == material.BestMerchant ? 1.25f : 1.0f);
}

// ===== 锻造成功率 =====
float GetForgeSuccessRate(int currentLevel) {
    // +0=100%, +1=95%, +2=90%, +3=80%, +4=70%, +5=60%, +6=50%, +7=40%, +8=25%, +9=10%
    float[] rates = {1.00f, 0.95f, 0.90f, 0.80f, 0.70f, 0.60f, 0.50f, 0.40f, 0.25f, 0.10f};
    return rates[currentLevel];
}

// ===== 锻造保底计数 =====
int GetPityThreshold(int currentLevel) {
    // +1~+3: 连续2次失败→第3次保底
    // +4~+6: 连续3次失败→第4次保底
    // +7~+8: 连续4次失败→第5次保底
    // +9: 无保底
    if (currentLevel <= 2) return 2;
    if (currentLevel <= 5) return 3;
    if (currentLevel <= 7) return 4;
    return int.MaxValue; // 无保底
}

// ===== 死亡铜钱损失 =====
int GetDeathPenalty(int carriedCopper) {
    if (carriedCopper <= 100) return (int)(carriedCopper * 0.20f);
    if (carriedCopper <= 500) return (int)(carriedCopper * 0.25f);
    return (int)(carriedCopper * 0.30f); // >500文统一30%·但>2000文额外触发巡逻队（调用方处理）
}

// ===== 死亡巡逻队触发检查（由死亡处理流程调用） =====
bool ShouldSpawnPatrolOnDeath(int carriedCopper) {
    return carriedCopper > 2000; // 携带超2000文·死亡点附近出现太史阁巡逻队
}

// ===== 刷怪衰减 =====
float GetDropRateMultiplier(int sameEnemyKilledInArea) {
    if (sameEnemyKilledInArea <= 20) return 1.0f;
    if (sameEnemyKilledInArea <= 50) return 0.7f;
    if (sameEnemyKilledInArea <= 100) return 0.3f; // +巡逻队
    return 0.0f; // 不掉铜钱
}

// ===== 道宫物价系数 =====
float GetDaoGongPriceMultiplier(int daoGongIndex) {
    // 星纪=1.0 玄枵=1.1 ... 寿星=2.5
    float[] multipliers = {1.0f, 1.1f, 1.2f, 1.3f, 1.4f, 1.5f, 1.6f, 1.7f, 1.8f, 2.0f, 2.2f, 2.5f};
    return multipliers[daoGongIndex];
}

// ===== 商人好感度折扣 =====
float GetRelationshipDiscount(int relationshipLevel) {
    float[] discounts = {0.00f, 0.05f, 0.10f, 0.15f, 0.20f, 0.25f};
    return discounts[relationshipLevel];
}

// ===== 铭刻词缀Tier概率 =====
int RollAffixTier() {
    float roll = Random.Range(0f, 100f);
    if (roll < 45f) return 1;  // T1 45%
    if (roll < 75f) return 2;  // T2 30%
    if (roll < 90f) return 3;  // T3 15%
    if (roll < 97f) return 4;  // T4 7%
    return 5;                   // T5 3%
}

// ===== 纳音数值重roll（均匀分布） =====
float RerollAffixValue(float min, float max) {
    return Random.Range(min, max);
}

// ===== 卦术寻宝星晶概率 =====
float GetDivinationStarCrystalChance(DivinationType type) {
    return type switch {
        DivinationType.Wealth => 0.15f,    // 卦问财帛：15%
        DivinationType.HuGua => 0.40f,     // 互卦追问暗面：40%
        DivinationType.LianHuGua => 0.80f, // 连互卦：80%
        _ => 0f
    };
}
```
