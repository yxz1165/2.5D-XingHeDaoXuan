# 经济系统分析 #07：Anno 1800

> **类型：** 城市建造 · 供应链管理 · 阶层需求
> **经济模型：** 需求金字塔·三阶层升级·跨岛供应链·贸易路线
> **分析日期：** 2026-08-04
> **对星河倒悬参考价值：** ⭐⭐⭐⭐ 需求层级·道宫间资源流转·同伴需求体系

## 一、货币设计——"三级货币"对应三个阶层

### 1.1 货币与阶层的耦合

Anno 1800 使用**多种货币**——但每种货币绑定一个社会阶层：

| 货币 | 对应阶层 | 核心消费 | 产出方式 |
|------|:--:|------|------|
| 💰 **金币** | 所有阶层 | 建筑·船只·战争 | 税收（主要）·贸易 |
| 🌾 **农民需求** | 🏠 农民 | 鱼·工作服·烈酒 | 生产链 |
| 🏭 **工人需求** | 🏭 工人 | 香肠·肥皂·面包·啤酒 | 更复杂的生产链 |
| 🎩 **工匠需求** | 🎩 工匠 | 罐头·缝纫机·皮草大衣·朗姆酒 | 跨岛供应链 |
| 💎 **工程师需求** | 💎 工程师 | 眼镜·咖啡·灯泡·怀表 | 新世界进口 |
| 👑 **投资人需求** | 👑 投资人 | 巧克力·香槟·雪茄·汽车·珠宝 | 全地图贸易网络 |

**"金币"是基础货币，但每个阶层有自己独特的"需求货币"——你必须满足这些需求，他们才愿意升级到下一阶层。**

### 1.2 为什么这样设计

```
传统城市建造（如模拟城市）：
  居民需求=水·电·垃圾处理·警察·消防 → 通用·无阶层差异
  问题：富人区和贫民区的需求完全一样·没有阶级感

Anno 1800：
  农民要鱼 → 你建渔场（简单·一个建筑解决）
  工人要香肠 → 你需要养猪场+屠宰场（两个建筑+运输线）
  工匠要罐头 → 你需要养牛场+炼铁厂+罐头厂（跨岛供应链！）
  工程师要眼镜 → 你需要石英矿+铜矿+玻璃厂+精密加工厂（跨地图贸易！）
  投资人要汽车 → 你需要橡胶（新世界）+钢铁+流水线+燃油（全游戏最复杂链）
```

**需求复杂度随阶层指数增长。** 这就是Anno的核心驱动力。

## 二、供应链——"跨岛"是核心

### 2.1 从"单岛自足"到"跨岛帝国"

```
游戏初期（农民·工人）：
  一个岛 → 自给自足
  鱼(海岸)+土豆(农田)+木材(森林)=满足农民
  +猪(农场)+小麦(农田)+啤酒花(农田)=满足工人

游戏中期（工匠）：
  第一个岛产能不足 → 必须占领第二个岛
  主岛=人口岛（养人·收税）
  副岛=农业岛（种小麦·养猪·种啤酒花）
  
  建立贸易路线：副岛→主岛·定期货船运输

游戏后期（工程师·投资人）：
  旧世界（欧洲）= 人口岛·重工业
  新世界（美洲）= 朗姆酒·咖啡·可可·巧克力·橡胶·金矿
  北极 = 天然气
  非洲 = 水利·造纸
  
  5-10条贸易路线·跨三个地图
```

### 2.2 "产业链长度"=游戏深度

每个产品的"产业链长度"不同：

```
鱼：1步（渔场→市场）
烈酒：2步（土豆农场→酿酒厂→市场）
香肠：3步（养猪场→屠宰场→市场）+小麦农场（喂猪）
罐头：5步（养牛场→炼铁厂→罐头厂→市场）+胡椒种植园（新世界进口）
缝纫机：6步（伐木场→锯木厂+铁矿→炼铁厂→缝纫机厂→市场）
汽车：10+步（橡胶园(新世界)+炼钢厂+流水线工厂+燃油(北极)+……）
```

**产业链长度=该产品的"经济重量"。** 生产10步链的汽车比生产1步链的鱼——需要10倍以上的建筑·工人·运输船·规划。

## 三、通胀控制——"幸福度"就是通胀控制器

### 3.1 为什么不能无限扩张

在大多数城市建造游戏中，你可以无限扩张——只要有钱。

在Anno 1800中，扩张受**"幸福度"**约束：

```
每个阶层有多个幸福度指标：
  农民：食物·衣物·信仰·酒吧
  工人：+香肠·+肥皂·+学校
  工匠：+罐头·+缝纫机·+大学·+剧院
  工程师：+眼镜·+咖啡·+电力·+银行
  投资人：+巧克力·+香槟·+汽车·+俱乐部

幸福度<阈值 → 居民不满 → 可能暴动 → 房屋被毁 → 税收暴跌
                → 你必须提供更多商品 → 需要更多生产建筑 → 
                需要更多工人 → 需要更多幸福度 → 循环

幸福度=经济扩张的"刹车"
```

### 3.2 "报纸"系统——消费驱动的通胀控制

Anno 1800 有一个独特的"报纸"系统——你可以编辑报纸来改变居民的消费率：

```
报纸编辑选项：
  "+30%烈酒消费·-10%收入" → 居民喝更多酒·你赚更多钱
  "-20%奢侈品消费·+15幸福度" → 居民节省·更开心·但税收减少
  "+25%所有商品消费·-20%幸福度" → 你暴富·但居民可能暴动

报纸=你手动调节"消费率"的工具
  消费率↑ → 生产需求↑ → 经济活跃↑ → 但幸福度↓
  消费率↓ → 生产需求↓ → 经济平稳·但税收↓
```

## 四、对"星河倒悬"的具体启示

### 4.1 道宫间的"跨岛供应链"

每座道宫可以生产独特的材料——类似Anno的不同岛屿：

```
星纪宫：主产青铜·铁（基础矿石）
玄枵宫：主产草药·木材（自然材料）
娵訾宫：主产丹药·毒物（炼丹材料）
降娄宫：主产精铁·钢·陨铁（高级金属）
大梁宫：主产符纸·朱砂（符箓材料）
实沉宫：主产战场遗物·古兵器（稀有材料）
鹑首宫：主产暗影精华（特殊材料）
鹑火宫：主产机关零件·齿轮（机械材料）
鹑尾宫：主产生死精华（阴阳材料）
大火宫：主产乐谱·音石（音律材料）
析木宫：主产量子碎片·重力粒（终极材料·极稀有）
寿星宫：主产星辉·九天星晶（不可替代·全游戏最稀有材料）

→ 玩家需要在已解锁的道宫之间"来回跑"来收集不同材料
→ 星碑传送费用（50文）阻止了无成本的反复跳转
→ 后期解锁传送网络→可以快速在道宫间流转
```

### 4.2 "阶层升级"=法器升级

Anno的居民阶层升级映射到星河倒悬的法器：

```
农民→工人→工匠→工程师→投资人
  ↑      ↑      ↑      ↑       ↑
Lv0→Lv+1→Lv+3→Lv+5→Lv+7→Lv+9

每升一级需要的"需求"（材料）越来越多：
  Lv+1：青铜×3（星纪宫·1种材料）
  Lv+3：精炼青铜×2+雷击桃木×1（星纪+玄枵·2种·跨宫）
  Lv+5：淬火青铜+千年雷击木+星晶碎片（3种·3座宫）
  Lv+7：陨铁+星核+暗影精华+精炼钢（4种·4座宫·跨地图）
  Lv+9：九天星晶×2+星辉+量子碎片+天命铭文（5种·全游戏）
```

### 4.3 "幸福度"=同伴满意度

Anno的幸福度 = 星河倒悬的同伴好感度：

```
同伴满意（好感度≥Lv3）→ 被动增益生效·特殊能力可触发
同伴不满意（好感度<Lv3）→ 被动增益减弱·特殊能力有概率失败
同伴极度不满（好感度=0·长期不理）→ 同伴离队（去星碑营地等待）

提升满意度：
  送仙酒（Hades启发）
  带该同伴出战（"我需要你"）
  完成同伴的专属剧情
  在营地与该同伴对话
```
