# 经济系统分析 #06：流放之路 (Path of Exile)

> **类型：** ARPG · 暗黑Like · 赛季制
> **经济模型：** 零金币·通货物品经济·以物易物·赛季重置
> **分析日期：** 2026-08-04
> **对星河倒悬参考价值：** ⭐⭐⭐⭐ 另类货币思路·锻造消耗品设计

---

## 一、货币设计——"没有金币"的世界

### 1.1 颠覆性的设计决策

流放之路是唯一一个**完全没有金币**的主流ARPG。

```
传统ARPG：
  打怪 → 金币 + 装备
  金币 → 买药水·修装备·赌博
  装备 → 用/卖/拆

流放之路：
  打怪 → 通货物品 + 装备
  通货物品 = 改造装备的道具
  改造石 → 把白色装备变成蓝色（随机1-2条词缀）
  点金石 → 把白色装备变成金色（随机4-6条词缀）
  混沌石 → 把金色装备的词缀全部随机重roll
  崇高石 → 给金色装备增加一条随机词缀
  神圣石 → 重roll金色装备的词缀数值范围
```

**这些"改造道具"就是流放之路的"货币"。** 它们同时是两个东西：消耗品和通货。

### 1.2 通货物品层级

| 层级 | 通货 | 功能 | 掉落稀有度 | ≈混沌石价值 |
|:--:|------|------|:--:|:--:|
| T0 | **智慧卷轴** | 鉴定装备 | 随处可见 | 1/200 |
| T1 | **改造石** | 白装→蓝装·随机词缀 | 常见 | 1/16~1/8 |
| T2 | **点金石** | 白装→金装·随机词缀 | 常见 | 1/4~1/3 |
| T3 | **混沌石** | 重roll金装所有词缀 | 不常见 | **1（基准）** |
| T4 | **崇高石** | 给金装增加1条词缀 | 稀有 | 50-200 |
| T5 | **神圣石** | 重roll金装词缀数值 | 稀有 | 5-15 |
| T6 | **镜之石** | 完美复制一件装备 | 极稀有（一个赛季全球掉~5个） | 50,000+ |

**注意：** 这些相对价值不是固定的——它是**玩家交易市场**决定的。混沌石对崇高石的汇率在一个赛季内可以波动5-10倍（赛季初：1崇高≈50混沌·赛季末：1崇高≈200混沌）。

### 1.3 为什么"无金币"是天才设计

```
金币经济的问题：
  打怪 → 金币 → 通胀（金币越来越多·物价越来越高）
  → 开发者必须在每个新赛季/版本引入"金币出口"来回收金币
  → 但玩家总会囤积

通货物品经济的解决方案：
  打怪 → 改造石 → 玩家把它"用掉"（改造装备了）
  → 改造石从经济中**消失**
  → 通货永远在"产生→消耗→消失"的循环中
  
  没有囤积——因为每次使用通货都是"赌博"。
  你有一颗崇高石 → 你用在装备上 → 可能出极品词缀 → 也可能出垃圾
  → 崇高石消失了 → 经济中少了一颗 → 通货永不通胀
```

**"通货就是消耗品"这个设计解决了游戏经济学中最难的问题——通胀。**

## 二、通货的"经济出口"——赌博心理

### 2.1 每次使用通货都是一次赌博

```
你有一件6连装备底子（已经很难得）
  你投入1颗崇高石 → "给这件装备增加一条随机词缀"
  
  可能的结果：
  A. +80最大生命 → 装备价值翻倍 → 赢了
  B. +8最大生命 → 装备几乎没变 → 亏了一颗崇高石
  C. +1反射物理伤害 → 装备增加了负面词缀 → 可能毁了一件好装备
  
  没有"确定的结果"——这就是为什么通货会不断被消耗
  不是"花5金币买药水"——是"用一颗稀有通货去赌一个神级装备"
```

### 2.2 通货→词缀的转化链条

```
白装（0词缀）→ 改造石 → 蓝装（1-2词缀·随机）
               → 点金石 → 金装（4-6词缀·随机）

蓝装（2词缀·都不错）→ 富豪石 → 金装（保留蓝装词缀+随机3-4条新词缀）

金装（5词缀·缺1条）→ 崇高石 → 金装（6词缀·第6条随机）

金装（6词缀·数值太烂）→ 神圣石 → 金装（保留6条词缀名·重roll数值范围）

金装（6词缀·全垃圾）→ 混沌石 → 金装（6条全新词缀·全部随机）
```

**这个链条不需要"金币"——每一步消耗的都是不同的通货物品。**

### 2.3 赛季重置=经济大洗牌

流放之路每3-4个月开一个新赛季：

```
赛季初（第1-10天）：
  崇高石 ≈ 10-30混沌石（通货极稀缺）
  一件50血的5连胸甲 = 5-10混沌石（装备紧缺）
  
赛季中（第20-60天）：
  崇高石 ≈ 80-120混沌石（通货通胀·但通货也在被消耗）
  一件50血的5连胸甲 = 1-2混沌石（装备泛滥）
  
赛季末（最后2周）：
  崇高石 ≈ 150-200混沌石
  极品6连胸甲 = 10-50崇高石（只有极品才值钱）
  
新赛季 → 一切归零 → 重新开始
```

赛季重置是流放之路对抗"永久通胀"的终极武器——**每3个月把经济清零。**

## 三、对"星河倒悬"的具体启示

### 3.1 可以借鉴的核心思路

| 流放之路 | 星河倒悬映射 |
|------|------|
| 改造石=白→蓝 | 青铜矿石→青铜锭→锻造Lv+1法器 |
| 崇高石=加词缀 | 铭刻石=给法器增加铭文词条 |
| 神圣石=reroll数值 | 纳音石=重roll法器的纳音词条数值 |
| 混沌石=完全随机 | 卦术重铸=用三钱摇卦来决定法器新词缀 |
| 镜之石=完美复制 | 九天星晶=法器终极突破·不可复制 |

### 3.2 "消耗品即货币"思路

在星河倒悬的锻造系统中，可以设计**"锻造通货"**——这些物品本身就是锻造材料，但当玩家之间需要交换时（如果有联机功能），它们就成了"货币"：

```
锻造通货层级（单机·不需要交易市场·每个物品有自己的用途）：
  
  T1 铭刻石：给法器随机增加一条铭文词缀
  T2 纳音石：重roll一条铭文词缀的数值
  T3 共鸣石：将两件法器的词缀合并（牺牲一件·强化另一件）
  T4 星核碎片：给法器增加一条固定词缀（不随机·可选）
  T5 九天星晶：法器终极突破·+9→+10·全游戏限量
```

### 3.3 不适合借鉴的

| 不借鉴 | 原因 |
|--------|------|
| **完全无金币** | 星河倒悬需要铜钱作为"通用交易媒介"·星碑传送·日常消耗 |
| **赛季重置** | 星河倒悬是单存档连续叙事·不能重置 |
| **玩家交易市场** | 星河倒悬是单机（至少初期）·不需要市场经济 |

### 3.4 最重要的启发

> **"通货就是消耗品"——这个设计原则可以应用在星河倒悬的锻造材料上。**
>
> 铭刻石不是"存着"的东西——是"用了就没了"的东西。每次使用=一次赌博=一次心跳加速。这就避免了你囤积100颗铭刻石永远不用——因为每一次用都可能让你的法器变强或变弱。
