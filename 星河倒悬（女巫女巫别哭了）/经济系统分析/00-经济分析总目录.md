# 全球优秀游戏经济系统——专项分析目录

> **目的：** 深入研究各类型游戏中顶尖的经济系统设计，提取可应用于"星河倒悬"的设计原则和具体机制。
> **分析方法：** 每款游戏从货币设计·资源循环·通胀控制·风险机制·玩家行为引导五个维度拆解。
> **创建日期：** 2026-08-04

---

## 分析维度说明

每个游戏的分析覆盖以下五个核心维度：

| 维度 | 核心问题 |
|------|------|
| **货币设计** | 几种货币？各自用途？为什么这样设计？ |
| **资源循环** | Tap(产出)→Converter(转化)→Drain(消耗)的闭环是怎样的？ |
| **通胀控制** | 如何防止后期"钱太多"？物价如何随进度变化？ |
| **风险机制** | 有没有死亡惩罚？有没有赌博/概率性消费？如何制造紧张感？ |
| **行为引导** | 经济系统在"引导"玩家做什么？探索？战斗？交易？还是囤积？ |

## 从这些分析中产生的"星河倒悬"设计决策

> 最终成果——完整经济系统设计文档：[[16-星河倒悬经济系统-完整设计]]

| 来源 | 启发 | 应用 |
|------|------|------|
| Elden Ring | 卢恩双用途（XP=货币）制造"升级vs购物"的永恒张力 | 铜钱可丢20-30%·星晶永不丢·类似"黄金卢恩"保险 |
| Elden Ring | 升级成本锁步曲线 | 法器锻造Lv+1→+9成本指数增长 |
| Elden Ring | BOSS奖励=关键消费节点 | 每个BOSS给2-5星晶+300-500铜钱·刚好够锻造升级 |
| Hollow Knight | 文物=不掉落货币 | 星晶=不掉落·铜钱可丢·类似"文物+吉欧"双层 |
| Hollow Knight | 终局黑洞（不屈护符=53%总消费） | 九天星阵=终极法器·占星晶总消耗60%+ |
| Hollow Knight | 精确总量控制 | 全游戏星晶约100枚·精确计算·确保稀缺 |
| Hades | 货币分层：局内丢·跨局留 | 铜钱/星晶双层=简化版分层 |
| Hades | 单向兑换（稀有→常见·不可逆） | 星晶不可用铜钱买·"往下容易·往上不可能" |
| Hades | "失败≠归零"——死了也有收获 | 死亡只丢20-30%铜钱·星晶全保留 |
| Factorio | 递归深度=经济复杂度 | 法器锻造Lv+1→+9·每级材料递归深度递增 |
| Factorio | 瓶颈轮转（不同阶段缺不同材料） | 星纪缺青铜→降娄缺精铁→鹑火缺陨铁→寿星缺九天星晶 |
| Factorio | "主总线"可视化材料流 | 锻造界面显示"材料溯源链" |
| 星露谷 | 多元化收入·四支柱 | 杀敌·探索寻宝·BOSS奖励·同伴辅助=四支柱 |
| 星露谷 | "不要卖原料"→加工增值 | 矿石锻造后再卖·鼓励锻造系统参与 |
| 星露谷 | 季节节奏=经济周期 | 12座道宫=12个"经济季节"·物价1.0→2.5递增 |
| 星露谷 | 体力/时间=经济配额 | 卦气=每日经济配额·0卦气→占卜受限→收入减少 |
| 流放之路 | 通货即消耗品·用了就消失 | 铭刻石·纳音石=消耗品=反囤积 |
| 流放之路 | 无金币经济·以物易物 | 九天星晶不可用铜钱买·最高价值只能"打"出来 |
| Anno 1800 | 需求金字塔·阶层升级 | 法器Lv+1→+9 = 需求金字塔·越高级需要越多道宫的材料 |
| Anno 1800 | 跨岛供应链 | 道宫间材料流转·星碑传送网络 |
| 巫师3 | 区域物价差异 | 12道宫物价1.0→2.5·商人类型影响收购价 |
| 巫师3 | "牛魔防卫军"·动态平衡 | 刷怪太多→太史阁巡逻队出现·滚动式防止无限刷 |
| 冰汽时代 | 希望/不满·道德经济 | 同伴士气系统·带出战+士气·冷落-士气 |
| 暗黑 | 掉落层级·"垃圾换希望" | 三钱摇卦寻宝=用卦气换"万一出了呢"的期待 |
| 暗黑 | 赌博商人·指定类型抽奖 | 卦问商机=指定商品类型预测折扣 |
| Satisfactory | 垂直整合·层级可视化 | 法器锻造界面·材料溯源链·视觉满足感 |
