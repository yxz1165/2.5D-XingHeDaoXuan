# 经济系统分析 #15：仁王2 (Nioh 2)

> **类型：** ARPG · 魂Like · 战国
> **经济模型：** 精华双用途·茶器收集·锻造传承·合魂·"魂系中的暗黑"
> **分析日期：** 2026-08-04
> **对星河倒悬参考价值：** ⭐⭐⭐⭐ 锻造传承·合魂系统·茶器=命盘

## 一、货币设计——精华双用途+金钱辅助

### 1.1 核心货币

| 货币 | 用途 | 获取 | 死亡掉落？ |
|------|------|------|:--:|
| 💛 **精华** | 升级属性（同魂系） | 杀敌·使用魂核 | ✅ 全丢·跑尸取回 |
| 💰 **金钱** | 锻造·合魂·买道具 | 杀敌·卖装备·任务奖励 | ❌ 不丢！ |
| ⚫ **魂核** | 妖怪化技能·守护灵升级 | BOSS掉落（必掉） | ❌ 不丢 |

**仁王2的最大创新：死亡只丢精华·不丢金钱。** 这比魂系更温和——你不会因为死了而"倾家荡产"，但精华依然有跑尸的紧张感。

### 1.2 茶器——"收集即经济"

```
茶器是仁王2独有的"收集品经济"：

茶器=名贵茶具（茶碗·茶罐·茶杓……）
获取：BOSS掉落·隐藏区域·特定任务奖励
用途：
  ├─ 放在茶室中→提升"茶器评价"
  ├─ 高评价→解锁隐藏任务·特殊锻造配方
  ├─ 茶器可以"鉴定"→随机属性→收集驱动
  └─ 少数极品茶器→提供被动Buff加成

茶器=装备·收集品·经济物品的三位一体
```

## 二、合魂系统——"装备的传承"

### 2.1 什么是合魂

合魂是仁王2的独特锻造系统——**你可以把一件低等级但词缀好的装备"喂"给高等级装备。**

```
合魂操作：
  基底装备（你正在用的·等级低但词缀完美）
  + 
  素材装备（刚捡到的·等级高但词缀垃圾）
  ↓ 花费金钱+素材
  基底装备的**等级提升**到素材装备的水平
  基底装备的**词缀保持不变**
  
→ 你不用"扔掉"辛苦洗出来的好词缀装备
→ 你可以把它"传承"下去·继承到你更高级的装备上
```

### 2.2 为什么合魂是天才设计

```
传统暗黑Like：
  打到更高级装备 → 正在用的低级装备（词缀完美）→ 分解→ 心疼

传统魂Like：
  永远用同一把武器 → 不需要换

仁王2的合魂：
  打到更高级装备 → 当成素材 → 喂给你的主武器 → 主武器升级 → 词缀保留
  
→ 你永远不用"放弃"你的主武器
→ 你的武器有"成长史"——它跟你一起变强
→ 这不是"换装备"——这是"传承"
```

## 三、锻造系统——"自己造装备"的完整循环

### 3.1 完整的锻造经济

```
仁王2的锻造比魂系深得多：

材料获取：
  分解不需要的装备 → 获得锻造材料
  关卡中采集 → 获得特殊矿石
  茶室评价 → 解锁高级锻造配方

锻造流程：
  铁匠铺 → 选择配方 → 投入材料 → 随机品质（白/黄/蓝/紫/绿/橙）
  → 不满意？→ 分解→重新锻造 → 循环

词缀洗练：
  在锻造时→投入特定材料→影响词缀概率
  锻造后→可以重铸单条词缀（类似暗黑的洗词缀）
  
  极品装备 = 无数次锻造 + 无数次重铸 + 合魂保持等级
```

### 3.2 "锻造比掉落更强"

仁王2的一个关键设计：**自己锻造的装备——词缀可控——往往比掉落的好。**

```
掉落装备：词缀完全随机 → 大概率垃圾
锻造装备：可以洗词缀 → 可以精确搭配Build
合魂升级：让锻造装备跟上你的等级 → 永不淘汰

→ 这个设计告诉你：不要依赖"运气"。锻造需要理解游戏系统。
→ "会锻造的人"打出的伤害是"只靠掉落的人"的2-3倍
```

## 四、对"星河倒悬"的具体启示

### 4.1 核心借鉴——合魂→法器的"传承锻造"

仁王2的合魂系统是星河倒悬法器系统最重要的参考：

```
合魂（仁王2）= 法器传承锻造（星河倒悬）

流程：
  你的桃木剑 Lv+3（词缀：离卦伤害+15%·暴击+8%）
  +
  一把刚获得的星辉桃木心（高级法器材料·来自大梁宫）
  ↓ 在星碑锻造·消耗星晶+铜钱
  桃木剑 Lv+5（保留：离卦伤害+15%·暴击+8%·新增：巽卦DOT+20%）
  
→ 类似仁王2的合魂——你的法器保留了好词缀·同时升了级
→ 你的桃木剑从星纪宫陪到你打到寿星宫·像仁王2的武器一样有"成长史"
```

### 4.2 茶器→同伴信物

茶器（收集品+被动+经济）的三位一体→星河倒悬的同伴信物：

```
茶器系统（仁王2）= 同伴信物（星河倒悬）

星君信物=十二星君的个人物品：
  锻锋的断锤碎片 → 放入星碑 → +火卦伤害·解锁真火铸造
  苏羽的断弓弦 → 放入星碑 → +风卦穿透·解锁闭眼射击
  石翁的丹砂葫芦 → 放入星碑 → +土卦减伤·解锁大地净化
  ……

信物=收集品（每座道宫隐藏1个）·被动Buff（数值加成）·剧情（解锁同伴记忆碎片）
```

### 4.3 锻造>掉落

暗黑Like中的"自己造的最强"原则应用于星河倒悬：

```
掉落法器（BOSS掉落·宝箱开出）：
  基础属性·随机1-2条词缀·不可洗
  → 过渡使用

锻造法器（星碑锻造·投入材料·铭刻）：
  可选择词缀倾向（乾/坤/离/坎……）
  可洗练单条词缀（消耗纳音石）
  可传承（保留词缀·升级等级）
  → 最终装备
  
→ 最强大的+9法器 = 锻造的·不是掉落的
→ "你不需要运气·你需要懂得卦术"
```
