## 一、货币设计——金币退居二线

### 1.1 暗黑4的货币体系

| 货币 | 核心用途 | 获取方式 | 通胀风险 |
|------|------|------|:--:|
| 🪙 **金币** | 洗词缀·买药水·修理·交易 | 杀敌·卖垃圾·任务 | 高·后期几十亿金币 |
| 💎 **低语古币** | 赌博商人（指定部位抽奖） | 完成低语任务 | 低·有上限(1000) |
| 🔴 **恶疫魔心**（赛季限定） | 镶嵌·赛季专属能力 | 精英怪·BOSS | 无·赛季结束即删除 |
| 🟡 **耀光棱晶** | 镶孔·升级宝石 | 世界BOSS·军团事件 | 中 |
| ⚪ **遗忘之魂** | 洗词缀·附魔 | 分解传奇装备 | 中·需要消耗传奇装备 |
| 🟣 **恶魔玫瑰** | 终极附魔 | 地狱狂潮采集 | 中 |

### 1.2 金币的"去中心化"

暗黑系列中，金币的用途越来越"去中心化"——从万物通用变成了"洗词缀专用"：

```
暗黑2：金币几乎没有用（SOJ=乔丹之石才是真正的货币）
暗黑3：金币有用（洗词缀·修理·制作宝石）但后期金币泛滥
暗黑4：金币主要用来洗词缀（每次数百万·是真正的大额出口）+
        低语古币用来赌博（上限1000·控制了赌博频率）+
        遗忘之魂用来附魔（分解传奇装备→限制供给）

→ 金币不再是"唯一"的·被分解成了多个专用货币
```

## 二、掉落表设计——"随机的艺术"

### 2.1 掉落层级

暗黑的掉落设计是整个ARPG品类的标准：

| 品质 | 颜色 | 掉落频率 | 用途 |
|:--:|:--:|:--:|------|
| 普通 | 白 | 极多·90% | 卖金币·或当作底材 |
| 魔法 | 蓝 | 多·8% | 前期过渡·或分解 |
| 稀有 | 黄 | 偶尔·1.5% | 可能有极品词缀·值得细看 |
| 传奇 | 橙 | 罕见·0.4% | 核心装备·传奇威能来源 |
| 独特 | 暗金 | 极罕见·0.1% | 成型Build核心 |
| 神话独特 | 紫 | 超级罕见 | 终极追求·一个赛季可能只掉1-2件 |

### 2.2 "掉落时间=价值"的心理锚定

```
玩家拿到一件白装：
  大脑反应：无（直接忽略·卖店）

玩家拿到一件传奇：
  大脑反应："来了！"（心跳加速·立刻查看词缀）
  
  查看词缀 → 
    A. 三条词缀全对（暴击·易伤·核心技能+）→ 极品！→ 多巴胺爆发
    B. 两条对一条错 → 还不错·洗一下 → 投入金币洗词缀 → 经济循环
    C. 全垃圾 → "又是分解货" → 分解 → 获得遗忘之魂 → 攒着附魔别的装备
```

**这就是暗黑的"经济循环"：掉落→兴奋/失望→消费（洗词缀/分解/附魔）→继续刷→继续掉落。**

### 2.3 赌博商人——"垃圾换希望"

低语古币的系统设计非常精妙：

```
低语古币（上限1000）→ 在赌博商人处消费

商人界面：
  "25古币→随机头盔"（可能是白/蓝/黄/传奇）
  "40古币→随机武器"
  "30古币→随机手套"
  ……

玩家心理：
  "我缺一个+暴击率的手套 → 我就赌手套 → 
   50古币一次 → 我可以赌20次 → 
   20次里可能有1-2次传奇 → 
   其中可能有一个不错的手套"
  
这就是"垃圾换希望"——
你花的是打怪攒的古币（垃圾时间）
换的是"万一出了呢"的期待（希望）
```

## 三、赛季经济——"每三个月归零"

### 3.1 赛季重置的经济效果

暗黑每3个月新赛季——经济归零：

```
赛季初（第1-2周）：
  所有人穷·装备稀缺·一件普通传奇可能改变Build
  经济感觉：每一件掉落都很重要

赛季中（第3-8周）：
  装备逐渐充裕·开始追求极品词缀
  经济感觉：刷装备→汰换→洗词缀循环

赛季末（最后2周）：
  装备基本成型·只差极品中的极品
  经济感觉：边际收益极低·等待新赛季

新赛季：
  一切归零·重新开始
  新的赛季机制 → "这次我要玩什么Build？"
```

### 3.2 赛季归零=消除积弊

```
非赛季（永久服）的问题：
  玩家仓库里囤了5年的装备·金币几百亿·材料几万
  → 不可能设计出"让这个玩家也觉得有用"的奖励
  → 新玩家和老玩家差距不可逾越
  → 经济系统无解

赛季制（定期重置）的解决方案：
  每3个月 → 所有人都从零开始 → 公平
  赛季结束 → 所有赛季物品转入永久服（"退役"）
  → 永久服成了"博物馆"而不是"竞技场"
```

## 四、对"星河倒悬"的具体启示

### 4.1 掉落层级映射

| 暗黑掉落 | 星河倒悬对应 |
|------|------|
| 白装（卖店/底材） | 普通材料（铜矿·铁矿石）→ 基础锻造·或卖铜钱 |
| 蓝装（过渡） | 稀有材料（精铁·秘银）→ 中级锻造 |
| 黄装（可能极品） | 史诗材料（陨铁·星核·暗影精华）→ 高级锻造·有概率出极品词缀 |
| 传奇（核心） | 星晶（关键资源·星碑交互·摇卦消耗） |
| 神话独特（终极） | 九天星晶·星君碎片（全游戏限量·法器+9→+10） |

### 4.2 "赌博"的星河版——三钱摇卦寻宝

低语古币(暗黑) ≈ 三钱摇卦寻宝(星河倒悬)

```
暗黑：花25古币 → 随机头盔（白/蓝/黄/传奇）
星河：花20卦气+5铜钱 → 摇卦 → 根据卦象寻宝 → 找到宝箱（Lv1-Lv5）

相同之处：
  都是"花资源买一个随机的希望"
  都有"万一出了呢"的赌博快感
  都受上限控制（古币上限1000·卦气有上限·24小时内每区域限量）

不同之处：
  暗黑=纯随机（抽奖→直接获得）
  星河=卦象引导（提示方位→探索→找到→这才获得）
  → 星河多了"探索"这一步·但奖励更可控（因为卦象提示了方位）
```

### 4.3 "分解=材料回收"——类比暗黑的遗忘之魂

暗黑分解传奇→遗忘之魂（越分解越想附魔→附魔需要更多遗忘之魂→需要更多传奇→继续刷）

星河倒悬的分解系统：
```
分解不需要的装备/材料 → 获得"星屑"（通用锻造材料）
星屑 → 用于法器进阶·附魔·铭刻

→ 你不用的东西不是"卖店"→是"回收"→进入锻造循环
→ 避免了"装备只能卖店"的无聊感
```

### 4.4 "新游戏+"——类比赛季重置

星河倒悬通关后的"新游戏+"模式：
```
新游戏+：保留法器（降级为Lv+0）·保留命盘·保留同伴好感度
         重置：铜钱（归零）·星晶（归零）·材料（归零）
         解锁：更高难度·新的铭文词缀·新的卦象连携
         
→ 类似暗黑赛季重置·但不是"完全归零"
→ 保留了一部分东西（你的人物·你的故事·你的同伴）
→ 重置了一部分东西（经济·材料·让重新收集有意义）
```
