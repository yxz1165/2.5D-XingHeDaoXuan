# 《十日终焉》文笔分析

**作者**：杀虫队队员  
**分析采样**：第1章（空屋游戏）、第353章（隐藏的高手）

---

## 一、"九位"——智斗小说的信息经济学

### 原文

> "早安，九位。"山羊头率先说话了。
>
> 坐在圆桌四周的无论怎么数都是十个人，加上山羊头自己，这屋里一共有十一个人。
>
> 「九位」是什么意思？

### 技法拆解

全书第一章第一个人说出的第一个数字就是错的。"九位"——不是口误。山羊头对数字精确到不会说错任何一个人数。他数的就是九——这意味着十个人中有一个不是"参与者"。

这一个小数字偏差——9≠10——是智斗小说最经典的"开局信息差"。不需要大段的背景讲解、不需要世界观手册。**一个数字——读者和主角同时发现它的不匹配——就能让整个场景从"绑架案"升级为"谁是卧底"。** 山羊头不需要解释任何规则——他只说了一个数字，但所有规则都已经隐含在那个数字里了。

### 对《星河倒悬》的应用

玄微子说"星位微调了几度"——这个"几度"应该在第一次提到时就是一个精确的数字（比如"三度半"），让读者意识到这不是随口的描述——是有意为之的精确欺诈。

## 二、人物的冷静分级——从最不冷静到最冷静

齐夏是所有人中最冷静的。他不说话。他"迅速打量了一下屋内的情况，片刻之后，神色就凝重了起来"——这是全书对齐夏的第一句正写。不是"他非常聪明"——是"他看到了别人没看到的东西"。

之后各人的反应依次排列：花臂男骂人→清冷女人谈法律→白大褂质疑时间→健壮青年问人数——每个人用一个反应定义性格，没有一句废话。

## 三、智斗场景的"隐藏底牌"——李香玲

> 李香玲感觉右手被抓住，当即面色一冷，整个人凌空一转......"但若你们觉得用武力就可以让我屈服的话……未免有些太小看我了。"

被所有人忽视的"不出众"角色——在最关键的时刻露出真实实力。不提前描写她的强大。突然翻转。

对《星河倒悬》的应用：商羽、林青黛、押狱林述——所有那些在太史阁体系里的"不起眼的人"——都应该用这种突然翻转的写法。不提前暗示"她后来会背叛"。只在那个瞬间给她一个动作。
