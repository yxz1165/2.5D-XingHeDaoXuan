## 二、核心写作原则

### 原则1：大场面从一个人写起
**来源**：赤心巡天

十二宫的觉醒时刻是宏大的——星君苏醒、神力爆发、封印崩裂。但描写的落点应该始终在**一个人**身上：金无痕的剑在抖、焦烈的法杖在他手中失控、林青黛看到自己的疤痕消失了。神力的宏大从一个人的瞳孔里反射出来。

### 原则2：恐怖的最高境界是你自己吓自己
**来源**：盗墓笔记

太史阁的恐怖不是暴力——是渗透。石壁上的人脸浮雕眼睛逐渐睁开——每一次看都睁大了一点，但你摸上去还是石头。假星图不是改了所有星——只改了那么几度，刚好让你三十年对不上卦，但你永远不确定是不是自己的问题。

### 原则3：日常感不是点缀，是世界观的血肉
**来源**：诡秘之主

玄伯的烟斗在桌腿上磕两下。冥婆在石桥上烧枯枝——蓝色的火焰舔着她能看到骨头的手指。辰生把油布包打开一条缝时星晷的三层环还在自己转。这些不是"中间穿插的环境描写"——**它们是世界观本身**。宏大的哲学命题如果不被装进烟斗和枯枝里，就是空洞的口号。

### 原则4："不正常"的人是最清醒的
**来源**：道诡异仙

十二位同伴在被唤醒之前——都是"不正常的人"：火鬼附身、半盲、疯子炼丹师、哑巴、废物学徒、不祥之兆的老太婆……但他们不是"不正常"——是**超出正常**。写他们的段落从不站在村民/太史阁的角度去写他们"可怜"——而是站在他们自己的角度：他们只是不愿意按错误的规则去活。

### 原则5：敌人的话要用最平静的口吻写
**来源**：诸神愚戏

"为您服务，是我的荣幸。"焦烈说的"就地封印"、闫序说的"天道计算不会出错"、商徵说的"历史由胜利者书写"——这些话说出来的口吻应该和医生说"请躺好"一模一样。**最恐怖的施暴者从不觉得自己在施暴。他们觉得自己在提供专业服务。**

### 原则6：层层揭示——每次只给一块拼图
**来源**：盗墓笔记

明月暗线：序章只给一个画面（面罩女人塞玉佩）。玄枵宫多给一个词（"巫医罪"）。降娄宫多给两个字（"等谁"）。大火宫多给一句话（"……人也一样"）。幕间才给完整的故事。坐标旋转暗线同理——齿轮翻转→空间常数→真南北线→密函→归位。每一层都不能跳过。

### 原则7：冷静者是最有魅力的
**来源**：十日终焉

辰生不是热血少年。他从不多话，但动手能力极强。他在炭窑里有三秒钟想"帮不帮"——想了，不是冲出去。他在金无痕面前问的不是"你怎么这么强"而是"你的剑练了多久"。哲学术语上这叫"实事求是"——从文字上，这叫**不说废话**。

## 三、各章节风格指引

| 章节 | 主控风格 | 参考来源 | 注意 |
|------|---------|---------|------|
| 序章·炭窑 | 悬疑+温情 | 盗墓笔记+诡秘之主 | 明月的出现不渲染悲壮——她累、她冷、她推了辰生一把。辰生伸出手不是"英雄的抉择"——是本能 |
| 第一章·世界观 | 冷峻纪实 | 毛泽东选集 | 四表、猎巫、山海经——用事实的口吻写。不需要形容词。不需要"这是多么残忍"。事实本身就是控诉 |
| 第二章·落星村 | 日常质感 | 诡秘之主 | 玄伯的药铺要有气味——当归、川芎、白芷。辰生碾药手指的茧。老槐树的树荫在几时几分落到药铺的哪个角落 |
| 星纪宫 | 火与觉醒 | 赤心巡天 | 锻锋的火焰从暗红→明亮→金色。焦烈的法杖在他手中"融化"——仿品遇到真品 |
| 玄枵宫 | 森林+诊断 | 道诡异仙 | 苏羽不觉得自己可怜。她的眼睛看得太远了——不是瞎。拿歪尺量对的人 |
| 娵訾宫 | 大地+毒素 | 赤心巡天 | 石翁尝毒土的段落——"苦参加三钱，甘草减两钱"。嘴唇发紫，手指溃烂。不渲染牺牲——他只是在做祖先做了几百年的事 |
| 降娄宫 | 海上+剑气 | 十日终焉 | 金无痕看真剑谱时手指在抖——不是恐惧，是**三观碎裂的疼痛**。顾锋在地上写字 |
| 大梁宫 | 机械+拆穿 | 十日终焉+诸神愚戏 | 鲁班语"她就是明白了它的运转机理"。不是毁——是**拆穿**。闫序的信仰不是被打败的——是被拆掉底层逻辑后自己塌的 |
| 实沉宫 | 战场+报名字 | 赤心巡天 | 石磐报名字报了一整夜。每报一个，一个亡灵放下武器。不煽情——他只是做了几千年前就该有人做的事 |
| 鹑首宫 | 黑暗+刺青 | 道诡异仙 | 影的刺青不是诅咒——是忏悔。辰生说的那句"你用惩罚自己来证明你有罪——但惩罚自己本身就是你无罪的理由"——语气要冷静，不能煽情 |
| 鹑火宫 | 冥河+劳动 | 诡秘之主 | 冥婆烧了一辈子蓝色的枯枝火，手指在火中能看到骨头。她说的"劳动是证明你活过"——不是宣言，是一个老人的自言自语 |
| 鹑尾宫 | 昆仑+牺牲 | 赤心巡天 | 析木的残影只剩一句话。空白碑。辰生独自跪了三天。商羽交出用血抄的密约——"这是我欠的债" |
| 大火宫 | 琴台+音乐 | 十日终焉+诸神愚戏 | 阮心唱出宫音的正确频率——不是神力，是**对的频率**。锁链不是被砸碎的——是被认出来的。辰生说"……人也一样"——四个字，不多不少 |
| 寿星宫外围 | 星图+颤抖 | 十日终焉 | 玄微子发现坐标旋转的段落——不是"他震惊了"——是他把星图旋转180度后的沉默。手指不抖了。三十年的颤抖不是病，是拒绝 |
| 幕间·汇合 | 篝火+讲述 | 盗墓笔记+赤心巡天 | 辰生讲述明月故事——不要煽情。让事实本身的力量说话。"四十七次火刑——歌没断"比任何抒情都有效 |
| 寿星宫 | 决战+哲学 | 赤心巡天+毛泽东选集 | 商徵的时间删除——"你以为你在战斗。但这场战斗从未发生。"这句话的腔调要和医生说话一模一样 |
| 终章·丈量 | 散步+拼接 | 诡秘之主+盗墓笔记 | 没有战斗。走走停停。每个丈量点都有一个故事。真舆图碎片解锁的瞬间——不是特效，是"对了"。玄微子不烧假图——留着让学生自己叠在一起看 |
| 终章·说书人 | 苍老的回望 | 盗墓笔记（50年后的口吻） | 老年辰生的说书——语言要简，节奏要慢，话里有停顿"——"。"茶凉了。"不是煽情，是陈述。 |

## 四、对话风格指南

### 辰生
短。少。从不解释自己。问题比回答多。
> "你的剑，练了多久？"
> "那她在被追捕之前——用那根针救了多少人？"
> "……人也一样。"

### 锻锋
有火气但不暴躁。觉醒后说话带着一种被烧过的平静。
> "我不是'火鬼'。回去报告商徵——荧惑之火没有被净化。它还在烧。"

### 苏羽
平静。她早就习惯了被叫做"不正常"。说这句话的时候不是委屈——是陈述一个她接受了十七年的事实。
> "他们的标准就是一把歪尺。拿歪尺量你，然后说你不对。"

### 玄伯
沉默。把烟斗在桌腿上磕两下。然后继续给病人抓药。
他不能用说的——他只能用做的。三十年来每一天的沉默，就是他唯一的语言。

### 明月
沙哑。疲惫。不道谢。三千年浓缩成两个字——
> "拿着。"

### 商徵
优雅、从容、学者风范。他说最恶的事用最文雅的口吻。"历史由胜利者书写——而我就是那个书写者。"这句话不带任何邪恶的笑声——他是真的这么相信。

### 说书人辰生（老年）
句子短。话中间有停顿"——"。不解释。让故事自己说话。
> "那年他十九岁。十九岁的人，摔倒比站稳容易。"
> "茶凉了。今天就到这儿。"

## 五、文笔自查清单

每次写完一段剧情，逐条检查：

1. [ ] 有没有至少一处从一个人的瞳孔里反射出的大场面？
2. [ ] 恐怖/压迫感是不是让角色自己吓自己，而不是作者替角色喊"好可怕！"？
3. [ ] 有没有至少一个具体的物质细节——气味、温度、触感、光的角度？
4. [ ] "不正常的人"的段落——是从他自己的视角写的，还是从旁人/作者的视角写的？（必须是前者）
5. [ ] 敌人说话的语气——是专业/冷静/"为您服务"式的，还是狰狞咆哮式的？（必须是前者）
6. [ ] 如果是揭示性质的段落——是不是只给了一块拼图，没有一次性倒完？
7. [ ] 辰生/同伴的对话——有没有可以删掉的字？（通常可以删掉一半）
8. [ ] 重要台词的腔调——是陈述事实，还是在煽情？（必须是前者）
9. [ ] 星君觉醒时刻——是宏大的星辰在燃烧，还是同伴的低语？（必须是后者）
10. [ ] 结尾——有没有提供一个安静的停顿？（"茶凉了。今天就到这儿。"）

## 六、禁止事项

- **禁止**用形容词堆砌情感。"悲壮""震撼""感人肺腑"——删掉。让读者自己感受。
- **禁止**替读者下结论。"这就是殖民主义的罪恶"——删掉。事实本身比任何结论都有力量。
- **禁止**让辰生说长篇大论。他不是演说家。他是动手的人。
- **禁止**让反派咆哮。"你们这些愚蠢的凡人！"——删掉。焦烈、闫序、钟鸣——他们应该像医生和工程师一样说话。
- **禁止**在结尾写"他们终于迎来了美好的明天"。结局是"茶凉了。今天就到这儿。他还要往西走。"
