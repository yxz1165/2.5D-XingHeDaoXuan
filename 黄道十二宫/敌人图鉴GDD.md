# 敌人图鉴 GDD —— 《星河倒悬》

## 1. Overview

敌人系统服务于三层叙事需求：**太史阁基层**是被洗脑的普通人、"可争取的中间力量"；**守史者**是买办精英、罪孽深浅不一；**海溟暗卫**是海外侵略者、纯粹的敌人。三种敌人在战斗中通过不同的视觉语言、AI行为和受击反应来传达各自的身份本质。

核心设计原则：
- **敌人即叙事**：击败一个海溟暗卫和击败一个太史阁杂役，在动画、音效、甚至UI反馈上都不同
- **仿品的"缺一口气"**：海溟势力的战斗动作在帧数据上刻意与星君职业"差一点"——攻速快但不精准、伤害高但不稳定
- **可争取的敌人**：太史阁基层有概率"觉醒"并离开战场，不计入击杀统计

## 2. 太史阁基层

### 2.1 概述

太史阁基层士兵大多是普通人——被太史阁招募的底层弟子、被洗脑的书吏、被海溟国"文明先进"话语蒙蔽的年轻人。他们的战斗AI倾向于"人多但弱"，被击败后的倒地动画较长（强调他们是人，不是怪物）。

### 2.2 敌人类型

| 敌人 | 生命 | 攻击 | 防御 | 韧性 | 行为特征 |
|------|------|------|------|------|---------|
| 史馆杂役 | 低 | 低 | 低 | 30 | 2-3人一组出没，攻击欲望低，被浮空后可追击至死 |
| 捕史者 | 中 | 中 | 中 | 80 | 移动快，发现玩家后会吹哨召唤增援（30s冷却） |
| 修史官（青焰） | 低 | 高 | 低 | 40 | 远程青焰攻击（海溟噬文火），持续火焰伤害3秒 |
| 守阁卫士 | 中 | 中 | 高 | 120 | 持盾，正面攻击伤害 -50%，需要绕背或破盾技能 |
| 化史炉监守 | 高 | 中 | 中 | 100 | 投掷化史灰（减速+禁疗3秒），死后爆炸（小范围青焰） |

### 2.3 觉醒机制

- 太史阁基层在血量 < 10% 时有 10% 概率触发"觉醒"
- 觉醒表现：武器掉落 → 角色跪地 → 说一段"觉醒台词" → 起身离开战场
- 觉醒不计入击杀数
- 每条觉醒台词随机从台词库抽取，反映不同身份的人"被蒙蔽"的真相

**觉醒台词库：**
- "他们说海溟国那边……是最好的……我攒了三年钱想去一次……我到底在做什么？"
- "我爷爷留给我一本旧书，被我自己烧了。他们说那是迷信。现在我想知道那本书写了什么……"
- "我是为了'稳定'才加入太史阁的。但这些年，我在稳定的谎言中度过了我的全部人生。"
- "这把剑是太史阁发的，不是我自己选的。我不想再拿着它了。"

## 3. 守史者

### 3.1 概述

守史者是太史阁的中层——各道宫的看守者。每人有自己的背景故事和与海溟国的关系深度。详见道宫关卡设计 GDD 的附录及每宫详细设计。

### 3.2 通用战斗特征

| 特征 | 说明 |
|------|------|
| 阶段转换 | 1-6宫 1阶段 / 7-10宫 2阶段 / 12宫 3+1阶段 |
| 反思犹豫 | 血量 < 30% 时攻击欲望 -10%、移速 -10%（人性残留） |
| 海溟加持 | 7宫后守史者第二阶段获得海溟秘术特效（视觉可见的"异化"） |
| 战后处理 | 被骗者可选择"不杀"（剧情选择，影响结局和部分NPC后续出场） |

## 4. 海溟暗卫

### 4.1 概述

海溟暗卫是海溟国直接派遣到中原的军事力量。在道宫1-3宫不出现（玩家还不知道海溟存在），从第4宫开始小规模渗透，到第10-12宫成为主力。

海溟暗卫的核心设计语言是**"仿品"**——他们使用的战斗技能在表面上与中华武学/丹术/机关术相似，但仔细观察就会发现关键环节的缺失。

### 4.2 敌人类型

| 敌人 | 生命 | 攻击 | 防御 | 韧性 | 首次出现 | 仿品特征 |
|------|------|------|------|------|---------|---------|
| 海溟暗哨 | 中 | 高 | 低 | 150 | 第4宫 | 隐身有蓝影（真刺客无形），背刺伤害不稳定 |
| 海溟武士 | 高 | 高 | 中 | 250 | 第5宫 | 剑术形似但无剑气，被太白技能命中可能"武器破碎"（25%概率） |
| 海溟方术士 | 低 | 高 | 低 | 150 | 第6宫 | 毒瓶伤害飘忽不定（-20%~+30%随机），说明丹方不全 |
| 海溟机关兽 | 极高 | 中 | 中 | 400 | 第8宫 | 关节处蓝火花，每30秒可能"自锁"3秒（自身无法行动） |
| 海溟咒术师 | 中 | 极高 | 低 | 120 | 第9宫 | 符咒伤害时高时低，每5次施法有1次"自噬"（反伤自己20% HP） |
| 海溟禁卫 | 极高 | 高 | 高 | 500 | 第10宫 | 全套仿品装备，暴击时有5%概率"哑火" |
| 海溟国师（BOSS） | BOSS级 | BOSS级 | BOSS级 | 2000 | 寿星宫隐藏 | 盗版十二星君技能缝合，见战斗GDD |

### 4.3 仿品脆弱性

- 真传星君职业攻击海溟仿品敌人时额外 +15% 伤害
- 被真传技能击败时有概率触发"仿品破碎"动画（武器/道具碎裂特效）
- 同一类型仿品敌人被击败 50 次后，该类型在后续道宫中数量减半（"仿品不可持续"的叙事暗示）

## 5. 精英怪

每个道宫有 2-3 种精英怪，是普通敌人和 BOSS 之间的过渡：

| 道宫 | 精英怪 | 特点 |
|------|-------|------|
| 星纪 | 冰焰巨蜥 | 两种元素切换（冰甲/火息） |
| 玄枵 | 活木守护者 | 每次被击败后分裂为两个小树人（最多分裂2次） |
| 娵訾 | 毒丹傀儡 | 死后自爆，爆炸范围 = 持续毒瘴 |
| 降娄 | 断剑执念体 | 三把飞剑环绕，必须同时击落 |
| 大梁 | 潮汐漩涡 | 周期性将玩家拉向/推离自身 |
| 实沉 | 亡灵副将 | 召唤阵亡士兵亡魂（每次召2个） |
| 鹑首 | 暗影猎手 | 只在玩家不看他时移动/攻击 |
| 鹑火 | 机关巨像 | 四个弱点需要依次击破 |
| 鹑尾 | 阴阳游魂 | 阳界无敌 → 阴界可攻击，反之亦然 |
| 大火 | 幻音回响 | 制造2个幻象分身，只有真身可被琴音暴露 |

## 6. AI行为框架

| 行为 | 太史阁基层 | 守史者 | 海溟暗卫 |
|------|-----------|--------|---------|
| 攻击欲望 | 低 | 中-高 | 高 |
| 战术配合 | 无 | 基础 | 高度协同 |
| 撤退/重整 | 会（血量低时） | 不会（BOSS除外） | 不会 |
| 受击反应 | 明显（符合"普通人"） | 较少 | 少（但仿品脆弱性触发时反应剧烈） |
| 玩家位置感知 | 短距离 | 中距离 | 长距离 |

## 7. 掉落规则

| 敌人类型 | 掉落 | 概率 |
|---------|------|------|
| 太史阁基层 | 铁矿石、铜矿石、普通药品 | 30% |
| 守史者 BOSS | 紫装（首杀100%）、BOSS材料、套装部件 | 首杀紫装必掉 |
| 海溟暗卫 | 海溟钢（唯一来源）、化史灰 | 40% |
| 精英怪 | 绿-蓝装、灵砂 | 100% 至少1件 |

## 8. 依赖系统

| 依赖系统 | 关系 |
|---------|------|
| 战斗系统 | 受击行为、韧性值、硬直等级、仿品脆弱性 |
| 道宫关卡 | 敌人分布、派系占比、BOSS配置 |
| 装备系统 | 掉落装备/材料 |
| 角色成长 | 击杀经验值 |

## 9. 可调参数

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `HaiMingWeaknessMult` | 1.15 | 真传对仿品伤害倍率 |
| `HaiMingWeaponBreakChance` | 25% | 仿品武器破碎概率 |
| `TaiShiGruntAwakenChance` | 10% | 太史阁基层觉醒概率 |
| `TaiShiGruntAwakenHP` | 10% | 觉醒触发血量阈值 |
| `HaiMingCopySelfLockChance` | 每30s一次 | 机关兽自锁概率 |
| `HaiMingCurseSelf harmChance` | 每5次施法1次 | 咒术师自噬概率 |

## 10. 验收标准

- [ ] 三种势力敌人在视觉上可清晰区分（太史阁=黑色+竹简纹 / 海溟=灰蓝+暗纹）
- [ ] 海溟仿品敌人被真传星君技能命中时触发 1.15x 伤害
- [ ] 太史阁基层 10% 概率在低血量时觉醒离开
- [ ] 敌人在不同道宫的派系占比符合道宫GDD设定
- [ ] BOSS 阶段转换流畅、视觉有明显变化
- [ ] 仿品脆弱性触发时有特殊音效和视觉反馈
