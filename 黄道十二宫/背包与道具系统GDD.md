# 背包与道具系统 GDD —— 《星河倒悬》

## 1. Overview

背包系统是玩家管理所有物品的枢纽：装备、消耗品、材料、关键道具、星君信物。采用列表+分类标签的经典布局，支持排序、过滤、批量操作。

核心设计原则：
- **分类清晰**：六大类物品各有独立标签页，互不混淆
- **关键道具即剧情载体**：星君信物、知残线索等关键道具不是"占背包格子的任务物品"，而是有独立展示和回顾功能
- **上限明确不无限扩张**：各分类有各自的上限和扩展方式，避免无尽堆叠

## 2. 物品分类

| 大类 | 标签名 | 默认容量 | 可扩展 | 说明 |
|------|-------|---------|--------|------|
| 装备 | 武器/防具/饰品 | 60 | 背包扩容道具 +10 | 已装备的不占背包格 |
| 消耗品 | 药品/食物/战斗道具 | 30 | 扩容道具 +5 | 同类可堆叠（上限 99） |
| 材料 | 矿石/草药/灵砂等 | 50 | 扩容道具 +10 | 同类可堆叠（上限 999） |
| 关键道具 | 任务/信物/信件 | 20 | 不扩展 | 独特物品，不堆叠 |
| 星君信物 | 火种/息壤等 | 12 | 不扩展 | 每宫通关获得 1 个 |
| 记忆碎片 | 紫装以上附带的文本 | 不限 | — | 仅文本，不占物理格 |

## 4. 材料系统

### 4.1 材料分级

| 等级 | 材料 | 用途 | 来源 |
|------|------|------|------|
| 凡 | 铁矿石、铜矿石、草药 | 白/绿装强化、基础药品 | 采集/杂兵掉落 |
| 灵 | 玄铁、灵砂、灵木 | 蓝/紫装强化、中级药品 | 精英怪/道宫宝箱 |
| 圣 | 星辰铁、灵石、星光粉尘 | 紫/橙装强化、仿品重铸 | BOSS/隐藏区域 |
| 邪（海溟） | 海溟钢、化史灰 | 仿品强化（仅限） | 海溟暗卫 |

### 4.2 采集系统

- **矿脉**：道宫和大地图特定位置，采集后 30 分钟刷新
- **草药**：特定地貌（丹霞山脉=火性草药，树海=木性草药）
- **BOSS材料**：每宫 BOSS 首杀必掉对应材料，重复击杀掉率 30%
- **海溟材料**：仅海溟暗卫掉落，后期可在大地图"东海巡逻区"刷取

## 6. 背包操作

### 6.1 排序

- 按稀有度、按获得时间、按名称、按类型
- 默认：按获得时间（新→旧）

### 6.2 快捷操作

| 操作 | 按键 | 效果 |
|------|------|------|
| 使用（消耗品） | 双击 / 右键→使用 | 立即使用，进入冷却 |
| 装备 | 右键→装备 | 替换当前槽位装备 |
| 对比 | 悬停 | 弹出当前装备 vs 悬停装备的对比浮窗 |
| 标记 | 右键→标记 | 标记为"收藏"（防误售/误拆） |
| 批量出售 | Shift+点击 | 选中多个同稀有度以下物品出售 |
| 批量分解 | Ctrl+点击 | 选中多个装备分解为材料 |

### 6.3 物品溢出处理

| 场景 | 处理 |
|------|------|
| 装备满 + 拾取新装备 | 弹出替换/丢弃二选一 |
| 消耗品满 + 拾取同类 | 自动合并到上限，超出丢弃 |
| 材料满 + 拾取 | 自动合并，超出部分提示"背包已满，材料丢弃" |
| 战斗中拾取 | 不弹出UI，超出部分自动丢弃；关键道具无论满否必定拾取 |

## 7. 存储箱（星碑仓库）

- 在每个道宫的存档点（星碑）处可访问共享存储箱
- 容量：100 格
- 用途：存放备用装备、多余材料、不想出售的信物
- 大地图主要城镇也有仓库NPC

## 8. 依赖系统

| 依赖系统 | 关系 |
|---------|------|
| 装备系统 | 装备类物品存储/装备/出售/分解 |
| 战斗系统 | 消耗品在战斗中使用、信物效果映射 |
| 商店系统 | 物品买卖接口 |
| UI系统 | 背包界面、快捷栏 |
| 存档系统 | 背包内容随存档保存 |

## 9. 可调参数

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `EquipBagSize` | 60 | 装备格默认容量 |
| `ConsumableBagSize` | 30 | 消耗品格默认容量 |
| `MaterialBagSize` | 50 | 材料格默认容量 |
| `ConsumableStackMax` | 99 | 消耗品最大堆叠 |
| `MaterialStackMax` | 999 | 材料最大堆叠 |
| `KeyItemBagSize` | 20 | 关键道具格容量 |
| `StashSize` | 100 | 仓库容量 |
| `BagExpansionPerUse` | +10(装备)/+5(消耗品)/+10(材料) | 扩容道具效果 |
