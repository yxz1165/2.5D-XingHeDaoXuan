# 道宫关卡设计文档

## 1. Overview

道宫是《星河倒悬》的核心关卡载体。十二座道宫分布在世界各处，每座对应一位银河神族星君，内部包含探索区域、三派系敌人（太史阁基层/守史者/海溟暗卫）、机关/谜题、守史者BOSS战、星君觉醒剧情演出，以及该道宫对应的**哲学命题**在玩法中的具象化。

玩家以主角辰生的身份进入道宫，目标是解除封印、收集母亲云岫的一缕魂魄，同时唤醒对应星君的记忆与神力。十二宫按固定顺序解锁，每通一宫开放下一宫。

**关键体验原则**：道宫不是"副本"——它是剧情推进的主舞台。每座道宫有独立的地貌、文化主题、敌人派系比例和情绪曲线。更重要的是，**每座道宫是一场"哲学实践课"**——玩家通过关卡设计和BOSS战的机制，亲身体验该宫的哲学命题。

---

## 2. 玩家幻想

- **探索未知**：每座道宫是全然不同的世界切片（冰火之地、海底观星台、活体机关城），推开门的瞬间产生"这次又会是什么"的期待。
- **渐入佳境**：道宫内部空间逐步展开，从外围到核心，难度和视觉奇观同步爬升。
- **"海溟国的痕迹"**：越深入探索，越能发现海溟国渗透的蛛丝马迹——某些区域的机关风格突变（从中华木石构造变为海溟钢铁风格）、某些敌人不是太史阁的而是海溟暗卫。玩家通过这些痕迹逐渐拼凑出太史阁背后的真正主子。
- **哲学命题的具象化**：每座道宫的关卡设计不是随意的地形生成——它的机制、敌人配置、甚至颜色调性，都在传达一个哲学命题。通关后的"觉醒之间"不是单纯的过场，而是对该宫哲学命题的叙事化总结。
- **有退路的勇气**：存档点的存在让玩家敢于探索深处，知道失败不会从头再来。

## 3. 详细规则

### 3.1 道宫解锁与进入

- 十二宫**顺序固定**，不可跳过：星纪→玄枵→娵訾→降娄→大梁→实沉→鹑首→鹑火→鹑尾→大火→析木→寿星
- 第 N+1 宫在通关第 N 宫后解锁
- 进入方式：在大地图上前往道宫入口，按 `F` 交互进入

### 3.2 道宫内部结构

每座道宫由以下区域组成：

```
[入口区] → [外围探索区] → [中层挑战区] → [核心BOSS区] → [觉醒之间]
   |            |               |               |              |
  存档点      存档点          存档点          BOSS前存档点   剧情演出
```

| 区域 | 功能 | 存档点数量 | 敌人类型 |
|------|------|-----------|---------|
| 入口区 | 氛围建立，简单战斗 | 1（入口处） | 太史阁基层为主 |
| 外围探索区 | 探索、机关、发现海溟痕迹 | 1-2 | 太史阁基层 + 少量海溟暗卫 |
| 中层挑战区 | 高强度战斗、精英怪 | 1-2 | 太史阁守史者副官 + 海溟暗卫 |
| 核心BOSS区 | 守史者BOSS战 | 1（BOSS门前） | 守史者（可能含海溟加持阶段） |
| 觉醒之间 | 剧情演出，星君觉醒，魂魄归位 | 无需存档 | 无战斗 |

### 3.3 敌人派系分布

每座道宫内的敌人分为三个派系，其比例随道宫推进而变化：

| 道宫阶段 | 太史阁基层 | 守史者及副官 | 海溟暗卫 | 说明 |
|---------|-----------|------------|---------|------|
| 1-3 宫（初期） | 90% | 10% | 0% | 海溟国尚未暴露 |
| 4-6 宫（中期） | 70% | 20% | 10% | 玩家开始发现海溟存在 |
| 7-9 宫（中后期） | 50% | 20% | 30% | 海溟渗透加深 |
| 10-11 宫（后期） | 30% | 20% | 50% | 海溟势力成为主力 |
| 12 宫（寿星） | 10% | 10% | 80% | 海溟国师直属精锐 |

### 3.4 存档点机制

- **外观**：以**"星碑"**形式呈现——半透明晶石碑，悬浮的星辰纹路缓缓旋转。
- **交互**：靠近后按 `F` 激活，激活后星碑亮起金色光芒。
- **效果**：记录进度、恢复全部生命值、补充基础药品（数量有上限）、不重置已清除的小怪。
- **限制**：每宫 3-5 个存档点（含入口+BOSS门前固定各 1 个），间距 8-20 分钟游戏流程。

### 3.7 道宫通关

- 击败守史者 → 进入觉醒之间 → 剧情演出（星君觉醒 + 哲学命题总结 + 魂魄归位）

## 4. 十二道宫详细设计

### 4.1 星纪宫 —— 矛盾的普遍性

| 项目 | 内容 |
|------|------|
| **哲学命题** | 矛盾的普遍性——哪里有压迫，哪里就有反抗 |
| **星君** | 荧惑星君（战士） |
| **地形** | 极北冰火之地：永夜冰原 + 地底火山群 |
| **守史者** | 焦烈（司火史）——海溟国直属 |
| **海溟关联** | 焦烈使用的"白焰术"是海溟国从荧惑火种中偷学篡改的 |
| **玩家体验** | 前半段在冰原中被各种火系机关压制（压迫感），后半段锻锋觉醒后火系机关开始为玩家所用（反抗） |
| **关卡机制** | 极寒/极热区域切换——在极寒区域移速降低但火系伤害增加；在极热区域持续掉血但冰系敌人被削弱 |
| **BOSS战设计** | 焦烈使用白焰——一种"干净的、工业化的火焰"，与荧惑星君觉醒后的金色神火形成视觉对比：白焰整齐、冰冷、工厂化；金焰狂暴、温暖、有生命 |
| **觉醒演出** | 锻锋在火焰中挺立——"我不是灾星，我是守护者"——火焰由红转金 |

### 4.2 玄枵宫 —— 实践出真知

| 项目 | 内容 |
|------|------|
| **哲学命题** | 实践论——认识从实践始，理论的基础是实践 |
| **星君** | 岁星巡狩（弓箭手） |
| **地形** | 南方活体树海：千年古树构成的移动迷宫 |
| **守史者** | 林青黛——被太史阁欺骗的母亲 |
| **海溟关联** | 太史阁告诉林青黛"神族害死了你的孩子"——这个谎言是海溟国统一编造的说辞模板 |
| **玩家体验** | 前半段苏羽被"眼疾"限制，玩家在模糊视野中战斗（受限认知）；后半段复明后精准射击（实践后的真知） |
| **关卡机制** | 树木缓慢移动改变路径，只有通过观察自然（树的影子方向、鸟的飞行轨迹）才能找到正确路线——**不能靠地图，只能靠实践** |
| **BOSS战设计** | 林青黛的"百兽试炼·伪"——试炼被海溟国删改了核心环节，原本是"与灵兽沟通"变成了"与灵兽战斗"。苏羽不攻击灵兽，而是用木星之力与它们对话 |
| **觉醒演出** | 苏羽复明——"我并非看不清远方，而是看得太远" |

### 4.3 娵訾宫 —— 内因与外因

| 项目 | 内容 |
|------|------|
| **哲学命题** | 内因是变化的根据，外因是变化的条件 |
| **星君** | 地隐星君（方术士） |
| **地形** | 西陲丹霞山脉：被毒瘴污染的上古炼丹圣地 |
| **守史者** | 卫重（司土史）——海溟国提供毒阵图纸 |
| **海溟关联** | 海溟国偷走炼丹术后，将搬不走的丹炉/药田用毒瘴污染——"能搬走的搬走，搬不走的毁掉" |
| **玩家体验** | 毒瘴环境不断削弱玩家（外因），但石翁的丹砂炼制能力在毒瘴中越来越强（内因） |
| **关卡机制** | "五毒阵"——金蚕/蝎子/蜈蚣/蟾蜍/毒蛇对应五行，需用正确丹方破解。中毒不是纯负面——某些区域只有中毒状态下才能通过（毒瘴与身体产生反应后可见隐藏道路） |
| **BOSS战设计** | 卫重启动自毁机关，丹炉即将爆炸。石翁用土行神力护住众人——**外因（毒瘴+自毁）强大，但内因（地隐神力）更根本** |
| **觉醒演出** | 石翁从废墟中爬出——"土是不会死的。石头可以被砸碎，但大地永远在那里" |

### 4.4 降娄宫 —— 捉主要矛盾

| 项目 | 内容 |
|------|------|
| **哲学命题** | 主要矛盾——捉住主要矛盾，一切问题迎刃而解 |
| **星君** | 太白剑仙（剑士） |
| **地形** | 海上剑冢：孤悬海外岛屿，插满断剑 |
| **守史者** | 金无痕——被海溟国篡改剑谱欺骗的剑客 |
| **海溟关联** | 金无痕使用的剑谱是海溟国删改版——删去"剑意""剑心"部分，只留形式 |
| **玩家体验** | 一开始辰生屡次挑战金无痕失败，每次失败后顾锋用手指向残卷中真正的剑谱——玩家逐渐明白**真正的目标不是战胜金无痕，而是让他看到真相** |
| **关卡机制** | 万剑阵——数百把断剑组成障碍。破解方法不是硬闯，而是用正确的剑谱激活四把"真剑"（隐藏在断剑中），真剑会指引通往忘川巨剑的路 |
| **BOSS战设计** | 金无痕三段变化：P1 使用假剑谱（剑招快但无剑气） → 辰生展示真剑谱 → P2 金无痕震惊中疯狂攻击（速度+30%但命中率-40%） → P3 金无痕醒悟，与顾锋合力劈开封印 |
| **觉醒演出** | 顾锋握最普通的铁剑挥出银河般剑气——"剑不在剑上，在人上" |

### 4.5 大梁宫 —— 去伪存真

| 项目 | 内容 |
|------|------|
| **哲学命题** | 现象与本质——去粗取精、去伪存真、由此及彼、由表及里 |
| **星君** | 辰星卦师（道士） |
| **地形** | 北海半沉观星台：二十八宿窗，潮汐紊乱 |
| **守史者** | 澹台明——卦辞被太史阁替换导致师父死亡 |
| **海溟关联** | 海溟国微调了星图数据——每颗星偏移几度，导致所有卦象都是错卦 |
| **玩家体验** | 前半段玄微子疯狂算卦但永远出错（用假星图），辰生用玉佩中真星图校准后每卦精准 |
| **关卡机制** | 水阵——需要正确卦象才能解开的水门。星图错误时水门永远打不开。玩家需要在观星台中逐窗比对玉佩星图与太史阁星图，找到差异 |
| **BOSS战设计** | 澹台明使用错误卦象攻击（伤害飘忽不定，有时暴击有时 miss），玄微子不使用攻击卦而使用治愈卦——治愈她的偏执 |
| **觉醒演出** | 玄微子的手指第一次停止颤抖——"元亨利贞。" |

### 4.6 实沉宫 —— 持久战与群众路线

| 项目 | 内容 |
|------|------|
| **哲学命题** | 持久战——战争的伟力之最深厚的根源存在于民众之中 |
| **星君** | 镇星大将（将军） |
| **地形** | 中原古战场：无数战死者亡魂徘徊 |
| **守史者** | 尉迟疆（亡灵）——被太史阁利用怨念的被骗爱国者 |
| **海溟关联** | 这片战场是中原抵抗海溟国侵略之战的遗址——海溟国通过太史阁使这场战役在史书上"消失"了 |
| **玩家体验** | 前半段石磐孤军奋战（疲惫、空洞感），后半段每一个阵位的士兵亡魂被"认出"和"记住"后成为友军 |
| **关卡机制** | 十道阵法——每道阵位有一个士兵亡魂，需要与亡魂"对话"（交互后观看一段记忆碎片），记起他们的名字和所属部队后，亡魂变为友军并破除该阵位 |
| **BOSS战设计** | 尉迟疆的怨念具象化为军阵。石磐不用武力——他一个一个喊出阵位上士兵的名字。最后一阵时尉迟疆的怨念消散——"你守的是一个谎言。但你不是谎言的制造者。" |
| **觉醒演出** | 石磐重举令旗——"我让他们为一个抽象的概念战斗。这是我的错。他们的名字，应该被记住。" |

### 4.7 鹑首宫 —— 矛盾的同一性

| 项目 | 内容 |
|------|------|
| **哲学命题** | 毒草可以变成肥料——矛盾的双方在一定条件下互相转化 |
| **星君** | 计都星使（刺客） |
| **地形** | 西南永夜森林：完全黑暗，不见天日 |
| **守史者** | 影怜——主动投靠海溟国的旧日同僚 |
| **海溟关联** | 影怜接受了海溟国的"暗杀术改良"——用海溟钢淬毒的匕首，杀伤力强但有"暗毒反噬" |
| **玩家体验** | 完全黑暗中战斗（依赖听觉和直觉），影的刺青在黑暗中发光（唯一光源）。影接受刺青不是诅咒而是忏悔后，刺青裂开露出星光——黑暗与光明融合 |
| **关卡机制** | 黑暗导航——没有地图，靠声音定位。影的刺青强度随敌人的接近而变亮（雷达机制） |
| **BOSS战设计** | 影怜使用海溟暗杀术（蓝色残影——仿品），影使用真正的暗杀术（完全无形——真传）。影击败影怜但不杀她——"让她看到真相。" |
| **觉醒演出** | 影的刺青裂开——"这是我为自己刻下的。不是诅咒。是记忆。" |

### 4.8 鹑火宫 —— 劳动创造文明

| 项目 | 内容 |
|------|------|
| **哲学命题** | 劳动创造了人本身——生产力是文明的基础 |
| **星君** | 神机星君（机关师） |
| **地形** | 沙漠活体机关城：结构不断变化的建筑体 |
| **守史者** | 公输矩——出卖师门换取海溟禁术 |
| **海溟关联** | 海溟国给公输矩的"禁术图纸"是偷来的墨子残篇+他们自己瞎补的部分——造出来的机关兽有致命缺陷 |
| **玩家体验** | 鲁班语一直以为自己是"废柴学徒"，直到他发现自己的失败是因为在机关中植入了星君级构造——凡人材料无法承载。换用正确的材料后，他的每一个"失败作品"都变成了神级造物 |
| **关卡机制** | 房间动态变化——每次进入时房间布局不同。需要用机关臂"理解"每个房间的机械原理才能找到出口 |
| **BOSS战设计** | 公输矩召唤海溟机关兽（巨大的钢铁造物，但关节处有蓝色火花——仿品缺陷）。鲁班语发现缺陷位置，机关兽被从内部瓦解 |
| **觉醒演出** | 鲁班语修复机关城——"不是我手艺差——是我用了错误的材料。用对的材料，什么都能造。" |

### 4.9 鹑尾宫 —— 新陈代谢

| 项目 | 内容 |
|------|------|
| **哲学命题** | 新陈代谢是宇宙间普遍的永远不可抵抗的规律 |
| **星君** | 玄冥星君（符师） |
| **地形** | 幽冥鬼城：生与死的夹缝 |
| **守史者** | 朱砂——主动投靠海溟国求长生 |
| **海溟关联** | 朱砂被海溟国的"永生实验"诱惑——海溟国从偷来的丹术中提取了错误的"不死药"配方 |
| **玩家体验** | 冥婆一直处于衰老濒死状态——但她不是被诅咒，而是长期承受阴气侵蚀。当她接受生死循环而非抗拒衰老时，神力恢复 |
| **关卡机制** | 阴阳两界切换——阳界可见物理结构，阴界可见灵魂印记。需要来回切换才能找到路径（某些门只在阴界可见，某些机关只在阳界可操作） |
| **BOSS战设计** | 朱砂已走火入魔——她的身体因服用海溟"不死药"而变异（肉体不朽但心智崩溃）。冥婆超度了她——不是消灭，是让她回到生死的正常循环中 |
| **觉醒演出** | 冥婆打破生死符——"老去不是诅咒。拒绝老去才是。" |

### 4.10 大火宫 —— 形式与内容

| 项目 | 内容 |
|------|------|
| **哲学命题** | 百花齐放，推陈出新——形式必须承载真实的内容 |
| **星君** | 天音星君（舞乐家） |
| **地形** | 幻音楼：以音乐建造的楼阁，任何进入者都会陷入音律幻境 |
| **守史者** | 师旷——被太史阁欺骗以为音乐危险 |
| **海溟关联** | 海溟国盗版中华乐谱——将乐谱中的"宫商角徵羽"改为七声音阶并署上自己的名字。被污染的旋律充满了不和谐音 |
| **玩家体验** | 幻音楼中的背景音乐随着玩家深入而变得越来越不和谐——海溟篡改版本。阮心将母亲长诗的旋律融入琴音后，背景音乐逐渐恢复为和谐的五音 |
| **关卡机制** | 音乐解谜——每个房间对应一个音律，需要用正确的旋律开启门扉。被污染的旋律（海溟版本）会生成错误的幻象敌人 |
| **BOSS战设计** | 阮心与师旷斗琴——阮心弹奏长诗旋律（五声音阶），师旷弹奏被污染旋律（七声音阶）。百鸟来朝，楼阁生辉——师旷在长诗旋律中听到自己失落的初心，自毁琴弦 |
| **觉醒演出** | 阮心复明——"你不是看不见。你是不愿看。" |

### 4.11 析木宫 —— 为有牺牲多壮志

| 项目 | 内容 |
|------|------|
| **哲学命题** | 砍头不要紧，只要主义真——牺牲的意义不在一时成败，而在代际传承 |
| **星君** | 析木星君（已故，残影试炼） |
| **地形** | 虚无裂缝：存在与不存在之间的领域 |
| **守史者** | 商羽——商徵之女，不知父亲真相 |
| **海溟关联** | 商羽在道宫中发现了父亲的密函——海溟国与商徵的密约原文。她第一次知道自己的父亲是买办 |
| **玩家体验** | 辰生**独自**进入试炼——没有同伴，没有切换职业。面对析木星君的残影，面对"你愿意承受死亡风险来继承力量吗"的终极问题 |
| **关卡机制** | 无存档点（入口一个，BOSS前一个，共 2 个）。全程无杂兵——只有析木星君的记忆碎片（可交互），拼凑出天裂之战中析木牺牲的真相 |
| **BOSS战设计** | 辰生 vs. 析木残影——不是生死搏斗，是**试炼**。三波：P1 承受重力碾压（证明意志） → P2 在重力场中保持站立（证明坚韧） → P3 用继承的重力能力打破封印（证明你值得） |
| **觉醒演出** | 辰生左眼变为星云状——"你不接受就会死。你不是因为不怕死才牺牲的。你是怕更多人死。" |
| **关键道具** | 商羽背叛父亲——交出密函。辰生获得海溟国密约的原始文本证据 |

### 4.12 寿星宫 —— 人民群众是历史的创造者

| 项目 | 内容 |
|------|------|
| **哲学命题** | 人民，只有人民，才是创造世界历史的动力 |
| **星君** | 织女星使（云岫/母亲） |
| **地形** | 倒悬神殿：悬浮于苍穹之上，太史阁总部 |
| **守史者** | 商徵（阁主）+ 海溟国师（隐藏阶段） |
| **海溟关联** | 这是海溟国在中华本土势力的指挥中心 |
| **玩家体验** | 12 位同伴全部到场。前半段玩家切换不同职业对抗海溟暗卫群，后半段与商徵对决 |
| **关卡机制** | 三层：外层（海溟暗卫群战，12位同伴各守一方）→ 中层（化史炉核心区，青焰环境伤害）→ 内层（商徵的密室） |
| **BOSS战设计** | **P1（商徵）**：时间篡改——他会"擦除"玩家的技能冷却，让玩家的技能进入假CD。需要用不同的技能连续攻击——"不能让历史被擦除" → **P2（商徵+化史炉）**：青焰环境伤害 + 商徵召唤被烧毁的典籍的怨念（知识本身的残骸） → **P3（海溟国师介入）**：国师使用盗版十二星君技能的缝合技（每一招都像某个星君但"缺了一口气"），12位同伴合力唱出长诗——长诗不是武器，是证词——击败国师 |
| **觉醒演出** | 云岫现身——"历史不是任人打扮的小姑娘。真相不在书上——真相在人的心里。当十二个人记住同一件事，那件事就从未被遗忘。" |
