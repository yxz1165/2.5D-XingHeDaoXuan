# 角色成长系统 GDD —— 《星河倒悬》

## 1. Overview

角色成长系统涵盖主角辰生和十位星君同伴的等级、属性、天赋、以及职业切换机制。成长分为三个维度：**等级成长**（线性数值）、**天赋盘**（分支选择）、**剧情觉醒**（质变节点）。

核心设计原则：
- **辰生是锚点**：辰生的等级决定队伍整体强度，同伴等级自动同步
- **天赋即哲学选择**：每个职业的天赋盘不是"哪个更强"的选择，而是"你认同哪种战斗哲学"
- **觉醒是质变**：关键剧情节点赋予永久性能力跃迁（第6宫后解锁职业切换第二槽位、第11宫后辰生获得重力能力）

## 2. 等级系统

### 2.1 基础参数

| 参数 | 值 |
|------|-----|
| 等级上限 | 60 |
| 经验曲线 | 指数型，每级所需经验 = 100 × 1.15^当前等级 |
| 满级总经验 | ~85万 |
| 预计满级时间 | 主线通关约 Lv45-50，全支线+隐藏约 Lv60 |

- 同伴属性 = 辰生同等级属性 × 职业系数（战士 1.1x HP/0.9x SPD，刺客 0.8x HP/1.3x SPD 等）

## 3. 天赋盘系统

每个职业有独立的天赋盘，分为三条路线。每升 3 级获得 1 个天赋点（Lv60 共 20 个天赋点），可跨职业分配。

### 3.1 天赋路线设计哲学

每个职业的三条路线不是随意的技能强化——它们对应该职业星君的**三种战斗哲学**：

| 职业 | 路线A | 路线B | 路线C |
|------|-------|-------|-------|
| 战士 | 怒火（输出） | 铁壁（坦克） | 燎原（团队） |
| 弓箭手 | 精准（单体） | 巡游（机动） | 生机（辅助） |
| 剑士 | 锋芒（爆发） | 剑心（持续） | 剑域（控制） |
| 道士 | 乾天（输出卦） | 坤地（防御卦） | 中和（辅助卦） |
| 刺客 | 暗杀（单体爆发） | 影舞（机动） | 侵蚀（debuff） |
| 将军 | 征伐（输出） | 固守（防御） | 统帅（团队） |
| 机关师 | 火力（炮台输出） | 巧技（机关控制） | 辅助（团队buff） |
| 符师 | 天符（攻击符） | 地符（防御符） | 人符（治疗符） |
| 舞乐家 | 破阵（进攻光环） | 清平（治疗光环） | 霓裳（速度光环） |
| 方术士 | 金丹（爆发） | 丹砂（持续） | 护体（生存） |
| 辰生 | 星云（重力） | 织女（团队） | 析木（牺牲/反伤） |

每个路线 6 个节点（含 2 个大节点），全点满一条路线需 6 点，点满两条需 12 点（Lv36），全满需 18 点（Lv54）。

### 3.2 辰生专属天赋盘

辰生的天赋不是职业天赋——他本人可以切换任何职业。辰生的天赋影响的是**全局被动**和**重力能力**：

**路线A：星云·引力**
- T1: 重力牵引范围 +20%
- T2: 重力牵引伤害 +30%
- T3（大）: 重力牵引可牵引 BOSS（距离减半）
- T4: 重力护罩期间每秒回复 1% HP
- T5: 星云能量获取 +25%
- T6（大）: 重力反转可对超级霸体目标生效

**路线B：织女·纽带**
- T1: 切换职业后 3 秒内伤害 +10%
- T2: 切换职业冷却 -25%
- T3（大）: 可装备第二个星君信物
- T4: 队友在信物共鸣下的双倍效果延长至 2x
- T5: 切换职业时，原职业资源保留 75%（原 50%）
- T6（大）: 战斗中可切换第三个职业（解锁第三槽位）

**路线C：析木·献身**
- T1: 受到伤害时星云能量获取 +15%
- T2: 生命低于 30% 时伤害 +20%
- T3（大）: 受到致命伤害时保留 1 点生命（冷却 5 min）
- T4: 每损失 10% HP，伤害 +3%
- T5: 重力护罩期间反弹 20% 伤害
- T6（大）: 死亡时自动触发一次重力爆炸（范围伤害 + 队友回复），每场战斗一次

## 4. 剧情觉醒节点

辰生在特定剧情节点获得永久性能力跃迁，这是"成长"的叙事维度：

| 节点 | 剧情位置 | 解锁能力 |
|------|---------|---------|
| 第1宫后 | 星纪宫通关 | 职业切换：可在辰生+1位星君之间切换 |
| 第3宫后 | 娵訾宫通关 | 解锁第二个同伴槽位（可带2位星君） |
| 第6宫后 | 实沉宫通关 | 战斗中可以切换职业（此前只能在存档点切换） |
| 第8宫后 | 鹑火宫通关 | 切换职业冷却时间减半 |
| 第11宫后 | 析木宫通关 | 获得重力能力（见战斗GDD 3.8） |
| 第12宫后 | 寿星宫通关 | 获得"长诗共鸣"——可同时召唤所有已觉醒星君的力量（终局大招） |

## 6. 依赖系统

| 依赖系统 | 关系 |
|---------|------|
| 战斗系统 | 属性映射、天赋效果、重力能力 |
| 道宫关卡 | 剧情觉醒节点在第 N 宫通关后触发 |
| 装备系统 | 属性叠加计算 |
| UI系统 | 天赋盘界面、等级显示 |

## 7. 可调参数

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `MaxLevel` | 60 | 等级上限 |
| `ExpCurveBase` | 100 | 经验曲线基数 |
| `ExpCurveGrowth` | 1.15 | 每级经验增长倍率 |
| `TalentPointsPerLevel` | 3 | 每 N 级获得 1 天赋点 |
| `CompanionExpRate_InParty` | 80% | 队伍内同伴经验获取 |
| `CompanionExpRate_Bench` | 30% | 非队伍同伴经验获取 |
| `AwakeningNodeCount` | 6 | 剧情觉醒节点数 |

## 8. 验收标准

- [ ] 辰生每升 1 级属性正确增长
- [ ] 每 3 级获得 1 个天赋点，可在任一职业天赋盘使用
- [ ] 天赋点可跨职业分配，切换职业后对应天赋生效
- [ ] 同伴等级在加入时自动同步为辰生等级 -2
- [ ] 6 个剧情觉醒节点在正确时机触发
- [ ] 第 11 宫后辰生重力能力正确解锁
- [ ] 辰生 3 条天赋路线的 T3/T6 大节点效果正确
