# UI 与 HUD 设计 GDD —— 《星河倒悬》

## 1. Overview

UI系统采用中国传统美学——水墨、星图纹样、竹简质感，与团结引擎 UI Toolkit 实现。战斗HUD追求信息清晰但不遮挡画面，菜单界面追求沉浸感。

核心设计原则：
- **少即是多**：HUD 默认只显示血条+资源条+技能冷却，其余信息按需浮现
- **中国传统视觉语言**：菜单背景用古纸/竹简纹理，光标音效用古琴泛音，过场字幕用竖排楷体
- **色盲友好**：元素颜色不仅靠颜色区分（火=菱形图标/水=圆形图标/金=方形图标等）
- **真伪可辨**：真传装备用金边，仿品装备用灰紫边+暗纹闪烁

## 2. 战斗 HUD

### 2.1 布局

```
┌─────────────────────────────────────────────┐
│ [同伴1血条]          [Boss血条(如有)]         │
│ [同伴2血条]                                  │
│                                             │
│                                             │
│                   (战斗区域)                  │
│                                             │
│                                             │
│ [连击数]                    [小地图(可选)]    │
│ [快捷键道具] [Q][E][1][2][3][4]  [资源条]    │
│ [HP条━━━━━━━━━━━━━━━]  [星云条(辰生)]       │
│ [当前职业图标]                              │
└─────────────────────────────────────────────┘
```

### 2.2 HUD 元素

| 元素 | 位置 | 显示规则 |
|------|------|---------|
| 主角血条 | 左下 | 始终显示，红色渐变为金色（对应五行火→土） |
| 职业资源条 | 左下（血条上方） | 始终显示，颜色随元素变化 |
| 星云能量条 | 左下（第11宫后） | 星云色（深蓝+银白粒子） |
| 当前职业图标 | 左下角 | 小尺寸星君符号 |
| 技能冷却 | 技能图标上 | 覆盖式扇形倒计时 |
| 连击计数器 | 左中 | 连击>10时显示，3秒无伤害消失 |
| 同伴血条 | 左上 | 2个小条，显示名字+血量 |
| BOSS血条 | 顶部居中 | BOSS战时显示，含阶段标记 |
| 快捷键道具 | 右下 | 当前装备的消耗品图标+数量 |
| 小地图 | 右上（可选） | 道宫内显示，可切换开/关 |
| 伤害数字 | 浮动 | 普攻白色/技能黄色/暴击橙色/元素蓝色/真传打仿品金色 |
| 异常状态图标 | 血条旁 | 小图标+剩余秒数 |

### 2.3 交互提示

| 场景 | 提示方式 |
|------|---------|
| 可对话NPC | 头顶浮现"…"气泡，靠近后变为对话图标 |
| 可拾取物品 | 地面光柱（白=普通/绿=精良/蓝=稀有/紫=史诗/橙=传说/灰紫闪烁=仿品） |
| 存档点 | 靠近时出现"按F激活"提示 |
| 机关/门 | 可交互时高亮边框 |
| BOSS技能预警 | 地面红色/蓝色范围指示器 |

## 3. 主菜单界面

### 3.1 菜单结构

```
主菜单 (Esc)
├── 继续游戏
├── 背包
│   ├── 装备 (武器/防具/饰品)
│   ├── 消耗品
│   ├── 材料
│   ├── 关键道具
│   ├── 星君信物
│   └── 记忆碎片
├── 角色
│   ├── 辰生 (属性+天赋盘)
│   ├── 同伴列表 (10人)
│   └── 职业切换
├── 星图 (世界地图+道宫入口)
├── 队伍 (编队)
├── 任务日志
├── 知残手札 (收集品阅读)
├── 系统设置
└── 返回游戏
```

### 3.2 背包界面

- 左侧：分类标签（竖排，竹简样式）
- 中间：物品网格列表（横向4列）
- 右侧：选中物品详情 + 操作按钮（装备/使用/出售/分解/标记）
- 底部：金币+材料数量概览
- 装备对比：悬停时自动弹出当前装备 vs 悬停装备的属性差异（绿色↑/红色↓）

### 3.3 角色界面

- 左侧：角色立绘（水墨风格）+ 等级/经验条
- 中间：属性面板（攻击/防御/生命/暴击/暴伤/元素增伤/抗暴/元素抗性）
- 右侧：天赋盘（三条路线可视化）
- 底部：当前装备预览（4槽位小图标）

### 3.4 星图（大地图）

- 卷轴展开式地图，水墨风格
- 已解锁区域：彩色 + 标注
- 未解锁区域：灰色 + 云遮
- 道宫入口：星辉标记（金色=已通关/蓝色=当前可进入/灰色=未解锁）
- 城镇/NPC：图标标注
- 点击可传送（仅已发现的星碑）

## 4. 对话框与过场

### 4.1 对话界面

- 底部居中：对话文字（仿宋体，22px）
- 左侧：说话者立绘（半身像）
- 右侧：对话选项（竖排，最多4项）
- 历史记录：↑键回看

### 4.2 过场字幕

- 竖排从右至左滚动（符合古文阅读习惯）
- 关键台词逐字显示（typewriter效果）+ 古琴泛音
- 哲学命题总结（每宫觉醒后的黑屏白字）使用大字楷体，停顿3秒

## 6. UI 视觉规范

### 6.1 调色板

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主背景 | 古纸黄 | #F5E6C8 |
| 文字主色 | 墨黑 | #2C1810 |
| 文字辅色 | 朱砂红 | #C04040 |
| 按钮常态 | 靛蓝 | #3B5998 |
| 按钮悬停 | 金色 | #C8A84E |
| 稀有度·白 | 灰白 | #C8C8C8 |
| 稀有度·绿 | 翠绿 | #4CAF50 |
| 稀有度·蓝 | 天蓝 | #2196F3 |
| 稀有度·紫 | 紫罗兰 | #9C27B0 |
| 稀有度·橙 | 金橙 | #FF9800 |
| 仿品标识 | 灰紫+暗纹 | #6A5A7A |
| 血条 | 朱红渐变 | #C04040→#D4A574 |
| 资源条（各职业） | 对应元素色 | 火红/木绿/金白/水蓝/土黄/暗紫/音青 |

### 6.2 字体

| 用途 | 字体 | 大小 |
|------|------|------|
| 标题 | 隶书/篆书风格 | 36px |
| 正文/对话 | 楷体 | 22px |
| HUD 数字 | 楷体加粗 | 18px |
| 伤害数字 | 行书风格 | 24-48px（按伤害量级） |
| 菜单标签 | 仿宋 | 16px |

### 6.3 图标

- 技能图标：方形45px，中国传统纹样风格（云纹/雷纹/星纹）
- 物品图标：方形40px，写实小图
- 元素图标：小尺寸，形状+颜色双重编码

## 7. 依赖系统

| 系统 | 关系 |
|------|------|
| 战斗系统 | HUD 数据来源 |
| 背包道具 | 背包界面数据 |
| 装备系统 | 装备对比、真伪标识 |
| 角色成长 | 角色界面、天赋盘 |
| 道宫关卡 | 大地图、存档点提示 |

## 8. 可调参数

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `DamageNumberDuration` | 1.0s | 伤害数字显示时长 |
| `ComboShowThreshold` | 10 | 连击计数器显示阈值 |
| `ComboFadeDelay` | 3.0s | 连击中断显示延迟 |
| `BossHPBarShow` | true | BOSS血条显示 |
| `MinimapDefault` | true | 小地图默认开关 |
| `ItemGlowIntensity` | 1.0 | 物品光柱亮度 |
