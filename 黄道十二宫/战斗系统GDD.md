# 战斗系统 GDD —— 《星河倒悬》

---

## 1. Overview

本作战斗是**2.5D 动作角色扮演**，采用 2D 横向卷轴空间 + 3D 渲染。玩家操作主角辰生，携带最多两位星君同伴（AI 操控或手动切换），在道宫中与太史阁守军和海溟国暗卫进行实时战斗。

**核心设计原则：**
- **低门槛，高上限**：按键数量少（鼠标左右键 + Q/E + 1-4），通过短按/长按双形态、连招派生、元素反应来撑起深度。
- **职业即身分**：每种职业不仅在技能模板上不同，在移动速度、闪避帧数、霸体窗口、资源机制上都有独特手感。每个职业承载一座道宫的哲学命题。
- **辰生的成长弧线**：从普通少年到继承析木之力，辰生的战斗能力随剧情推进发生质变——这是叙事与玩法统一的最高体现。
- **敌人分层**：太史阁基层（被洗脑的凡人）、太史阁守史者（买办精英）、海溟暗卫（海外侵略者直接派遣的精锐）——三层敌人对应三种战斗风格。
- **数据驱动**：所有伤害公式、硬直阈值、元素倍率均为外部可调参数。

**每宫哲学主题映射：**

| 道宫 | 哲学主题 | 战斗体验 |
|------|---------|---------|
| 星纪 | 矛盾的普遍性——哪里有压迫，哪里就有反抗 | 被火焰包围 → 在烈焰中反击 |
| 玄枵 | 实践论——认识从实践始 | 闭眼战斗 → 复明后精准射击 |
| 娵訾 | 内因与外因——外因是条件，内因是根据 | 毒瘴削弱 → 丹砂内炼突破 |
| 降娄 | 主要矛盾——捉住主要矛盾，一切迎刃而解 | 万剑阵迷惑 → 破解真剑谱 |
| 大梁 | 现象与本质——去粗取精，去伪存真 | 错误星图 → 校准后卦卦精准 |
| 实沉 | 持久战——伟力之根源存在于民众之中 | 孤军奋战 → 战友亡魂觉醒 |
| 鹑首 | 矛盾的同一性——毒草可以变成肥料 | 黑暗中的恐惧 → 接受暗影之力 |
| 鹑火 | 生产力——劳动创造了人本身 | 失败作品 → 理解材料本质 |
| 鹑尾 | 新陈代谢——生死循环的规律 | 衰老濒死 → 接受生死循环 |
| 大火 | 形式与内容——百花齐放，推陈出新 | 被污染的旋律 → 真实的长诗旋律 |
| 析木 | 为有牺牲多壮志——砍头不要紧，只要主义真 | 独自面对残影 → 继承牺牲之力 |
| 寿星 | 人民群众是历史的创造者 | 时间被抹除 → 十二人合力唱出真相 |

## 2. 玩家幻想

- **一个键，三种味道**：短按/长按的双形态让每个技能都有快速版和蓄力版，玩家在对"安全"和"伤害"之间不断做微决策。
- **连段的快感**：普攻连段取消技能后摇 → 技能取消闪避 → 闪避后反打，形成"永不停止"的流畅战斗循环。
- **看了就知道是什么**：受击特效、音效、震屏、hitstop 共同构成清晰的命中反馈。
- **职业之间不是换个皮**：切到战士是"硬扛正面"，切到刺客是"找背一击脱离"，手感差异肉眼可见。
- **从少年到继承者**：析木宫之后，辰生获得重力操控能力，战斗从"靠同伴"升级为"同伴+自身神力"的双核模式。

## 3. 详细规则

### 3.1 伤害计算

#### 3.1.1 基础伤害公式

```
基础伤害 = 攻击力 × 技能倍率 × (1 + 等级加成)
暴击伤害 = 基础伤害 × (1 + 暴击伤害加成)    [若暴击判定成功]
元素加成 = 暴击伤害 × (1 + 元素增伤)
最终伤害 = 元素加成 × (1 - 减伤率) × (1 + 伤害浮动)
```

#### 3.1.2 减伤率公式

```
减伤率 = 防御力 / (防御力 + 200 + 目标等级 × 10)
```
- 当防御力 = 200 + 目标等级 × 10 时，减伤率 = 50%
- 减伤率上限：80%

#### 3.1.3 暴击判定

```
暴击率 = 基础暴击率 + (暴击属性 - 目标抗暴属性) / 100 × 1%
暴击率上限：80%，下限：5%
暴击伤害加成：默认 +50%
```

#### 3.1.4 攻击力构成

```
总攻击力 = (角色基础攻击 + 武器攻击) × (1 + 攻击力加成%) + 固定攻击加成
```

#### 3.1.5 等级压制

```
等级差 = 攻击方等级 - 防御方等级
等级加成 = clamp(等级差 × 0.03, 0, 0.45)    // 每级3%，最多45%加成
```
- 攻击方低等级无惩罚（`clamp` 下限为 0），鼓励越级挑战。这正是"弱者可以战胜强者"的唯物辩证法——胜负不由等级决定，由操作和策略决定。

### 3.2 命中、受击与反馈

#### 3.2.1 攻击判定架构

- 所有攻击技能在团结引擎中通过 `Collider` (Trigger) 或 `Physics.OverlapSphere/Box` 实现攻击盒。
- 攻击盒在技能的**有效帧**期间激活，由 Animation Event 或帧数据驱动开关。
- 受击方通过 `HurtBox` (Trigger Collider) 接收攻击盒的碰撞事件。

#### 3.2.2 命中停顿 (Hitstop)

| 攻击类型 | Hitstop 时长 | 适用范围 |
|---------|-------------|---------|
| 普攻 | 1-2 帧 (60fps) | 攻击方 + 受击方 |
| 技能 | 2-4 帧 | 攻击方 + 受击方 |
| 大招/处决 | 6-10 帧 | 攻击方 + 受击方 + 镜头震动 |
| 弹反成功 | 8-12 帧 | 双方 + 全屏暂停感 |
| 辰生重力爆发 | 12-15 帧 | 全场敌人 + 全屏暂停 + 星云特效 |

- Hitstop 期间游戏时间缩放为 0，粒子效果继续播放。

#### 3.2.3 受击硬直等级

| 等级 | 名称 | 持续时间 | 表现 | 被触发条件 |
|------|------|---------|------|-----------|
| Lv0 | 无反应 | — | 继续当前动作 | 伤害 < 最大生命值 5% |
| Lv1 | 轻微抖动 | 4-6 帧 | 角色模型抖动，可继续行动 | 普攻命中 |
| Lv2 | 硬直 | 12-20 帧 | 角色后仰，不可行动 | 技能命中，伤害 > 阈值 |
| Lv3 | 击退 | 20-30 帧 | 角色滑退一段距离 + 硬直 | 重击/蓄力技能 |
| Lv4 | 浮空 | 30-40 帧 | 被击飞至空中 | 升龙类技能 |
| Lv5 | 击倒 | 50-70 帧 | 倒地 → 起身 | 终结技/破韧后追击 |

- BOSS 最小硬直反应为 Lv1，不受 Lv0 影响（Boss 不会"无反应"，星君的力量不容轻视）。
- 海溟国暗卫精英具有特殊"受身"能力：Lv4 浮空后可强制落地，消耗其护盾值。

### 3.3 霸体、韧性、破韧

#### 3.3.1 韧性条 (Poise)

```
韧性最大值 = 基础韧性 + 等级 × 韧性成长系数
```

- 韧性条在非受击状态下每 2 秒恢复 `韧性最大值 × 5%`
- 韧性条为 0 时，进入**破韧状态**：持续 4 秒，期间所有攻击对其产生 Lv4（浮空）或以上硬直
- 破韧结束后，韧性恢复到满

#### 3.3.2 霸体 (Super Armor / Hyper Armor)

- **霸体**：角色在执行特定动作期间不受 Lv1-Lv2 硬直影响，但仍受 Lv3 以上硬直
- **超级霸体**：不受任何硬直影响，但伤害照常计算
- **无敌**：不受伤害也不受硬直

各职业霸体窗口：

| 职业 | 霸体技能 | 类型 |
|------|---------|------|
| 战士 | 盾牌格挡（长按右键）中 | 超级霸体 |
| 战士 | 旋风斩（长按E）全程 | 霸体 |
| 战士 | 跳劈（长按2）下落阶段 | 无敌 |
| 将军 | 据守（长按Q）全程 | 超级霸体 |
| 方术士 | 雄黄护体（短按2）前3秒 | 霸体 |
| 方术士 | 朱砂掌（长按Q）出掌帧 | 霸体 |
| 符师 | 金刚符（长按2）1秒 | 无敌 |
| 舞乐家 | 反弹琵琶（长按Q）旋转期间 | 霸体 |
| 辰生（析木后） | 重力护罩（长按右键）全程 | 超级霸体 + 减伤50% |

#### 3.3.3 主角受击规则

- 主角**不适用韧性条**——主角被攻击时直接进入硬直动画（受击方角色永远可被连续命中惩罚）
- 但主角的闪避期间有无敌帧（见 3.5），可以通过操作规避伤害
- 主角被浮空后可受身（空中按空格），消耗 50% 当前精力

### 3.4 连招系统

#### 3.4.1 普攻连段

- 每个职业有固定的普攻连段（通常 3-5 段）。
- 在上一段普攻的**后摇窗口**（最后 30% 的动画帧）输入下一段 → 连段继续。
- 在**非后摇窗口**输入 → 从第一段重新开始（连段断）。

| 职业 | 连段数 | 特点 |
|------|-------|------|
| 战士 | 4 | 第3段带横扫（范围），第4段下砸击退 |
| 弓箭手 | 3 | 第3段后跳一步并射击，自动拉开距离 |
| 剑士 | 5 | 第5段即居合斩，高暴击率 |
| 道士 | 3 | 每段近战，第3段附带自动演卦（随机卦象） |
| 刺客 | 4 | 第2、4段自动绕至目标背后 |
| 将军 | 3 | 第3段击退扇形范围 |
| 机关师 | 3 | 每段命中减短炮台冷却 0.3 秒 |
| 符师 | 3 | 每段命中回复少量精力 |
| 舞乐家 | 4 | 第4段为回旋击退周围敌人 |
| 方术士 | 3 | 第3段获得 1 点丹砂 |
| 辰生（析木后） | 4 | 第3段附带重力牵引（拉近敌人），第4段重力爆发（击退周围） |

#### 3.4.2 技能取消规则

**允许取消：**
- 普攻后摇 → 技能（任意段普攻的最后 30% 帧）
- 技能后摇 → 闪避
- 普攻过程中 → 闪避（所有职业通用）
- 闪避 → 普攻

**禁止取消：**
- 普攻前摇/命中帧 → 技能
- 技能命中帧 → 闪避
- 技能 → 技能（不允许技能连打，CD 为硬限制）

#### 3.4.3 浮空与空中追打

| 职业 | 浮空技 |
|------|-------|
| 剑士 | 升龙斩（长按Q） |
| 战士 | 盾牌猛击接Q（短按Q命中后立刻短按Q第二次） |
| 刺客 | 暗影步（短按右键）从背后来 |
| 将军 | 冲锋阵（长按2） |
| 方术士 | 铅汞囚笼（长按E）吸附后 |
| 辰生（析木后） | 重力反转（Q短按）——将前方敌人抬升至空中 |

- 浮空后 0.8 秒内，可使用"空中追打"技能（各职业至多 1 个）。
- 空中追打后自动落地，不可无限浮空。

#### 3.4.4 连击数增益

```
连击伤害加成 = min(连击数 × 0.5%, 10%)    // 每击 +0.5%，上限 +10%
```

- 连击中断条件：3 秒内未造成任何伤害
- 部分装备/talent 可提升此上限

### 3.5 闪避与无敌帧

#### 3.5.1 通用闪避参数

| 参数 | 值 |
|------|-----|
| 闪避动画总帧数 | 25 帧 (60fps) |
| 无敌帧窗口 | 6-18 帧（13 帧有效无敌） |
| 闪避方向 | WASD 输入方向；无输入则向后闪 |
| 闪避距离 | 3.5m |
| 闪避冷却 | 无硬冷却，但闪避结束后有 3 帧"硬直帧"不可再次闪避 |

#### 3.5.2 职业差异化

| 职业 | 无敌帧窗口 | 闪避距离 | 特殊 |
|------|-----------|---------|------|
| 战士 | 4-16 帧 | 3.0m | 闪避时仍承受 30% 伤害——**"矛盾的普遍性"：压迫不消失，但反抗者更坚韧** |
| 弓箭手 | 6-20 帧 | 4.5m | 长闪避距离——**"实践"出空间以观察和瞄准** |
| 剑士 | 6-18 帧 | 3.5m | 标准——**"捉主要矛盾"：精准闪避优于盲目闪避** |
| 道士 | 8-18 帧 | 3.5m | 闪避后 1 秒内下一个卦象瞬发——**"去伪存真"后认知加速** |
| 刺客 | 4-22 帧 | 5.0m | 最长无敌帧 + 最远距离——**"矛盾转化"：黑暗面转化为战术优势** |
| 将军 | 2-12 帧 | 2.5m | 最短无敌帧，但闪避时霸体——**"持久战"不靠闪避靠坚守** |
| 机关师 | 6-16 帧 | 3.0m | 闪避后炮台获得 1 秒攻速提升——**"劳动创造"：连闪避都在生产** |
| 符师 | 6-18 帧 | 3.5m | 标准——**"新陈代谢"：闪避是旧状态的结束和新状态的开始** |
| 舞乐家 | 6-18 帧 | 4.0m | 闪避=舞步，结束后自动向敌人方向滑回——**"形式与内容"：动作即艺术** |
| 方术士 | 6-16 帧 | 3.0m | 闪避路径上留下丹砂粉尘（短时持续伤害）——**"内因外因"：退避中也在转化环境** |
| 辰生（析木后） | 6-18 帧 | 4.0m | 闪避后 0.5 秒内下次普攻附带重力牵引——**"牺牲之志"：每一个闪避都是反击的准备** |

#### 3.5.3 闪避优先级

在以下状态中可闪避：普攻后摇（所有帧）、技能后摇（所有帧）、移动中、站立

不可闪避：普攻前摇/命中帧、技能前摇/命中帧、受击硬直中、已被浮空/击倒、闪避结束后的 3 帧硬直

| 元素 | 异常状态 | 效果 | 持续 |
|------|---------|------|------|

- BOSS 对异常状态的持续时间减半。
- 同类异常不可叠加，重复触发刷新持续时间。
- 不同异常可同时存在于同一目标上。

| 方术士 | 丹砂 | 100 | 普攻 +10，击杀 +30 | 炼丹消耗 30/颗 |
| 辰生（析木后） | 星云 | 100 | 受到伤害 +10/次，击杀敌人 +20 | 重力技能消耗 25-40 |

- 切换职业时，原职业资源保留 50%，新职业资源从 50% 开始。

### 3.8 辰生专属能力（析木宫后解锁）

析木宫之后，辰生继承析木星君的力量，获得**重力操控**能力。这不是一个"新职业"——辰生仍然可以在战斗中切换为其他星君职业，但获得以下专属技能：

| 按键 | 短按 | 长按 |
|------|------|------|
| `右键`（新增） | **重力牵引**——将前方锥形范围内的敌人向辰生拉近 3m，造成少量伤害 | **重力护罩**——持续消耗星云能量，周身产生重力场，承受伤害 -50%，超级霸体 |
| `Q`（辰生专属） | **重力反转**——将前方单个敌人浮空（Lv4），无视其当前硬直状态 | **星辰坠**——以辰生为中心，向周围释放重力冲击波，击退并眩晕 2 秒 |
| `E`（辰生专属） | **星云步**——向鼠标方向瞬移 6m，路径上的敌人被轻微推开 | **重力锚**——在当前位置设下重力锚，5 秒内周围敌人移速 -40% |

- 辰生的左眼瞳孔变为星云状（剧情表现），在释放重力技能时星云旋转加速（视觉反馈）。
- 辰生的星云能量在非战斗状态缓慢回复（10%/秒），在战斗中不自动回复——必须通过受击和击杀来获取。
- 这个设计体现析木星君的哲学命题：**"为有牺牲多壮志"——你必须承受伤害、直面敌人，才能获得反击的力量。**

### 3.10 敌人类型与受击行为

敌人分为三大势力：

#### 3.10.1 太史阁基层（被洗脑的凡人）

| 敌人类型 | 韧性值 | 硬直最小等级 | 特点 |
|---------|-------|------------|------|
| 史馆杂役 | 30-50 | Lv1 | 数量多，攻击欲望低，可被浮空追击至死 |
| 捕史者（斥候） | 60-100 | Lv1 | 移动快，会呼叫增援 |
| 修史官（法师型） | 40-60 | Lv1 | 远程青焰攻击（海溟噬文火），持续伤害 |

**设计意图**：太史阁基层大多是被洗脑的普通人，战斗表现上倾向于"人多但弱"——不是恶人，是工具。击败他们后可以触发短暂的"觉醒"动画（概率 10%），表现为放下武器离开战场。这是**"分清敌友，争取中间力量"的统一战线思想**的战斗体现。

#### 3.10.2 守史者（买办精英 BOSS）

| 敌人类型 | 韧性值 | 硬直最小等级 | 特殊行为 |
|---------|-------|------------|---------|
| 守史者（1-6宫） | 500-800 | Lv1 | 单阶段，血量 < 30% 时反思犹豫（输出降低 10%） |
| 守史者（7-10宫） | 800-1200 | Lv1 | 两阶段，第二阶段获得海溟国秘术加持 |
| 商羽（析木宫） | 600 | Lv1 | 非真正敌人，剧情中选择背叛太史阁 |
| 商徵（寿星宫） | 1500 | Lv0 | 时间篡改+3阶段，见下方 |

**设计意图**：守史者的"反思犹豫"机制体现了一个核心叙事——他们不是纯粹的恶人，而是被洗脑/被欺骗/被收买的买办。低血量时的犹豫是人性残留的表现。1-6宫的守史者罪孽较轻（大多是被骗的），7-10宫的守史者则更深入地与海溟国合作，第二阶段获得海溟秘术加持——视觉上会有明显的"海外邪术"特效变化。

#### 3.10.3 海溟国暗卫（海外侵略者精锐）

| 敌人类型 | 韧性值 | 硬直最小等级 | 特殊行为 |
|---------|-------|------------|---------|
| 海溟暗哨 | 150-200 | Lv2 | 隐身突袭，使用偷学篡改后的暗杀术——动作与刺客职业相似但"缺了一口气" |
| 海溟武士 | 250-400 | Lv2 | 使用仿制中华剑术——剑招形似但无剑气，被真正的太白剑士技能命中后有概率"武器破碎" |
| 海溟方术士 | 200-300 | Lv1 | 使用偷窃篡改后的炼丹术——投掷毒瓶和炸裂丹，但爆炸范围不稳定（劣质仿品） |
| 海溟国师（最终BOSS附加阶段） | 2000 | Lv0 | 见下方 |

**设计意图**：海溟国势力的核心视觉主题是**"仿品"**——他们的战斗动作与星君职业有表面相似性，但关键细节缺失：
- 海溟暗哨的隐身会有蓝色残影（刺客影的隐身完全无形）
- 海溟武士的剑术命中后没有 hitstop（因为他们的剑没有"剑气"——没有灵魂）
- 海溟方术士的炸弹爆炸范围不可预测（因为丹方是偷了一半自己瞎补的）

当玩家使用对应星君职业击败海溟仿品敌人时，触发特殊击杀动画——仿品的武器/道具在星君正版力量面前碎裂。这是**"真传 vs 仿品"**的战斗叙事。

## 4. 公式汇总

```
# 伤害
ActualDamage = (ATK × SkillMult × (1 + LevelDiff × 0.03) × (1 + CritBonus if crit))
             × ElementMult
             × (1 - DEF / (DEF + 200 + TargetLevel × 10))
             × (1 + Rand(-0.05, +0.05))

# 暴击
CritChance = min(BaseCrit + (Crit - AntiCrit) / 100 × 0.01, 0.80)
CritBonus  = 0.50 + CritDmgBonus

# 元素
ElementMult = 1.3 (克制) / 1.0 (中立) / 0.7 (被克制) / 1.5 (暗↔音)

# 韧性伤害
PoiseDmg = SkillBasePoiseDmg × (1 + PoiseDmgBonus)

# 减伤率
DR = min(DEF / (DEF + 200 + TargetLevel × 10), 0.80)

# 连击加成
ComboBonus = min(ComboCount × 0.005, 0.10)

# 等级压制
LevelBonus = clamp(AttackerLevel - DefenderLevel, 0, 15) × 0.03

# 海溟仿品脆弱性
if (Attacker.IsStarLord && Defender.IsHaiMingCopy):
    Damage ×= 1.15   # 真传对仿品额外 15% 伤害
```
