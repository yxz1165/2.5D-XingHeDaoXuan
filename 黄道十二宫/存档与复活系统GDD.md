# 《星河倒悬》——存档与复活系统GDD

---

## 一、设计问题的提出

### 1.1 游戏机制与叙事一致性的矛盾

任何带有战斗和死亡风险的游戏，都必须回答三个问题：

| 机制问题 | 常见的"游戏化"答案 | 叙事层面的隐患 |
|---------|-------------------|--------------|
| 为什么能存档？ | 暂停菜单 → 保存 | 与故事世界无关，是纯粹的meta操作 |
| 为什么能复活？ | 读档 / 检查点重生 | 角色"死过"这件事在故事中被忽略了 |
| 为什么Boss战能重来？ | 自动存档 / 重试按钮 | 严重破坏叙事沉浸——"我已经打败他了，为什么又要打？" |

对大多数游戏而言，玩家已经习惯了" gameplay-story segregation "——玩法归玩法，故事归故事。但对于《星河倒悬》——一个以"实事求是"为核心哲学命题、所有系统都服务于叙事深度的游戏——这种割裂是不可接受的。

**本作中不存在"纯游戏机制"。每一个系统都必须有世界观的锚点。**

### 1.2 本作的特殊挑战

《星河倒悬》有几个特征让这个问题变得更加尖锐：

1. **十二宫关卡是线性叙事的**：每座宫殿对应一段不可逆转的角色觉醒。如果玩家在Boss战中死亡，不能简单地"重生在Boss房门口"——这会让觉醒时刻的仪式感荡然无存。

2. **大型战斗场景密集**：Boss战本身就是剧情高潮。反复重试会稀释情感冲击力。

3. **说书人框架**：辰生老年成为说书人，以回望视角讲述自己的旅程。这个框架天然提供了一种"事后讲述"的叙事层次——死亡可以被讲述，但需要被赋予意义。

4. **辰星卦师的时间权柄**：十二星君中有一位执掌时间与预知的星君（辰星卦师）。时间操作在你的世界观中不是外挂，而是内建的宇宙法则。

**设计目标：让存档、死亡、复活成为故事的一部分，而不是故事的漏洞。**

## 二、世界观锚点分析

### 2.1 现有设定中可以承载机制的四个锚点

在开始设计之前，先盘点已有的世界观资产：

| 锚点 | 来源 | 可承载的机制方向 |
|------|------|-----------------|
| **辰星卦师**（时间/预知） | 剧情大纲 1.1 | 时间回溯的逻辑基础——十二星君中有一位就是管时间的 |
| **织女星使**（命运编织） | 剧情大纲 1.1 | 母亲云岫在陨落前为儿子编织的"命运之线" |
| **十二宫封印网络** | 剧情大纲 1.3 | 每座宫殿是时间线的钉子——因为封印虚噬需要锚定时间 |
| **说书人框架**（老年辰生回望） | 剧情大纲 终章 | 死亡 = "那次他没走通"，被说书人以回望视角讲出来 |

这四个锚点不是临时发明的，而是已经在33,000字剧情大纲中存在的基础设定。设计任务不是"加一个新系统"，而是"让这些已有的设定产生机制层面的果实"。

### 2.2 为什么不选别的锚点

| 被排除的方案 | 排除原因 |
|------------|---------|
| 玄冥星君（生死）做"冥界复活" | 生死权柄过于宏大，复活会削弱死亡的分量；且与"实事求是"精神冲突 |
| 西陆秘术 | 用敌人的技术复活自己，伦理层面不通 |
| 纯游戏化（主菜单读档） | 与本作"一切服务于叙事"的设计哲学根本冲突 |
| 轮回转世 | 星君转世机制已经有，但那是数百年尺度的，不适合"五分钟前死了现在回来" |

**结论：辰星卦师的时间权柄 + 织女星使的命运编织 = 这是一个关于"时间回溯"而非"死而复生"的系统。**

## 三、方案推演与取舍

### 3.1 推演过程

```
问题：辰生在战斗中倒下 → 需要"重来" → 这个"重来"怎么在故事中成立？

思路一：他是神族转世，杀不死。
→ 问题：那还打什么？而且"杀不死"和"能重来"是两回事。
→ 否决。

思路二：他在做梦/预知/辰星卦师的卦象推演。
→ 问题：如果十二宫都是推演，那真实的辰生在哪？叙事被抽空了。
→ 否决。

思路三：时间回溯——他在某个时间点留下了锚，倒下时被拉回那个点。
→ 条件：需要（a）一个锚定时间的器物（b）锚定时间的操作（c）回溯的触发条件
→ 三个条件都可以嵌入现有世界观而不制造矛盾。
→ 采纳。
```

### 3.2 核心设计命题的拆解

确定了"时间回溯"方向后，需要回答以下问题：

| 问题 | 答案方向 |
|------|---------|
| 谁提供回溯的力量？ | 辰星卦师（时间法则）+ 织女星使（命运之线）= 双神合力 |
| 用什么器物触发？ | 需要一件可携带的、有传承背景的、在故事中已经埋了伏笔的器物 |
| 怎么操作？ | 需要场景中的"锚点"，辰生主动与之交互 |
| 回溯的范围是什么？ | 局部时间回溯——辰生的记忆保留，敌人/场景重置到锚点时刻 |
| Boss战怎么处理？ | 沉睡星君的灵魂本能地保护辰生——不需要锚点，星君自己就是锚 |
| 叙事上怎么解释"死过"？ | 说书人框架：死亡 = 被折叠的时间线，说书人用一两句话带过 |

## 四、器物设定：九天星晷

### 4.1 外形描述

巴掌大的青铜圆盘，厚度约半寸。手感温润，揣在怀里时微微发暖。盘面有三层同心环，每层可独立旋转：

- **外层**：十二星次（星纪、玄枵、娵訾、降娄、大梁、实沉、鹑首、鹑火、鹑尾、大火、析木、寿星），以星纹篆字刻成
- **中层**：二十八宿（角亢氐房心尾箕……），以细线星图刻成
- **内层**：十二地支时辰（子丑寅卯辰巳午未申酉戌亥），以天干地支组合标记

三层环的背面刻着四个字，字体不同于任何已知的篆法，更接近星轨的弧线——那是辰星卦师陨落前，用手指直接在青铜上写的：

> **"彰往察来"**
>
> ——《周易·系辞下》

### 4.2 制造者与传承链

```
辰星卦师（陨落前）
  │
  │ 留下设计图 + 时间法则的碎片
  │
  ▼
第一代知残者工匠（约300年前，北廷统治时期）
  │
  │ 根据残图研制第一版星晷，失败数次，最后成功
  │ 第一版被太史阁发现，工匠被处死，星晷被砸毁
  │ 但图纸被同门带走，藏于民间
  │
  ▼
历代知残者工匠（约300年间，代代相传）
  │
  │ 每一代工匠都对星晷进行微调和完善
  │ 同时等待预言中的那个少年
  │
  ▼
玄伯的师父（约60年前）
  │
  │ 最后一代制作者
  │ 在玄伯三十岁那年，将星晷传给他
  │ "等到右手腕有青色星纹的少年。"
  │
  ▼
玄伯（约30年前至今）
  │
  │ 将星晷藏在药铺暗格最深处
  │ 和《星轨残卷》、遗书、荧惑钥匙在一起
  │ 押了三十年的命在这四样东西上
  │
  ▼
辰生（序章结尾）
  │
  │ 在落星村药铺的灰烬中，翻出了暗格
  │ 四样东西：星晷 + 星轨残卷 + 遗书 + 荧惑钥匙
  │ 遗书上只写了去哪里，没有写怎么去
  │ 星晷上刻着怎么做
```

### 4.3 器物与主题的呼应

星晷不是一件"神器"——它是一个**工具**。这是重要的设定选择。

- 它没有自主意志，需要辰生主动操作
- 它的力量不是来自它自己，而是来自十二宫的时间锚点网络——辰星卦师留下的法则
- 它由知残者工匠代代打磨，是**人民群众的集体创造**，不是神明赐予的法宝
- 它被太史阁砸毁过一次，但图纸在民间流传，重新制造——**文明可以被砸毁，但不能被消灭**

这与本作"人民群众是历史的创造者"的核心主题一致。

### 4.4 星晷的获取时机

**序章结尾，落星村药铺灰烬中。**

辰生在灰烬中翻找时，手指触到了一个温热的东西。星晷在灰烬中微微发烫——不是因为火烧，而是因为它感应到了辰生手腕上的星纹。

这是辰生开始"刻星"的第一个锚点。但此时他还不知道这件器物怎么用——他只知道玄伯把它和最重要的东西放在一起。使用方法的揭示放在星纪宫——荧惑星君觉醒后，锻锋看到星晷，认出了辰星卦师的笔迹。

> 锻锋："这个字迹……是辰星的。他留了东西给你？"
> 辰生："我不认识字迹。我只知道——玄伯把它和《星轨残卷》放在一起。"
> 锻锋（拿起星晷，三层环在他手中自动转了一下）："这不是武器。这是……一把钥匙。一把开时间的钥匙。"
> 辰生："怎么用？"
> 锻锋："找个星碑。我教你。"

## 五、设施：星碑

### 5.1 什么是星碑

星碑是十二星君在修建十二宫的同时，沿途设置的**时间信标**。它们的原始功能是天裂之战时的战术支援——星君可以在星碑之间瞬时传送军情。辰星卦师将时间法则注入这些石碑后，它们获得了额外的功能：**记录一个时间切片**。

### 5.2 外观与分布

圆形石台，直径约两步。石台表面光滑如镜，刻着放射状的星轨纹路——从中心的一个圆孔（星晷放置位）向外扩散，像涟漪。

石台边缘有微弱的、几乎看不见的星辉——白天不易察觉，夜晚会看到淡淡的银蓝色光晕。石台上方的天空总是比其他地方更清澈一点，即使穿过树冠也能看到一两颗不该在白天出现的星星。

**星碑的分布原则**：在十二宫的领域内及周边，每一座星碑对应一个"需要被记住的时刻"。典型分布：

| 位置 | 功能 |
|------|------|
| 宫殿入口 | 进入新领域前留下锚点 |
| 关键岔路 | 大型解谜或探索区域的分叉点 |
| Boss门前 | 战斗前的最后准备 |
| 重要遗物旁 | 触发"星忆"之前——因为记忆可能击垮辰生 |
| 野外营地 | 长距离旅途中的安全节点 |

每个主要关卡（一座宫殿+周边区域）约分布 4-7 个星碑。

### 5.3 星碑的叙事意义

星碑不只是存档点。每一座星碑上刻着的星轨纹路，对应着它修建时的天象——也就是说，每一座星碑记录了一个**真实的、发生在数千年前的夜晚**。

当辰生将星晷放入星碑中心时，他不仅是在存自己的档。他是在和数千年前修建这座碑的那个夜晚**对表**。

> *那个夜晚，也许有一颗星星格外亮。那颗星星的名字，也许就是正在这座宫殿深处沉睡的那个星君。几千年前他亲手修了这座碑，几千年后辰生在这座碑前留下锚点，准备去唤醒他。*

这不是游戏机制。这是**时间上的守望**。

## 六、操作机制：刻星（存档）

### 6.1 操作流程

1. 辰生走到星碑旁
2. 按交互键（F）
3. 辰生蹲下，将星晷放在石台中心的圆孔中
4. 三层环在星碑的星辉中自动旋转对齐——对准当前时刻、当前地点的天象
5. 当三层环扣合拢——"咔"的一声轻响
6. 星碑的纹路短暂亮起，然后恢复原样
7. 星晷微微发烫——此刻已被刻入星河
8. 辰生收起星晷

**全程约2-3秒**，不需要打开菜单，不需要选择存档位。

### 6.2 设计选择：为什么是单存档自动覆盖

| 选择 | 理由 |
|------|------|
| **只有一个刻星位**（不允许多存档） | 时间线只有一条。辰星卦师的法则是"彰往察来"——看清过去，面向未来——不是"在多个过去之间挑选"。多存档从世界观角度不成立。 |
| **自动覆盖上次刻星** | 新的锚点覆盖旧的锚点。每一次刻星都是一次"往前走"的承诺。 |
| **刻星不需要消耗** | 这是辰星卦师留给后来者的礼物，不是一种需要付费的服务。 |
| **在星碑处刻星后星晷会发烫** | 物理反馈，让"被记录"变成一种可以感知的体验 |

### 6.3 刻星时保留什么

刻星时刻记录的是辰生**当前的全部状态**：

- 生命值、内力值、状态效果
- 已获得的装备和物品
- 已解锁的技能和等级
- 已触发的剧情进度
- 场景中已改变的要素（打开的门、启动的机关、击败的敌人）

这意味着：如果辰生在刻星后获得了一把剑，然后死亡回溯——那把剑还在。时间回溯不是"读档到过去"，是"带着现在的自己回到过去"。这是辰星卦师的时间法则与物理时间的根本区别——**意识穿越了时间的折叠，但身体和物品需要重新构建。物品随意识保留，但世界状态重置。**

（注：这是一个微妙但重要的设定。详见"星溯"一节。）

### 6.4 UI呈现

刻星时不弹出任何对话框。只有三样东西：

1. **视觉**：星碑纹路亮起→星晷环扣合拢→纹路熄灭
2. **听觉**：三层环依次扣合的三声轻响→最后一声"咔"
3. **触觉**（手柄）：星晷发烫时的微弱震动

刻星成功后，画面右上角短暂闪过星晷的图标（约1秒），然后消失。不需要文字提示"已存档"——玩家会学会信任这个反馈。

## 七、操作机制：星溯（死亡复活）

### 7.1 触发条件

辰生生命值归零时，世界进入"星溯"状态，而非"死亡"状态。

### 7.2 完整演出序列

```
第1秒：画面开始变暗，但不是黑屏——是星辉的银蓝色逐渐渗入边缘
第2秒：辰生胸口的玉佩自主亮起——那是母亲留下的命运之线被牵动了
第3秒：星晷从辰生怀中飞出，悬浮在他身前
第4秒：三层环开始逆向旋转——不是对齐，是"回到对齐之前"
第5秒：辰生的身体被星辉包裹，逐渐透明
第6秒：画面完全变成银蓝色，辰生消失
第7秒：从银蓝色中浮现出最近一次刻星时的场景
第8秒：辰生从星辉中走出，站在星碑旁边，星晷已经回到他手中
```

**全程约5-8秒。** 与常见的"黑屏→读条→重生"不同，星溯是一段微型的叙事演出。玩家在等待的不是加载，而是**在观看辰生被时间拉回原点**。

### 7.3 溯后状态

| 保留的 | 重置的 |
|--------|--------|
| 辰生的记忆（= 玩家的记忆） | 场景回到刻星时刻的状态 |
| 生命值、内力值 = 满状态 | 所有敌人复活/归位 |
| 已获得的装备、物品、技能 | 已触发的机关、已打开的门 |
| 剧情进度 | 场景中的消耗品和可破坏物 |

设计选择的关键在于**保留什么、重置什么**：
- 保留物品和技能，因为辰生的"存在状态"随他一起穿越了时间折叠——他手上还握着那把剑，剑当然也在
- 重置场景和敌人，因为这些"世界状态"绑定的是那个时刻的时空切片
- 重置机关和门，因为"打开的门"是场景状态，而辰生回到的是门还没被打开的时刻

### 7.4 对"保留物品"的叙事解释

这是最容易产生逻辑漏洞的地方：如果物品保留了，那为什么敌人不保留？

答案是：**物品没有自主的存在性，而敌人有。**

一件铁剑——它的存在被时间折叠时，是纯粹的物理对象。它被辰生带在身上时，处于他的时间线内。当回溯发生时，辰生的时间线被拉回锚点——他身上的一切随他一起回去了。

一个敌人——它是一个独立的个体，有自己的时间线。它会停留在它自己的时刻，不会被辰生的回溯牵着走。

这就是辰星卦师时间法则的核心：**你可以折叠自己的因果，但你不能折叠别人的。**

### 7.5 星溯次数

从叙事角度，星溯没有次数限制——母亲留下的命运之线不会"用完"。但从游戏体验角度，可以在难度选项中加入限制：

| 难度 | 星溯限制 |
|------|---------|
| 凡人（普通） | 无限制 |
| 星君（困难） | 每次刻星后仅有3次星溯机会，用尽后需重新刻星 |
| 实事求是（极难） | 每次刻星后仅有1次星溯机会 |

高难度下的限制有世界观解释：每一次星溯都在时间线上留下了一道微小的褶皱。过多的褶皱会吸引虚噬的注意力。辰生可以选择继续——但代价是接下来的区域变得更危险。

## 八、大型战斗的特殊处理：星君的沉睡庇护

### 8.1 问题

Boss战区域通常不会放置星碑——那太不自然了。但如果玩家在Boss战中倒下，要求他们从宫殿入口的星碑重新跑图，这在体验上是不可接受的。

更重要的是：Boss战是"觉醒时刻"的核心。如果把Boss战变成读档→跑图→重试的循环，那情感冲击力就全毁了。

### 8.2 解决方案：星君即锚点

在宫殿核心区域——靠近沉睡星君的地方——不需要星碑。

沉睡中的星君，灵魂被太史阁的封印压制了数百年乃至上千年，意识模糊如梦境。但他/她的灵魂深处，仍然保留着星君的本能：**感知同类的气息。**

辰生走进核心区域时，沉睡星君感受到了他。
不是"知道了他是谁"——意识太模糊了，做不到。
是一种更原始的感知——**星次的共振。** 荧惑的火焰听到荧惑的火焰。岁星的木之息嗅到岁星的木之息。

> *星君不知道你是谁，不知道你为什么来，不知道现在是哪一年。*
> *但你的灵魂泛着他的同胞的气息——辰星卦师、织女星使、荧惑星君……那些他几千年没见面的人，他们的灵魂碎片就在你身上。*
> *他在梦里想问你：他们还好吗？*
> *他做不到。他太虚弱了。*
> *他只能做一件事——用最后一点清醒的本能，在时间线上为你划一道痕。*

这就是Boss战中的自动锚点：不是刻星，是**星君的沉睡庇护**。

### 8.3 机制运作

1. 辰生进入Boss战区域（通常是一个自然边界——如水晶棺室的门槛、祭坛的台阶、火焰核心的熔岩桥）
2. 微弱的星辉在辰生脚下闪烁一次——星君的灵魂感应到了他
3. 此位置自动成为一个"临时锚点"（不需要玩家操作，也不需要星晷）
4. 如果辰生在Boss战中倒下→星溯→回到这个临时锚点→Boss满血复活→玩家可以立即重试
5. Boss战结束后→临时锚点消散→星君不再沉睡，庇护也不需要了

**玩家体验：** Boss战中没有额外的跑图时间。重试是即时的，但每一次重试都有一个情感上的理由——不是"游戏读取了存档"，而是"星君在等你准备好"。

### 8.4 叙事层面的双向救赎

这个设计构成了一个重要的情感闭环。

**表面叙事**：辰生来救星君。他是唤醒者，是施救者。

**暗线叙事**：星君在沉睡中用最后的力量保护辰生。被救者一直在救施救者。

觉醒不是单方面的施舍——它是双向的抵达。辰生走了很远的路来唤醒星君，星君在梦里等了他几千年。

> 锻锋觉醒后，辰生告诉他：我在你门前死了三次。
> 锻锋沉默了一会儿："……三次。我不知道。我在做梦。但我梦见有人在叫我。我叫了三次——'再试一次'——我不知道他有没有听到。"
> 辰生："我听到了。每次倒下的时候，有东西在把我往回拉。"
> 锻锋："那不是我在拉你。那是你在拉你自己。我只是……没放手。"

## 九、叙事框架：说书人如何处理死亡

### 9.1 Loading画面不是Loading画面

每一次从星溯回到刻星点的过渡时间（即实际的loading时间），画面显示的应该是**茶棚中的老年辰生**，而不是进度条。

画面描述：一间简朴的茶棚，木头桌凳，棚顶有补过的痕迹。一束阳光从天窗斜照进来，落在一张旧桌面上。桌上放着一块云板（说书人的醒木）和一杯凉茶。老年辰生坐在桌后——须发已白，脸上有风霜的刻痕，但眼神沉静如水。他拿起云板。

**在桌上敲了一下。**

> "啪。"

然后他开口。台词根据死亡场景变化。

### 9.2 死亡台词库（示例）

台词设计原则：
- **每句不超过20字**——说书人的口头语言，不是书面语
- **不抱怨、不解释**——不是游戏提示，是回望
- **有时点到为止，有时一语双关**——让玩家自己想

| 触发条件 | 说书人台词 |
|---------|-----------|
| 第一次在任何地方倒下 | "那年他十九岁。十九岁的人，摔倒比站稳容易。" |
| 被普通小怪击杀 | "那条路，他走了三次才走通。不急——年轻人有的是时间。" |
| 被环境伤害（陷阱、坠落） | "那年他还不够小心。后来就好了。" |
| 每个宫殿第一次死亡 | "星纪宫——他第一次知道，有些坎不是一次就能翻的。"（宫名随当前宫变化） |
| 被Boss的某个招式秒杀 | "第二次，他终于听清了那一剑破空的声音。躲开了。" |
| 在同一个Boss处多次死亡 | "……那段路确实不好走。我到现在还记得。" |
| 连续死亡3次以上 | "你们别催。我在想——从哪儿开始讲好。" |
| 死亡前打到Boss残血（<10%） | "差一点。就差那么一点。他又站了起来。" |
| 死亡前是满血被秒 | "那一下太快。他没反应过来。不怪他。" |

### 9.3 说书人频率控制

不是每次死亡都要说书人出场。否则会从"有意义的回望"变成"烦人的加载画面"。

| 死亡场景 | 说书人出场 |
|---------|-----------|
| 每个宫殿的第一次死亡 | ✅ 出场 |
| Boss战首次死亡 | ✅ 出场 |
| Boss战第3、6、9次死亡 | ✅ 出场（不连续，隔两次） |
| 连续死亡3次以上的下一次 | ✅ 出场 |
| 普通杂兵战死亡 | ❌ 只显示星溯演出 + 快速加载 |
| 第2-5次普通Boss死亡 | ❌ 同上 |

说书人出场需要节制。它是一粒盐——偶尔尝到，才有味道。

### 9.4 说书人的长篇独白（关键节点）

在某些特殊的、叙事重量极大的死亡之后——如第一次死在宫殿深处、第一次在某个关键抉择后死亡——说书人会有更长的独白。这些独白不仅是Loading画面，本身也是剧情推进的一部分。

示例：辰生第一次在星纪宫倒下后：

> 老年辰生敲了一下云板。
>
> "那年我十九岁。落星村的药铺刚烧成灰，玄伯的血迹还留在我袖子上，干了的血是褐色的——和铁锈一个颜色。"
>
> "我揣着一块玉佩、一页残卷、一把叫不出名字的铁片——还有一个我不认识的女人的银针——进了一座被冰雪和火焰劈成两半的山。"
>
> "我不知道自己是什么。我只知道有人在追我。有人在等我。有人死了——为了让我站在这儿。"
>
> "然后我也倒下了。"
>
> "荧惑的火焰第一次烧到我身上时，我才明白——那些倒下去的人，不是因为不够强。是因为他们前面已经倒了太多人，没有人拉他们一把。"
>
> "但我有人拉。一个在梦里等了我几千年的人——他没松手。"
>
> "我再站起来的时候，火焰换了颜色。"
>
> *云板再敲。*
>
> "各位——这是他第一次站起来。不是最后一次。但第一次——总是最难的。"

**长篇独白只在每座宫殿的第一次死亡时出现。十二座宫殿 = 十二段独白。** 它们是辰生性格弧线的缩影：从少年的迷茫→到战士的觉醒→到说书人的回望。

## 十、情感闭环：这个系统究竟在讲什么

### 10.1 它讲的是"传承"

星晷不是神器，是历代知残者工匠打磨的工具。
星碑不是魔法建筑，是星君在几千年前修建的信标。
星溯不是神力，是母亲在十九年前编进命运线里的一道保险。

**没有一样东西是辰生自己造的。全都是先辈留给他的。** 辰生能一次次站起来，不是因为他是天选之子——而是因为有人在他之前，花了几百年的时间，替他准备了这些。

### 10.2 它讲的是"等待"

星君在梦里等了几千年。玄伯押了三十年。知残者工匠传了十几代。母亲在星空中织了十九年。

辰生能"重来"——是因为太多人在等他。

### 10.3 它讲的是"实事求是"

时间回溯不是奇迹，是工具——就像母亲的银针、锻锋的锤子、石翁的丹炉。它来自辰星卦师的设计图，由凡人工匠制造，由母亲的命运线激活，由星君的庇护辅助。

它不是"神力"——它是**科学**。是宇宙法则的一种应用。是和锻锋的真火、苏羽的感知一样的——**被掩盖的知识，被重新发现。**

## 十一、系统参数汇总

| 参数 | 值 | 设计理由 |
|------|-----|---------|
| 存档方式 | 星碑处交互，单存档位 | 时间线只有一条 |
| 存档耗时 | 2-3秒演出 | 不能打断战斗节奏，但有仪式感 |
| 刻星后保留 | 全部玩家状态 + 物品 + 技能 | 物品随辰生的存在状态穿越时间折叠 |
| 星溯后重置 | 场景状态 + 敌人 + 机关 | 世界绑定该时空切片 |
| 星溯演出时长 | 5-8秒 | 需要叙事感但不能太久 |
| Boss战锚点 | 自动触发，沉睡星君的灵魂庇护 | 不需要跑图，立即重试 |
| 说书人出场率 | 关键死亡（宫殿首次/Boss首次/连续3次+） | 节制才有力量 |
| 高难度星溯限制 | 困难3次/极难1次 | 每次刻星后的可用次数，鼓励谨慎但保留容错 |
| 星晷获取时机 | 序章结尾，落星村灰烬中 | 与《星轨残卷》、遗书、荧惑钥匙一起 |
| 星晷使用教程 | 星纪宫，锻锋教导 | 第一个同伴，第一次"同类"的传承 |

## 十二、与其它系统的接口

| 关联系统 | 接口 |
|---------|------|
| 战斗系统 | 星溯后的满状态复活意味着"资源管理"不是战斗的核心压力——压力在于理解和执行 |
| 装备系统 | 星溯保留物品 → 刻星前获得的装备不会丢失 |
| 角色成长系统 | 星溯保留经验/技能 → 死亡不会"惩罚进度"，只会"要求重新尝试" |
| UI系统 | 刻星图标 + 星溯演出 + 说书人Loading画面 |
| 关卡设计 | 星碑的分布决定了关卡节奏——需要与关卡设计师协同规划 |
| 叙事系统 | 说书人独白 = 叙事的组成部分；沉睡庇护 = 角色关系事件 |
